# ジャンルの下限（「完成している」と感じる最小の機能）

番号は `$game-controls` の references/genres.md（操作の割り当て）と同じ。こちらは**遊びとして欠けてはいけない機能**。
下限は依頼に書かれていなくても作る。下限を超えるもの（ステージ選択・ショップ・育成要素など）は依頼にあるときだけ。

全ジャンル共通: 開始・目的に向けた進行・適切な区切り・失敗からの復帰。短時間ゲームは結果と再挑戦、進行型は進行保存と続きから。スコア/自己ベストは得点を競う作品だけ（`$game-ux` §6）。

| 1 | プラットフォーマー | 走る・可変ジャンプ（押す長さで高さ）・coyote と入力の先行受付・頂点で重力を弱める・着地の煙と音・敵 1〜2 種・ゴールか距離・落ちたら即やり直し | Celeste: 端から離れた後も数フレーム跳べる、壁ジャンプの判定は壁から数 px まで広げる。「難しくても優しく感じる」 |
| 2 | 見下ろしアクション・探索 | 8 方向の移動・壁の滑り（斜めで引っかからない）・敵 2 種（近づく / 撃つ）・体力と無敵時間・拾う物・出口か目標 | 被弾後 0.5〜1 秒の無敵と点滅（自機だけ・透明度で。`$game-ux` §5） |

| 7 | カード | 手札・場・山札の 3 領域・出せるカードの強調・相手（CPU 1 種）・ターンの表示・勝敗と再戦 | 出せない操作は無反応にせず理由を出す |
| 8 | リズム | 判定の窓（Perfect ±40〜50ms・Good ±100〜130ms。初心者向けは広く）・ノーツの先読み表示・判定の文字・コンボ・オフセット調整（設定に 1 つ）・曲の終わり | 判定は音の再生位置（`get_playback_position()` + 最後のミックスからの時間 − 出力の遅れ）で取る。フレーム時刻で取らない |

| — | 対戦（2〜8 人） | 待機室と開始・誰の番 / 誰が勝ったかの明示・切断時の扱い・再戦 | `$game-multiplayer` |

どのジャンルにも当てはまらないときは、共通の下限 + 「入力で目的に向けて進む規則を1つ」を下限にする。
