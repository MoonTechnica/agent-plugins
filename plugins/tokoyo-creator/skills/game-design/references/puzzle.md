# パズルの作り方（規則・問題・並べ方・検証）

パズルの面白さは**「分かった」の瞬間**。難しさは手数や探す量ではなく、気づく必要のある考え方の数で決まる。
操作の割り当ては `$game-controls` references/genres.md §6、下限は [genres-minimum.md](genres-minimum.md) #6。

## 1. 規則を作る

- 規則（mechanic）は**少なく、組み合わせで深く**。1 本のパズルゲームに規則 3〜6 個（Baba Is You・Stephen's Sausage Roll・Snakebird の考え方）。
- 規則ごとに「何ができて・何ができないか」を 1 文で言える。例外のある規則を作らない（例外は別の規則として出す）。
- 見た目で規則が分かる: 押せる物・動かない物・危ない物を形と色で分ける（色だけに頼らない。`$game-ux` §4）。
- 規則は `rules.gd` に書き（`$game-design` §3）、盤面は `tuning.gd` か `godot/levels/*.json` のデータにする。

## 2. 1 問を作る（気づきから逆算する）

1. **気づかせたいこと**を 1 文で決める（「箱は押せるが引けない。だから先に回り込む」）。
2. その気づきが**無いと解けない最小の盤面**を作る。関係ない物は置かない（気が散る・別解が増える）。
3. 「やりがちな間違い」を 1 つ用意する（すぐ試したくなる手が、1 手先で詰む）。間違いから学べる配置にする。
4. 解いて、**別解**（狙っていない近道）が無いか確かめる（§4）。別解で気づきを飛ばせるなら、盤面を削る・物を足す。
5. 盤面を小さくできないか考える。同じ気づきなら小さい方が良い問題。

## 3. 並べ方（導入 → 発展 → ひねり）

| 段 | 内容 | 数の目安 |
|---|---|---|
| 導入 | 新しい規則を 1 つ、失敗しにくい盤面で見せる | 1〜2 問 |
| 発展 | その規則だけで、気づきを 1 つずつ足す | 2〜4 問 |
| 組み合わせ | 前の規則と組む | 2〜4 問 |
| ひねり | 規則の意外な使い方（今まで障害だった物を道具に） | 1〜2 問 |
| 休み | 簡単な問題・ご褒美の問題 | 山の後に 1 問 |

- 難しさは鋸の歯（`$game-balance` §3）。山の後に簡単な問題を置く。
- 詰まったときに**別の問題へ進める**（区切りの中で 2〜3 問を並行して選べる）。1 問で全体が止まらないように。
- 落ち物・マッチ 3 のように盤面が乱数で決まる遊びは、乱数の偏りを抑える（袋。`$game-balance` §6）。

## 4. 解けることを機械で確かめる

- **小さな盤面は総当たり（幅優先探索）**で最短手数と解の数を数える headless スクリプトを `scripts/` に置く
  （`godot --headless --path godot --script ../scripts/solve.gd`。`$game-playtest` §2 と同じ置き方）。状態を文字列にして訪問済みを持つ。
- 確かめること: 解ける・最短手数が狙いどおり・狙っていない短い解が無い・詰み（どの手も先が無い）を検出できる。
- 大きな盤面（総当たりが終わらない）は、作者の解を手順として保存し、その手順で解けることだけ確かめる。
- 生成するパズル（毎回違う盤面）は、生成した盤面を必ず解いてから出す。解けない盤面・簡単すぎる盤面は捨てる。

## 5. やり直しと手助け

- **1 手戻す（undo）**と最初からを必ず置く。undo は何回でも、0.1 秒以内に反応。キーは `$game-controls` の割り当て。
- 詰み（手が無い）を検出したら、穏やかに知らせて undo を勧める。黙って止まらない。
- ヒントは段階で: ①どこを見るか → ②何を使うか → ③最初の 1 手。全部の答えを一度に出さない。ヒントを使っても記録は残す
  （遊びを閉ざさない。`$game-ux` references/accessibility.md）。
- 解けた瞬間は 0.3〜1 秒の気持ちよい演出（盤面が光る・音が鳴る）、すぐ次へ。手数とベストを見せる。

## 6. 検査

- [ ] 規則ごとに 1 文で説明でき、見た目で区別できる
- [ ] 各問題の「気づかせたいこと」を書いた（`design/puzzles.md` か levels のデータの注記）
- [ ] 総当たりか作者の手順で、全問が解けることを確かめた。狙っていない短い解が無い
- [ ] undo・最初から・詰みの検出がある
- [ ] 並びに導入・発展・ひねり・休みがある。詰まっても別の問題へ進める
