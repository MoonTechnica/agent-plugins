# 数値の式（目標の時間から逆算する）

ここの式は出発点。決めた値は `godot/tuning.gd` に置き、遊んだ感覚と `assets/balance_sim.gd` の分布で直す。

## 1. 動き

移動・ジャンプの式は `$game-character-camera` §1（高さと滞空時間から重力と初速を出す）。

## 2. 成長（経験値・レベル）

`need(L)` = レベル L から L+1 に必要な経験値。**先に「L→L+1 に何秒かけたいか」の表を作り**、
1 秒あたりの稼ぎ（敵 1 体の経験値 × 1 分に倒す数 / 60）を掛けて need を出す。式はその表に近いものを選ぶ。

| 形 | 式 | 向いている遊び |
|---|---|---|
| べき乗 | `need(L) = base * pow(L, p)`（p = 1.5〜2.5） | RPG・アクション RPG。後半ほど緩やかに長くなる |
| 等比 | `need(L) = base * pow(r, L - 1)`（r = 1.1〜1.25） | 敵の経験値も等比で増える遊び。r が大きいと急に壁になる |
| 1 回の挑戦の中（サバイバー） | 最初の 3〜5 レベルは 10〜20 秒ごと、その後 30〜60 秒ごと | 1 回 10〜30 分の挑戦 |

- 敵の経験値も成長させるなら、**稼ぎの伸び ÷ need の伸び**が 1 より少し小さい（だんだん長くなる）ことを表で確かめる。
- 最大レベルを決める。決めないと、表の先で数値が壊れる。

## 3. 経済

- **稼ぎ（1 分）**と**価格**を同じ表に並べ、「その時点の稼ぎの何秒分か」を列にする。序盤 20〜60 秒分、中盤 1〜3 分分、
  目玉の買い物 5〜10 分分（小さい作品の目安）。
- 放置・インクリメンタル: `cost(n) = c0 * pow(g, n)`（g = 1.07〜1.15。n は同じ物を買った回数）。
  効果は `n * e` か `e * pow(1.05, n)` 程度にし、費用の伸びが効果の伸びより速いことで次の種類へ目を向けさせる。
  新しい種類の解放は「前の種類の費用の伸びが目立ってきた頃」に置く。
- インフレ対策: 中盤以降の報酬を等比で増やすなら、価格も同じ比で上げる。出る道（消耗品・修理・見た目）を増やす。

## 4. 戦い

| 求めたいもの | 式 |
|---|---|
| 敵の体力（倒すまで n 回） | `hp = damage * n`（会心・弱点で 1 段減る程度に、n は 0.5 の余裕を持たせる） |
| 戦いの長さ | `秒 ≒ hp / (damage * 当たる回数/秒 * 命中率)`。ボスは命中率を 0.4〜0.6 で見積もる（避けている時間がある） |
| 防御（割合） | `taken = attack * 100 / (100 + defense)`。defense 100 で半分 |
| 会心 | 確率 5〜15%・倍率 1.5〜2.0。期待値の伸びは `1 + rate * (mult - 1)` |
| 1 秒あたりの効果（DPS） | `damage * 発射数/秒 * 命中率 * 会心の期待値`。強化の候補はこれと費用で比べる |

## 5. 乱数

| 道具 | 書き方（GDScript の考え方） |
|---|---|
| 袋 | 候補を配列に入れて `shuffle()`（state の seed の RNG で並べ替える）、空になったら作り直す |
| 天井 | 外れた回数を state に持ち、`misses >= N` なら確定、当たったら 0 に戻す |
| 積み上げ | `chance = base + misses * step`、当たったら misses を 0 に。期待値が base より上がるので base を下げて合わせる |
| 重み付き | 重みの合計を 1 回取り、`rng.randf() * total` を累積和で探す。重みは `tuning.gd` の表 |

## 6. 難しさの曲線（エンドレス・波）

- 速さ: `speed(t) = min(max_speed, v0 + a * t)`、速いほど加速を緩める（`a` を段で下げる。Canabalt 型）。
- 波 k の脅威: `threat(k) = t0 + step * k` を基本にし、5 波ごとに山（×1.3〜1.5）と次の波を休み（×0.7）にする。
  脅威は「敵の役割ごとの重み × 数」で数え、数値だけで上げない（新しい役割を加える波を決める）。
- 出現の最低間隔: 避けられない配置を作らない（「次の障害までの時間 ≥ 反応 0.25 秒 + 動作に要る時間」）。
