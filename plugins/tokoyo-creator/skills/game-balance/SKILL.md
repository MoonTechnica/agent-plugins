# 数値で整える（難しさ・成長・経済）

数値は**狙う感じ（`design/brief.md`）を時間の上に並べる道具**。「何秒で何が起き、何回で倒れ、何分で次が手に入るか」を
先に決め、式はそれを満たすように選ぶ。式から始めない。

- 数値は全部 `godot/tuning.gd`（`$game-design` §3）。表にできるもの（波・出現・強化・レベル）は `const` の配列か Dictionary にする。
- 決めた狙いと根拠は `design/balance.md` に短く残す（「雑魚は 2 回で倒れる。最初の 30 秒で強化を 2 回買える」）。
  次のターンで数値を直す人（自分）が、何を守るべきか分かるようにする。
- 式の一覧は [references/formulas.md](references/formulas.md)。

## 1. 先に時間の目標を決める

| 決めること | 例 | 置き場所 |
|---|---|---|
| 1 回の長さ | 初めての人は 30〜60 秒で負ける、慣れた人は 2〜3 分続く | brief「1 回の長さ」 |
| 最初の成功 | 5〜15 秒で核の動詞が 1 回成功する | `$game-design` references/fun.md §2 |
| 最初の報酬・強化 | 30 秒以内に 1〜2 回 | balance.md |
| 区切りの長さ | 波 10〜60 秒・部屋 20〜60 秒・面 1〜3 分 | tuning の表 |
| 次の目標が見える間隔 | 小さい作品: 1〜3 分ごと。RPG: 次の目標が数分以内に見える（`$game-design` references/exemplars.md） | balance.md |
| 全体 | アーケード: 区切りなし（腕前で伸びる）。面クリア型: 全体 10〜40 分 | brief |

## 2. 戦いの数値は「倒すまでの回数」と「耐えられる回数」で決める

攻撃力・体力を個別に決めず、**比**で決める（`$game-combat`）。

| 対象 | 倒すまでの回数（基本攻撃） | プレイヤーが耐えられる被弾 |
|---|---|---|
| 雑魚 | 1〜3 回 | — |
| 強い敵（エリート） | 5〜10 回 | — |
| ミニボス / ボス / 最終ボス | 戦いの長さ 30〜60 秒 / 1.5〜3 分 / 3〜5 分 になる回数 | — |
| プレイヤー | — | 雑魚の攻撃 3〜6 回、ボスの大技 2〜3 回 |

- 強化で攻撃力が上がっても、**回数の段**（3 回 → 2 回 → 1 回）が変わったときにだけ手応えが変わる。上げ幅は段をまたぐように選ぶ。
- 防御の式は引き算（攻撃 − 防御）より割合（`攻撃 × 100 / (100 + 防御)`）を既定にする。引き算は 0 ダメージの壁ができやすい。
- 終盤の敵の体力をただ倍々にしない（スポンジ化）。新しい役割・組み合わせで難しくする（`$game-design` references/fun.md §1）。

## 3. 難しさの曲線

- **鋸の歯**: 区切りの中で上がり、区切りの頭で少し下がる。山（強敵・ボス・大群）の後に休み。直線で上げない。
- **上げる道具の優先順**: 新しい敵の役割・仕掛けを足す > 組み合わせる > 配置・タイミングを厳しくする > 数を増やす > 数値（速さ・体力）を上げる。
- エンドレスは速さ・密度に上限を作る（Canabalt は 800px/s で頭打ち。`$game-design` references/exemplars.md）。上限の先は腕前の勝負。
- **難易度の選択**は、作品が挑戦（Challenge）を狙うなら「やさしい」を 1 つ足すか、補助（無敵・遅く・猶予を広く）の設定にする
  （`$game-ux` references/accessibility.md）。補助を選んでも記録やランキングの扱いだけ変え、遊びは閉ざさない。
- 動的な難易度調整（負け続けると少し楽に）は**見えない範囲で小さく**（出現を 10〜20% 減らす・回復を出しやすく）。
  上手い人を罰する調整（勝っている人を遅くする）は対戦の追い上げ（パーティー）以外で使わない。

## 4. シミュレーションで分布を見る（`assets/balance_sim.gd`）

`rules.gd` がある遊び（`$game-design` §3）は、数値を直したら**腕前の違う bot に多数の seed で遊ばせ**、
終わるまでの秒・点数の分布と、何秒台で終わったか（難しさの山）を見る。

1. `<kit>/skills/game-balance/assets/balance_sim.gd` を `scripts/balance_sim.gd` にコピーする（`godot/` の外。本番の pack に入れない）。
2. `_policies()` を、このゲームの入力の形に合わせて 2〜3 人分書く（初めての人 = でたらめ・遅い反応、慣れた人 = 状態を見て判断、上手い人 = ほぼ最善で少し遅れる）。
   完璧な bot は作らない（反応の遅れ 0.2〜0.4 秒・ときどき間違える）。
3. `_targets()` に §1 の時間の目標を書く（`min_p10` / `max_p50` / `min_unfinished` / `max_unfinished`）。
4. `godot --headless --path godot --script ../scripts/balance_sim.gd` を回す。✗ が出たら `tuning.gd` だけを直して回し直す。
   ✓ も ✗ も出ないのは失敗（スクリプトを読めていない）。
5. 結果（p10 / p50 / p90 と終わった時刻の山）を `design/balance.md` に写す。

- 読み方: 「終わった時刻」が 1 つの区間に集中していたら、その時刻に**壁**がある（急に難しくなる）。狙いの山（ボス・大群）以外の壁は直す。
  初めての人の p10 が数秒なら導入が厳しすぎる。上手い人の「終わらない」が多すぎるなら上限が甘い。
- 進行型（RPG・放置・経営）は `rules.gd` に `is_over` が無いので、このスクリプトは使わない。代わりに
  「経過時間ごとの所持金・レベル・強さ」を 1 分刻みで表にする小さな headless スクリプトを書き、§5 の目標と比べる。
- シミュレーションは遊んだ感覚の代わりではない。壊れた数値を早く見つける道具で、手触り（操作の気持ちよさ）は測れない。

## 5. 成長と経済

- **成長は「次まで」の時間で決める**。レベル 1→2 は 30〜60 秒、その後は少しずつ長く。式は [references/formulas.md](references/formulas.md) §2。
- **経済は「入る道」と「出る道」を両方作る**。入る道（敵・宝・時間）だけだと所持金が膨らみ、買う物が無くなる。
  出る道: 強化・消耗品・修理・入場料・見た目。中盤以降は所持金の上がり方と価格の上がり方を揃える。
- 価格は手に入る速さの何秒分かで決める（「この強化は今の稼ぎで 45 秒分」）。最初の 30 秒で 2 回買えるのが放置・強化型の目安。
- 放置・インクリメンタルの費用は等比（1 回ごとに 1.07〜1.15 倍）、効果は等差か緩い等比にして、**新しい種類の解放**で曲線を一段上げる。
- 恒久の強化（ローグライトのメタ進行）は、1 回の挑戦で少なくとも 1 つ何かが進む量にする（負けが前進になる）。
  ただし恒久強化だけで勝てる設計にしない（腕前の比重を残す）。

## 6. 乱数

- **乱数は「驚き」に使い、「理不尽」に使わない**。結果が悪くても、プレイヤーが次の判断で取り返せる余地を残す。
- 偏りを抑える道具: **袋**（全部を 1 回ずつ引いてから引き直す。Tetris の 7-bag）、**天井**（N 回外れたら確定）、
  **確率の積み上げ**（外れるたびに少し上がる）。レアドロップ・会心・宝箱には天井を付ける。
- 表示する確率は本当の確率にする。「90% 命中」が連続で外れると人は理不尽に感じるので、命中率の表示が重要な遊び
  （タクティクス）は、外れの連続を抑える仕組みを入れる。
- 乱数は state に持たせた seed から引く（`$game-design` §3）。同じ seed で同じ結果になると、§4 のシミュレーションと再現ができる。

## 7. 選択肢の価値を比べる

- 強化・カード・武器の候補は**同じ物差し**で比べる: 1 秒あたりの効果（DPS・稼ぎ）、生存時間、範囲、操作の手間。
  表にして、どれも「ある状況で一番」になっているか見る。常に一番の物は弱め、常に最下位の物は役割を足す。
- 「全部 +10%」の強化だけにしない（`$game-design` references/fun.md §4 #14）。性質が変わる強化（貫通・分裂・反射）と、
  組み合わせで掛け算になる強化を混ぜる。取った瞬間に見た目が変わる物を優先する。

- [ ] 難しさの曲線に山と休みがある。数値だけで難しくしていない
- [ ] `rules.gd` がある遊びは `balance_sim.gd` を回し、狙い以外の壁が無い
- [ ] 経済に出る道がある。最初の報酬・強化が 30 秒以内
- [ ] レア・会心・宝箱の乱数に偏りの抑制がある
