# ジャンル別の操作の割り当て

遊びの説明に合うジャンルの節だけ読めばよい。どれにも当てはまらないときは、いちばん近いものを土台にし、
SKILL.md §2 の決まりごとで埋める。Godot での部品の使い方（InputMap・移動スティック・`TouchScreenButton`）は
[godot-input.md](godot-input.md)。

どのジャンルにも共通:

- **ポーズ**: PC は `Escape` / `P`、スマホは**右上のポーズボタン**（44px 以上。メニュー類は画面の上に置く）、ゲームパッドは Start
- **決定・開始・もう一度**: Space / Enter / クリック / タップ / ゲームパッドの下のボタン。再挑戦がある作品は **R** でリトライ。RPG の進行を無確認で消さない
- **メニュー**（タイトル・ポーズ・リザルト）は Control のフォーカスで上下に動かして端でループ、下のボタンで決定、右のボタンで戻る
- **操作説明**はタイトル・ポーズの「操作方法」画面に入力方法ごとに置き、プレイ中は初めての瞬間に一言だけ示す（SKILL.md §4）
- 各節の「ゲームパッド」行の対応度（`full` / `partial`）は SKILL.md §7 の基準で `manifest.json` の `gamepad` に書く
- 表の「InputMap」はアクション名と、そこへ登録するキー / パッドの例。スマホは「スマホ」列の部品を置く

## 1. 横スクロール・プラットフォーマー（ジャンプして進む）

| InputMap | スマホ |
|---|---|
| `move_left` / `move_right`（← → / A D・十字キー・左スティック）、`jump`（Space / ↑ / W / Z・下）、`attack`（X / J・左） | 左下に移動スティック（**x だけ使う**）、右下にジャンプ（大）+ 攻撃 |

- 上キーがジャンプなので、移動の上下は使わない（`get_move()` の y を捨てる。斜めに倒しても左右の速さが落ちないよう、
  x を少し強めてよい。godot-input.md §1）。
- **押している長さでジャンプの高さを変える**（`is_action_just_released(&"jump")` で上昇を打ち切る）。
- 足場から落ちた直後の 0.1 秒はまだジャンプできる、着地の 0.1 秒前の入力を覚えておく（タッチの遅れも吸収する）。
- **ゲームパッド**: 左スティック / 十字キーで移動、下でジャンプ、左で攻撃。**`full`**
- **手応えの定番**（`$game-ux` §2）: 着地の小さな煙と潰れ（squash）、ジャンプの伸び、敵を踏んだらヒットストップ 50ms。

## 2. 見下ろしアクション・探索（上下左右に歩く）

| InputMap | スマホ |
|---|---|
| `move_*`（WASD / 矢印・左スティック）、`action`（Space / J / Enter・下）、`dash`（Shift / K・左） | 左下に移動スティック、右下にアクション 1〜2 個 |

- `get_move()` はアナログ（長さ 0〜1）。速度にそのまま掛けると、スマホで「少しだけ動かす」ができる。
- `CharacterBody2D` は `motion_mode = MOTION_MODE_FLOATING`（壁で引っかからない）。
- キャラクターの向きは最後に 0 でなかった移動の向きにする（止まっても向きが戻らない）。
- **ゲームパッド**: 左スティック / 十字キーで歩く（アナログ）、下で主アクション、左でダッシュ。**`full`**
- **手応えの定番**（`$game-ux` §2）: 攻撃が当たった敵の白い点滅とノックバック、倒したら破片、拾った物は浮かぶ数字。

## 3. シューティング

### 3a. 縦・横スクロールの弾幕（自機を動かして避ける）

| InputMap | スマホ |
|---|---|
| `move_*`（WASD / 矢印・左スティック）、`shot`（Z / Space、押しっぱなし。自動でもよい）、`bomb`（X・下） | **指をずらした分だけ自機が動く相対ドラッグ**（指の下に自機を置かない）。ショットは自動、ボムはボタン |

- 相対ドラッグは `InputEventScreenDrag.relative` を自機の位置に足す（index で 1 本の指を追う）。キーとパッドは `move_*`。
- **スマホではショットを自動にする**（押し続けとドラッグの同時操作をさせない）。PC も自動でよい。
- 自機の当たり判定は見た目よりずっと小さく、点で示す（`$game-design` references/exemplars.md）。

### 3b. ツインスティック（移動と照準が別）

| InputMap | スマホ |
|---|---|
| `move_*`（WASD・左スティック）、`aim_*`（右スティック）、射撃（左クリック・押している間か自動） | 左下に移動スティック、**照準は一番近い敵に自動で合わせ、射撃も自動** |

- スマホで 2 本のスティックを同時に操作させない。「動いている間は撃たない・止まると近くの敵を撃つ」も定番（Archero）。
- マウスの照準は `get_global_mouse_position()` から自機への向き。
- **ゲームパッド**: 3a は左スティックで自機、ショットは自動、ボムは下。3b は左スティックで移動、右スティックで照準、照準が 0 なら近い敵に自動。**`full`**
- **手応えの定番**（`$game-ux` §2）: 発射のたびにカメラを狙いと逆に数 px 蹴る、当たった敵の白い点滅、撃破の破片と小さな揺れ。自機の被弾はヒットストップ + 揺れ。

## 4. エンドレスランナー

| InputMap | スマホ |
|---|---|
| `jump`（Space / ↑ / W・下）、`slide`（↓ / S）、`lane_left` / `lane_right`（← → / A D・十字キー） | **スワイプ**（上 = ジャンプ、下 = スライド、左右 = レーン）。タップでもジャンプ |

- スワイプは `_unhandled_input` の `InputEventScreenTouch` の押した位置と離した位置の差で判定する（短い距離はタップ）。
  画面の操作部は出さない。スワイプは画面の中央寄りで始めるよう、最初の 1 手で示す。
- 入力は**キューに積んで次の判定で使う**（先行入力。着地の直前のスワイプを捨てない）。
- **ゲームパッド**: 十字キー / 左スティックの上下左右をスワイプと同じキューに積む。下のボタンでもジャンプ。**`full`**
- **手応えの定番**（`$game-ux` §2）: 障害物に当たった瞬間のヒットストップと揺れ、コインは浮かぶ「+1」、スライドの土煙。

## 5. ワンボタン（フラッピー系・タイミング 1 つ）

| InputMap | スマホ |
|---|---|
| `flap`（Space / ↑ / クリック・下） | 画面のどこでもタップ |

- タップは `_unhandled_input` の `InputEventScreenTouch`（押した瞬間）で即座に反応させる。まねのマウス
  （`DEVICE_ID_EMULATION`）を数えない。開始画面を抜ける最初の 1 回は開始の決定として扱い、羽ばたきにしない。
- **ゲームパッド**: 下のボタン。**`full`**
- **手応えの定番**（`$game-ux` §2）: 押した瞬間の伸びと短い音、通過ごとに数字が跳ねる、ぶつかったらヒットストップ。

## 6. パズル・盤面（オセロ、三目並べ、2048、マッチ 3、ナンプレ、落ち物）

| 種類 | PC | スマホ |
|---|---|---|
| マスを選ぶ（オセロ・三目並べ・ナンプレ） | クリック。矢印でカーソル + Enter / Space でも | マスを直接タップ |
| 入れ替え（マッチ 3） | クリック → 隣をクリック、またはドラッグ | タップ → 隣をタップ、またはスワイプ（**両方受け付ける**） |
| 全体を動かす（2048） | 矢印 / WASD | スワイプ |
| 落ち物（テトリス系） | ← → 移動、↑ / X 回転、↓ ソフトドロップ、Space ハードドロップ | 下に ◀ ▶ と回転・落下の `TouchScreenButton`、盤面のタップで回転も可 |

- **操作部は出さない**（落ち物を除く）。マスは 44px 以上になるよう盤面の大きさを決める（`$game-screen-layout`）。
- **ドラッグでしかできない操作を作らない**。ドラッグの代わりに「タップ → タップ」でも同じことができるようにする。
- 選んでいるマスは枠や色で示す（キーボードのカーソルとタッチの選択を同じ見た目にする）。
- マスの判定はタッチ / クリックの位置を盤面の座標へ変換して行う（Camera2D があるなら `get_canvas_transform()` の逆で）。
- **ゲームパッド**: **十字キー / 左スティックでマスのカーソルを動かし、下で決定、右で選択を取り消す**。マッチ 3 は「決定 → 隣を選んで決定」の
  2 段階。2048 はスワイプと同じ 1 手に。落ち物は十字キーの左右で移動、下で回転、左でハードドロップ。**格子は端でループしない**。**`full`**
- **手応えの定番**（`$game-ux` §2）: 消えるマスの pop（拡大して消える）とパーティクル、連鎖ごとに音程を上げる、置けない所は小さく震える。

## 7. カードゲーム

| PC | スマホ |
|---|---|
| クリックで選ぶ → 「出す」ボタンかもう一度クリック。ドラッグで場へ出すのも可。数字キー 1〜9 で手札を選べると便利 | タップで選ぶ（持ち上げて拡大表示）→ 「出す」ボタン。ドラッグは補助 |

- カードの詳細を hover で出さない（スマホに無い）。選んだカードを大きく見せる。
- 「出す」「パス」などの決定はカードとは別の大きなボタン（44px 以上）にし、画面の下部に置く。
- 手札が多いときはカードを重ねて並べ、触れる幅（見えている部分）を 44px 以上に保つ。
- **ゲームパッド**: 左右で手札のカーソル、下で選ぶ / 出す、右で戻す、上下で場と手札を移る。選んでいるカードは持ち上げて拡大（タッチの選択と
  同じ見た目）。「出す」「パス」のボタンにもカーソルが乗る（メニューと同じ線形。端でループ）。**`full`**
- **手応えの定番**（`$game-ux` §2）: 出したカードの着地の跳ね、得点の数字が増えていく演出、出せないカードは灰色 + 鍵か「出せません」。

## 8. リズム・音ゲー

| InputMap | スマホ |
|---|---|
| レーンごとのアクション（4 レーンなら D F J K、または ← ↓ ↑ →・十字キー）、Space | **画面下部のレーン全体がタップの範囲**（レーンの幅いっぱい） |

- レーンのタップは `InputEventScreenTouch` を index ごとに扱う（複数の指）。レーンの判定は x 座標で。
- 時間は音の再生位置を基準にする: `player.get_playback_position() + AudioServer.get_time_since_last_mix() - AudioServer.get_output_latency()`
  （前フレームより戻った値は捨てる）。フレームの経過時間で数えるとずれる。
- 判定の幅を広めにし（タッチは入力の遅れが大きい）、設定にタイミング調整（オフセット）を 1 つ置く。開始は最初の操作（音の解禁）の後。
- **ゲームパッド**: レーンにボタンを割り当てる（4 レーンなら十字キーの 左・下・上・右、または 左・下・上・右のボタン）。**`full`**（レーンが 6 を超えるなら `partial`）
- **手応えの定番**（`$game-ux` §2）: 判定文字（PERFECT / GOOD / MISS）の跳ね、押したレーンの光、コンボ数の拡大。判定は色だけでなく文字で。

## 9. レース・乗り物

| InputMap | スマホ |
|---|---|
| `steer_left` / `steer_right`（← → / A D・左スティック）、`brake`（↓ / S・下）、`boost`（Space・左）。アクセルは自動 | 左下に移動スティック（**x だけ使う**）、右下にブレーキ・ブースト |

- ステアとアクセルの同時押しをさせない（自動アクセル）。傾きでのステアは `TokoyoDevice` で任意に足してよいが、スティックでも遊べるようにする。
- **ゲームパッド**: 左スティック / 十字キーの左右でステア、下でブレーキ、左でブースト。ブレーキをトリガーに置くなら `JOY_AXIS_TRIGGER_LEFT` を登録。**`full`**
- **手応えの定番**（`$game-ux` §2）: 壁やほかの車に当たったときの火花と小さな揺れ、ブーストの速度線（`effects` に掛ける）。

## 10. 3D 三人称・一人称（歩き回る）

| InputMap | スマホ |
|---|---|
| `move_*`（WASD・左スティック）、`look_*`（右スティック）、`jump`（Space・下）、`action`（E / F / クリック・左）。カメラはマウスの**ドラッグ** | 左下に移動スティック、**右半分をドラッグしてカメラ**、右下にジャンプ・アクション |

- カメラのドラッグは、スティックの始動範囲の外で始まったタッチを index で追い、`InputEventScreenDrag.screen_relative` で回す
  （解像度で感度が変わらない）。PC はマウスのドラッグ（`InputEventMouseMotion.screen_relative`。ボタンを押している間）。マウス固定は使わない（SKILL.md §2）。
- 移動の向きはカメラの向き基準にする（スティックの上 = カメラの前）。
- 感度は控えめに（1px で 0.3〜0.5 度）。上下の角度は制限する。
- **ゲームパッド**: 左スティックで移動、右スティックでカメラ（1 フレーム 2〜3 度を上限に。上下は制限）、下でジャンプ、左でアクション。**`full`**
- **手応えの定番**（`$game-ux` §2）: 攻撃が当たったらヒットストップ 50〜80ms と当たった物の点滅。カメラは揺らしすぎない（一人称は揺らさない）。

## 11. ひっぱり・投げる・打つ（アングリーバード、ゴルフ、ビリヤード）

| PC | スマホ |
|---|---|
| ドラッグして離す（マウス）。矢印で角度・Space を押す長さで強さ、でも操作できると親切 | ドラッグして離す |

- タッチとマウスは同じ流れで書く（押す → 動かして狙う → 離して発射）。タッチは index、マウスはまねのマウスを除外して二重に数えない。
  タッチが `canceled` で終わったら撃たずに取り消す。
- 指の下に予測線が隠れるので、狙いの線は指と反対側に伸ばす。
- **ゲームパッド**: **左スティックで狙う向き、下のボタンを押している長さで強さ**（離して発射。ゲージを出す）。これがドラッグの代替になる。付けられないなら **`partial`**
- **手応えの定番**（`$game-ux` §2）: 引っぱる長さに合わせて予測線とゲージが伸びる、離した瞬間の伸び、当たった物の揺れと破片。

## 12. ターン制・ストラテジー・シミュレーション・経営

| PC | スマホ |
|---|---|
| クリックで選ぶ → クリックで指示、右クリック / Escape で取り消し（右クリックだけに頼らない）、ホイールで拡大、ドラッグで移動 | タップで選ぶ → タップで指示、「取り消し」ボタン、1 本指ドラッグで移動、**拡大縮小はボタン（＋ −）**（ピンチは付けてもよいが必須にしない） |

- 取り消し・ターン終了などのボタンは画面の端に固定し、44px 以上にする。
- 選んでいるものと、選べる場所（移動できるマス等）をはっきり示す。
- **ゲームパッド**: 十字キー / 左スティックでマスや駒のカーソル、下で選ぶ / 指示、右で取り消し、Start でメニュー（ターン終了はメニューか上のボタン）。
  拡大縮小は L1 / R1。マップの移動はカーソルが端に来たら追従。**`full`**（自由な位置の指定が中心なら `partial`）
- **手応えの定番**（`$game-ux` §2）: 選んだ駒の浮き上がり、移動できるマスの表示（色 + 印）、攻撃の結果は数字を浮かべる。

## 13. クリッカー・放置

| PC | スマホ |
|---|---|
| クリック（Space でも可） | タップ |

- 連打を強いない。押し続けで連続実行、または自動化の強化を用意する。
- 数字は大きく、増えたことが分かる演出（ポップ）を付ける。
- **ゲームパッド**: 下のボタンで押す（押し続けで連続実行）。強化の一覧はカーソル + 下で買う。**`full`**
- **手応えの定番**（`$game-ux` §2）: 押すたびに押した物が縮んで戻る、数字のポップ、大きな節目（桁が上がる）で派手な演出。

## 14. 格闘・対戦アクション

| InputMap | スマホ |
|---|---|
| `move_*`（WASD / 矢印・左スティック）、`light`（J / Z・下）、`heavy`（K / X・左）、`special`（L / C・右） | 左下に移動スティック、右下に 2〜3 ボタン（弱・強・必殺） |

- コマンド入力（↓↘→ + 攻撃）を必須にしない。必殺技は専用ボタン 1 つで出せるようにする。
- 押し分けが大事なので `TouchScreenButton.passby_press` は false にする。
- オンライン対戦は `$game-multiplayer` を先に読む（入力は `TokoyoSpace` でサーバーへ送る）。
- **ゲームパッド**: 左スティック / 十字キーで移動、下 = 弱、左 = 強、右 = 必殺。**`full`**
- **手応えの定番**（`$game-ux` §2）: 当たりはヒットストップ 4〜6 フレーム（66〜100ms）とノックバック、ガードは火花の色と音を変える。

## 15. RPG（会話・所持品・クエスト・地域探索）

- 探索は WASD / 矢印・左下の移動スティック・ゲームパッドの左スティック。主アクションは調べる / 話す / 決定へ統一する。
- 会話 / 所持品 / 設定を開くときは探索の入力を離し（`stick.set_shown(false)`）、移動へ同じ入力を流さない。メニューは Control のフォーカスで選び、タップでも同じ状態遷移を使う。
- Escape / 画面の戻る / ゲームパッドの右で 1 段閉じる。会話の決定を押しっぱなしで連続消費せず、目的と次の操作を表示する。
- 主操作部は最大 4 ボタン。全コマンドを常時並べず、会話 / 戦闘 / 探索の状態に応じた割り当てを示す。
- ロード / 保存失敗のメニューでも未保存状態と再試行を操作できるようにする。新規開始は保存済み進行を上書きする前に確認する。
- データと保存の詳細は `$game-design` の `references/rpg.md`。性能設定を入力方式だけで決めない。
