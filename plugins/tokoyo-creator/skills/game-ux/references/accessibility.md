# 遊べる人を増やす（アクセシビリティの設定と作り方）

SKILL.md の §3（読める）・§4（色だけ・音だけに頼らない）・§5（動きの安全）は全作品の下限。ここは**その上に足す設定と作り方**で、
遊びに合うものを選んで入れる。設定は SKILL.md §7 と同じ設定画面・同じ Store の `settings` に足す（フィールドを足して版を上げる）。

## 1. どの作品にも入れやすい（費用が小さい）

| 項目 | 作り方 |
|---|---|
| 文字の大きさ | 設定に「文字: 標準 / 大」。Theme の `default_font_size` を 1.25 倍に。HUD の配置が崩れないか縦横で確かめる（`$game-screen-layout`） |
| ボタンを押し続ける操作 → 切り替え | 長押し（溜め・走る・照準）に「押すたびに切り替え」の設定 |
| 連打 → 押しっぱなし | 連打の遊びは「押し続けると一定の速さで連打」を選べる |
| 一時停止 | いつでも止められる（対戦を除く）。止めている間は時間・敵が進まない |
| 時間の制限 | 制限が遊びの核でないなら「時間 1.5 倍 / 制限なし」を選べる |
| 字幕 | 台詞・大事な効果音を文字でも出す（§2） |

## 2. 音の情報を画面にも

- 台詞は字幕（誰が話しているか + 本文）。背景に半透明の帯を敷き、読める大きさで。
- 画面の外の大事な音（後ろの敵・爆発の予告）は**方向の印**を画面の端に出す（`$game-combat` の画面外の印と同じ部品でよい）。
- リズムゲームは音が核なので、音を消しても遊べるとは限らない。代わりに見た目の拍（光・振動）を強める設定を置く。

## 3. 色と見え方

- 色で分けた物（敵の種類・チーム・パズルの色）は**形・模様・印**でも分ける（SKILL.md §4）。色覚の設定（色の組み替え）は、
  形で分けてあるなら必須ではない。入れるなら赤緑・青黄の 2 種の色の組を Theme で差し替える。
- 予告・危険の色は背景と明るさの差で見分けられる（灰色にしても分かるか、撮影した画像を白黒にして確かめる）。
- 暗い作品は「明るさ」の設定（環境光・`Environment.adjustment_brightness` を 1.0〜1.4）。暗さが演出でも、次の道は見えるように。

## 4. 難しさの手助け（遊びを閉ざさない）

- 難しさを選べる遊びは「やさしい」を、**下手な人への罰ではなく**別の楽しみ方として名前を付ける（「物語を楽しむ」など）。
- 手助けの例（Celeste のアシストモードの考え方）: ゲームの速さ 70〜90%・被弾の回数を増やす・無敵・ジャンプの回数を増やす・
  ヒントを出す・パズルの答えの段階表示（`$game-design` references/puzzle.md §5）。選んでも記録や結末を閉ざさない（記録に印を付けるのはよい）。
- 手助けの値は `tuning.gd` の倍率で入れ、規則（`rules.gd`）は変えない。`$game-balance` §4 の検査をやさしい設定でも回す（クリアできるか）。

## 5. 操作の割り当て

- キーとパッドの割り当ての変更は、操作が 6 つ以上ある作品で入れる。InputMap の action を `InputMap.action_erase_events` / `action_add_event` で
  置き換え、保存は設定と一緒に（`$game-controls`）。
- 片手で遊べるか: スマホの縦画面の遊びは片手の親指で主な操作ができるように（`$game-controls` の配置）。
- 押しにくい同時押し（3 つ以上）を核の操作に使わない。

## 6. 検査

- [ ] 文字の大きさ・字幕・一時停止を入れた（入れないなら理由を `design/playtest.md` に）
- [ ] 色で分けた物は形でも分かる。白黒にしても予告が見える
- [ ] 長押し・連打・時間制限に代わりの設定がある（遊びの核でない限り）
- [ ] 手助けの設定でも最後まで遊べる（`$game-balance` の検査）
