# 音の設計（役割・混ぜ方・音楽の切り替え・Web の制限）

音は**画面に出ない情報**を運ぶ（後ろの敵・攻撃の予告・残り時間）。バスとミュートの設定は SKILL.md §7、
効果音の量と鳴らし方は [feedback.md](feedback.md) §6、素材の作り方は `$game-asset-tools` §7。

## 1. 役割ごとに決める（`design/style-guide.md` の「音」に書く）

| 役割 | 例 | 規則 |
|---|---|---|
| 操作の返事 | 押した・決定・取り消し・無効 | 同じフレームで鳴らす。短い（0.05〜0.2 秒） |
| 結果 | 当てた・取った・倒した・失敗 | 良い = 高く明るい、悪い = 低く濁る。連続は回数で音程を上げる |
| 予告 | 敵の攻撃の構え・時間切れ間近・ボスの大技 | **予告の絵と同時**に鳴らす。予告の音は他の音より先に聞こえる帯域（高め）に |
| 気配 | 足音・唸り・遠くの物音 | ホラー・ステルスでは主役。距離で小さく、左右で位置を示す（§4 の Web の注意） |
| 環境 | 風・水・街のざわめき | ループで小さく。区切り（部屋・地域）ごとに替える |
| 音楽 | 探索・戦闘・ボス・勝利 | 場面の山と休みに合わせる（§3）。BGM のバスで |

- 1 つの区切りで同時に鳴る効果音は 8〜16 個まで。同じ音を同時に何個も鳴らさない（`max_polyphony`、近い時刻は 1 つに）。
- 大事な音（予告・被弾・失敗）は**画面にも同じ情報**を出す（字幕・印。[accessibility.md](accessibility.md) §2）。

## 2. 混ぜ方

- 大事な音が鳴る間は音楽・環境を下げる（ダッキング）。Web ではバスのエフェクト（Compressor の sidechain）が鳴らないので、
  `AudioServer.set_bus_volume_db()` を Tween で 0.1 秒下げて 0.4 秒で戻す方法にする（両方で同じに動く）。
- 音量の目安（BGM バス -6〜-10 dB を基準に）: 操作の返事 -12 dB 前後、結果 -6 dB、予告 -3 dB、環境 -18 dB。最後は実機で聞いて決める。
- 同じ音の繰り返しは `pitch_scale` を ±8% 揺らす（[feedback.md](feedback.md) §5 の表）。足音は 3〜4 種を順番でなく袋から。

## 3. 音楽の切り替え

- 場面が変わるとき（探索 → 戦闘 → 勝利）は**拍・小節の区切りで替える**と途切れて聞こえない。
  Godot 4.5 の `AudioStreamInteractive` は曲（clip）と遷移の表を持ち、遷移の開始を「すぐ・次の拍・次の小節・曲の終わり」から、
  フェードの有無と長さを選べる。切り替えは `get_stream_playback().switch_to_clip_by_name(&"battle")`。
  Web の Sample 再生で拍に合った切り替えができるかは未確認（§4）。確かめられないときは 0.5〜1 秒のクロスフェード（2 つの `AudioStreamPlayer` の音量を Tween）にする。
- 重ね合わせ（同じ曲に打楽器を足す・抜く）は `AudioStreamSynchronized`。緊張に合わせて層の音量を変える。
- 音楽を止める・小さくする場面も作る（静けさがあるから山が効く。ホラーでは特に）。
- ループの継ぎ目は素材の側で整える（ループ点の指定。`$game-asset-tools` §7）。

## 4. Web の制限（Godot 4.5）

Web 書き出しは既定で **Sample 再生**（ブラウザの音声機能に任せる。遅れが少ない）。この再生では次が使えない・崩れる:

| 使えない・崩れる | 代わり |
|---|---|
| バスのエフェクト（リバーブ・EQ・Compressor など） | 素材に焼き込む。ダッキングはバスの音量の Tween（§2） |
| ドップラー・手続きで作る音（`AudioStreamGenerator`） | 使わない。必要なら素材で |
| 3D の位置の音（`AudioStreamPlayer3D`）が正しく鳴らないことがある | 大事な位置の情報は左右の音量（`AudioStreamPlayer2D` か手で `volume_db`）と画面の印で |

- `AudioStreamPlayer.playback_type` を Stream にすると全機能が使えるが遅れが増える。操作の返事・リズムの音には使わない。
- 組み込み（モバイルのネイティブ）とブラウザで同じに聞こえるか、両方のプレビューで確かめる。確かめていない物は `design/playtest.md` に未確認と書く。
- 最初の操作の前は音が鳴らない（ブラウザの制限）。BGM は最初の操作の後に始める（`$game-controls` §3）。

## 5. 検査

- [ ] 予告・被弾・失敗の音があり、画面にも同じ情報が出る
- [ ] 同時に鳴る音を絞った（`max_polyphony`、近い時刻の重複を 1 つに）
- [ ] 大事な音の間に音楽が下がる（バスの音量で）
- [ ] 音楽の切り替えが途切れて聞こえない
- [ ] Web で使えない機能（バスのエフェクト・ドップラー）に頼っていない
