# 遊べる体験にする（最初の 30 秒・手応え・読める画面・動きの安全・再挑戦）

難しくしていいのは**遊びのルールだけ**。読めない・押せない・何が起きたか分からない・戻れない・待たされる、は全部
**意図しない摩擦**で、この Skill はそれを消す。Platform の検証は「起動して描画できるか」までしか見ない。
**遊べるかどうかはここで確かめる**。

画面の形と置き場所は `$game-screen-layout`、操作は `$game-controls`。この Skill はその上の体験を決める。

## 1. 最初の 30 秒

| 規則 | 書き方 |
|---|---|
| タイトルはゲーム画面そのもの + ロゴ + 開始/続きから + 補助の「操作方法」「設定」。**操作の説明文はタイトルに並べない** | `$game-screen-layout` §5、`$game-controls` §4 |
| **最初の 1 手を画面の中で示す**（必ず） | 開始から**最初の入力が来るまで**（最長 5 秒）、最初にすることを画面に出す: 押す物・取る物を光らせる / 進む方向の矢印 / 「▼ タップで跳ぶ」の吹き出し。**入力が来たら消す**。文は 1 つ、10 文字前後 |
| 最初の課題は必ず成功できる | 最初の敵は遅い・最初の的は大きく近い・最初の問題は 1 手で解ける。**最初の 10〜20 秒は失敗しにくく**する（残機や時間を減らしにくい配置） |
| 難しさは滑らかに上げる | 時間か得点で連続的に（急な段差を作らない）。難しさの選択肢は利用者が求めたときだけ作る |
| 設定で開始を妨げない | 適切な既定値ですぐ開始でき、開始前にも任意で設定を開ける（§7）。設定の通過を強制しない |
| 説明で開始を妨げない | 操作はタイトル/ポーズの「操作方法」画面で入力方法ごとに丁寧に説明し、プレイ中は初めて要る瞬間に一言だけ示す。説明ページの通過を強制しない |

開始・再開・設定・読み込みを作る/変更する時は [references/start-screen.md](references/start-screen.md) を読む。
ジャンルと初回/再訪の状態に合う入口を選び、機能一覧を全ゲームへ一律に足さない。

## 2. 手応え

- 入力への見た目の反応は**同じフレーム**で始める（0.1 秒を超えると「反応していない」と感じる）。
  押した物が変わる（縮む・明るくなる）+ 短い音。
- 次の 4 種類の出来事には**必ず**反応を出す。量と道具ごとの書き方は [references/feedback.md](references/feedback.md)。

  | 出来事 | 最低限 |
  |---|---|
  | 良い（取った・当てた・そろった） | 伸び縮み + パーティクル + 浮かぶ数字（+10）+ 高い音。攻撃が当たったアクションには**短いヒットストップ**も |
  | 悪い（やられた・外した・時間切れ） | ヒットストップ + 画面の揺れ + 点滅 1 回 + 低い音。**何が起きたか分かる形**（当たった物を光らせる） |
  | 記録更新・クリア | 段階的な演出 1〜1.5 秒。**タップ / キーでスキップ**できる |
  | 無効な操作（押せない所・使えない時） | 小さく震える / 一瞬灰色 + 短い低い音。**無反応にしない** |

- **揺れ・点滅・パーティクルの量は 1 つの強さ `effects`（0〜1、既定 1）に掛ける**。§5 と §7 で 0 にできるようにする。
  `effects` が 0 でもヒットストップと音は残す（何が起きたかの情報だから）。
- 盛るのは「何が起きたか」を伝えるため。HUD・盤面・自機が読めなくなる揺れや点滅は入れない。
- 動く物にはイージングを付ける（出るとき減速して止まる。消えるときは出るときより短く）。

## 3. 読める・見える

| 対象 | 規則 |
|---|---|
| 本文（説明・ボタンの文字・メニュー） | **端末上で 16pt 以上**（スマホでは 720 基準の論理 px で **28〜32**。Godot の既定 16 は約 9pt で小さすぎる） |
| 補足（小さい注記） | **端末上で 12pt 未満にしない**（720 基準で 22 以上） |
| プレイ中に読む数字（スコア・残り時間・残機） | **端末上で 24pt 以上**（720 基準で 44 以上） |
| 長い文 | 1 行 **40 文字まで**、行間 **1.5 倍**。入り切らないときは文字を小さくせず、行を増やすか文を短くする |
| コントラスト | 文字と重要な HUD（ゲージ・照準・印）は、背景の**いちばん近い色の所**に対して **4.5:1 以上**。端末上で 36pt 以上の大きい文字は 3:1 以上 |
| ゲーム画面の上の文字 | 背景は動いて色が変わるので、**背板（半透明の帯・α 0.5 以上）か縁取り（2px 以上）**を必ず付ける |
| 画像の中の文字 | 生成する画像（看板・ボタン・背景）に文字を焼き込まない。文字は Label などのテキストで描く（拡大・縁取り・言語の変更が効かなくなる） |
| 常時表示 | プレイ中に常に見せる情報は **2〜3 個まで**（スコア・残り時間 / 残機・目標）。ほかは必要な瞬間だけ出す |

720 基準（`canvas_items` + `expand`）では短辺が 720 になるので、スマホでは 1pt ≈ 1.8 論理 px。文字の大きさはプロジェクトの Theme の
`default_font_size` で 1 か所に決め、Label ごとに上書きしない。**日本語のフォントを同梱する**（Web は端末のフォントを使えない。
`$game-godot` references/best-practices.md）。大きさは実端末の表示倍率で確認する（`$game-screen-layout` §4）。

## 4. 色だけ・音だけに頼らない

- 色で分ける物（敵 / 味方・成功 / 失敗・レア度・チーム）は**形・記号・文字も変える**。**赤と緑だけで分けない**。
- **音で伝えることは全部、見える形でも出す**（消音・騒がしい場所で遊ばれる）。音は手応えの一部（§2）だが、音が無くても遊べること。
- 使えない物を灰色で示すなら、鍵の記号か「使えません」の文字も付ける。
- 時間切れが近いことは、数字の色と大きさの変化 + 音の**両方**で知らせる（残り 5 秒など）。

## 5. 動きの安全（光過敏・揺れ酔い）

| 規則 | 理由 |
|---|---|
| **画面の 20% 以上の面積が光る点滅は 1 秒に 3 回まで**。それより小さい物（被弾後の無敵の自機・当たった敵）は速く点滅してよいが、明暗の反転（白黒の切り替え）ではなく**透明度（α 1 ↔ 0.3）**で | 光過敏てんかんの発作の閾値（WCAG 2.3.1。回数と面積の両方を超えたものが危ない）。警告を出すより作らない |
| **赤の全画面フラッシュを使わない**。ダメージの全画面表現は 1 回・半透明（α 0.3 以下）・0.2 秒で消える | 赤は閾値が低い |
| 白黒のようにコントラストの強い縞・格子を、画面の 20% 以上の大きさで動かさない | 模様も発作の引き金になる |
| 一人称の頭の揺れ（bob）・武器の揺れを入れない。3D のカメラを利用者の操作なしに回さない | 揺れ酔い |
| 読ませる画面（タイトル・ポーズ・リザルト）の後ろで背景を動かし続けない（止めるか、暗く落とす） | 読むのを妨げる |
| **設定に「画面の揺れ」（`effects` を 0 / 1）を置き、開始前から切り替えられるようにする** | Godot の標準の API では端末の「視差効果を減らす」を読めない（Web と組み込みの両方で同じように動く手段が無い）。揺れに弱い人が自分で止められるようにする |

## 6. 失敗と再挑戦

以下のスコア/自己ベストは得点を競う短時間ゲーム向け。RPG/探索は次の目的・進行・復帰先・続きからを示す。
未保存/最後の保存確定/再試行/競合を表示し、敗北で保存済み進行を不用意に失わせない。

- リザルトに出す:
  1. スコア（大きく）と自己ベスト。**更新したら「NEW RECORD」**を跳ねさせる
  2. 前回との差（「+3」「−2」）
  3. **終わった理由の一言**（「岩に当たった」「時間切れ」）
  4. 「もう一度」。結果を人に見せたくなる遊びなら「共有」も（`$game-screen-layout` §5.1）
- **再挑戦は操作 1 回で、1 秒以内に遊びが始まる**。記録更新の演出はタップでスキップできる。
- 失敗した瞬間は、何が起きたか分かる形にする（当たった物を光らせる・一瞬止める。§2 の「悪い」）。
- ミスで前に戻すなら数秒分まで。長いやり直しをさせない。

## 7. 音と設定

- **効果音と BGM は別のオーディオバス**（`default_bus_layout.tres` に `SFX` と `BGM`）に流し、ミュートを別々に持つ。
  `AudioStreamPlayer.bus` で振り分け、設定は `AudioServer.set_bus_mute(AudioServer.get_bus_index(&"SFX"), not settings.sfx)` で反映する。
  BGM は少し下げる（-6〜-10 dB）。Web ではバスの音量・ミュートは効くが、リバーブなどのエフェクトは鳴らない。
  BGM は最初の操作の後に鳴らし始める（`$game-controls` §3）。

- 右上のミュートボタン（`$game-controls` §3）は両方をまとめて切り替える。**開始画面とポーズ画面から同じ設定を開き、個別のトグル**を置く:
  「効果音」「BGM」（BGM があるときだけ）「画面の揺れ」（`effects` を 0 / 1）。44px 以上で、タップ・クリック・
  キー / ゲームパッドのカーソル（Control のフォーカス）のどれでも切り替えられる。
- 設定は **Store に保存**する（`TokoyoApp.save(value)`。次に遊ぶときも効く）。Store をほかに使わないゲームでもこのために宣言する:

  ```json
  {
    "storeSchemaVersion": 1,
    "storeSchema": {
      "fields": {
        "settings": { "type": "object", "default": { "sfx": true, "bgm": true, "effects": 1 } }
      }
    },
    "capabilities": ["store.read", "store.write"]
  }
  ```

  起動時は `TokoyoApp.store_loaded` か `save_status()` が `loaded` になってから `TokoyoApp.data` の設定を読み、
  トグルを変えたときに設定を含むデータ全体を `TokoyoApp.save()` する（読み込み中・失敗中に上書きしない。`$game-godot`）。
  **保存に失敗しても遊びは止めない**（`push_warning` して続け、`failed` を画面に小さく示す）。
  進行型は設定と進行の保存を一元化し、互いに上書きしない。未保存を表示し活動中に再試行する。
  一時停止中（`TokoyoApp.is_paused()`）は保存を呼ばない。復帰後の活動中に再試行する。詳細は `$game-design` references/rpg.md。
  自己ベストも同じ Store に `best` として持ってよい。前の版の `storeSchema` があるなら、**フィールドを足して**
  `storeSchemaVersion` を 1 つ上げる（消す・改名は不可）。
- 音の素材と鳴らし方は `$game-asset-tools` §7。

## 8. 読み込みの待ち時間

- 起動時の読み込みは**進み具合 + 開始を兼ねた画面**にする（読み終わったら「タップで開始」に変わる）。
- **1 秒**を超えうる待ちには動いていることが分かる表示を、**10 秒**を超えうる待ちには進み具合（%）を出す。
  %は測れる取得量/作業量がある時だけ。測れない時は現在の準備段階を示し、架空の%や演出のための待ち時間を作らない。
  開始可能/準備失敗/再試行の状態は references/start-screen.md §3 に従う。
- `bundles/` の取得中は遊びを止めない（先読み。`$game-3d-and-bundles`）。対戦の待機も同じ（`$game-multiplayer` §5）。

## 9. 出力前のチェック

- [ ] 開始から最初の入力まで、最初の 1 手が画面に示され、入力で消える
- [ ] 最初の 10〜20 秒は失敗しにくく、難しさは滑らかに上がる
- [ ] 良い / 悪い / 記録更新 / 無効な操作 の 4 種類に、見える反応と音がある
- [ ] 揺れ・点滅・パーティクルが `effects` に掛かり、設定の「画面の揺れ」で 0 になる
- [ ] 画面の 20% 以上が光る点滅は 1 秒に 3 回まで（小さい物の点滅は透明度で）。赤の全画面フラッシュが無い
- [ ] 端末上で本文 16pt・補足 12pt 以上・プレイ中の数字 24pt 以上（720 基準で 28 / 22 / 44 以上）。日本語のフォントを同梱した。長い文は 1 行 40 文字以内
- [ ] ゲーム画面の上の文字に背板か縁取りがあり、4.5:1 を満たす。画像に文字を焼き込んでいない
- [ ] 色だけ・音だけで伝えている情報が無い
- [ ] 短時間ゲームは結果と再挑戦、進行型は目的/進行/復帰先/続きから/保存状態がある
- [ ] 開始前とポーズ中から同じ設定を開ける。効果音 / BGM / 画面の揺れは実在するものだけ表示し、`storeSchema.settings` に保存される
- [ ] 1 秒を超えうる読み込みに表示がある
- [ ] 開始画面を作った/変えたなら references/start-screen.md §5 の該当項目を実操作と実画像で確認し、未確認を分けて記録した
