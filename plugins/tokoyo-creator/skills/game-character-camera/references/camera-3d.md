# 3D のカメラ

## 1. 三人称（`assets/orbit_camera_3d.gd`）

木の形:

```text
Player (CharacterBody3D)
CameraRig (Node3D, orbit_camera_3d.gd, target = Player)   ← プレイヤーの子にしない（top_level で独立）
└─ Pitch (Node3D)
   └─ SpringArm3D (spring_length = distance, collision_mask = 地形の層だけ)
      └─ Camera3D
```

| 項目 | 目安 | 理由 |
|---|---|---|
| 追う点 | キャラの頭より少し下（身長の 0.8 倍） | 足元と前が両方見える |
| 距離 | 3.5〜6 m（人型）。狭い屋内は短く | 遠いと敵の予告が小さい、近いと周りが見えない |
| 上下の限界 | 見下ろし −55° 〜 見上げ +25° | 真上・真下まで回すと地面にめり込む・空しか見えない |
| 位置の追従 | `1 - exp(-k*dt)`、k = 8〜15 | 固すぎると揺れ、柔らかすぎると置いていかれる |
| 右スティック | 最大 120〜180°/秒、遊び 0.2 | マウスより遅く。加速曲線は付けなくてよい |
| マウス・タッチのドラッグ | 0.15〜0.35°/px。設定で変えられる | 感度は好みが大きく分かれる |
| 上下の反転 | 設定に入れる | 反転派が一定数いる |

- **壁抜け防止**は `SpringArm3D`。`collision_mask` は地形・壁だけ（敵・弾・プレイヤーを入れない）。プレイヤーの体は
  `add_excluded_object(rid)` で外す（部品が自動で行う）。腕が縮む球の半径は `shape` に `SphereShape3D`（0.2〜0.3 m）を入れると
  カメラが壁にめり込みにくい。
- **背中へ向き直す**（`recenter()`）: ボタン 1 つ（パッドは右スティック押し込み、スマホは画面の小さなボタン）で、キャラの後ろへ
  0.2〜0.4 秒で回す。**勝手に回さない**（`$game-ux` §5 の揺れ酔い）。視点を触ったら向き直しをやめる（部品が行う）。
- **見えない敵**: 画面の外から攻撃する敵には画面端の印（方向の矢印）と、予告の音を出す（`$game-combat` §5）。
- カメラとキャラの間の木・柱がキャラを隠すときは、その物を半透明にするより、距離を縮める・その物を置かない方が軽い
  （Compatibility では半透明の重なりが重い・並びが崩れる。`$game-art-direction` references/vfx.md）。

## 2. ロックオン

- 押すと、画面中央に近く・距離が近い敵（視野内・遮るものが無い）を選ぶ。もう一度押すと解除、スティックを倒すと隣の敵へ切り替え。
- ロック中はカメラの向きを「プレイヤー → 敵」の中間点へ向け、プレイヤーと敵が両方画面に入るよう少し引く。
- 敵が近づきすぎてカメラが真上を向かないよう、上下の角度は通常と同じ限界を守る。
- 倒した・見失った（遮られて 1〜2 秒）ら自動で解除するか、次の敵へ移す（遊びに合わせて 1 つに決める）。
- 印（ロックの輪）は敵の上に出す。輪の色は攻撃色と別にする（予告と混ざらない）。

## 3. 一人称

- `Camera3D` をプレイヤーの頭の位置に置き、左右は体（`CharacterBody3D`）、上下はカメラだけを回す。上下は ±85°。
- PC は Pointer Lock（`Input.mouse_mode = Input.MOUSE_MODE_CAPTURED`）を**クリックしてから**有効にする（ブラウザは利用者の操作が要る）。
  Esc で解除されたらポーズへ（`$game-controls`）。
- 頭の揺れ（bob）・武器の揺れは入れない（`$game-ux` §5）。重さは足音・着地の音と小さな土煙で出す。
- 手元の武器・道具は**別のカメラ**（`SubViewport`）ではなく、近い位置のメッシュで十分（Compatibility で軽い）。壁にめり込むなら短くする。
- スマホの一人称は画面の右半分のドラッグで視点、左で移動。照準の補助（敵の近くで感度を下げる）を入れる。

## 4. 見下ろし・等角

- 角度 45〜60°、距離はプレイヤーの周り（スマホ縦で横 12〜20 m）が見える程度。`Camera3D.projection` の正射影（orthographic）は
  タクティクス・街づくりで遠近の歪みが無く読みやすい。
- 先読み: 移動の向き（ツインスティックなら照準の向き）へ画面の 10〜20% ずらす。
- 手前の壁・屋根がプレイヤーを隠すなら、プレイヤーとカメラの間にある物だけ隠す（屋根の層を消す・壁を低く作る）。
- 回転できるカメラ（街づくり）は 90° 刻みで回すと、方角と入力の対応が分かりやすい。

## 5. 固定カメラと演出のカメラ

- 部屋ごとに固定のカメラを切り替えるなら、切り替わった直後は**前の入力の向きを保つ**（スティックを離すまで）。
- 演出（ボスの登場・扉が開く）でカメラを奪うのは 1〜3 秒まで。飛ばせるようにする。戻すときは元の向きへ滑らかに。
- 揺れ（trauma）は `Camera3D.h_offset` / `v_offset` か、Camera の親を少し動かす（`$game-ux` references/feedback.md）。
  カメラの向きを大きく回す揺れは酔いやすい。
