# 動きとカメラ（3C）

プレイヤーが最初の 10 秒で感じるのは**動きとカメラの手触り**。ここが重い・滑る・見えないと、遊びの中身が良くても続かない。
数値は全部 `godot/tuning.gd` に置き、「何秒で最高速」「何タイル跳べる」で決める（`$game-balance` §1）。
入力の読み方（InputMap・移動スティック・パッド）は `$game-controls`、キャラのアニメ（状態機械・ブレンド・足滑り・伸び縮み）は `$game-motion`、揺れ・ヒットストップは `$game-ux` references/feedback.md、
画面の比率とカメラの範囲は `$game-screen-layout`。

|---|---|
| この SKILL.md | 操作キャラとカメラを作る・変えるとき |
| [references/camera-3d.md](references/camera-3d.md) | 3D のカメラ（三人称・一人称・ロックオン・見下ろし）を作るとき |
| `assets/orbit_camera_3d.gd` | 三人称の追従カメラの検証済み部品（SpringArm3D・上下の限界・右スティック・ボタンで背中へ向き直す・移動の向き） |

## 1. 動き（2D / 3D 共通の数値）

| 項目 | 目安 | 理由 |
|---|---|---|
| 最高速までの時間 | 0.05〜0.15 秒（アクション）、0.2〜0.4 秒（重さを出す遊び・乗り物） | 遅いと「重い」、0 だと「軽すぎて止まれない」 |
| 止まるまでの時間 | 加速より短く（0.03〜0.1 秒） | 止まりたい所で止まれることが精密さ |
| 空中の左右制御 | 地上の 60〜90% | 0 だと理不尽、100% だと重さが消える |
| 切り返し | 逆向きの入力は加速の 1.5〜2 倍で減速 | 方向転換の反応が「手に付く」感じを作る |

- 速度は `move_toward(velocity.x, target, accel * delta)` で近づける（加速・減速・切り返しで `accel` を変える）。
  `lerp` を毎フレーム掛けるとフレームレートで手触りが変わる。
- `CharacterBody2D` / `CharacterBody3D` の `velocity` を変えて `move_and_slide()`。物理の剛体（RigidBody）でプレイヤーを動かさない
  （`$game-physics`）。坂は `floor_max_angle`、段差は `floor_snap_length`、動く床は `platform_on_leave` を設定する。
- **物理の補間**（`physics/common/physics_interpolation`）を入れるなら `$game-godot` references/best-practices.md の手順に従う。
  入れないなら高リフレッシュの端末でカクつかないか確かめる。

### ジャンプは高さと時間から決める

先に「何タイル跳ぶか（高さ h）」「頂点まで何秒（t）」を決め、重力と初速を出す:

```gdscript
# tuning.gd
const JUMP_HEIGHT := 72.0          # px（2D）か m（3D）。例: 2D はタイル 16px × 4.5
const JUMP_TIME_TO_PEAK := 0.36    # 秒。0.3〜0.45 が軽快。0.5 以上はふわっとした遊び
const JUMP_TIME_TO_FALL := 0.28    # 秒。上りより短く（落ちるのを速く）すると重さと気持ちよさが出る
const JUMP_VELOCITY := 2.0 * JUMP_HEIGHT / JUMP_TIME_TO_PEAK                   # 初速（上向き）
const GRAVITY_UP := 2.0 * JUMP_HEIGHT / (JUMP_TIME_TO_PEAK * JUMP_TIME_TO_PEAK)
const GRAVITY_DOWN := 2.0 * JUMP_HEIGHT / (JUMP_TIME_TO_FALL * JUMP_TIME_TO_FALL)
```

- 2D は y が下向きなので `velocity.y = -JUMP_VELOCITY`、3D は `velocity.y = JUMP_VELOCITY`。
- 上昇中は `GRAVITY_UP`、下降中（または上昇中にボタンを離したら）は `GRAVITY_DOWN`。**可変ジャンプ**（離すと低く）はこれで出る。
- 落下速度に上限（終端速度。初速の 1.0〜1.5 倍）を付ける。無いと長い落下で床を突き抜ける・制御できない。

### ごまかし（入れるのが標準）

| 名前 | 値 | 内容 |
|---|---|---|
| コヨーテタイム | 0.08〜0.12 秒 | 床を離れた直後もジャンプできる |
| 先行入力（ジャンプ） | 0.1〜0.15 秒 | 着地の直前に押したジャンプを着地で出す |
| 角の補正 | 数 px | 頭が天井の角に少しだけ当たったら横へずらして通す |
| 着地の判定 | 見た目より少し下 | 足が床に「乗った」と感じるタイミングを合わせる |

`$game-combat` §1 の攻撃の先行入力と同じ考え方。押したのに出ない、をなくす。

## 2. 2D のカメラ

- `Camera2D` の位置補間（`position_smoothing_enabled`、速さ 4〜8）か、自前で `1.0 - exp(-k * delta)` で追う。
- **遊び（dead zone）**: `drag_horizontal_enabled` / `drag_vertical_enabled` と `drag_*_margin`。小さく左右に動いてもカメラが揺れない。
- **先読み（look-ahead）**: 進む向きへ画面の 15〜25% ずらす。向きを変えたら 0.3〜0.6 秒かけて移る（すぐ移すと酔う）。
- 横スクロールの縦は**着地したときだけ**追う（ジャンプの上下でカメラが上下しない）。高い所へ登ったら追う。
- 部屋で区切る遊び（メトロイドヴァニア・ゼルダ型）は `limit_left/top/right/bottom` を部屋ごとに切り替え、部屋の移動は 0.2〜0.4 秒で滑らせる
  （`$game-level-design`）。
- ズーム: 戦いの多い場面は少し引き、静かな場面は寄る。変えるのは 0.5 秒以上かけて。`$game-screen-layout` §1 の比率の扱いを守る。

## 3. 3D の視点を選ぶ

| 視点 | 向いている遊び | 注意 |
|---|---|---|
| 三人称（背中の後ろ） | 3D アクション・冒険・ソウルライク | 壁抜け・見えない敵・カメラ操作の負担。[references/camera-3d.md](references/camera-3d.md) §1 |
| 一人称 | 探索・ホラー・射撃・謎解き | 酔い（視野角・揺れ・速さ）。足元が見えないので足場の遊びは控えめに |
| 見下ろし（固定の角度） | ツインスティック・ハクスラ・タクティクス・街づくり | カメラを回させないなら壁の手前を透かす。スマホと相性がよい |
| 横から（2.5D） | 3D の見た目の横スクロール | 奥行きの移動を遊びに入れるなら影で位置を見せる |
| 固定カメラ（部屋ごと） | 古典ホラー・パズル | カメラが切り替わる瞬間に入力の向きを保つ（切り替わる前の向きで動き続ける） |

**スマホで遊ぶ 3D は、まず「カメラを回さなくてよい設計」を考える**（見下ろし・ロックオン・ボタン 1 つで背中へ向き直す）。
片手の親指で移動、もう片方でカメラ・攻撃・ジャンプを全部やるのは難しい（`$game-controls`）。

## 4. 3D の動き

- 入力（移動スティック）は**カメラの水平の向き**で回してから使う（`orbit_camera_3d.gd` の `move_direction()`）。
- キャラの向きは移動方向へ `lerp_angle` で回す（0.08〜0.15 秒で振り向く）。急に向きが変わると軽すぎる。
- ロックオン中はキャラが敵を向き、移動は敵の周りを回る（横移動）。
- 着地・方向転換・ダッシュには短い土煙と音（`$game-ux` references/feedback.md）。
- 地面の影（丸い影の板）を足元に置くと、ジャンプ中の位置と高さが分かる（Compatibility では Decal が使えない。`$game-art-direction` references/vfx.md）。

## 5. 酔いと見やすさ

- 一人称の頭の揺れ（bob）・武器の揺れは入れない。**利用者の操作なしに 3D のカメラを回さない**（`$game-ux` §5）。
  背中へ向き直すのはボタンを押したとき（`recenter()`）、ロックオンを押したときだけ。
- カメラの揺れ（trauma）は設定の「画面の揺れ」（`effects`）で切れる（`$game-ux` §5、references/accessibility.md）。
- 視野角（FOV）の既定は一人称 75〜90°、三人称 60〜75°。速さで FOV を広げる演出は 5〜10° まで。
- 暗い場面でもプレイヤーの位置・次に行く道が分かる光を置く（`$game-art-direction`）。

## 6. 検査（`design/playtest.md` に書く）

- [ ] 最高速・止まる・ジャンプの高さと時間が `tuning.gd` にあり、§1 の目安の範囲（外すなら理由）
- [ ] コヨーテタイムと先行入力がある。可変ジャンプが効く。落下速度に上限がある
- [ ] 2D: 小さく動いてもカメラが揺れない、進む向きの先が見える。3D: 壁でカメラがキャラの中に入らない
- [ ] 3D: スティックの上 = 画面の奥。カメラを回さなくても主な遊びが成り立つ（スマホ）
- [ ] 頭の揺れが無く、利用者の操作なしにカメラが回らない。画面の揺れを設定で切れる
