# ボスの設計

ボスは**それまでに覚えたことの試験**であり、作品の看板の仕掛けを最も濃く使う場面。体力が多いだけの雑魚にしない。
規模はインディー（Hollow Knight・Cuphead・Enter the Gungeon の考え方を借りる。量は真似しない）。

## 1. 先に決める 4 つ（`design/brief.md` か `design/bosses.md` に書く）

| 決めること | 規則 |
|---|---|
| 試すこと | このボスで確かめる技能を 1〜2 個（「ジャンプの高さの調整」「突進を横へ避ける」）。それまでの区切りで教えた技能だけ |
| 看板の使い方 | 作品の核の動詞・看板の仕掛けがボス戦で一番活きる形（Downwell 型なら踏む・撃つ・落ちるの全部を使わせる） |
| 技の一覧 | 2〜4 種で始める。各技に予告（形・光・音）と、明確な隙（recovery の長さ）を決める |
| 段階（phase） | 2〜3 段階。体力の 60〜70% と 30% 前後で切り替え、新しい技を 1 つ足すか既存の技を組み合わせる |

## 2. 技の作り方

- **全部の技は予告がある**（`../SKILL.md` §1）。予告の長さはボスの最初の段階で長く、後の段階で少し短くしてよい
  （ただし 12F を下回らせない）。
- 技は**避け方が 1 つに決まる**ように作る（横へ・跳ぶ・下がる・隠れる）。同じ予告で避け方が違う技を作らない。
- 隙（recovery）は技の強さに比例させる。大技の後は 1〜2 秒の攻撃の機会を必ず作る。
- 技の選び方は完全な乱数にしない。**同じ技を 3 回続けない**、直前の技と相性の悪い組み合わせを出さない
  （避けた先に次の技が置かれて詰む）。小さな順番の表 + 揺らぎで選ぶ。
- 画面全体を覆う攻撃には必ず安全地帯を作り、安全地帯自体を予告で示す。
- 弾幕型は「弾の模様が読める」こと。模様は回転・扇・壁の 3 種を組み合わせ、隙間はプレイヤーの当たり判定の 2 倍以上。

## 3. 段階の切り替え

- 切り替えは**演出で知らせる**: ボスの見た目が変わる（壊れる・光る・怒る）、短い無敵の間に音楽が変わる（`$game-ux` references/sound-design.md）。
  切り替え中の 1〜2 秒はボスもプレイヤーも攻撃しない。
- 新しい段階では「前の段階の技 + 新しい要素 1 つ」。全部入れ替えない（習熟が無駄にならない）。
- 最後の段階は少しだけ速く・激しく。プレイヤーの体力が少ない状況でこそ勝てる「あと少し」の緊張を作る。

## 4. 負けたときと勝ったとき

- **やり直しまでを短く**: ボスの直前にチェックポイント。戻り道（runback）は 10 秒以内か無し。
  何度目かの挑戦で「ボスのことが分かってきた」と感じられるよう、技の順番の表は毎回少しずつ違ってよいが、同じ技は同じ予告。
- 負けた画面に「ボスの残り体力」を一瞬見せる（あと少しだった、が次の挑戦の理由になる）。
- 勝った瞬間: ヒットストップ長め（100〜200ms）→ スローか停止 → 崩れる演出 1〜3 秒 → 報酬。音楽を止めて静けさを置く。
- 物語のあるゲームは、ボスの前後に短い言葉（1〜3 行）を置く（`$game-design` references/narrative.md）。長い会話でテンポを止めない。

## 5. ボスの検査

- [ ] 試す技能・看板の使い方・技の一覧・段階を書いた
- [ ] 全部の技に形・光・音の予告と、避け方が 1 つに決まる形がある
- [ ] 大技の後に攻撃の機会がある。同じ技が 3 回続かない。避けた先で詰む組み合わせが無い
- [ ] 段階の切り替えが演出で分かり、切り替え中に攻撃されない
- [ ] 負けてから再挑戦まで 10 秒以内。負けた画面で残り体力が分かる
- [ ] 戦いの長さが目安に収まる（ミニボス 30〜60 秒、ボス 1.5〜3 分、最終ボス 3〜5 分。`$game-balance` §2）
