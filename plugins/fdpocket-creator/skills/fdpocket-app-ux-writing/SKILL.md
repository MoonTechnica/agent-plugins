# 画面の文言を書く

*文言は辞書に置く（`$fdpocket-app-ui` §1 の i18n）。この Skill は**何を書くか**。*

目的は、**読まずに使えて、迷ったときに読めば分かること**。画面の文言は説明書ではなく操作の一部。

## 1. 原則

1. **利用者の業務の言葉で書く**。依頼・添付・`design/context.md` に出てくる呼び方をそのまま使う（「案件」と呼ぶ会社で「プロジェクト」と書かない）。同じものを画面ごとに別の名前で呼ばない。
2. **内部の言葉を出さない**: モデル名・テーブル・ID・`status` の値・「レコード」「データ」「エンティティ」「同期」「API」。
3. **短く**: ボタンは 2〜6 文字（en は 1〜3 語）、見出しは 1 行、補足は 1 文。
4. **具体的な動詞**: 「追加する」「保存する」「申請を送る」。「OK」「はい」「送信」「実行」だけにしない。ボタンの文言は**押すと何が起きるか**。
5. **利用者を責めない**: 「入力が不正です」ではなく「メールアドレスの形で入力してください（例: name@example.com）」。
6. **流れの中で同じ動詞を使う**: 「公開する」ボタンの結果は「公開しました」、状態は「公開中」。途中で「リリース」「反映」に言い換えない。
7. **見出しの上の小さな英字ラベル・「→」付きのボタン・中黒でつないだ補足**（`A · B · C`）を飾りで使わない（`$fdpocket-app-visual` §8）。
8. 敬語の量をそろえる（ja は「です・ます」で、ボタンは「〜する」）。感嘆符・絵文字・「！」の多用をしない。

## 2. 場面ごとの型

| 場面 | 型 | 例（ja / en） |
|---|---|---|
| 主ボタン | 動詞 + 対象（対象が自明なら動詞だけ） | 「タスクを追加」 / "Add task" |
| 送信中 | 進行形 | 「保存しています…」 / "Saving…" |
| 入力欄の名前 | 名詞。必須なら付けず、**任意のほうに「（任意）」** | 「担当者」「メモ（任意）」 / "Assignee", "Note (optional)" |
| 入力の補足 | 形・例・用途を 1 文。プレースホルダーに大事なことを書かない（入力すると消える） | 「取引先に表示されます」 |
| 空の表示 | 何が無いか + 何をすると埋まるか + ボタン | 「まだ予約はありません。最初の予約を入れましょう」→「予約を入れる」 |
| 検索結果なし | 何で探したか + 次の手 | 「『棚卸し』に一致するタスクはありません」→「条件を外す」 |
| エラー | 何が起きたか + どうすればよいか（原因が分からなければ再試行を） | 「保存できませんでした。通信を確かめて、もう一度お試しください」 |
| 権限が無い | 誰ならできるか | 「この設定は管理者だけが変更できます」 |
| 確認（戻せない操作） | 見出しは質問、本文は**何がどうなるか**、ボタンは動詞 | 「『棚卸し』を削除しますか？」「コメント 3 件も削除され、元に戻せません」→「削除する」/「やめる」 |
| 成功の知らせ | 何が済んだか（画面で見えるなら出さない） | 「申請を送りました。承認されると通知が届きます」 |
| 通知（Push） | 誰が・何を・何について。1 行目だけで分かる | 「佐藤さんが『見積』にコメントしました」 |

## 3. 数・日時・名前を文に入れる

- 件数は ICU の複数形か、言語ごとの関数で（en: "1 task" / "3 tasks"）。「1件(s)」のような書き方をしない。
- 文の中の値は語順が言語で違う。文字列をつなげず、辞書に `{count}` `{name}` の入る文を置く。
- 人の名前・利用者が書いた文はそのまま出す（翻訳しない）。長いときは `truncate`。

## 4. en も同じ質で

- ja を機械的に訳さない。en は Sentence case（"Add task"、"Add Task" にしない）、ボタンは動詞で始める。
- en は ja より 1.3〜1.5 倍長くなる。ボタン・タブ・表の見出しが en でも 1 行に収まるか、`kit shot --locale en` と `--locale ja` で両方撮って見る。

## 5. 書いたら見直す

- [ ] 画面のどこにも内部の言葉・英語の値（`pending` など）が出ていない
- [ ] 同じものを同じ名前で呼んでいる（一覧・詳細・通知・掲載情報で）
- [ ] すべてのボタンが「押すと何が起きるか」を言っている。押した後の知らせと状態も同じ動詞
- [ ] 空・エラー・確認の文に、次にすることがある
- [ ] 全対応言語で抜け・長すぎ・生のキーが無い
