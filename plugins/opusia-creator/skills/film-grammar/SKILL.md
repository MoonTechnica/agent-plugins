# 映像文法（カットが繋がる条件）

身体感覚のある視点・空撮・FPV・複合カメラを設計するときは
[references/camera-design.md](references/camera-design.md) を読む。
用語を列挙するだけで終えず、**文字コンテの `shot` / `note` に保存し、絵コンテの構図と
プリビズの位置・向きへ引き継ぐ**。単語の対応は
[references/shot-vocabulary.md](references/shot-vocabulary.md) §3。
Motion Prompt の作例・番号をカメラ設計に使うときは
[references/motion-prompt.md](references/motion-prompt.md) を読む。

## 0. なぜ生成でこそ効くか

実写の現場は**カバレッジ**を撮る。マスター・寄り・切り返しを一通り押さえておき、
繋がらなければ編集室で別のテイクに逃げる。

生成にもこの保険は**半分だけ**ある。**マスター**（シーンの空間・立ち位置・光を
決める引きの静止画 1 枚。`set_scene_master`）を先に描けば、絵コンテの全コマが
その中で描かれ、空間と光が揃う（`storyboard` §1.5）。動画はその絵コンテから撮るので
揃ったまま届く。**無いのは「撮ってから選ぶ」ほう**で、寄り・切り返しは頼んだ
1 通りしか出てこない。

| | 実写 | 生成 |
|---|---|---|
| 空間と光の正本 | マスター | **マスター**（静止画 1 枚を絵コンテの前に。無いとコマごとに別の場所になる） |
| 1 シーンから得られる画 | 撮った全アングル | **頼んだ 1 通りだけ**（多カットでも 1 パス） |
| 繋がらないと分かったとき | 別テイクに差し替える | **撮り直し = 再課金** |
| 気づく時点 | 編集で | コンタクトシート（`get_asset_preview`）で見るまで気づけない |

つまり**繋がる条件は「撮る前」に満たしておくしかない**。ここに書いてあるのは
そのための条件で、絵コンテ（`storyboard`）を作る時点で効かせる。マスターは
空間と光を揃えるが、**カット割り・視線・イマジナリーラインは揃えてくれない**。

## 1. ショットサイズは情報量と距離感を同時に決める

カメラと被写体の距離は 3 つを一度に決める ——
**どれだけ情報が入るか / どこを見るか / どれだけ近く感じるか**。

| サイズ | 画角 | 伝わるもの | 使いどころ |
|---|---|---|---|
| **ロング / 引き** | 場所ごと | 状況・位置関係・スケール | シーンの頭。人物を小さく見せて孤立や圧を出す |
| **ミディアム** | 腰から上 | 人物と周囲の関係 | 芝居の基本。会話の受け |
| **ミディアムアップ** | 胸から上 | 表情 + 身振り | **会話の主戦場**。感情が強い場面 |
| **アップ** | 顔 | 感情そのもの | 決めの 1 カット。多用すると効かなくなる |
| **大アップ** | 目・手・物 | 緊張・違和感 | 一撃。連発しない |

**基本形は「引きから寄りへ」。** シーンの頭で場所と位置関係を見せ、話が進むほど
寄っていく。これだけで感情が上がっていく設計になる。**誰に寄るか**（シーンの視点人物。
カメラの位置が同情の方向を決める）は [references/direction-design.md](references/direction-design.md) §5。

- **寄りっぱなしにしない。** どこで何が起きているか分からなくなる。
- **引きっぱなしにしない。** 誰の話か分からず、感情が乗らない。
- **アップを最初に使わない。** 上げ幅が無くなり、山場で打つ手が残らない。

## 2. 繋がらない原因はほぼ 3 つ

### 2.1 イマジナリーライン（180 度）を跨いだ

2 人の間に引いた線の**片側からだけ**撮る。跨ぐと画面上で 2 人が急に入れ替わり、
同じ方向を向いて喋っているように見える。

```
        A ●──────────● B        ← イマジナリーライン
    ┌─────────────────────┐
    │   ○    ○    ○       │     ← カメラはこちら側にだけ置く
    └─────────────────────┘
```

- A は**画面右**を向いて B を見る / B は**画面左**を向いて A を見る。これが揃うと繋がる。
- 移動・乗り物・スポーツも同じ（**進行方向を画面上で一定に**保つ）。
- **跨ぎたいときは 4 つの方法のどれかを使う**（カメラが動いて越える、線上の正面か真後ろのカットを
  1 枚挟む、カットアウェイを挟む、人物が動いて線を引き直す。[references/cut-to-cut.md](references/cut-to-cut.md) §4）。混乱を意図する場面ではわざと跨いでよいが、**事故と
  区別が付かないので理由が要る**。

### 2.2 同じ被写体を似すぎた角度で撮った（30 度ルール）

同じ人物を続けて撮るなら、**カメラを 30 度以上振る**。振らずに繋ぐと人物が
瞬間移動したように**ピクッと飛ぶ**（ジャンプカット）。

同じ軸のまま寄りたいときは、**ショットサイズを 1 段以上変える**（ミディアム → アップ）。
中途半端に寄ると「意図した寄り」ではなく「事故」に見える。

### 2.3 画面方向が入れ替わった

同じ人物・物がカットをまたいで**画面の左右で入れ替わる**と、別の場所に見える。
出ていく方向と入ってくる方向も繋げる（右に出たら次のカットでは左から入る）。

## 3. 視線とアクションで縫う

**視線の一致**: 見ている人のカットと、見られている物のカットは、**目線の高さと
向きが対応**していなければならない。見上げているなら、次は見下ろした画角になる。
ずれると同じ空間に居ないように見える。

**アクション繋ぎ**: 動作の**途中**で切る。ドアに手を掛けた瞬間に引きから寄りへ切ると、
動作が繋がって切れ目が消える。動作の**前後**で切ると間延びする。

| やること | 効果 |
|---|---|
| 動きの途中で切る | 切れ目が見えなくなる |
| 動きが終わってから切る | 「待ち」が出る。間として意図する場合だけ |
| 同じ動きを 2 カットで重ねる | 動作がダブって見える（**生成では起きやすい**） |

切る位置は**動作の始まり〜 1/3**、寄り側のカットの動きは遅く。**カメラが動くカット同士**の繋ぎ
（止め → 止めが既定・動き → 動きは向きと速さを揃える）、match cut、ホイップや被写体で画面を塞ぐ転換、
次の注目点の置き方は [references/cut-to-cut.md](references/cut-to-cut.md)。

## 4. カットの尺とリズム

**尺は情報量で決まる。** 画に入っている情報を読み取る時間が要る。

| 画 | 目安 |
|---|---|
| アップ（顔だけ） | 1〜2 秒でも読める |
| ミディアム | 2〜4 秒 |
| ロング / 情報の多い画 | 3〜5 秒。初出の場所はさらに長く |
| 文字・細かい情報が写る | 読み切れる時間（黙読 + α） |

- **同じ長さのカットを並べない。** 等間隔は「編集していない」ように見える
  （MV が安っぽく見える最大の原因がこれ。`genre-playbook` の MV 篇）。
- **作品全体の平均は形式の実測に合わせる**（現代映画 3〜5 秒・TV アニメ約 4〜5 秒・縦型 2〜3 秒）。
  生成モデルの尺（8〜10 秒）は 1 回に撮れる上限で、1 カットの長さではない
  （`screenwriter` の references/cut-timing.md §4）。
- **緊張を上げるときはカットを短く**していく。落ち着かせるときは長く。ただし**速さと緊張は
  別物** —— 落ち着かないのは「動きが収まる前に切られる」から。緊張の既定は「短くする」ではなく
  「収めてから切るか、収める前に切るか」の選択（[references/direction-design.md](references/direction-design.md) §2）。
- **会話は間で演じる。** 台詞の切れ目でカットを切らず、聞いている側の顔に少し留まると
  芝居になる（音と画をずらす手は `audio-engineer` の J カット / L カット）。
- **曲が主役の映像では [references/beat-sync.md](references/beat-sync.md) を開く。**
  切る根拠は 5 つ（拍・歌詞・旋律 / 和声・芝居・物語）で、**拍はその 1 つ**。サビ / ドロップ /
  ダンスは拍に乗せ切り、A メロは歌詞と芝居、ブリッジは拍から浮かせ、台詞のある場面は感情 →
  物語で切る。**全カットが拍に乗った映像は「機械的」という欠陥**。拍で切るカットは拍の
  1〜2 コマ前に置き、拍で着地させる動きは拍より前に始める。

## 5. シーンの入り方と出方

1. **確立ショット**（引き）で場所・時間帯・誰が居るかを見せる
2. 芝居に応じて寄っていく
3. 出るときは**次に繋がる情報**を残す（去る方向・残った物・音）

**シーンの弧は「引きで始め → 寄りながら短く → 最後に少し引いて長く」**（実測。寄りの弧は作品全体ではなく
**シーンごとに 1 回**描く）。作品のカメラの規則・視点・撮り方の選択・入りと出の型は
[references/scene-camera.md](references/scene-camera.md)。

**場所が変わったら必ず確立ショットを入れる。** 生成では背景が毎回違って出るので、
省くと「どこの話か分からないまま会話が続く」状態になりやすい。

**時間経過**は、同じ構図で光だけ変える / 引きに戻す / 物の変化（食べかけ → 空皿）で見せる。

## 6. 切り替えの意味（何を使うと何と読まれるか）

| 切り替え | 読まれ方 | 使いどころ |
|---|---|---|
| **カット** | 同じ時間の続き | 既定。9 割はこれ |
| **ディゾルブ（OL）** | 時間が飛んだ・場所が変わった | シーンの繋ぎ。多用すると回想だらけに見える |
| **フェード（F.I / F.O）** | 段落が終わった | 章の切れ目・話数の頭と尻 |
| **ホワイトアウト** | 衝撃・記憶・回想の境目 | 強い。1 本に何度も使わない |

**迷ったらカット。** 効果を付けるのは「そこに意味の切れ目がある」ときだけ。
**選んだ意味を `apply_transition` の key と秒数に落とす手順は [references/transitions.md](references/transitions.md)**（自分で HTML を書かない）。

繋がらないカットを効果で誤魔化すと、繋がらないうえに間延びする。場面転換に意味を持たせる
4 択（連想 match / 対比 smash / 音の先行 sound bridge / 何もしない）と、隣り合う 2 カットの
「連続 / 対比 / 衝突」は [references/direction-design.md](references/direction-design.md) §6。
**クライマックスはカットだけで繋ぐ**（ディゾルブ・フェードは導入と中盤に回す）。ワイプ・中間の空間・
音の先行など他の転換と、転換を作品の型として反復する話は [references/scene-camera.md](references/scene-camera.md) §8。

## 7. 隣り合う 2 カットの検査

絵コンテができたら、**隣り合う 2 コマを 1 組ずつ**この 6 点で見る。その前に**シーンが観客の感情を
狙いどおり動かすか**（Murch: 感情 51% が最優先。[references/direction-design.md](references/direction-design.md) §11）。

| # | 検査 | 落ちていたら |
|---|---|---|
| 0 | このシーンで観客の感情が A → B へ動くか。山場の直前は山場と同じ軸の反対側か | 技法ではなく狙いを書き直す（direction-design §11） |
| 1 | イマジナリーラインの同じ側か | 片方の左右を入れ替える |
| 2 | 同じ被写体なら 30 度以上振れているか、サイズが 1 段違うか | 角度かサイズを変える |
| 3 | 人と物の画面上の左右が保たれているか | 構図を直す |
| 4 | 視線の向きと高さが噛み合っているか | 画角（アオリ / フカン）を直す |
| 5 | 光の向きと時間帯が揃っているか | 揃える（`art-director` の画づくり） |
| 6 | 尺が同じ長さで並んでいないか | 割り直す |

**カメラが動くカットが隣り合うとき**は、[references/cut-to-cut.md](references/cut-to-cut.md) §11 の
12 点（動と静・向きと速さ・サイズの跳び・軸の越え方・注目点の位置・音で縫う）も見る。

機械で読める部分（サイズの並び・場所の変わり目・パンの向き）は `screenwriter` の
`scripts/shot_lint.py` が先に見る。**この検査は絵コンテの段でやる。** 動画にしてから気づくと、そのカットの生成費が
丸ごと無駄になる。

## 8. 用語表

絵コンテの日本語表記（T.U / PAN / アオリ など）と、生成プロンプトで通じる英語表現の
