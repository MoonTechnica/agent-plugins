# 継ぎ目の演出（トランジション）を選んで当てる

`SKILL.md` §6 は**意味**（ディゾルブは経過、ホワイトアウトは衝撃…）を決める。ここは
それを **`apply_transition` の `key` と秒数に落とす**手順。当てるのは自分で HTML を書かず、
**`apply_transition`**（外すのは `remove_transition`）。

## 0. まず「当てない」を選ぶ

**既定はただのカット。** 演出が要るのは、継ぎ目が**何かを言う**ときだけ（時間・場所の経過 /
衝撃 / 回想 / 章の切れ目）。繋がらないカットを演出で誤魔化さない（`SKILL.md` §6）。
**クライマックスはカットだけで繋ぐ。**

## 1. 意味 → key

| 継ぎ目が言うこと | key |
|---|---|
| 時間が経った・場所が変わった（静かに） | `dissolve` |
| 回想・夢・ぼんやり思い出す | `mix`（ぼかしながら溶ける） |
| 別の場所へ**運動として**移る（黒澤の拭い） | `wipe` |
| テンポよく次へ（紹介・解説・MV の拍） | `motion` |
| 強調して寄る・驚き | `zoomIn` |
| 衝撃・記憶の境目・フラッシュ | `whiteFlash`（既定は約 0.4 秒） |
| 緊張・デジタル・不穏 | `rgbShift` |
| 場面を絞って寄せる・開く（目・窓・レンズ） | `x-iris`（同梱） |
| 時間が進む・タイマー・時計の針 | `x-clock`（同梱。時計回りに開く） |
| 窓の日よけ・ブラインド越しに切り替わる | `x-blinds`（同梱） |

**秒数は作品のエネルギーで決める**（HyperFrames 公式の指針）: 静か（ウェルネス・ブランドの物語）
0.5〜0.8 秒 / 中庸（解説・SaaS）0.3〜0.5 秒 / 高い（プロモ・スポーツ・音楽・ローンチ）0.15〜0.3 秒。
`seconds` を省くと 1 秒（Premiere の既定）。`align` は既定の `center`（継ぎ目の中央合わせ）で
よい。素材の余白が片側にしか無いときは、足りないぶんを機械が反対側へ回して尺を保つ。

## 2. 作品全体のルール

- **主役は 1 種類（継ぎ目の 6〜7 割）＋アクセントは 1〜2 種類まで。** 継ぎ目ごとに違う
  トランジションを使うと、様式でなく散らかりに見える（HyperFrames 公式の指針）。
- **反復して初めて様式になる**（`scene-camera.md` §8）。型を決めたら作品を通じて同じ種類・同じ秒数で。
- `whiteFlash` は強い。1 本に何度も使わない（`SKILL.md` §6）。
- 音のクリップ（BGM・ナレーション）には当てられない（断られる）。音の繋ぎは `data-fx-chain` /
  `data-automation`（compositor §11）。

## 3. 手順

1. 継ぎ目の一覧を作る（`timeline_report.py` の出力、または `get_composition_bundle`）。
2. 各継ぎ目に「カット / key / 秒」を決める。決められない継ぎ目は**カット**。
3. `apply_transition(composition_id, target=<継ぎ目の後ろのクリップの id>, key=…, seconds=…)`。
   1 本ごとに新しい版が積まれる。読んだ後に人が触っていれば断られるので、読み直してやり直す。
4. **戻りの `repeated_frames` を読む。** `true` は素材の余白が無く、継ぎ目で既に見せたフレームを
   回し直している（一瞬巻き戻る）。クリップを短くする・余白のある素材にする、のどちらかで避ける。
5. 当てたら**継ぎ目の前後 1 秒を snapshot で見る**（`npx hyperframes snapshot --at <秒>`）。
   `get_composition_bundle` → `hyperframes check --json --at-transitions` → `record_check`
   は compositor §2 のとおり。

## 4. やってはいけないこと

- **継ぎ目の複製クリップを自分で書かない。** 別レーン・`z-index`・素材の開始位置・
  `data-studio-fx-*` を揃えられず、黒に落ちる / 画面から外せない効果になる。
- **同じ継ぎ目に 2 つ重ねない。** 当て直すときは外さずにもう一度 `apply_transition`
  （前の層は置き直す前に片付く）。
- **トランジションで尺を稼がない。** 継ぎ目の演出はクリップの時刻を動かさない（重ねて演じる）ので、
  全体の尺は変わらない。尺が足りないのは別の問題。

## 5. 新しいトランジションを作る

7 種と同梱の 3 種で足りないときだけ。**先に `list_transitions` を引く**（似たものがあればそれを使う）。
作るのは `define_transition`（`key` は `x-slice` 形、`css` は `@keyframes hf-fx-<key>-in` と
`-out` の **2 本だけ**）。**書いた CSS は検査を通らないと何も書かれず、問題は全部まとめて返る。**

**作り方の要点**（根拠は `docs/_research/2026-11-17-hyperframes-custom-transitions.md` §1。
Chromium と WebKit で実測した）:

- **隠す・出すのは `clip-path` で書く。** 入りは入ってくる側の絵を相手の上に重ねて「隠れた状態 → 素の状態」、
  出は出ていく側の絵を「素の状態 → 消えた状態」。`opacity` / `transform` / `filter: blur()` も補間される。
- **`polygon()` は全停止点で頂点数を揃える**（違うと 50% で飛ぶ）。円は `circle()` でなく多角形で
  （Chromium で縁が揺れる）。扇・縞・斜めは、頂点数を固定して座標だけ動かす
  （同梱の `x-clock` / `x-blinds` がその型）。
- **`var()` とカスタムプロパティは使えない**（`mask-image` を `@keyframes` の中で動かしても補間されない）。
- **作れないもの**: 波紋・渦・グリッチのブロックずれ（ピクセル単位の歪み）、JS で作る破片、
  頂点数が変わる形（星のアイリス）。これらは HyperFrames のシェーダー遷移の領域で、今は使えない。
- 作ったら **`apply_transition` で当てて、継ぎ目の前後 1 秒を snapshot で見る**。人も画面の効果タブに
  同じものが並ぶので、名前（`label`）は人が読んで分かる言葉で付ける。

例（左から拭う）:

```css
@keyframes hf-fx-x-slice-in  { from { clip-path: inset(0 100% 0 0) } to { clip-path: inset(0 0 0 0) } }
@keyframes hf-fx-x-slice-out { from { clip-path: inset(0 0 0 0) } to { clip-path: inset(0 0 0 100%) } }
```
