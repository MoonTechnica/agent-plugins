## 1. 動と静の組み合わせ

| 繋ぎ目 | 扱い |
|---|---|
| **止め → 止め** | **既定**。動くカットは静止で始まり静止で終わるように設計し、繋ぎ目は静止部分に置く（Bowen 規則 29） |
| **動き → 動き** | 許されるが、**カメラの向きと速さを揃える**のが条件。揃わないとテンポの段差に見える |
| **止め → 動きの途中**（途中に入る） | 衝撃を狙うときだけ。狙いが無ければ動き出す前の静止コマから入る。**途中に入るほうが、途中で出るより悪い** |
| **動き → 止め** | 受け止める形。動いていた**同じ被写体**が次のカットで止まっていると飛ぶので、被写体が止まるか画面を抜けてから切る（規則 30） |

- **パン・ティルトの向きを繋ぎ目で反転させない**（規則 31）。反転させるのは対立・衝撃を見せるときだけ。
- **場所や時間を跳ばすときは、被写体が画面を抜けきってから切り**、次は空の画から始めて被写体を入れる（規則 34）。
- カメラの動きの加速中・減速中のどこで切るかの定量は、一次資料で見つからなかった。**最も速い部分同士か、
  止まり切った後**の 2 択で設計し、中途半端な減速の途中で切らない。

## 2. 動作の繋ぎ（cut on action）

- **動作の始まり〜 1/3 の所で切る**（Bowen p.146）。知覚実験（Smith）では、動作の始まりに合わせたカットの
  約 1/3 が観客に気づかれなかった。動作が終わってから切ると「待ち」になる。
- **重ねるか飛ばすかは決着していない**: 実務書は 2〜5 コマ重ねる（Bowen / Dmytryk / Bordwell）、
  実験（Hecht & Kalkofen 2009）は約 180 ms 飛ばすほうを観客が好んだ。**±2〜5 コマの範囲で目で合わせる。**
  生成ではダブり（同じ動きが 2 回見える）が起きやすいので、**一致〜少し飛ばす**側から試す。
- **寄りのカットの動きは遅くする**。同じ速さだと寄りのほうが速く見える（規則 25）。
- 立ち上がりは、**目が画面の上端を抜ける前に切る**（規則 24）。

## 3. サイズと角度の進行

- **アクションの最中にロングからアップへ直接飛ばない**。間にミディアム（別角度）を挟む（規則 36）。
  飛ばしてよいのは**衝撃を狙い、かつ人物が誰か既に分かっていて、合わせる動作が少ない**ときだけ。
- 寄り → 引き（逆方向）は、引き → 寄りより許容される。
- **同じ軸で 1 段だけ寄るのは避ける**（ジャンプに見える）。寄るなら角度も変える。同じ軸の寄りを使うなら
  **連続させて「ズームの代わり」**にする（Bowen p.211 の punch-in）。
- 群像でアップが続いたら、**早めに引きへ戻す**（誰がどこに居るかを取り戻す）。
- **ジャンプカットは作品の中で一貫したスタイル**として使う。1 回だけだと事故に見える。

## 4. 軸（180 度）の越え方 —— 4 つのどれかを使う

（Grammar of the Shot p.163。SKILL.md §2.1 の補足）

| 方法 | 中身 | 生成での作り方 |
|---|---|---|
| **カメラが動いて越える** | arc / 回り込みで、越える瞬間を見せる | プリビズで orbit を組んで参照に渡す（`previz` の camera-moves.md §8） |
| **線上のショットを挟む** | 正面か真後ろ（ニュートラル）のカットを 1 枚 | 1 カット足すだけ。最も安い |
| **カットアウェイを挟む** | 手元・物・風景など、軸を持たないカット | 同上。心象風景は生成で最も安定する |
| **被写体が動いて線を引き直す** | 人物が歩いて位置が入れ替わる | 動線を本文に書く |

**何もしないで越えない。** 例外は速いモンタージュで、そこでは軸より**注目点の位置**を優先してよい（§10）。

## 5. match cut —— 2 カットを組で設計する

| 種類 | 揃えるもの | 既定の繋ぎ |
|---|---|---|
| **形・色・構図**（graphic match） | 形・大きさ・**画面上の位置**・色 | 場所・時間が変わるならディゾルブも可。一致が強ければカット |
| **動き**（movement match） | 動きの向き・速さ・画面上の位置 | カット（動作の途中で別の場面へ） |
| **視線**（eyeline match） | 見る人の視線の向きと高さ → 見られる物 | カット。視線が対象に**止まった直後**に切る |
| **音**（sound match） | 同じ音・似た音 | カット + J/L（§8） |
| **意味**（idea match） | 2 つを並べて生まれる第 3 の意味 | カット / ディゾルブ |

1. **事前に設計する。** match cut は後から探して見つかるものではない（Bowen p.147）。**字コンテの段で
   2 カットを組にして書き、両方の構図を同時に決める**。
2. **揃えるのは 1〜2 要素に絞る**（画面上の位置と大きさ、または動きの向き）。全部合わせようとして全部ずれるより強い。
3. **形は画面中央に置く**と一致が読まれやすい。
4. **精密な match は観客を物語から一瞬引き剥がす**（Bordwell）。章の切れ目・時間の跳躍・連想にだけ使い、
   会話の途中に置かない。
5. **一致が強ければディゾルブをカットに格上げできる**（『アラビアのロレンス』のマッチ → 日の出は脚本ではディゾルブ。
   編集の Coates が出ていく側を 2 コマ削ってカットにした）。弱ければディゾルブで補う。
6. 『2001年宇宙の旅』の骨 → 衛星は、Bordwell によれば一致は「かなりゆるい」。**滑らかさではなく衝撃として働く**
   match もある。狙いが「滑らか」か「衝撃」かを先に決める。

## 6. カメラで作る転換（画面が情報を持たない瞬間で繋ぐ）

| 技法 | 成立条件 |
|---|---|
| **ホイップパン** | A の尻と B の頭が**同じ向き・ほぼ同じ速さ**でホイップしている。最も速い部分同士を繋ぐ（規則 39） |
| **被写体で塞ぐ**（natural wipe） | 前景の人・車・柱がレンズ前を横切って画面を一瞬塞ぐ。縦もある（カメラが上昇して天井や枝を抜け、B も上向きの動きで下から出る）（規則 38） |
| **黒に寄る / 黒から引く**（hidden cut） | 暗い背中や物に寄って画面を埋め、次は同じ黒から引いて出る（『ロープ』『1917』） |
| **ピントを外す / 戻す** | 一次資料での手順は未確認。ボケている時間は短く |
| **クラッシュズーム** | 目はズームしないので目立つ。**目立たせたい繋ぎ**にだけ使う |

共通の原理:

1. **前後で運動の向きを揃える**（向き・速さ・回転方向・上下）。
2. **2 カットを組で作る。** どれも「撮る側が意図して用意した素材」が前提。後から編集で作るのは代用。
3. **1 回だけ使うと浮く**。作品の中でモチーフとして複数回使う（規則 38）。
4. 隠しカットは**物語への没入があって初めて隠れる**（『ロープ』の分析）。技術だけで隠そうとしない。

**生成ではホイップ・クラッシュズーム・ディゾルブ・ワイプ・光の転換は編集（タイムライン）で作る**のが既定。
生成に頼むのは各カットの端のブレ（ホイップの入口と出口）まで。詳細は `ai-video-craft` の references/seams.md。

## 7. 視線誘導（eye trace）—— 次の注目点をどこに置くか

| 状況 | 置き方 |
|---|---|
| **カットが速い**（1 秒前後・アクション・サビ） | **注目点を中央か同じ 1 点に固定**。目が探さずに読める（『マッドマックス 怒りのデス・ロード』は約 2,700 ショットをほぼ中央の構図で撮り、速い繋ぎを読ませた） |
| 会話・リアクション | 前のカットの**視線の先**に次の注目点を置く。目が画面を横切る動きがカットを運ぶ |
| 動く被写体の繋ぎ | 前のカットで被写体が**向かっている画面位置**に、次のカットの被写体を置く |
| 不安・混乱を作る | 注目点を前のカットと**反対の隅**へ（意図したときだけ） |

カットの直後、視線は約 360〜400 ms で顔に集まる（Smith）。注目点が画面外へ流れると視線は中央へ戻る。

## 8. 画の不一致を音で縫う

知覚実験（Smith & Henderson 2008）では、**音を消すとカットの見落としがほぼ消えた**。音がカットを隠している。

| 画の不一致 | 縫い方（`audio-engineer` へ依頼） |
|---|---|
| 動作の一致が甘い | 動作音・環境音をカットを跨いで連続させる |
| 軸を越える / 向きが変わる | 次の画の音を先に入れる J カット（音源を見に行く形にする） |
| サイズの大きな跳び | 前の音を残す L カットで、アップに慣れる時間を作る |
| 時間・場所の跳躍 | 次の場面の音を 1〜2 秒先に（sound bridge） |
| 衝撃を**意図**する | 画と音を同時に切り替え、明るさか動きの量の急変と組み合わせる |

## 9. クロスカッティング（2 つの筋を交互に見せる）

| 狙い | A 側の画面方向 | B 側の画面方向 |
|---|---|---|
| 追う / 追われる | 右へ | 右へ（同じ向き） |
| 接近・衝突・合流 | 右へ | 左へ（向かい合う） |
| 救出（締切） | 救う側は前進の向きを一定に | 待つ側は静止か、追い詰められる向き |

- **交互の周期を次第に短くする**（『鳥』のガソリンスタンドは 20 → 18 → 16 … → 8 コマ）。短くなるにつれ寄り、カメラも速くする。
- 別々の場所で撮った 2 人が向かい合う方向で交互に見せると、**存在しない連続空間**が知覚される（Levin & Simons）。
- 同じ向きの動きを交互に見せると「同じ場所」に見えやすいので、**両側に確立ショットか色・光の差**を持たせる。
- 電話など離れた 2 か所の会話は、**画面の反対側から空いた画面を横切って見合う**構図にする。

## 10. 迷ったときの優先順位（Murch の Rule of Six）

**感情 > 物語 > リズム > 視線誘導 > 画面上の向き（軸） > 3D 空間の連続** の順で守り、下位から捨てる
（「感情より先に物語を捨てるな…」）。カメラ側の文法（軸・30 度・動作の一致）は下位の 2 つにあたる。

- **感情的に正しい瞬間で切り**、下位の不一致は §4（ニュートラル・カットアウェイ）と §8（音）で縫う。
- 生成で起きる典型の失敗は逆向き: **動作の一致を取るために、感情の瞬間からずれた位置で切る**。
- 視線誘導は軸より上。**速い繋ぎでは注目点の位置を揃えるほうを取り、軸は崩してよい。**
- 比率（51 / 23 / 10 / 7 / 5 / 4）より**順序**を規則として使う。

## 11. 検査表（カメラが動くカットが隣り合うとき）

| # | 見ること | 落ちたら |
|---|---|---|
| A | 繋ぎ目は「静→静 / 動→動 / 静→動 / 動→静」のどれか。それは狙いどおりか | 静止の頭・尻を残して切り直す / 狙いを書く |
| B | 動→動なら、カメラの**向き**と**速さ**が揃っているか（ホイップは最速部分同士か） | 片方の動きを書き直す |
| C | 同じ被写体が「動」→「止」になっていないか | 被写体が止まる / 抜けるまで待つ |
