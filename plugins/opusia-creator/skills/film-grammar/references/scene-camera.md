# シーン全体・作品全体のカメラ設計

## 1. 作品ごとにカメラの規則を先に書く（3〜6 行）

**規則が無いと、全シーンが「なめらかな前進ドリー」に収束する。** 撮影監督は撮る前に
「このカメラはこう振る舞う」を決めている（Lubezki:「芸術は制約からできている」）。

| 決める軸 | 例 |
|---|---|
| 支持具 | 手持ち / 固定 / スライダーとドリーだけ / ステディカム |
| レンズ帯 | 広角 1 本（Children of Men はほぼ 18mm）/ 標準 / 望遠で観察 |
| 寄りの扱い | 「アップはほぼ使わない」/「アップは頂点だけ」 |
| 視点 | POV を使わない / 主人公から離れない / 観察者に留まる |
| 構図 | 正面・左右対称（Wes Anderson）/ 低い固定（小津）/ 一点透視（Kubrick） |
| 動きの動機 | 「人物が動いたときだけ動く」/「感情が変わったときだけ寄る」 |

- **規則は否定形でよい**（「POV を使わない」「クロースアップをほぼ使わない」。Children of Men の規則）。
- **速く切る作品なら「主要な要素を画面中央に置く」を規則に入れる**（『マッドマックス 怒りのデス・ロード』。
  cut-to-cut.md §7）。
- 書いた規則は**タイムラインの企画（作品の 1 行）と一緒に残し**、全シーンの字コンテがそれに従う。

## 2. 規則を変える点を 1〜2 か所だけ決める（camera arc）

規則が途中で変わった瞬間は、**物語の転換として読まれる**。

| 作品 | 変化 |
|---|---|
| 『Mommy』 | 1:1 の画面が、主人公が解放される場面で横に広がる |
| 『ジョーカー』 | 固定 → 手持ち → 終盤はクレーン（人物の変化に合わせて支持具が変わる） |
| 『グランド・ブダペスト・ホテル』 | 時代ごとにアスペクト比を変える |

- **破るのは作品で 1〜2 回まで**。何度も変えると規則が無いのと同じになる。
- 生成では**アスペクト比は書き出し時にしか変えられない**ので、支持具（固定 → 手持ち）・レンズ帯・
  寄りの解禁で変化を作るのが現実的。

## 3. シーンの弧 —— 引きで始め、寄りながら短く、最後に少し引いて長く

実測（Cutting 2016。ハリウッド映画のショットを計測）:

- シーンは**引きで始まり、寄りながらショットが短くなり、最後にまた少し引いて長くなる**。
- **ショットサイズの寄りはシーンごとに起きる現象**で、作品全体で「だんだん寄る」のではない。
- **クライマックスではショットが急に短くなり、ディゾルブとフェードが最も少ない**。

→ **寄りの弧はシーンごとに 1 回描く。** 作品全体の盛り上がりは、シーンの弧の振れ幅（どこまで寄るか・
どこまで短くするか）で作る。

## 4. 最大の寄りは頂点のために取っておく

- **クロースアップは「本気で意味するとき」だけ**（Deakins。『ハッド』は寄りが約 6 カットしかない）。
  序盤で使うと、山場で打つ手が無くなる（SKILL.md §1「アップを最初に使わない」）。
- **見せないことは寄りの究極の取り置き**。恐怖や謎は、対象を見せずに作る（『ジョーズ』のサメ）。
- 対話では、**左右を固定**し（単独の寄りでもそれぞれの側に寄せる）、**左右対称の 2 ショットは休戦・転回の
  瞬間にだけ置く**。応酬の間は肩なめと単独の寄りで切り返す（『ソーシャル・ネットワーク』）。

## 5. 撮り方を 1 つ選ぶ（シーンごと）

実写のカバレッジ（マスター + 寄り + 切り返しを全部撮って編集で選ぶ）は、生成では費用がそのまま
増えるので使えない（`genre-playbook` の drama-film.md §2）。**選ぶのは撮り方そのもの**:

| 撮り方 | 向くとき | 生成での作り方 |
|---|---|---|
| **切り返し**（2 ショット → 肩なめ → 単独の寄り） | 対話・対立。誰に寄るかで「誰の物語か」が決まる | 1 パスの multi-shot。毎ショット左右を書く（`ai-video-craft` の references/seams.md §3） |
| **2 ショットで受ける** | 関係そのものを見せたい。台詞と芝居が通っている | 1 カット。**台詞が通っているなら切らない** —— カバレッジは使う義務ではない |
| **1 カットで構図を作り直す**（人物が動いて構図が変わる） | 移動・登場・関係の変化 | プリビズで動線とカメラを組む（`previz` の camera-moves.md §8.5） |
| **遅れて場所を見せる** | 謎・没入。ディテールから入る | 寄りから入り、2〜3 カット以内に場所が分かる引きを入れる（§7） |

**長回しは「途切れなさ」が何を意味するかを 1 文で書けるときだけ**（実時間・逃げ場の無さ・そこにいる感覚）。
生成では 1 回の尺に上限があるので、長回しに見せるなら転換を隠して繋ぐ（cut-to-cut.md §6）。

## 6. シーンごとに視点を 1 つ決める

| 視点 | 中身 | カメラの振る舞い |
|---|---|---|
| **主観** | 人物の目そのもの（POV） | 「見る人 → 見えるもの → 反応」の往復でだけ使い、短くする |
| **付き従う** | 人物から離れず、人物が知ることだけを見せる | 人物の動きに同期して動く。POV にはしない（Children of Men は POV 無しで主人公から離れない） |
| **観察者** | 距離を置いて見る | 固定・引き・望遠。人物の目の高さに入らない |
| **全知** | 誰も知らないことを観客にだけ見せる | サスペンスに使う（direction-design.md §4） |

**「主人公に付き従う」と「主人公の目」は別の手段。** 前者は主観を強めつつ人物の顔を見せ続けられるので、
生成でも扱いやすい（POV の切り返しは視線の一致が崩れやすい）。

## 7. シーンの入りと出

| 入り方 | 使いどころ |
|---|---|
| **確立ショット（引き）** | 既定。場所・時間帯・誰が居るか |
| **遅れて確立する**（ディテール → 引き） | 謎・没入。**省いてはいけない**。2〜3 カット以内に引きを入れる |
| **中間の空間から入る**（無人の場所・空・物） | 前の場面の余韻を残す（小津の「中間の空間」）。場所をあまり明確にせず、韻で前後を結ぶ |
| **移動で入る**（人物が画面へ入る・カメラが入っていく） | 勢いを受け渡す |

| 出方 | 読まれ方 |
|---|---|
| 引いて終える（T.B / crane up） | 終止・孤立・状況 |
| 寄ったまま次へ持ち越す | 感情を次の場面へ運ぶ |
| 人物が画面を出ていく | 場面の終わり。出た方向と次の入りの方向を揃える |
| 物・音を残す | 次の場面の伏線・韻 |

**最初のショットには後で回収するモチーフを置き、最後のショットでそれを変形して返す**（ブックエンド）。

## 8. シーン間の転換 —— 時間・空間・意味の関係

SKILL.md §6（カット / ディゾルブ / フェード / ホワイトアウト）に、次を足す。

| 転換 | 時間 | 空間 | 意味 |
|---|---|---|---|
| **match cut**（形・動き） | 大きな跳躍も可 | 別 | 「同じもの」「連想」（cut-to-cut.md §5） |
| **音の先行**（pre-lap / sound bridge） | 次を先取り | 次を先取り | 期待・不安・内面。**音で 2 つの場面を同一視**させることもできる（『地獄の黙示録』の天井の扇風機とヘリの羽音） |
| **ワイプ** | 経過 | 別の場所へ | 転換を**運動として**見せる（黒澤） |
| **中間の空間**（無人のカット） | 休止 | 曖昧 | 前後を韻で結ぶ（小津） |
| **軸上の寄り・引きの連続**（axial cut） | 連続 | 同じ | 強調（黒澤『七人の侍』の村人の超ロング → 近く → さらに近く） |
| **動きで繋ぐ** | 連続感 | 別 | 前の出の動きと次の入りの動きを同じ向き・速さに |

- **クライマックスはカットだけで繋ぐ。** ディゾルブ・フェードは導入と、筋が絡む中盤に回す（Cutting 2016）。
- **同じ繋ぎでもディゾルブは「経過」、カットは「衝撃・連想」**。一致が強ければカットのほうが強い。
- **転換の型は作品を通じて反復して初めて様式になる**（黒澤のワイプ・今敏の match cut・小津の中間の空間・
  Edgar Wright のホイップ）。1 回だけの奇抜な転換は事故に見える。**型は §1 の規則に含める**。
- **意図した転換は字コンテの段で 2 カットを組にして設計する**（Edgar Wright はほぼすべての転換を
  絵コンテで決めている）。後から効果で繋ぐと「繋がらないカットを効果で誤魔化す」になる。

## 9. 尺はなだらかに変える

- 実測（Cutting 2010）では、**隣り合うショットの長さは互いに相関している**（急に変わらない）。
  **尺の急な段差は頂点と衝撃にだけ**使う。
- 加速したいときは等比的に詰める（『鳥』のガソリンスタンドは 20 → 18 → 16 … → 8 コマ）。
- 作品全体の平均カット長は形式の実測に合わせる（SKILL.md §4、`screenwriter` の references/cut-timing.md）。

## 10. 設計の手順（チェックリスト）

### 作品（タイムライン）単位 —— 1 回だけ

- [ ] カメラの規則を 3〜6 行で書いた（§1）
- [ ] 規則を変える点を 1〜2 か所だけ決めた（§2）
- [ ] 転換の型を 1 つ決めた（カット主体 / ワイプ / match cut の連鎖 / 中間の空間 / ホイップ）（§8）
- [ ] 最初のショットに後で回収するモチーフを置いた（§7）

### シーン単位

- [ ] 視点を 1 つ決めた（§6）
- [ ] 撮り方を 1 つ決めた（§5）
- [ ] 頂点のカットを 1 つ決め、最大の寄りはそこまで使わない（§4）
- [ ] 対話なら左右を固定し、左右対称の 2 ショットを置く瞬間を決めた（§4）
- [ ] 尺の弧: 頭は引きで長め → 中盤は寄りで短く → 尻は少し引いて長め（§3）
- [ ] 動かすカットは動機（人物の動き / 感情の変化）があるものだけ。規則で禁じた動きを使っていない（§1）
- [ ] 入りと出を決め、次のシーンへの転換の種類と、それが伝える関係を書いた（§7・§8）
- [ ] クライマックス区間でディゾルブ・フェードを使っていない（§8）
