# 演出の設計（direction design）—— 目的 → 候補 → 外す条件

企画（①）と字コンテ（④）の前、そして「盛り上がらない」「散らかって見える」「技法が目に付く」と
言われたときに開く。**演出は技法を当てる仕事ではなく、4 段の判断**:

```
① 作品の 1 行の狙い（観客に最後にどう感じてほしいか）
② シーンごとに「観客の感情を A から B へ」と「なぜ今このシーンか」
③ その移動に効く技法の候補（§1 の表）
④ 外す条件の確認（直前で同じ手を使っていないか / 情報が立っているか / 技法が見えないか）
```

**「この時は必ずこうする」とは書かない。** 候補と、外す条件だけを書く。優先順位がぶつかったら
Murch の重み（感情 51 / 物語 23 / リズム 10 / 視線 7 / 2D 5 / 3D 4）で**下から捨てる**。

目次: §1 目的 → 候補 → 外す条件（総表）/ §2 緊張曲線 / §3 対比・反復・モチーフ / §4 情報の制御 /
§5 視点 / §6 隣り合う 2 カットと場面転換 / §7 色・光・象徴 / §8 トーン / §9 日本のアニメの手 /
§10 生成で効く技法・難しい技法 / §11 検査

出典は `docs/_research/2026-10-01-direction-design-principles.md`（Lumet『Making Movies』、Mamet、
Hitchcock–Truffaut、Murch、Bordwell & Thompson、Eisenstein / Kuleshov、Eggleston、Bong Joon-ho と
『パラサイト』編集者、出崎統・富野由悠季・新海誠・高畑勲の発言、Pixar のストーリー原則ほか）。

## 1. 目的 → 候補 → 外す条件（総表）

| 目的 | 候補 | 外す条件 |
|---|---|---|
| **感情**を動かす | 視点人物の近さ（§5）/ 対比の落差（§3）/ 色の推移（§7）/ 休符（§2）/ 心象風景（§9）/ 音の先行・無音（`audio-engineer`） | 直前のシーンで同じ手を使った / 情報がまだ立っていない |
| **情報**を渡す | 確立ショット（`SKILL.md` §5）/ サスペンスとして先に見せる（§4）/ 無人の繋ぎカット（§9）/ 字幕 | 対比・衝突と同じカットに載せない（情報が読めなくなる） |
| **リズム**を作る | 尺の揺らぎ（`SKILL.md` §4）/ 拍（`beat-sync.md`）/ 動きを収める・収めない（§2）/ Rule of three（§3） | 等間隔 / 全カット同じ終わり方 |
| **意味**を生む | 衝突モンタージュ（§6）/ match cut（§6）/ モチーフの回帰（§3）/ 象徴（§7）/ 上手・下手の反転（§5） | 作品に数回。短尺・縦型では情報密度に負ける |

**検査の一般形**: この技法を外しても、観客の感情・情報・リズム・意味のどれかが欠けるか。
欠けないなら外す（Bresson「美しい画像ではなく、必要な画像を」）。直前の 3 カット / 3 シーンで
同じ技法を使っていたら別の候補へ。**技法が目に付いたら失敗**（Lumet「良い様式とは見えない様式」）。
**最初に思いついた案は捨てる**（Pixar #12。「悲しい → 雨」は既定値であって選択ではない）。

### 設計単位ごとに決めること

| 単位 | 1 行で決めること | 受け皿 |
|---|---|---|
| 作品 | **最後の 1 カットを見た観客の状態**（ログラインは筋の要約で、感情の着地が無い） | 企画書（`genre-playbook` §2.5） |
| シークエンス（10〜15 分） | その区間だけの**緊張の問い**（「この 10 分で分かるのは ___ か」） | ハコ書き |
| シーン | 誰が何を欲し / 得られないと何が起き / **なぜ今か** + **観客の感情 A → B**（人物側の転換とは別物） | `scene-writing` §4 |
| カット | **このカットで観客に何を見させるか**（「medium close-up」は答えで、問いはこちら） | `cuts.shot` |

Lumet の『十二人の怒れる男』は「部屋が狭まっていく」という 1 行から、レンズ（広角 → 望遠）と
カメラ高（上 → 目線 → 下）を**作品全体の筋書き**として決め、最後の屋外だけ最広角・最高位置で
息をさせた。**作品単位の推移を先に決めると、シーン単位の判断が揃う。**

## 2. 緊張曲線（tension curve）

| 狙い | 候補 | 外す条件 |
|---|---|---|
| 緊張を**上げる** | 試みの前提を変えて段を踏む（`scene-writing` §8）/ **動きが収まる前に切る** / 情報を観客に先に渡す（§4）/ 音を止める・先に出す | 「収まる前に切る」を全編でやると「ずっと忙しい」。山場の手前の 1〜2 シーンに限る |
| 緊張を**保つ** | 同じ高さで続けない。小さな解放（笑い・小さな勝ち）を挟んで次の段へ | 短尺（3 分以下）は解放を挟む尺が無い → 表情 1 カット |
| 緊張を**解放する** | 動きを収めてから切る / 引き（T.B・crane up）/ 無音のあとに環境音 / 色を開く | 解放の直後にまた解放を置かない（平坦になる） |
| **休符**を置く | 山の直前に動きと音を止める。長さは**山の高さに比例**（短尺 1 秒未満、長尺はカットを伸ばす） | 状況が言葉で立っていない所に置くと「置いていかれた」 |
| シークエンスに**問い**を立てる | 10〜15 分の塊ごとに 1 つ | 短尺・MV は作品全体で 1 つ |

- **速さと緊張は別物。** 落ち着かないのは「カットが短い」からではなく「動きが収まる前に切られる」
  から（Bordwell）。平均 1.6〜1.9 秒でも酔わない作品がある。**緊張を上げたいときの既定は
  「短くする」ではなく「収めてから切るか、収める前に切るか」の選択**
- 緊張は段を踏んで上げる（rising）。同じ高さで続く（static）・段を飛ばす（jumping）は失敗（Egri）。
  「盛り上がらない」と言われたら、構成の型を当てる**前に**どの段が static / jumping かを見る
- MV は曲の区間が曲線そのもの（`beat-sync.md` §7 の密度表が代用）

## 3. 対比・反復・モチーフ

| 狙い | 候補 | 外す条件 |
|---|---|---|
| 山場を**立たせる** | 直前のカットを山場と**同じ軸の反対側**に（静 → 動、無音 → 音、引き → 寄り、寒色 → 暖色） | 同時に 2 軸以上変えない。毎シーンでやると落差が常態化する（**作品に 2〜3 回**） |
| 2 人 / 2 つの筋を**比べさせる** | パラレリズム（同じ構図・同じ動作を別の人物で） | 比べる軸（勝ち / 負け など）が無いなら並べても何も起きない |
| 作品を **1 本に繋ぐ** | モチーフ 1 つ（`scene-writing` §17）。初出・中間・終盤の 3 回、**終盤は意味が変わっている**（割れた湯呑み → 継いだ湯呑み） | 3 回とも同じ意味なら水増し。4 回以上は押し付け |
| **終わった**と分からせる | ブックエンド（Opening / Final Image の対）。同じ構図で**何かが違う** | 何も違わない対は「戻っただけ」 |
| 笑わせる / 怖がらせる / 回収する | Rule of three。2 回で型を作り、3 回目で裏切る。**3 回目が同じなら 1 回でよかった** | 短尺は 2 回目で裏切ってよい |

**対比は「同じ軸の両端を隣に置く」ときだけ効く。** 軸が違う 2 つを並べても対比にならない。
**反復は「同じものが、意味を変えて戻ってくる」こと**（Bordwell & Thompson）。同じ意味のまま
戻すのは水増し。情報を渡すカット（確立ショット・説明）で対比を狙わない。

## 4. 情報の制御（誰が何を知っているか）

毎シーンで 3 択を**選ぶ**。Hitchcock の「観客には知らせる」は既定であって、**どんでん返しそのものが
見せ場のときは例外**と本人が言っている。

| 狙い | 選ぶもの | 外す条件 |
|---|---|---|
| 同じ尺の会話を**緊張として保たせたい** | **サスペンス**（観客 > 人物。爆弾・期限・持ち物・相手の嘘を先に見せる） | 短尺は「待たせる」尺が無い → フックで見せてすぐ出す |
| **一撃**で終わらせたい / どんでん返しが売り | **サプライズ**（観客 = 人物。突然）。**作品に 1 回**。直前まで観客の知識を人物と同じに制限する | 連発すると観客が「どうせ裏がある」と構え、サスペンスが作れなくなる |
| 観客に**探させたい**（謎解き・ホラー） | **ミステリー**（観客 = 人物。問いを明示し、手掛かりを植える） | 答えを出さない問いを積まない |
| 人物の無知を**痛ましく / 可笑しく** | **dramatic irony**（観客が人物より知っている）。事実を観客に見せてから、知らない人物の行動を撮る | 知った直後に人物も知ると irony は生まれない。**知ってから知るまでの距離**を取る |
| **伏線** | 植える → 2 回目で同じ意味のまま見せる → 回収（§3 の Rule of three）。回収は植えた物で | 回収しない物を目立たせない。**偶然で窮地に入れるのはよいが、偶然で救わない**（Pixar #19） |

- 知識の**範囲**（誰より多く知るか）と**深さ**（内面にどこまで入るか）は別の軸。ホラー・ミステリーは
  範囲を制限（人物と同じだけ）、ドラマは非制限で irony を作る
- **情報の設計はカメラを縛る。** 人物が見ていない物を観客に見せた時点で非制限になる（§5）

## 5. 視点（誰の目で見せるか）

| 狙い | 候補 | 外す条件 |
|---|---|---|
| **誰のシーンか**を決める | シーンの頭で視点人物を 1 人決め、**その人物の「見る」カットを最初に置く**。切り返しはその側を長く | 群像・対等な対決では意図して均等に配る。「決めていない」と「均等にした」は別 |
| 観客を**肩入れ**させたい | その人物の目線の高さ・近いサイズ・POV を 1 回 | 悪役に肩入れさせたくないなら悪役の POV を撮らない（撮ると同情が移る。『サイコ』の沼） |
| 観客を**突き放したい**（滑稽・無力・客観） | 引き・俯瞰・ドア枠や前景越し・固定 | 突き放したまま山場に入ると感情が乗らない。山場の前に 1 度は寄る |
| 内面を**見せたい** | 「見る → 見える物 → 反応」の 3 点（Hitchcock「最も純粋な映画的発想」）。**見える物を選ぶ**（犬なら善人、半裸の女なら好色爺。反応の顔は同じでよい） | 「不安そうな顔」を指示しない（内面は撮れない）。顔ではなく**見ている物**を変える |
| 優劣・攻守を**画面の左右**で | 上位 / 攻める側を上手（右）、下位 / 守る側を下手（左）。逆転の瞬間に入れ替える | 入れ替えはイマジナリーラインの跨ぎと同じ事故に見える → 跨ぐ瞬間を見せる（`SKILL.md` §2.1） |
| 進む・抗うを**移動の向き**で | 作品内で「進む方向」を 1 つ決めて守る。二次資料による富野『映像の原則』の要約では、右 → 左（上手 → 下手）= 流れに従う・行く、左 → 右（下手 → 上手）= 上手の強者に逆らう・挑む。移動の向きを揃えると短く感じ、混ぜると長く感じる | 左右の意味は普遍の法則ではない（実証研究では左右差が出ていない）。**作品内の記号**として一貫させるときだけ効く |
| 視点の**一貫性** | 1 シーン 1 視点人物。変えるなら場所か時間が変わるとき | 1 シーン内で視点を往復させると、誰の感情を追えばよいか分からなくなる |

**カメラの位置が同情の方向を決める。** 「引きから寄りへ」（`SKILL.md` §1）の**誰に寄るか**は
ここで決まる。画面内の大きさは重要度に比例（Hitchcock's Rule。`previz` camera-moves §7）。
生成では「見る人 → 風景 → 反応」が最も安全な 3 点（人物同士の切り返しは視線の一致が崩れる）。

## 6. 隣り合う 2 カットの関係と、場面転換の意味

隣り合う 2 カットは **連続（linkage）/ 対比（§3）/ 衝突（collision）** のどれか。`SKILL.md` §2〜3 は
連続（繋がる条件）の話で、ここはそれ以外。

| 狙い | 候補 | 外す条件 |
|---|---|---|
| 隣り合うカットで**第 3 の意味**を生む | 無関係に見える 2 カットを隣接（人物 × 物 / 出来事 × 自然 / 行為 × 比喩）。Kuleshov の 3 点に組み込む | **作品に数回。** 連発すると「何の場面か分からない」。確立ショットの代わりにはならない |
| **概念**を語る | 比喩のカットを 1 枚挟む | 短尺・縦型は情報密度に負ける。長尺の山場に限る |
| 場面転換で**「同じ」**と読ませる | match cut（形・動き・色のどれか 1 つを揃える） | 揃えるものが曖昧だと「繋がらないカット」。生成では形より**色・動きの方向**が揃えやすい |
| 場面転換で**「逆」**と読ませる（皮肉・落差） | smash cut。音も一緒に切る | 真面目な場面の直後はトーンが壊れる（§8）。コメディか、破る意図があるとき |
| 場面転換で**期待 / 不安**を作る | sound bridge（次の音を 1〜2 秒先に。J カット） | 何の音か読めないと不安ではなく混乱 |
| 時間経過・章の切れ目 | ディゾルブ / フェード（`SKILL.md` §6） | — |

**「迷ったらカット」（`SKILL.md` §6）は正しい既定。** 効果を付けるのは、上の表のどれを狙うかを
理由付きで言えるときだけ。

## 7. 色・光・象徴

| 狙い | 候補 | 外す条件 |
|---|---|---|
| 作品全体の**感情の起伏を色で** | カラースクリプト（`art-director` visual-design §2）を**緊張曲線（§2）の節目で変える**: 日常は彩度を抑え、山場は彩度か明度を離し、決着後は戻るが**同じ色には戻さない**（§3 のブックエンド） | 12 シーン超は 2 枚に。MV は区間ごと |
| **1 色に 1 つの意味** | 人物・場所・物のどれか 1 つに色を固定し、意味が変わる瞬間に色を変える | **作品で意味を持つ色は 1〜2 色。** 全要素に振らない |
| **象徴物**を置く | `scene-writing` §17 の「繰り返す物」を**人物の動作のついでに**映す。**寄るのは回収の 1 回だけ** | 毎回寄る / 象徴物だけのカットを連発する / 台詞で説明する。**「これは象徴だ」と見えた瞬間に効果が消える**（McKee）。Bresson「考えを隠せ、ただし見つけられるように」 |
| **光の推移**で状況の変化を語る | 同じ場所の 2 シーンで光の向き・硬さ・色温度のどれか 1 つを変える | 同じシーン内では変えない（連続性が優先） |
| **天候・季節**で心情を | 一致させるか、**わざとずらす**か選ぶ | ずらすのは作品に 1 回。毎回ずらすと皮肉が常態化する |

カラースクリプトは「感情の起伏を色で書いた作品の要約」（Eggleston）。生成では**色・光・天候が
最も確実に効く演出変数**（表情より安定）。象徴物は手に持たせず、机・床・背景に置く。

## 8. トーン（作品が題材に向ける態度）

| 狙い | 候補 | 外す条件 |
|---|---|---|
| トーンを**決める** | 企画書に 1 語（乾いた / 温かい / 冷笑 / 真顔の滑稽）。**冒頭 1 シーンで観客に教える**（短尺ならフック 3 秒） | 「コメディ」はジャンルでトーンではない |
| トーンを**保つ** | 台詞と芝居（口調）は固定。調整は `shot`（寄り / 引き）・尺・音・色（Bong「芝居はジャンルで変えない。変えるのはカメラと編集」） | ジャンルが変わる場面で口調を変えない |
| トーンを**気づかれずに移す** | 予兆を 3 回。1 回目は背景、2 回目は音、3 回目で本番（『パラサイト』の「小雨でコートが濡れたのに気づかない」） | 短尺は移す尺が無い → 最初から両方の約束をする |
| トーンを**破って落差を作る** | 解放（笑い・安堵）の直後に緊張。音を先に切る。**笑わせた直後が最も怖がらせやすい** | 真面目一辺倒の作品で 1 回だけやると事故に見える。やるなら冒頭で「この作品は破る」と約束しておく |
| 不一致を**検査する** | 隣り合うシーンの終わり / 始まりの感情を並べ、「解放 → 解放」「予兆無しの別種の緊張」が無いか | — |

ホラーの中の笑い・コメディの中の真剣は「緊張と解放」の同じ機構。怖い場面に怖い音楽を敷くと
観客が構える（音が先に答えを言う）。

## 9. 日本のアニメの手（主観的な時間）

| 狙い | 候補 | 外す条件 |
|---|---|---|
| 人物の中で**時間が止まる瞬間** | 止め絵（`static shot, subtle motion only`）+ ゆっくりの寄りかパン。ハーモニー調は画風指定で | **出来事を伝える所で止めない**（「何が起きたか」が飛ぶ）。1 シーンに 1 回 |
| 同じ瞬間を**強調して反復** | 三回パン（3 サイズで 3 カット、同じ動き） | 作品に 1〜2 回。多用すると様式が前に出る。生成では 3 カット = 3 倍の費用 |
| 顔を映さずに**感情**を | 空・光・窓・無人の部屋（新海の心象風景）/ 日常の行為を長く（高畑）/ 無人の繋ぎカット（庵野） | 状況が立っていない所に置くと「置いていかれた」。縦型は 3 秒上限 |
| 止め絵を **3 秒超**見せる | 画の中で 1 つ変える（光が差す・音が入る・じわ寄り） | 変化無しの 3 秒超は遅滞（富野「静止画は約 3 秒で読み終わる」） |
| 動きを**速く見せる** | 前に溜め、後に止め（タメ → 決め → 止め） | 全カットでやると「全部が決め」になり、決めが無くなる |

止め絵・ハーモニーは**主観的な時間を作る装置**（出崎「瞬間の美を残したい」）であって、尺を稼ぐ
道具ではない。心象風景は**生成で最も安定する演出**（人物・手指・文字が無い）。

## 10. 生成で効く技法・難しい技法

| 技法 | 生成での効き | 理由 |
|---|---|---|
| 情報の制御（§4） | **効く** | カットの**順番**の問題。生成費が増えない |
| 対比（§3） | **効く** | 光・色・サイズはプロンプトで最も安定して効く変数で、それがそのまま対比の軸 |
| モチーフ（§3・§7） | **効く（物に限る）** | 物 1 つを毎カットの `note` に書けば出る。**人物の変化をモチーフにするのは難しい**（同一性の揺れと区別が付かない） |
| 心象風景（§9） | **最も安定** | 人物・手指・文字が無い |
| 色と光の推移（§7） | **効く** | 時間帯・光の向き・色温度はプロンプトで指定でき、背景シートで担保できる |
| 音による緊張・解放・J / L カット | **効く（費用ゼロ）** | タイムラインで後から変えられる唯一の層 |
| 場面転換の意味づけ（§6） | **半分** | smash と sound bridge は無料。match cut は形を揃えにくい → 色か動きの方向で |
| 衝突モンタージュ（§6） | **効く（並べ替えは無料）** | ただし「挟む物」は生成前に撮っておく |
| 視点の 3 点（§5） | **風景なら効く / 人物の切り返しは崩れる** | 「見る人 → 風景 → 反応」は安定。顔同士は視線の一致が崩れる |
| 止め絵・溜め（§9） | **指示が要る** | モデルは常に動かす |
| 長回しの緊張（§2） | **不可** | ネイティブ尺を超える 1 カットは作れない → カットを割って積む |
| 微細な表情の反応 | **出にくい** | 反応は顔ではなく**動作・物・音**で（手が止まる・湯呑みを置く・水音が止む）。Kuleshov 以来「反応カットの顔は無表情でよい」が原理なので、制約への妥協ではなく正しい形と一致する |
| 象徴物を手に持たせる | **避ける** | 手指の破綻。机・床・背景に |

**編集で変えられる層と、生成時に確定する層を分ける。** 順番・尺・音・転換・色補正は後から変え
られる（費用ゼロ）。**サイズ・角度・POV・動き・光の向き**は生成時に確定する。迷った技法が前者なら
後回しにしてよく、後者なら絵コンテの前に決める。意図した技法が成立したかは `cinematographer` §3.6 のとおり
コンタクトシートを自分の目で見て確かめる。
