# カメラを選び、文字コンテから絵コンテ・プリビズへ渡す

用語の定義と英語表現は [shot-vocabulary.md](shot-vocabulary.md) §3–4 が正本。
ここは選択・組み合わせ・引き継ぎの判断。用語を知っているだけで使用したことにしない。

## 1. 目的から選ぶ

| 狙い | 候補 | 外す条件 |
|---|---|---|
| 人物とその場にいる感覚 | 控えめな手持ち、人物と同期する追い | 顔・商品・文字の読みやすさが主役なら揺れを弱める |
| 歩く本人の目線 | POV の移動＋歩調由来の揺れ | 頭の変位をそのまま誇張しない。視線の安定も設計 |
| 立ち止まった主観 | 小さな重心移動＋呼吸 | 歩行の揺れを残さない。完全固定の指定と混ぜない |
| 衝撃・着地・反動 | 原因の瞬間だけ揺らし減衰 | 全尺を同じ周期で揺らさない |
| 人物・建物の立体を見せる | 注視する回り込み＋前景の視差 | 背景が無いなら回り込む効果が乏しい |
| 位置を変えず視線を移す | Pan / Tilt | 視差や被写体の裏側を見せたいなら位置を移す |
| 場所の規模・人物の小ささ | 後退上昇・真俯瞰の上昇 | 情報を明かす前に景色全体を見せない |
| 隠れた景色を明かす | 障害物からの上昇・横移動、稜線越え | 何に隠れ、いつ何が現れるかを定義できない |
| 飛行の身体感覚・速度 | 地形沿いの低空移動・バンク・急降下からの引き起こし | 単なる風景紹介なら安定した空撮が候補 |

候補を全部使わない。場面の狙いに合うものを選び、明示されたユーザーの希望を
「固定が既定」という一般論で消さない。

## 2. 主要軌道と補助動作を分ける

カメラ設計を **位置の経路 / 向き・注視点 / 画角 / 揺れ / 時間** に分ける。
主要な移動1つに、必要な補助動作を足す。複合軌道は一貫した目的と終点を持たせる。

- 歩行主観: 前進を主軌道、歩調の上下動・低速の横揺れ・小さな呼吸を補助にする。
  歩き出し・停止で歩行成分だけを滑らかに増減し、停止後は呼吸・重心移動が残る。
- 手持ち撮影: 人物の目ではなく撮影者のカメラ。呼吸・足音・移動を人物と機械的に同期させない。
- 回り込み: 注視点を固定するか、向きを世界座標で固定するかを決める。
  Arc は部分円弧にも使うので、名称から360度を推測しない。
- 空撮: 高さ・半径・速度・注視点・水平保持を独立に決める。
  後退上昇や螺旋上昇は一貫した複合軌道で、無関係な動きの羅列とは違う。
- FPV: バンクを姿勢として経路に連動させる。手持ちノイズを加えるだけで FPV にしない。
- レンズ: ドリーとズームを混同しない。ドリーズームなら対象の画面内サイズを一定にする。

揺れを実装する場合は振幅（m / 度）・周期（Hz / 歩調）・位相・発生時刻・減衰・
ローカル軸か世界軸かを決める。数値はショットのレンズ・距離・画面で調整する演出値で、
一律の「人間らしい正解値」は無い。生成用の文章は読み取れる動きと強さを短く残す。

## 3. 文字コンテに保存する

`shot` に英語で **サイズ・視点＋主要軌道＋注視・姿勢条件＋必要な揺れ**を書く。
`note` に **動機、開始構図→経路→終了構図、きっかけと停止、見せる対象、音**を書く。
撮影時に初めて思いつく指示にせず、絵コンテを描く前からカットに持たせる。

| 例 | `shot` | `note` に残す演出 |
|---|---|---|
| 歩行主観 | `wide shot, first-person tracking shot, subtle head bobbing, camera sway and breathing motion, stable forward gaze` | 廊下を歩く。扉を見つけて止まる。停止に合わせ歩行の揺れが収まり、呼吸だけ残る。SE:接地 |
| 中心を注視して回る | `medium shot, 90-degree orbit around the subject, maintaining subject lock and a level horizon` | 人物の正面から側面へ回り、背後の扉を明かす。人物を中央に保持。上から見た回転方向も指定 |
| 向きを保って円周移動 | `wide shot, circular dolly through a 90-degree arc, maintaining a fixed world-space orientation` | 円の中心へ向き直らない。遠方の同じ方角を向いたまま前景が流れる |
| その場で左右を見る | `wide shot, pan right, camera position fixed` | 同じ位置から顔を右へ向ける。位置は動かさず、最後に扉を捉えて止まる |
| 人物から空撮へ | `wide shot, dronie, ascending backward while keeping the person in frame, level horizon` | 崖の人物から後退上昇。終点で海岸全体が見え、人物が小さくなる。風の音 |
| FPV | `wide shot, FPV chase along the ridge with banked turns` | 尾根沿いに追う。曲がる区間でだけ画面が傾く。終点は次カットの進行方向へ抜ける |

補足を生成プロンプトへ渡すときは、モデルの言語・参照仕様に合わせる。
プリビズを正本として渡す段では、その経路と矛盾する別のカメラ指示を足さない。

## 4. 絵コンテ・プリビズ・動画で確認するもの

| 工程 | 引き継ぐ内容・確認 |
|---|---|
| 絵コンテ | 各カットの視点・サイズ・人物の位置・前景・水平線を描き分ける。静止画だけで経路や揺れを伝え切ったことにしない |
| プリビズ | 位置のキーと向きのキーを別々に設計し、注視の有無を選ぶ。経路の途中でも主役・遮蔽・姿勢を確認 |
| 動画 | 開始・中間・終了で目的の対象が読めるか、視差と向きが正しいか、揺れの原因と停止が一致するかを見る |

高い場所から見ている1枚だけでは「上昇」を証明できず、人物の正面の1枚だけでは
Orbit と Pan を区別できない。レビューでは文字の動作と対にして確認する。
細かい揺れや一回転は静止画コンタクトシートだけでは検証できないので動画を再生する。
生成は軌道・振幅・拍の厳密一致を保証しない。不一致なら無言で別技法に置き換えず、
何が再現できなかったかを示し、既存の修正・再生成の手順に従う。

## 5. 参照した一次情報

- [Unity Cinemachine Noise Settings](https://github.com/Unity-Technologies/com.unity.cinemachine/blob/main/com.unity.cinemachine/Documentation~/CinemachineNoiseProfiles.md): 基本経路に加える位置・回転のノイズ。
- [Unity Noise と Impulse](https://docs.unity.cn/Packages/com.unity.cinemachine%406.6/manual/setup-apply-noise.html): 継続的な揺れと出来事に反応する揺れを分ける。
- [DJI QuickShots](https://repair.dji.com/help/content?customId=01700006483&lang=en&paperDocType=ARTICLE&re=US&spaceId=17): Dronie / Rocket / Circle / Helix / Boomerang / Asteroid の動作。生成AIの対応表ではない。
- [Sony Lens breathing](https://helpguide.sony.net/di-app/cdv/v1/en/Content/Lens_breathing.htm): 呼吸動作とレンズ由来の画角変化を区別。
- [Three.js Camera](https://threejs.org/docs/pages/Camera.html) / [Quaternion](https://threejs.org/docs/pages/Quaternion.html): -Z の視線と回転の表現。
