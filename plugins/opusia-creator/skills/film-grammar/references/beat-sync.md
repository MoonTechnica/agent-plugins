# 音楽に合わせて切る（beat-synced editing）—— どのカットを拍に乗せ、どれを外すか

曲が主役の映像（MV・リリックビデオ・ダンス・BGM 主体）と、物語ものの中の音楽主体の区間で、
**カット・カメラの動き・画面内の動きを、拍・歌詞・芝居のどれに合わせるかを決める**ときに開く。
曲の地図（`audio_map.v2`）を読んだ後、字コンテを割る前に読む。

**実務の形は「尺は拍で、位置は根拠で」。** 548 本の MV の実測では、ショットの長さは 1 拍〜1 小節に
揃うのに、切り替わる時刻がダウンビートと一致する度合いは 0.16〜0.36 止まり。**全カットが拍に
乗っている映像は「機械的」と評される欠陥**であり、編集者の一致点は「毎拍切るのは簡単。問題は
なぜそこで切るか」。

> **この製品の MV の既定: シーンとカットの切り替わりは必ず拍の上に置く**（ユーザーの指定。
> 拍から外れた切り替わりは違和感として目立つ）。「機械的」を避けるのは**拍から外すこと**ではなく、
> **どの拍で切るかを散らすこと**で行う —— 小節頭 / 2・4 拍目 / キメの打点を乗り換え、1 / 2 / 4 小節を
> 混ぜる（§3.1・§7）。歌詞・芝居で切るカットも、**語頭やピークに最も近い拍**へ寄せる。拍から外すのは
> ユーザーが求めたとき、またはテンポが揺れる区間（ルバート。地図の `cut_hint` が `phrase_flow`）だけ。
> 置き方: シーンの頭は `apply_scene_proposal(boundaries_sec=…)`、シーンの中のカットは確定動画が
> 入ったら `align_scene_cuts(cut_starts_sec=…)`（実測したカットごとにクリップを割って拍に置く）。

## 0. 適用の判断（まずここ）

| 場面 | 拍に乗せるか | 根拠 |
|---|---|---|
| **台詞のある場面**（物語もの） | **乗せない**。感情 → 物語 → リズムの順で切る（Murch: Emotion 51% / Story 23% / Rhythm 10%） | Baby Driver でさえ会話は感情で切り、リアクションを 20 秒持たせた |
| 無台詞のモンタージュ・OP / ED・移動 | 乗せる。尺を小節で設計し、画面内の動きを拍に | Scorsese "Layla"（ショットの尺を小節で設計） |
| アクションの決め（衝突・発砲・着地） | 乗せる。**動作のピーク**を拍・フィル・コードチェンジに | Baby Driver の "anchor points" |
| 感情の転換点（視線・沈黙） | 拍より芝居。拍に乗ったら偶然でよい | Murch |
| **MV のサビ / ドロップ / ダンス** | 乗せ切る | 実測でも区間境界の一致が最も高い |
| **MV の A メロ・ブリッジ・ナラティブ区間** | 歌詞と芝居で切る。ブリッジは「遅く、詩的に」拍から浮かせる | Pozzi（編集者）、Kearns「音を切って物語として編んでから曲を戻す」 |
| **パフォーマンス MV**（演奏・歌唱を撮る） | 同期は**口と手の継続性**で担保。カットは楽器の入り・語頭で切り、ダウンビート一致を要求しない | 実測で最も拍に乗らない（0.16） |
| バラード・テンポが曖昧な曲・ルバートの区間（地図の `cut_hint` が `phrase_flow`） | 拍グリッドを捨てる（`phrase_flow`）。歌詞の切れ目・旋律の山・和声の変わり目をアンカーに | 遅い曲でも「精度」は置き場所に宿る（Street Spirit） |
| 不安・狂気・倦怠を描く区間 | **同期の精度を意図的に落とす**のが演出になる | 仮ミックスのズレを監督が採用した例 |

## 1. 切る根拠は 5 つ —— カットごとに 1 つ決めてから位置を決める

| 根拠（cut motive） | 何に合わせるか | 位置の決め方 |
|---|---|---|
| **拍**（beat） | ダウンビート・バックビート・区間の頭 | §3 |
| **歌詞**（lyric） | 語頭、または意味の切れ目・ブレス | 語頭が拍頭とずれていても**語頭を優先**（ずれは欠陥ではなく先行の効果。§4） |
| **旋律・音色・和声** | フレーズの山、楽器の入れ替わり、コードチェンジ、フィル、ブレイク | 地図の `events`（楽器の出入り・キメ・ブレイク）と `arrangement`。キメは拍に乗っていなくてよい |
| **芝居**（action） | 動作のピーク・視線・息・ためらい | ピークを拍に置くか、拍を見ずに芝居で切る |
| **物語**（story） | 因果・反応 | 拍を見ない（§0） |

- **拍は 5 つのうちの 1 つであって既定値ではない。** 区間ごとの既定は §2
- 字コンテの `note` に根拠を併記する（`♪ 2 bars · cut: lyric "word"` / `cut: action peak`）。
  書かないと下流で全部拍に吸着される
- **アンカー（§9）の間で根拠を変えてよい。** むしろ同じ根拠が続くと単調になる

## 2. 区間とジャンルで既定を変える

| 区間 | 第 1 根拠 | 第 2 根拠 | 拍との関係 |
|---|---|---|---|
| intro | 旋律・音色（楽器の入り） | 区間頭 | 小節頭に**動き**を置く。カットは少なく |
| verse（A メロ） | **歌詞**（語頭・意味の切れ目） | 芝居（視線・息） | 小節頭は節目にだけ。語頭を優先 |
| pre-chorus / build-up | 拍（加速） | 歌詞 | 小節頭 → 2・4 拍 → 毎拍と詰めていく |
| **chorus / drop** | **拍** | 動作のピーク | **頭は区間頭**（既定。外すなら意図を書く）。中は 1 拍〜1 小節 |
| bridge / breakdown | 芝居・歌詞・長回し | 旋律 | **拍から浮かせる**（`phrase_flow`）。戻るのは次のサビ頭 |
| dance 区間 | 8 カウント（2 小節）の頭と振りの決め | 拍 | 角度替えは 8 カウントの頭か最後のカウント |
| narrative 区間 | 物語・感情 | 芝居 | 拍で切らない |
| performance 区間 | 口・手の継続性（語頭・楽器の入り） | 拍 | ダウンビート一致を要求しない |
| outro | 旋律の減衰 | 区間頭 | 伸ばす。最後の 1 カットだけ終止に |

ジャンル別の既定（実測）: **ヒップホップ / レゲトン / R&B** はショットが 1 拍の長さに揃い（7 割超）
毎拍刻みが既定。**ポップ**は拍との一致は中程度だが**区間境界で切る度合いが最高**（サビ頭で画を変える
のはポップの実態）。**ロック / ダンス・エレクトロ**は意外にもダウンビート一致が低く、尺は小節に
揃うが位置は浮く。EDM だから全部拍、ではない。

## 3. 拍で切ると決めたカットの置き場所

### 3.1 拍の階層と担当楽器

| 階層 | 担当楽器（4/4 のポピュラー音楽の既定） | 切る重み |
|---|---|---|
| **区間の頭**（サビ・ドロップ）と**編成の変化** | | 最上位。`sections[].start_sec` / `events[].at_sec`（magnitude 2 以上） |
| **フレーズ頭**（4 / 8 小節） | | 交互配置（歌 ↔ 風景）の切り替えもここで |
| **小節頭**（ダウンビート） | キック | 既定の間隔は 1〜2 小節 |
| **バックビート**（2・4 拍目） | スネア | ずっと 1 拍目で切らない。ここで切ると「編集している」感じが出る |
| 細分（8 分・16 分） | ハイハット | 連打はサビの決め所だけ |

**1 フレーズの中で担当楽器を 1 回は乗り換える**（スネアで数回 → 次は切らない → キックで切る →
ハイハットで連打）。グリッドの中にいながら等間隔が崩れる。1 拍 = 60 ÷ BPM 秒、4/4 の 1 小節 =
240 ÷ BPM 秒（拍子が違えば `beat_grid.py --meter`）。

### 3.2 置く位置は拍の 1〜2 コマ前

**合わせると決めたカットは拍点の 40〜80 ms 前（24fps で 1〜2 コマ）に置く。** 拍ぴったりは遅れて
見える。根拠は 3 つ: 人は規則的な拍に対して数十 ms 先回りして動く、音の知覚上の拍点は物理的な
立ち上がりより後ろにある、映像が音より先に来るズレは 125 ms まで気づかれないが音が先だと 45 ms で
気づく（ITU-R BT.1359-1）。

| 何を拍に合わせるか | 置く位置 |
|---|---|
| カット（画が変わる瞬間） | 拍点の 1〜2 コマ前（`t_cut = t_beat − 0.04〜0.08`） |
| 動きの着地（カメラが止まる・物が当たる・文字が決まる） | **終点**を拍点に。始点はその 40〜190 ms 前 |
| 反応（ヒットで光る・現れる） | 拍点〜45 ms 後 |
| 口の動き | ±0。音が先なら +45 ms、画が先なら −125 ms が検知の限度 |

キック・スネアが拍を担う曲は拍点が鋭い。歌やパッドが拍を担う曲は知覚の拍点が帯になるので、
厳密な吸着に意味が無い（§0 の `phrase_flow`）。

## 4. 拍から外す技法 —— 外すときは「塊」で

1 回だけ裏拍に置くのではなく、意図が読める単位で外す。いずれも**タイムラインの `data-start` の
オフセットだけで実現でき、クリップを作り直さない**。

| 技法 | 形 | 効果 |
|---|---|---|
| **区間先行**（anticipation） | 1 区間のカットを**すべて** `t_beat − Δa`（Δa は 1/4〜1/2 拍）に置き、次の区間頭で Δa = 0 に戻す | 戻った瞬間が「ハマった」感になる（Adele "Rolling in the Deep" 2:20〜） |
| **山の直前で外し、山で戻す** | サビ直前の 1〜2 カットを拍から外す（§7 の「1 拍止める」の代わり。両方はやらない） | 驚き・山の際立ち・indie な手触り |
| **ブリッジを浮かせる** | 区間まるごと `phrase_flow`。長回し・芝居・歌詞で切る | 「遅く、詩的に」。次のサビ頭で拍へ戻る |
| **歌唱カットの入りを ±1 拍** | 語頭の 1 拍前に顔へ（待ち構える）／ 1 拍後に顔へ（風景に歌が乗ってから追いつく） | サビ頭だけ ±0。入りが全部 ±0 だと機械的 |
| **担当楽器の乗り換え** | §3.1 | 等間隔が崩れる |
| **キメに合わせる**（hit cut） | 全パートが揃って打つアクセント・スタブ・フィルの区間で、**1 ヒット = 1 カット**（または光・動作のピーク 1 つ）。時刻は `scene_plan[].hits_sec`（`events` の `kime`）の**実際の打点**に 1〜2 コマ先行で合わせる —— **拍の格子ではない**（キメはシンコペートしていることが多い） | 曲にキメがある所だけ。**1 曲に数回**で、サビのたびにやらない。直前に長めのカットか静止を置かないと落差が出ない。カットは生成し直さず**既にあるクリップを別アングル・別シーンから回す**（費用ゼロ） |
| **不完全同期を残す** | `phrase_flow` + Δa をばらつかせる | 不安・狂気・倦怠（§0） |

§3.2 の「1〜2 コマ前」は**合わせて見せる**ための微小先行で、ここの Δa は**ズレとして聞こえる量**。
意味が違う。

## 5. カットではなく「動きのピーク」を拍に置く

拍に乗せられる画の出来事はカット以外に 4 つある: **動作のピーク**（振り向く・着地・殴る）、
**カメラの停止 / 方向転換**、**光と色の変化**、**文字の出入り**。**カットを拍から外しても、ショットの
中の出来事が拍を踏めば同期して見える**（"Cut so the ACTION in the SHOT hits on the beat"）。
生成費も増えない。

- **拍で着地させる動きは拍より前に始める。** 拍で始まる動きは遅れて見える
- **1 ヒットに乗せる出来事は 1 つ。** 全部を同時に動かすと拍が見えなくなる
- パフォーマンス区間ではこれが**既定**: 拍は身体（演奏・振付・口）が踏み、カットは楽器の入りと
  語頭で切る（Gondry "Around the World" は集団 = 楽器で、同期を身体だけで取る）
- 俳優に「カウント」を渡して芝居を拍に乗せる（Baby Driver）。生成では参照音声を渡す（§11）か、
  動作を「ゆっくり始まり、最後に決まる」と書いて着地を小節末に寄せる

## 6. カメラの動きは小節で

- **動きの尺は拍数で決める**: 速い = 1〜2 拍、普通 = 1 小節、ゆっくり = 2〜4 小節
- **終点（止まる小節頭・サビ頭・ドロップ）を先に決め、始点 = 終点 − 尺**
- **1 カットの動きは 1 つ。1 カットの中で拍ごとに動かさない**（酔う）。A メロ・ブリッジは 1 フレーズに
  1 回が目安。**サビ・ドロップはカットごとに別の動きを並べ、同じ動きを 2 回続けない**
  （`genre-playbook` の references/mv-dynamics.md §2。勢いは 1 カットに動きを積むのではなく、短いカットを並べて出す）
- 溜め（build-up）の動きは小節頭か hard stop で収めるのが既定。尻切れにするなら意図（不安・宙吊り）を書く
- **ブリッジ・ナラティブ区間では止まる位置を拍から外してよい**（§2）
- `ease` は着地させるなら `ease-out`、拍で急に動き出すなら `ease-in`、拍を跨いで通過するなら `linear`
- whip pan は 0.18〜0.45 秒で終点を拍点に。カット境界に置けばカット隠しになる
- 「bump」（拍で小さく揺らす）は 2・4 拍に、1 フレーズに 1〜2 回まで

| 技法 | 拍での設計 |
|---|---|
| push in / pull back を小節に合わせる | 1〜2 小節かけて動き、小節頭で止める |
| ドロップで速度 / 方向を変える | ドロップ前は遅い push、後は速い動きか静止。ドロップの時刻でカットを割る |
| フレーズで往復 | 4 小節で寄り、次の 4 小節で戻る |
| 動きの連続 | 前のカットの pan の向きと速度を次が受け継ぐ |

## 7. 密度と揺らぎ（等間隔にしない）

実測の平均ショット長は現代映画で 3〜5 秒（Bordwell。Cutting らの計測で約 4 秒）、MV は約 2 秒（寄りの分析例）。出典は `screenwriter` の references/cut-timing.md §4。**「1 カット = 1〜2 小節」が実測と一致する**
（120 BPM なら 2〜4 秒）。ただし区間ごとに別の密度を持つ:

| 区間 | 密度 |
|---|---|
| intro / verse | 長いカット（2〜4 小節）。切る根拠は歌詞・芝居 |
| pre-chorus / build-up | 寄っていく・短くしていく |
| **chorus / drop** | 最短・最多（1〜2 小節。生成は 15 秒に 5〜6 カット）。頭で画が変わり、サイズを 2 段以上跳ばす組を 1 つ以上（mv-dynamics.md §1） |
| bridge / breakdown | **密度を落とすだけでなく、切る根拠を変える**（拍 → 芝居・歌詞・長回し） |
| **サビ / ドロップの直前** | 1 拍（または 1 小節）止める、**か**、直前の 1〜2 カットを拍から外す（§4） |
| outro | 伸ばす |

**拍で切ると同じ長さが並ぶのが構造上の既定になる。** 1 / 2 / 4 小節を混ぜる、担当楽器を乗り換える、
長い・短いを塊で来させる（注意を保つショット長の揺らぎは 1/f。長短はランダムではなく相関を持つ）。

**交互配置（歌 ↔ 風景、パフォーマンス ↔ ナラティブ）はフレーズ単位**（2〜4 小節）。拍単位で
往復すると忙しいだけになる。繰り返しのフレーズは 2 回目を短く、3 回目は新しい角度があるときだけ。

## 8. 歌詞と画

歌詞に画を当てる関係は 3 つ: **illustrate**（見たまま）/ **amplify**（意味を広げる）/ **disjuncture**（外す）。
**既定は amplify。** 「歌詞を見たまま絵にする（see-say）」は避けるが、歌詞にある語は大胆な画の
「許可証」として使う（Dave Meyers「歌詞の家を建てる」）。全部 illustrate なら説明的、全部 disjuncture
なら歌と無関係に見える。

- **歌詞で切る位置は語頭か、意味の切れ目（ブレス）**。日本語の歌い出しは語頭が拍頭に乗らないことが
  多い（アウフタクト・シンコペート）ので、語頭で切ると自動的に拍から外れる。それでよい
- 語頭の時刻は `speech_to_text` の語時刻（`audio-engineer` §7）
- リリックビデオの文字は 2 型: **映像先行型**（文字が画の出来事として拍に乗る）/ **楽曲先行型**
  （読める速度が優先で拍から浮いてよい）。先に型を決める

## 9. アンカーを決めてから逆算する

**必ず合わせる点（アンカー）を先に決め、そこから後ろ向きに埋める。** アンカーは拍だけではない:
サビ頭・ドロップ・**コードチェンジ・フィル・ブレイク・キメ**・歌詞のキーワード・曲が止まる瞬間・
**芝居のピーク・視線**。アンカーの間は §2 の根拠と §7 の密度で埋め、合わない所はアンカーから遠い側で
吸収する。アンカーの間で切る根拠を変えてよい。

曲の地図（`audio_map.v2`）で使えるアンカー: `sections[].start_sec`（区間の頭）、`events[]`
（楽器が入る / 抜ける / 全員が入る / 引き算 / ソロ / キメ / 止め / ドロップ / ビルド / 歌の出入り）、
`phrases[].start_sec`（フレーズの頭）、`scene_plan[].hits_sec`（キメの打点）。**時刻はすべて計測**
（拍・小節頭は `music_analysis.v1` の実測。キメは計測の打点）なので、聴き取りの誤差を見込まなくてよい。
打楽器の打点は鋭いのでそのまま 1〜2 コマ先行で置けるが、歌やパッドが担う拍は帯が広い（§3.2）。

## 10. 拍はコマに乗らない

128 BPM の 1 拍 = 0.46875 秒 = 24fps で **11.25 コマ**。コマに乗るのは fps × 60 ÷ BPM が整数の
テンポだけ（24fps なら 60 / 72 / 80 / 90 / 96 / 120 / 144 / 180 BPM）。

| 丸め方 | 128 BPM・24fps で 32 拍後 | 判定 |
|---|---|---|
| 毎拍 11 コマに丸めて累積 | **−333 ms**（8 コマ） | **禁止** |
| **絶対時刻 `i × 60 / BPM` を持ち、置く拍だけ最寄りコマへ** | 最大 20.8 ms（半コマ） | **既定** |
| 小数秒のまま置く | 0 | タイムライン（HyperFrames の `data-start`）では可能 |

**整数秒に小節が乗るテンポは 80 / 120 / 160 BPM 系だけ。** 128 BPM は 8 小節（15 秒）でしか
乗らず、140 BPM はどの小節数でも乗らない。だから字コンテ（整数秒）に拍は乗らない（§11）。
推定 BPM は半分 / 倍に外れることが多く、±1 BPM の誤差は 1 分で約 1 拍ずれる。**だから BPM から
外挿しない** —— 拍と小節頭は計測（`music_analysis.v1` の `beats_sec` / `downbeats_sec`）をそのまま使う
（`compositor` の `beat_grid.py --analysis`）。

## 11. 工程ごとの責務

拍を**正確に**置けるのはタイムラインだけ。上流は「小節数で尺を決め、切る根拠を決め、ピークを拍の
近くに置く」まで。

| 工程 | 時間の単位 | やること |
|---|---|---|
| 曲の地図（`audio-engineer`） | 秒（計測の小節頭） | 機械が拍・小節頭・編成を測り、Gemini が区間・出来事・分割を名付ける。区間ごとの**既定の切る根拠**（§2）と誰を映すかは `scene_plan[].visual` に、キメは `hits_sec` に入っている |
| 字コンテ（`screenwriter`） | **整数秒** | 尺は小節数、`duration_seconds = ceil(小節数 × 240 ÷ BPM)`。`note` に `♪ 2 bars · cut: lyric "word"`。1 回の生成に入らないシーンはフレーズの頭で割る（地図の境目は動かさない） |
| グリッド絵コンテ（`storyboard`） | コマ | `action` のコマは**動作のピーク**の絵、`lyric` のコマはその語を言う顔かその語の画。サビ頭のコマは画を変える（既定） |
| プリビズ（`previz`） | カット内秒 | 止まるキーを小節頭に（ブリッジでは外してよい）。キーの `t` は小数でよい |
| 生成（`cinematographer`） | 整数秒 | 歌・ダンスは参照音声を渡す。`lyric` のクリップは参照音声を**語頭の 1 拍前から**切ると先行が生成側で起きる |
| タイムライン（`compositor`） | **小数秒** | **確定動画が入ったら `align_scene_cuts` で全カットの頭を拍に置く**（`beat` → 拍点、`lyric` → 語頭に最も近い拍、`action` → ピークが拍に来る拍）。区間先行は `data-start` の一括オフセット。`data-duration` は小節の実秒、切り上げの余りは `data-media-start` で捨てる |

**参照音声は小節頭から小節頭まで ms 単位で切る**（`slice_media`。128 BPM 2 小節 = 3750 ms）。
途中から切ると拍の位相が揃わない。切った音の頭 = クリップの頭なので、`data-start` はその小節頭。

## 12. 外し方（こう見えたら）

| 症状 | 原因 | 直し方 |
|---|---|---|
| 「全部合っていて機械的・広告っぽい・indie 感が無い」 | 全区間で全カットが拍に乗っている | A メロかブリッジの切る根拠を歌詞・芝居に変える。山の直前を外す。区間先行（§4） |
| 「ずっと同じテンポで切り替わる」 | 毎拍 / 毎小節で等間隔 | 1 / 2 / 4 小節を混ぜ、担当楽器を乗り換える（§3.1・§7） |
| 「合っているはずなのに遅れて見える」 | カットが拍ぴったり | 1〜2 コマ前へ（§3.2） |
| 「サビで何も起きない」 | 区間の頭で画が変わっていない | サビ頭をアンカーに（§9） |
| 「歌詞と絵が全部一致していて説明的」 | 全部 illustrate | amplify を既定に（§8） |
| 「歌唱カットの入りが全部同じ」 | 語頭 ±0 に固定 | ±1 拍のばらつき（§4） |
| 「後半ほどずれる」 | 毎拍丸めの累積 / BPM の外挿 | 絶対時刻で持つ。区間ごとに基準を取り直す（§10） |
| 「忙しいだけで気持ちよくない」 | 歌 ↔ 風景を拍単位で往復 | フレーズ単位に（§7） |
| 「台詞の場面が音楽に振り回されている」 | 台詞区間を拍で切った | 感情 → 物語で切る（§0） |
| 「動きが拍に乗らない」 | 拍で動き出している | 着地を拍に。動き出しは前（§5） |
| 「カメラが揺れ続けて酔う」 | bump を毎拍 | 1 フレーズに 1〜2 回（§6） |
