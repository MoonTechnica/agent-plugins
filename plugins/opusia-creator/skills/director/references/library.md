# ライブラリの整理（フォルダ・キャンバス・素材の置き場所）

左パネルの「ライブラリ」は**フォルダ 1 本の木**で、人もあなたも同じ操作で整理する。
パスは `/第1話/キャラ` の形（途中の段はフォルダ）。id でも指せる。

| やること | tool |
|---|---|
| 中を見る | `list_folder`（`path` を省くとルート = 未整理。`include_home=true` で書き出し・絵コンテ・没案も出る） |
| フォルダを作る | `make_folder`（途中の段もまとめて作る。既にあればそれを返す） |
| 動かす | `move_library_items`（パスか id を最大 200。`to` を省くとルート） |
| 名前を変える | `rename_library_item` |
| 空のフォルダを消す | `remove_folder`（中身があれば何もせず数を返す） |
| 作るときに置く | `create_canvas` / `put_document` / `register_upload` の `folder` |

## 整理を頼まれたら

0. **発話の参照に `folder` が付いていれば、それが整理の対象範囲。** ライブラリの「AI に整理を
   頼む」から来た依頼で、その id を `list_folder` / `move_library_items` の `to` にそのまま渡せる。
   範囲の外は触らない
1. **まず `list_folder` で今の形を見る。** 読まずに箱を作らない
2. **頼まれた範囲の中は、誰が置いたものでも組み替えてよい。** 各行の `placed_by_kind` は
   最後に置いた主体（`user` = 人 / `agent` = AI / `default` = 作成時の既定）。人が作った
   フォルダの分け方は**意図として読み**、活かせるなら活かす。崩すなら、なぜそうしたかを
   返事に書く
3. **3 階層までに収める。** 名前は人が読む言葉で付ける（「第1話」「キャラ」「背景」「音」）。
   中身の無いテンプレートの箱を先に並べない
4. 動かしたものは返事に **「前の場所 → 今の場所」** でまとめる。人は依頼ごと取り消せる
   （`revert_thread`。後から人が触った項目は戻らない）

## しないこと

- **頼まれていない整理はしない。** 生成・取り込みのついでに既存の項目を動かさない
  （新しく作ったものを `folder` で置くのはよい。置き場所は依頼の対象範囲のフォルダ）
- **素材を消さない。** 要らないと判断したものは除外（`set_asset_excluded`）を提案する
- 「整理しますか？」と確認を挟まない。頼まれたらやり、気に入らなければ取り消してもらう

## 知っておくこと

- 生成物は**キャンバスのノードに着地した時点では没案としてライブラリに出ない**。確定すると
  キャンバスと同じフォルダに出る。だから**成果物の置き場所はキャンバスの `folder` で決める**
- `list_folder` の `in_use: true` はタイムライン・シーン・スロット・確定で使われているもの。
  フォルダを動かしても制作は壊れないが、「要らない」と判断する材料にはしない（除外の提案は未使用から）
- 行き先に同名のフォルダがあると「名前 (2)」になる。改名で同名を指定すると断られる
- 書き出し・絵コンテ・セリフの音声など住処が別にあるものも、フォルダへ入れればライブラリに出る

## 盤面（キャンバス）の作法

- **添付に `canvas_node id=…` があれば `get_canvas_node` で引き、その盤面で作業する**（別の盤面を作らない）。
  空ノードならそこへ着地、中身があるなら参照にして同じ盤面に空ノードを置く。`prompt` / `model` は引き継ぐ
- `arrange_canvas` は**頼まれたときだけ**（人が置いたノードも動かしてよい。件数を報告。戻すのは `from_*`）。
  5 枚以上・動画をまとめて投げる前は、見積（`estimate_asset_generation`）を会話に 1 行書く（止まらない）
