# 音の演出

「どの tool でどう作るか」は SKILL.md 本体にある。ここは**音をどう使うと
映像が良くなるか**の作法。

## 1. 音は 3 層に分けて考える

| 層 | 中身 | 原則 |
|---|---|---|
| **台詞・ナレーション** | 喋っている声 | **最優先**。何があっても聞こえること |
| **効果音（SE）** | 動作・物・環境の音 | 画で起きたことに対応させる |
| **音楽（BGM）** | 曲 | **感情の補助**。常時鳴らさない |

**この 3 つを別々に作って、タイムラインで重ねる**（`compositor`）。
1 つの音源に混ぜてしまうと、あとで音量を調整できない。

## 2. BGM は入れっぱなしにしない

**最も多い失敗が「頭から尻まで曲が鳴っている」。** ずっと鳴っていると、
盛り上げたい所で上げる余地が無くなり、全編が平坦になる。

| やること | 効果 |
|---|---|
| **入る所と切る所を決める** | 入った瞬間に感情が動く |
| **山場の直前で切る** | 落差で強くなる |
| **台詞の下では音量を下げる** | 台詞が聞こえる（ダッキング） |
| **場面転換で切り替える** | 場所が変わったことが音でも分かる |

**曲を切るのは怖くない。** 無音は失敗ではなく手段（§4）。

## 3. J カットと L カット（音と画をずらす）

**切り替えの位置を、音と画で意図的にずらす**。会話と場面転換が一気に自然になる。

| 名前 | 何が起きるか | 使いどころ |
|---|---|---|
| **J カット** | **次のカットの音が先に**聞こえ、あとから画が変わる | テンポを上げる。次を予感させる |
| **L カット** | **前のカットの音が残ったまま**画が先に変わる | 余韻を残す。しっとり見せる |

```
J カット          L カット
画 ─────┬─────    画 ─────┬─────
音 ──┬────────    音 ────────┬──
```

- **会話は L カット**が基本。喋り終わる前に聞き手の顔へ切ると、反応が見える。
- **場面転換は J カット**。次の場所の音（雑踏・雨）を先に聞かせると、
  切り替わった瞬間に違和感が無い。
- **音と画を同じ位置で切り続けない。** 全部が揃っていると、切り替えのたびに
  ぶつ切りに感じる。

## 4. 無音を使う

**音を入れないことも演出。** ずっと何か鳴っている中で急に無音になると、
そこに強く注意が向く。

| 使いどころ | 中身 |
|---|---|
| 衝撃の瞬間 | 大きな音の直後に無音を置くと、衝撃が増す |
| 山場の直前 | 溜める |
| 主観の表現 | 呆然・耳鳴り・水中 |

**完全な無音は短く。** 長いと「音が壊れた」と思われる。
環境音だけ残す（BGM と SE を落とす）ほうが安全。

## 5. 効果音は「画で起きたこと」に対応させる

- **画に無い音を鳴らさない**（何の音か分からず、不安になるだけ）。
- **画にある動作には音を付ける**（ドアが閉まったのに無音だと嘘に見える）。
- **決めの効果音**はスロットに確定して使い回す（SKILL.md §3）。
  作品を通して同じ音が鳴ると、それが作品の記号になる。

## 6. 環境音を敷く

**最も効くのに最も忘れられるのが環境音。** 台詞と BGM だけだと、
その場所に居る感じが出ない。

- 場所ごとに 1 本敷く（教室のざわめき、雨、風、街の遠鳴り）。
- **場所が変わったら環境音も変える。** 変わらないと同じ場所に見える。
- 音量は小さく、**気づかれない程度**に。

## 7. 生成動画に音が付いてくる場合

多くの動画モデルは `generate_audio` を有効にすると音も一緒に作る
（**既定は false なので、明示しないと鳴らない**）。台詞を喋らせる場合の
書き方と選び方は `ai-video-craft` の references/lip-sync.md にある。

音楽・効果音として使う場合は、**そのまま使わない。**

- カットごとに音の質・音量・環境がばらつくので、**並べると繋がらない**。
- 使うなら**その音だけを残し、環境音と BGM は自分で敷き直す**。
- 台詞は生成音声に任せず、キャラクターの声の既定から作る（SKILL.md §3.5）。
  そうしないと同じキャラの声が話数ごとに変わる。

## 8. 音量の順序

タイムラインで重ねるときの優先順位。**この順で聞こえるように調整する**。

```
台詞 ＞ 決めの効果音 ＞ BGM ＞ 環境音
```

- **台詞の下では BGM を下げる。** 上げるのではなく、下げて場所を空ける。
- **全部を大きくしない。** 何が大事か分からなくなる。
- 生成モデルは音量を揃えないので、**調整はタイムライン側で**行う
  （音源を作り直さない。SKILL.md §5）。

## 9. MV のとき

音が先に確定する唯一の形式。順序と拍の合わせ方は
`genre-playbook` の MV 篇（references/mv.md）が正本。
