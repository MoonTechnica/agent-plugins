# 縦型と短尺の設計

## 0. 縦型は横型の切り抜きではない

**横で作って縦に切ると、必ず 2 つが壊れる。**

1. **構図が壊れる** — 横型は左右の関係で見せる（2 ショット、肩なめ、広い背景）。
   縦に切ると片方が枠外に出る。
2. **下が使えない** — 縦型は**画面下部が UI に覆われている**。横型の字幕位置を
   そのまま持ってくると、再生 UI の裏に入って読めない。

縦型でやるなら**最初から縦で設計する**。生成の段でも、そのシーンを縦で出すなら
絵コンテの向きを `portrait` にする（`storyboard`）。

## 1. どこが隠れるか（セーフゾーン）

画面は 1080 x 1920。**四辺は UI に食われる**ので、意味のあるものを置けるのは
中央の限られた範囲になる。

| 範囲 | 実寸 | 何のため |
|---|---|---|
| **全プラットフォーム共通の安全域** | **中央 840 x 1280**（x=60, y=140。`scripts/safe_zone.py`） | ここに収めれば、どこに出しても隠れない |
| 上部 | 約 140 px | ステータスバー・アカウント表示 |
| 下部 | **約 400〜500 px** | キャプション・音源表示・操作 |
| 右端 | 約 180 px | いいね・コメント・共有の縦列 |
| 左端 | 約 60 px | 余白 |

**下部が一番深い。** プラットフォームごとに 320〜500 px と幅があり、**更新のたびに
増える**傾向がある。実寸と差分は **[references/safe-zones.md](references/safe-zones.md)**。

- **顔と字幕を下端に置かない。** 最も隠れる。
- **右下は最悪の位置**（操作列とキャプションが重なる）。
- 迷ったら **840 x 1280 の内側**で完結させる。

## 2. 縦画面の構図

| 決まり | 理由 |
|---|---|
| **被写体は中央から上寄り**に置く | 下は UI に食われる。顔が下にあると隠れる |
| **寄りを基本にする** | 横幅が無いので、引きにすると被写体が小さすぎて読めない |
| **1 画面に 1 つの情報** | 縦は横方向の情報を並べられない |
| **縦の奥行きを使う** | 手前と奥、上下の高低差（階段・見上げ・見下ろし）が縦では効く |
| **人物は 1〜2 人まで** | 3 人を並べると誰も読めない |

**横型で効く画（広い風景、2 ショット、横移動）は縦では死ぬ。**
代わりに効くのは、**顔のアップ、手元、見上げ / 見下ろし、縦に伸びるもの**。

## 3. 冒頭 3 秒

**離脱の大半は冒頭 3 秒で起きる。** ここを設計しないと、
後ろがどれだけ良くても見られない。

**3 秒に置くもの**:

| 型 | 中身 |
|---|---|
| **疑問** | 答えが気になる問いを最初の 1 行に |
| **否定・逆張り** | 「〜はやめたほうがいい」 |
| **意外性** | 予想と違う画・状況を最初のカットに |
| **タイムリミット** | 「あと 3 日で〜」 |
| **異常な状態から始める** | 説明せずに、渦中の画から入る |

**3 秒に置いてはいけないもの**: ロゴ、タイトル、名乗り、前置き、
ゆっくりしたフェードイン、状況説明の引き画。**全部あとで足りる。**

**フックは画と音の両方で立てる。** 音を切って見ている人が多いので、
**最初の 1 行は画面に文字でも出す**。

## 3.5 フックの次は、20 秒で「誰・どこ・望み・障害」を立て終える

**3 秒で掴んだあと、何の話か分からないまま進むと、そこで 2 回目の離脱が起きる。**

| いつ | 何を立てるか | どうやって |
|---|---|---|
| **0〜3 秒** | フック | 画と文字（§3。まだ音が出ていない環境がある） |
| **3〜20 秒**（30 秒尺なら 10 秒まで） | **誰が・どこで・何を望み・何が邪魔か** | **セリフ ＋ 字幕**が主経路 |

**縦型は「ながら見」される。** 電車で降りる駅を確認しながら、列に並びながら見るので、
**画面から目を離してもストーリーを追える**必要がある。縦型ショートドラマの現場では
「ト書きで説明せず、**セリフで説明してください**」と言われる —— 長尺の作法とは逆を向く。

| 規律 | 中身 |
|---|---|
| **呼称を言わせる** | 人物は**初登場から 2 発話以内**に、呼ぶ／名乗る／肩書きで呼ばれる。短尺は長編より名前を多く呼ばせてよい |
| **場所・関係・時間・目的は言葉にも載せる** | 画にしか無い情報はミュート視聴に届かない。生成映像は微細な表情差も出にくい |
| **場所と時刻はテロップでよい** | ミュートでも読める唯一の経路 |
| **台詞の量には下限がある** | **150 字/分**。割ったら情報不足（`screenwriter` の references/dialogue-and-exposition.md） |
| **無音は最長 3 秒** | 無言カットを連続させない |

**「表情で見せる」を単独の解決策にしない。** 縦型は顔が大きく映るぶん表情が効くが、
**表情に預けた情報は、音を切っている人にも、生成の振れにも弱い**。必ず言葉か文字で二重化する。

## 4. 見られ方の形と、画が変わる間隔

視聴維持の曲線は 3 つの形に分かれる。**狙うのは 3 つ目**。

| 形 | 何が起きているか |
|---|---|
| **崖** | 冒頭 3 秒で急落。フックが無い。ここで終わる |
| **こぶ** | 中盤まで保つ。悪くない |
| **平ら** | 最後まで落ちず、末尾が頭に繋がる。**最良** |

**画は 1.5〜2 秒に 1 回変える。** 同じ画が 3 秒以上続くと落ちる。
変えるのはカットでなくてもよい（寄る、角度が変わる、文字が変わる）。

- **序盤の 3〜15 秒が最も漏れる。** フックで約束したものを**すぐ出す**。
  引っ張ると、引っ張ったぶんだけ落ちる。
- **山を後半に置かない。** 短尺では前半に見せ場を出す。
- 長めの尺なら、**10〜15 秒ごとに小さな引き**を入れて繋ぎ止める。

### 「間」はここと矛盾しない

`screenwriter` の references/scene-writing.md §11 は「1 シーンに台詞の無いカットを
最低 1 つ」と言うが、**それはカットを 3 秒止めることではない**。
短尺の間は**音を止める / 動きを止める**で作る（1 カット・1 秒未満・無音）。
カットを伸ばして間を作れるのは長尺のやり方（同 §13）。

**同じく「先に教えて、待たせる」（同 §12）も、短尺では「待たせる」を捨てる。**
フックで先に見せ、**約束したものはすぐ出す**。ここと食い違う所は**この節を優先する**。

## 5. ループさせる

**末尾のフレームが冒頭のフレームに繋がる**と、見ている側は終わりに気づかずに
2 周目に入る。これが最も効く仕掛けで、作る側の手間はほとんどかからない。

作り方は 2 つ:

1. **最後のカットを冒頭と同じ構図にする**（同じ画角・同じ服・同じ場所）
2. **最後の台詞の答えが冒頭の 1 行になる**ようにする

**終わりの誘導文（「フォローしてね」）はループを壊す。** 20 秒の作品に 3 秒入れると
尺の 15% を捨てたうえに、繋がりが切れて 2 周目に入らなくなる。
**入れるなら画面の隅に重ねる**か、入れない。

## 6. 字幕

- **音を切って見られる前提**で作る。台詞は原則すべて字幕にする。
- 置くのは**画面の下 1/3 …ではなく、その少し上**。下 400〜500 px は UI に隠れる。
- **1 度に 1〜2 行、短く。** 読み切れない字幕は無いのと同じ。
- 文字は生成に任せず、**タイムライン側で載せる**（`compositor`）。
  生成に文字を頼むと読めない字が出る（`ai-video-craft` §5）。

## 7. 尺

| 形式 | 目安 |
|---|---|
| ショート動画（SNS） | 15〜60 秒 |
| 縦型ショートドラマ 1 話 | **1〜3 分** |
| 縦型ショートアニメ 1 話 | 30 秒〜2 分 |
| 1 カットの尺 | **2〜3 秒**（縦型は横型よりテンポが速い） |

**尺は「短くできないか」から考える。** 生成は尺がそのまま費用なので、
短くすることは品質と費用の両方に効く。

## 8. 出す前の確認

| # | 確認 |
|---|---|
| 1 | 顔・字幕・重要な情報が **840 x 1280 の内側**にあるか |
| 2 | 冒頭 3 秒に**フックがあり**、ロゴや前置きが無いか |
| 3 | 最初の 1 行が**文字でも出ている**か（音を切って見られる） |
| 4 | 画が **1.5〜2 秒に 1 回**変わっているか |
| 5 | 末尾が冒頭に**繋がる**か（ループ） |
| 6 | 終わりの誘導文で**ループを壊していない**か |
| 7 | 被写体が**中央から上寄り**にあるか |
| 8 | 横型からの切り抜きになっていないか |
| 9 | **20 秒以内**（30 秒尺なら 10 秒）に誰・どこ・望み・障害が**言葉で**立っているか（§3.5） |
| 10 | 人物が**初登場から 2 発話以内**に呼称で特定されているか |
| 11 | 台詞が **150 字/分**以上あるか（`screenwriter` の `scripts/dialogue_report.py` で測る） |
