# テイクの 1 カットだけを直す（カットの差し替え）

**本番テイクができたシーンは、シーン全体を撮り直さない。** だめなカットを 1 つ丸ごと
切り出し、video-to-video（Gemini Omni / Kling O3）で編集して、**元のテイクの同じカットに
差し戻す**。他のカットは 1 フレームも変わらない。

| | 費用（目安） | 変わるところ |
|---|---|---|
| **カットの差し替え**（この手順） | 直すカットの秒数 × $0.10（Omni 720p）/ $0.15（1080p） | そのカットだけ |
| シーン全体の撮り直し | シーン全体の秒数 × 生成モデルの単価（**桁で高い**） | 合っていたカットまで別物になる |

撮り直しは**人が明確に指示したときだけ**（`generate_scene` の `regenerate_reason` に
人の言葉を引く。会話の中では承認待ちになる）。「自分で見てだめだと思った」は理由にならない。

## 0. なぜカット丸ごとなのか

**継ぎ目を、元からあるハードカットに重ねるため。** 編集モデルの出力は、指示していない
ところでも光・色・人物の位置がわずかにずれる。ショットの途中で切って差し込むと、
その 1 コマで画が跳ねて見える。カットの境目なら、もともと画が切り替わる場所なので
ずれが見えない。**だめなのがカットの一部でも、差し替えるのはカット全体**にする
（指示で「Keep everything else the same.」と縛るので、直したい所以外はほぼ残る）。

切り出しと差し戻しは**サーバーの tool**（`extract_cut` / `replace_cut`）がやる。
**テイクを手元へ落とさない・ffmpeg を組まない。** 秒ではなく**コマ**で切るので隣の
ショットが 1 枚も混ざらず、差し戻したテイクは**元とコマ数が同じ**になる（尺が 1 コマでも
変わるとタイムラインのカットがずれる）。

## 1. どのカットかを決める

`get_asset_preview(<テイク>)` の **`cuts`** にカットごとの番号（1 始まり）と秒数が並ぶ。
カットの境目は取り込み時に測ってある（生成したテイクも、人が上げた動画も同じ）。

- どのカットがだめかは `get_asset_preview` のコンタクトシートを見て自分で決める
- `cuts` が `null`（古い素材で測っていない）でも `extract_cut` はその場で同じ検出をかける
- 検出はハードカット向け。**ディゾルブ・フェードでは切れ目が出ず、閃光・高速パンでは
  余計に出る**。数が字コンテと合わないときは、コンタクトシートで見て、
  正しい開始秒を `cut_starts_s`（先頭は 0）で `extract_cut` / `replace_cut` の両方に渡す

## 2. モデルを選ぶ（カットの秒数で決まる）

`python3 <SKILL_DIR>/scripts/edit_plan.py --preview <get_asset_preview の JSON> [--region eu]` が
全カットのモデル・`max_seconds`・部品の最少数を出す（下の表を手で引かない）。

| カットの秒数 | モデル | `max_seconds` | 制約 |
|---|---|---|---|
| **10 秒以下（既定）** | `gemini-omni-flash` | `10` | 入力は 10 秒まで。**解像度を必ずテイクに揃える**（360p / 720p / 1080p / 4k）。声は編集しない。**EEA・スイス・英国では使えない** |
| 10 秒超〜15 秒 / Omni が地域で使えない | `kling-o3-pro` | `15` | 入力は **3〜15 秒・短辺 720px 以上** |
| 15 秒超 | `gemini-omni-flash`（部品に分けて） | `10` | §2.1 |

引数は必ず `get_model_capabilities(model=…, task="video_edit")` で引いてから埋める。
費用は `estimate_asset_generation`（編集と同じ request）で引く。

### 2.1 長いカットは部品に分かれる

カットが `max_seconds` を超えると、`extract_cut` が**画の動きが一番少ない所**で部品に
分け、部品ごとに 1 素材を返す（隣り合う部品は継ぎ目の前後 0.5 秒ずつ重なる）。
`replace_cut` が重なりを**クロスフェードで溶かして**戻すので、部品ごとの微妙なずれが
1 コマで跳ねない。

- 分けるのは丸ごと渡せるモデルが無いときだけ（10〜15 秒は分けずに Kling で丸ごと）
- 部品の編集は**全部同じ指示・同じ解像度**で（違えると継ぎ目で中身が変わる）
- 戻したらコンタクトシートで継ぎ目のコマを見て、形が二重に見えないか確かめる

## 3. 切り出す

```
extract_cut({asset_id: <テイク>, cut: 2, max_seconds: 10, canvas_id: <シーンの盤面>})
→ { cut: 2, cuts: 3, start_ms, end_ms, seconds, parts: [{part: 1, asset_id, …}] }
```

`parts` が編集する元（音なし）。盤面ではテイクの右に並ぶ。

## 4. 編集する

```
create_canvas_nodes(...)                       # 部品ごとに空の video ノードを 1 つ
get_model_capabilities(model="gemini-omni-flash", task="video_edit")
generate_asset(
  task="video_edit", model="gemini-omni-flash", canvas_node_id=<空ノード>,
  media=[{slot: "source_video", asset_id: <parts[n].asset_id>}],
  fields={
    prompt: "<変えることを 1 文>. Keep everything else the same.",
    resolution: "<テイクに合わせる。720 なら 720p、1080 なら 1080p>",
  },
)
wait_for_generations → get_asset_preview で必ず見る
```

- **指示は短く、1 つだけ。** モデルの説明どおり「Simple prompts work best」。
  直したいことが 2 つあるなら 2 回に分ける（1 回目の出力を 2 回目の `source_video` にする）
- **「Keep everything else the same.」を必ず付ける。** 無いとカット全体が描き直される
- **解像度はテイクに揃える。** 低い段で直すと、そこだけ眠い画になる
- **声は編集できない**（Omni の制約）。台詞の言い間違い・声の質はカットの差し替えでは直らない
- **台詞の途中の口元を描き直すと、元の音と口がずれうる。** 口を含むカットを直したら
  §5 のあと、口と音の合致は確かめられないので「未確認」と書いて人に渡す

## 5. 元のテイクに差し戻す

```
replace_cut({asset_id: <テイク>, cut: 2, max_seconds: 10, canvas_id: <盤面>,
             edited_asset_ids: [<部品 1 の編集結果>, …]})   # parts の順
→ { asset_id: <直したテイク>, parts: [{part, edited_asset_id, length_gap_s}] }
set_scene_confirmed(scene_id, <直したテイク>)
```

- `max_seconds` / `cut_starts_s` は `extract_cut` と**同じ値**（同じ割り方になる）
- 寸法・fps・尺のずれは吸収し、**コマ数は元と同じ・音は元のまま**（映像だけ差し替える）。
  `length_gap_s` が 0.3 秒を超えたら動きが間延び / 途切れしていないか見る
- 縦横比が違う編集結果は**引き伸ばさずに断られる**（人物が太る / 細る）。編集をやり直す
- **前のテイクは消えない**（確定枠の差し替えであって上書きではない）
- **タイムラインは付いてくる。** レーンのクリップはシーンの確定動画を変数で再生して
  いるので、確定を差し替えればそのまま新しいテイクになる。コマ数が同じなので
  `align_scene_cuts` で割ったカットの位置（`data-media-start`）もずれない。
  `set_scene_confirmed` で区間（`media_start_ms` / `media_end_ms`）を使っていたシーンは、
  **区間を渡さずに呼ぶ**（前の区間がそのまま残り、尺が同じなので正しい）
- 同じシーンで別のカットも直すなら、返ったテイクを次の `asset_id` にして §3 から繰り返す
  （確定は最後に 1 回でよい）

## 6. 直らないとき

| 症状 | やること |
|---|---|
| 同じカットを 2 回編集しても直らない | **止めて人に返す。** 何を何回試したかと、残る選択肢（撮り直す / そのまま使う）を書く。自分の判断で撮り直さない |
| 声・台詞そのものがだめ | カットの差し替えでは直らない（Omni は声を編集しない）。人に返す |
| 動きの構成から違う（人物の位置・カット割り） | 差し替えの範囲を超える。人に返す |
| 部品に分けたら継ぎ目で形が二重に見える / 部品ごとに中身が違う | 継ぎ目を動きの少ない所へ寄せる手はもう打ってある。人に返す |
| `video_edit` が地域で断られる（EEA・スイス・英国） | `kling-o3-pro` で（`max_seconds: 15`） |
| `replace_cut` が `aspect ratio differs` で止まる | 編集の解像度・向きの指定を見直して編集し直す |

人に返すときは、撮り直す場合の見積（`estimate_scene_generation`）も添える。
人が「撮り直して」と言ったら、その言葉を `regenerate_reason` に引いて `generate_scene` を呼ぶ。
