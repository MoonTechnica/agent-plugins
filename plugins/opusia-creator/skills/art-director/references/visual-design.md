# 画づくり（色と光の設計）

「どの tool でどう作るか」は SKILL.md 本体にある。ここは**どう作ると
1 本に見えるか**の作法。

## 1. 1 本に見えるかどうかは色と光で決まる

カットごとに絵柄が揃っていても、**色と光の方針が無いと 1 本に見えない**。
生成は毎回違う光を作るので、**先に決めて指示し続ける**しかない。

先に決めるのは 4 つ。

| # | 決めること | 例 |
|---|---|---|
| 1 | **時間帯ごとのパレット** | 朝＝寒色で明るい / 夕＝橙 / 夜＝青と人工光 |
| 2 | **光の向き** | 窓は画面左から。シーンを通して変えない |
| 3 | **明度の方針** | 明るく軽い（ハイキー）か、暗く重い（ローキー）か |
| 4 | **画風** | セル調 / 水彩 / 実写 / フィルム調 |

**これを `series_bible.v1` か設定資料として置き、話数ごとに決め直さない**
（決め直すと必ずずれる）。

## 2. カラースクリプト

作品全体の色を、**シーン順に 1 枚ずつ並べた設計図**。長編アニメで使われてきた
手法で、**感情の起伏を色で設計する**。

**1 枚ずつ集めて並べるのではなく、`generate_material_sheet(kind="colorscript")` で
1 回の生成として作る**（SKILL.md §5.5）。タイムラインのシーン列から、各セルを
そのシーンの代表色の構図で描いた 1 枚が出る。人物も文字も描かない、色と明度と光だけ。

```
generate_material_sheet({ kind: "colorscript",
                          subject: { key: <composition_id> }, ... })
```

**④ 文字コンテの後**に作る（シーンが無いと断られる）。12 シーンまで。

出来た 1 枚を見るときの観点:

1. 色が**単調に続いていないか**
2. **山場で変わっているか**
3. 話数をまたいで**同じ時間帯が同じ色か**

| 見るところ | 直し方 |
|---|---|
| 全編が同じ色調 | 山場の前後で色を振る（寒色 → 暖色は既定値の 1 つで唯一の答えではない。作品の狙いの色で） |
| 山場と日常が同じ明度 | 山場だけ明度か彩度を離す |
| 話数をまたいで色が違う | 時間帯ごとのパレットに戻す |

検査の前に**設計**がある。カラースクリプトは「感情の起伏を色で書いた作品の要約」（Eggleston）なので、
**どこで変えるかは緊張曲線の節目**（日常は彩度を抑え、山場で彩度か明度を離し、決着後は戻るが
同じ色には戻さない）。**意味を持たせる色は作品で 1〜2 色**（人物・場所・物のどれか 1 つに固定し、
意味が変わる瞬間に色を変える）。光の推移（同じ場所の 2 シーンで光の向き・硬さ・色温度を 1 つ変える）も
同じ考え方。判断は `film-grammar` の references/direction-design.md §7。

**生成では特に効く。** 1 枚ずつ作ると全体の色設計が無いまま進むので、
並べた時に「なんとなく散らかった」映像になりやすい。

## 3. 光の連続性

**同じシーン内で光が変わると、別の場所に見える。**
`film-grammar` §7 の検査項目 5 がこれ。

| 揃えるもの | ずれると |
|---|---|
| **光の向き** | 顔の影の位置が変わり、別の時間に見える |
| **色温度** | 暖色と寒色が混ざり、別の場所に見える |
| **明るさ** | カットごとに露出が飛ぶ |
| **影の硬さ** | 晴れと曇りが混ざる |

**プロンプトに毎カット同じ光の指示を書く。** 「前のカットと同じ光」は効かない
（モデルは前のカットを見ていない。`ai-video-craft` §6）。

## 4. 光で感情を作る

| 光 | 読まれ方 |
|---|---|
| **順光**（正面から） | 明快・健全・情報が読める |
| **逆光** | 感情を隠す・神秘・シルエット |
| **サイド光**（横） | 立体的・葛藤・二面性 |
| **アオリの光**（下から） | 不気味・異常 |
| **ハイキー**（影が少ない） | 軽い・日常・コメディ |
| **ローキー**（影が濃い） | 重い・緊張・サスペンス |

**逆光は生成でも安定して出る**うえ、**顔の細部を隠せる**ので
同一性の破綻を目立たなくできる（`ai-video-craft` §6）。

## 5. 色で人物を見分けさせる

短尺・縦型では、**視聴者が人物を覚える時間が無い**。

- **主要人物ごとに色を割り当てる**（服・髪・持ち物）。
- 対立する 2 人は**補色で対比**させる。
- 背景の色と人物の色を**離す**（同系色だと沈んで見えない）。

これは `genre-playbook` の短編篇（short-drama.md §2、vertical-anime.md）の
「見た目で役割が分かるようにする」と同じことを、色の側から見たもの。

## 6. 縦型のとき

- **背景の情報量を減らす。** 縦は横幅が無いので、背景が細かいと人物が沈む。
- **被写体と背景の明度差を大きく**取る（小さい画面で見られる）。
- 画面が小さい前提なので、**細部で見せない**（表情と色で見せる）。

詳細は `vertical-shortform`。

## 7. 実写系のとき

様式に寄せるほど破綻が隠れる（`genre-playbook` の drama-film.md §5）。

| 寄せ先 | 効果 |
|---|---|
| **夜・雨・霧** | 細部が見えず、破綻が目立たない |
| **フィルム調・粒子** | 生成特有の質感が馴染む |
| **モノクロ・強い色被り** | 色の不一致が消える |
| **浅い被写界深度** | 背景の破綻がボケる |

**ただし作品の狙いを曲げてまで寄せない。** 破綻を隠すために全編を夜にすると、
それは別の作品になる。判断に迷う所なので、**寄せる前にユーザーへ確認する**。

## 8. 確定素材との関係

ここで決めた方針は、**スロットに確定した設定資料として実体を持たせる**
（SKILL.md §1）。方針を言葉で持っているだけだと、生成のたびにずれる。

- 背景は**時間帯ごとに別のシート**（`background.classroom.dusk`）。
  同じシートに混ぜない —— 光が変われば別の設定資料になる。
- 同じ場所の別時間帯は、**確定済みの昼のシートを参照に渡して**作る。
  そうすると同じ場所に見える（渡さないと窓の数が変わる）。
- アニメの美術としての作り方（美術設定・美術ボード・BOOK・アイレベル・
  キャラが乗る前提の明度設計）は [background-art.md](background-art.md)。
