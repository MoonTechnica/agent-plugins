# 動かす前提の静止画（`motion` のシーンの絵）

静止画を描いて HyperFrames で動かすシーン（作り方の選び方と作法は `genre-playbook` の
references/motion-stills.md）の**絵の描かせ方**。設定資料シートとは別物で、ここで描く絵は
**本編にそのまま出る**。層に分けて動かすので、1 枚の絵としての出来に加えて
「動かしたときに壊れないか」で描く。

## 1. 何を、いつ描くか

| 段 | 描くもの | 枚数 | いつ |
|---|---|---|---|
| 方向性 | **スタイルフレーム 2〜3 枚**（完成の質の止め画。色・質感・書体の当たり・配置） | 2〜3 | 企画の段。全カットの物差し |
| V コン | **ラフ**（そのカットの構図） | 1 カット 1 枚 | 字コンテの後。`storyboard` が V コンに載せる（`set_cut_board`） |
| 本番 | **動かす前提の静止画**と差分 | V コンで承認されたカットだけ | V コンの承認の後。層に分けるのはこの後 |

**V コンの承認より前に本番を描かない。** 差し替えが出るのが前提で、本番を描いた後に
構図を直すと層への分解と差分まで全部やり直しになる。

## 2. ラフと本番（同じモデル・`quality` だけ変える）

| | ラフ | 本番 |
|---|---|---|
| tool | `generate_asset`（画像） | `generate_asset`（画像）/ 差分は `image_edit` |
| モデル | `gpt-image-2.5`（flare。1 枚 1 カットで情報を詰めない） | 同じ |
| `quality` | `"low"`。迷ったら `"medium"` | **`"xhigh"`**。寄る・長く映る・見せ場は **`"max"`**（本編にそのまま出る。SKILL.md §2「1 カットだけの場所」と同じ判断） |
| 寸法 | 仕上がりの比率で小さく（構図が分かればよい） | §3（描き足し・寄るなら大きく） |
| 参照 | キャラの設定表・スタイルフレーム | 同じ + **承認したラフ**（構図の参照の 1 枚として） |

- **別のモデルでラフを描かない。** 絵柄が変わり、本番で構図から取り直しになる。
- **ラフを元画像にして仕上げない**（拡大・加筆で本番にしない）。粗さが移る。本番はラフを
  参照の 1 枚として添えて描き直す。構図が保たれないときは、ラフの構図を字コンテの
  「画」の列に言葉で書き起こし、それで描く。
- **ラフを飛ばしてよいカット**: 層に分けず寸法も上げないカットは、本番 1 枚が安いので
  ラフを描かず本番を直接描き、それを V コンに載せる。ラフが効くのは、承認の前に
  layerize（1 層 $0.03〜）や大きな寸法に払いたくないカット。
- 文字・図解だけのカットは**絵を描かない**（組み立てたもの自体が V コン。`compositor`）。

## 3. 本番の描き方の決まり

| 決まり | 理由 |
|---|---|
| **画面の外まで描く**（仕上がりより縦横 10〜20% 広く。プロンプトに「画面の外まで背景が続く」と書き、寸法をその分大きく取る） | 寄り・パン・視差で縁が見える |
| **寄るカットは大きく描く**（1080p の顔の寄りなら 2160p） | 拡大で粗れる。**gpt-image-2.5 の上限は 3840×2160**（総画素 8,294,400）なので、描き足しと 2 倍は両立しない。寄る量を描ける範囲に収める（カメラの移動量の上限は compositor） |
| 揺らすもの（髪・服・リボン・マント）は**体から離して垂らす** | layerize が描き足す量が減り崩れにくい（`compositor` の references/layer-rig.md §2） |
| 層は**前景 / 人物 / 背景 / 効果**の 4 つを最低限に、揺らすものだけ足す | 実務の最小単位。分けすぎは課金（1 層ごと）と組み立ての手間 |
| 落ち影は別の層にする（分けるならプロンプトで名指し） | 人物を動かすと影が残る |
| **文字・ロゴ・UI・吹き出し・擬音は描かない** | 読めない字が出る・直せない・翻訳と縦横の作り直しができない。文字は HyperFrames で載せる |
| モーションコミックは**コマ単位で描く**（1 コマ = 1 枚） | コマの中をカメラで見せ、吹き出しは字幕として出し入れする |
| 塗りは重ねの少ないもの（フラットなアニメ塗りか厚塗り。乗算・グラデの重ねは避ける） | 層に分けたときに継ぎ目が出にくい。1 枚絵 MV では真似しやすさが拡散力になる |
| 作品の中で画風を固定する | スタイルフレームから外さない（§8「絵柄を揃える」） |

## 4. 層に分ける

`generate_asset` の `seedream-5-layerize`（task `image_layerize`）。**分けたいものを名指しし、
残りは 1 枚にまとめさせる**。プロンプトの書き方と出力の扱い（ベースは背景、index と素材名の
対応、bounding box の寸法へ縮めて貼る）は `compositor` の references/layer-rig.md §1〜§4。

- 分けた後は**分けた層だけを使う**（layerize は描き直しなので、元の絵と混ぜると形が少し違う）。
- **持ち込みの完成した 1 枚は layerize しない**（形が変わる）。被写体だけ要るなら背景除去で切り抜く
  （`compositor` の references/subject-text-layering.md §4）。
- 分かれ方は `get_asset_preview` で 1 枚ずつ見る。足りなければプロンプトを変えて分け直す。

## 5. 差分（表情・目・口）

| 決まり | 中身 |
|---|---|
| **同じ構図・同じ寸法で `image_edit` から作る** | 生成し直すと位置がずれ、切り替えたときに顔が跳ねる |
| 元は**層に分ける前の本番の絵**にし、差分も同じプロンプトで同じ層に分ける | 顔の層どうしを差し替える |
| 最低限は 3 枚: 目開・口閉 / 目閉・口閉 / 目開・口開 | まばたきと口パク。滑らかにするなら半目・中口を足す |
| 表情（笑顔・切ない・泣き）は**感情の転換点の数だけ** | 差分が増えるほど費用と手間が増える。字コンテの転換点から数える |
| 話者が複数なら**人ごとに口の差分** | 口パクは話者ごとに切り替える |

差分の位置が揃っているかは `get_asset_preview` で重ねて見る（compositor の検査でも見る）。

## 6. 混ぜるとき

- **3D の背景 × 2D のキャラ**: キャラの層だけを描く（背景は 3D）。光の向きを 3D の背景の
  キーライトに揃えてプロンプトに書く。
- **生成した動画の上に重ねる層**（文字は描かない。粒子・光の素材など）: 透過が要る素材は
  今のところ `generate_asset` の task `image_background_removal`（BiRefNet v2）で切り抜く
  （カタログが gpt-image-2.5 の `background: transparent` をまだ通していない）。

## 7. 歌詞を見せる MV のカット

歌詞の演出（`genre-playbook` の references/mv-lyrics.md）が入るカットは、文字が載る前提で描く。

| 注文 | 理由 |
|---|---|
| **文字の置き場を構図で空ける**（字コンテで決めた左右・上下・人物の後ろ） | 余白が無いと巨大な字が人物を潰す。散らし組みは人物の左右に縦の列が入る空きが要る |
| **人物を別の層に分ける**（layerize で「人物 / 背景」を名指し。人物の輪郭の外に塗り足し） | 文字を人物の後ろに回す・3D に置くカットは層が無いとできない |
| **差し色を絵の中に仕込む**（瞳・小物・光） | 文字の色はそこから取る。モノクロの絵でも 1 色だけ残す |
| 顔に重ねる予定のカットは、**顔の周りの明度を文字の色と離す** | 赤い字ならグレー〜白の地。重なった字が読める |
| 看板・紙など文字が入りそうな物は**無地で描く** | 文字はタイムラインで載せる（絵に描かせない） |
| 3D の奥行きに板として並べる絵は、**板 1 枚ずつ別に描く**（前景・人物・背景） | 層の間に文字を挟む |
