# ジャンル別の作法

## 0. 先に決めるのは尺と形式

**構成は尺で決まる。** 同じ話でも 90 分と 60 秒では別の設計になるので、
ジャンルより先に**尺と形式**を確定する。ここが決まっていないまま脚本に入ると、
必ず途中で作り直しになる。

決めること: **尺 / 縦か横か / 1 本か連作か / 誰がどこで見るか**。

## 1. 構成の型を選ぶ

物語の型の全文 — セーブ・ザ・キャットの 15 ビートと 10 のジャンル分類、
ストーリーサークル、三幕構成、起承転結と序破急、短尺への畳み方、連作のアーク —
は **[references/beat-sheets.md](references/beat-sheets.md)** にある。

| 尺 | 使う型 | どこに |
|---|---|---|
| **60 秒以下** | フック → 設定 → 展開 → 山 → オチ（5 ブロック） | references/beat-sheets.md §5 |
| **1〜3 分**（ショートドラマ 1 話） | 5 ブロック + 引き | 同上 §5 / short-drama.md |
| **5〜15 分**（ショートアニメ・1 話完結） | ストーリーサークル 8 段 | 同上 §3 |
| **20〜30 分**（TV アニメ・ドラマ 1 話） | 三幕構成 + A / B パート | 同上 §2 |
| **60 分以上**（映画） | **セーブ・ザ・キャット 15 ビート** | 同上 §1 |
| 連作全体のうねり | アークを別に設計する | 同上 §6 |
| **MV**（尺ではなく曲で決まる） | **曲の構造そのもの**。物語の型を当てない | mv.md §1.5 |
| **説明もの**（尺ではなく約束で決まる） | **約束 → 根拠 → CTA のビート表**（PAS / 未来の先取り / デモ / BAB / 機能→便益、教えるなら 概念 / 手順 / 列挙 / 事例）。物語の型を当てない | explainer.md §1 |

**型は当てはめるものではなく、点検に使うもの。** 先に書いて、あとから
「山が中間に来ているか」「主人公が変わったか」を型で確かめるのが実務的。

**その「あと」は、脚本の本文ではなくハコ書きの段に置く**（`screenwriter` §1.5）。
箱を並べた時点で当てれば、抜けが見つかっても**箱を入れ替えるだけ**で済む。
本文まで書いてから当てると、全文の書き直しになる。

⚠️ **MV だけは尺で選ばない。** 3 分の MV に「1〜3 分 = 5 ブロック + 引き」を
当てない —— **MV の構成は曲の区間（イントロ / A メロ / サビ …）がそのまま決める**。
物語を入れる場合も、区間に配る形になる（mv.md §1.5）。

⚠️ **説明ものも尺で選ばない。** 60 秒のサービス紹介に 5 ブロックを当てない ——
**約束が 2 ビート目までに着地し、残りが全部その根拠**になっていればよい
（explainer.md §2）。主人公も欲求も山場も要らない。

## 2.5 企画書とログライン（**脚本より先**）

**①企画では、まず `series_bible.v1`（`name`「企画書」）に次を書く。**
ここが空のまま脚本に入ると、構成の型を当てても何も直らない。

| 項目 | 中身 |
|---|---|
| タイトル（仮） | — |
| **ログライン** | **1〜2 文。下の 4 要素がすべて入っていること** |
| ジャンル | — |
| 世界観 | 1 段落 |
| **ターゲット** | 誰がどこでどう見るか（縦持ちの通勤中 / テレビの前 / 配信を一気に） |
| **この企画の売り** | **これでしか提供できないもの**。「面白い」は売りではない |
| **最後の 1 カットを見た観客の状態** | 1 行。ログラインは筋の要約で感情の着地が無い。ここから様式（寄り方・色・音）を導く（`film-grammar` の references/direction-design.md §1） |
| **トーン（題材に向ける態度）** | 1 語（乾いた / 温かい / 冷笑 / 真顔の滑稽）。「コメディ」はジャンルでトーンではない。冒頭 1 シーンで観客に教える（同 §8） |

### ログラインの 4 要素

```
① 主人公は誰か  ② 何を望んでいるか  ③ 何が起きるか  ④ どんな話になるか
```

**4 つが書けない企画は、たいてい②（主人公の欲求）が決まっていない。**
そのまま脚本に入ると、山場で誰が何を得たのか分からない話になる。

**ログラインが 4 要素を満たすまで脚本に進まない。** 1 行なので直すのがタダで、
ここで直せば脚本の書き直しが要らない。

## 3. どのジャンルでも最初に決める 5 つ

企画書（§2.5）に加えて、この 5 つを文書（`series_bible.v1`）に置く。
**話数ごとに決め直さない** — ずれると、話数をまたいだ時に破綻する。
説明ものは 1 を「**誰に・何を約束するか**」に読み替える（ログラインの 4 要素は要らない。
explainer.md §0）。

| # | 決めること | 決めないと |
|---|---|---|
| 1 | **誰の話か**（主人公と、その人が何を欲しているか） | 山場が来ても誰の勝ちか分からない |
| 2 | **画風**（絵柄・実写かアニメか・時代） | カットごとに絵柄が振れる |
| 3 | **色と光の方針**（光は字コンテの言葉で持つ。見本の画像を動画に渡さない。`cinematographer` §0） | シーンごとに時間帯が飛ぶ（`art-director`） |
| 4 | **尺と話数** | 予算が読めない（`director` §5） |
| 5 | **縦か横か** | 絵コンテの向きが決まらない（`storyboard`） |

## 4. 全ジャンル共通の落とし穴

| 落とし穴 | なぜ起きるか |
|---|---|
| **登場人物が多すぎる** | 短いほど致命的。関係を把握できず離脱する |
| **説明から始まる** | 状況説明は画で見せられる。台詞で説明しない |
| **山場が終盤にしかない** | 短尺では前半に見せ場が要る |
| **話数ごとに設定を書き直す** | 必ずずれる。設定は 1 か所に置いて参照する |
| **尺を先に決めていない** | 構成が決まらず、生成費も読めない |
| **展開が早すぎる** | 求めたものが 1 回目の試みで手に入っている / 変化の直前に揺り戻しが無い / 山場が説明より短い。**型を当てても直らない**ので `screenwriter` §3.4 |

## 5. 生成で作るときに全ジャンルへ効くこと

- **カットを増やすほど費用が増える。** カット数の目安は各篇にあるが、
  **迷ったら減らす**（尺を詰めるほうが、品質と費用の両方に効く）。
- **絵コンテは 1 シーン 1 枚**（`storyboard`）。ジャンルが変わっても同じ。ただし
  静止画 + 動きで作るシーンは絵コンテが生成の入力にならず、1 カット 1 枚のラフになる
  （references/motion-stills.md §3）。
- **撮れないものは避けて設計する**（手指・文字・群衆。`ai-video-craft` §5）。
  ジャンルの定石であっても、破綻する題材なら別の見せ方に置き換える。
