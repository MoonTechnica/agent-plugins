# 縦型ショートアニメ

アニメの作法（anime.md）と縦型の設計（`vertical-shortform`）が交差する形式。
**生成と最も相性が良く、いま最も伸びている**。専業スタジオが立ち上がり、
年間数百本規模で作られ始めている。

## 1. なぜ生成と相性が良いか

| 理由 | 中身 |
|---|---|
| **尺が短い** | 1 話 30 秒〜2 分。モデルのネイティブ尺で足りる（`ai-video-craft` §1） |
| **カット数が少ない** | 横型アニメの 300 カットに対し、1 話 15〜40 カット |
| **止め絵が許される** | アニメの文法として自然。生成の弱点（動きの破綻）を避けられる |
| **登場人物が少ない** | 縦画面に 1〜2 人。同一性を保つ相手が少ない |
| **実写の再現度が要らない** | 絵柄が作品の様式なので、生成の癖が欠点になりにくい |

## 2. 規模の目安

| | 目安 |
|---|---|
| 1 話の尺 | **30 秒〜2 分** |
| 1 話のカット数 | 15〜40 |
| **1 カットの尺** | **2〜3 秒**（横型より明確に速い） |
| 登場人物 | 1 話につき **1〜2 人**（多くて 3 人） |
| 話数 | 連作前提。1 話で完結させず**引き**で終える |

## 3. 縦画面でアニメを撮る

**横型アニメの構図はそのままでは使えない。** 縦で効くものに置き換える。

| 横型で効く | 縦型での置き換え |
|---|---|
| 2 ショット（横並び） | **切り返し**、または**前後に配置**（手前と奥） |
| 広い背景の引き | **見上げ / 見下ろし**。縦に高さを使う |
| 横移動の追いかけ | **奥行き方向**の移動（こちらへ来る / 去る） |
| 横に長いレイアウト | **縦の PAN**（上から下へ振る）で見せる |

**縦で強いのは顔のアップ。** 横幅が無いぶん、表情がそのまま画面を占める。
アニメは表情の芝居が主力なので、**縦型はアニメに向いている**。

## 4. 止め絵と縦 PAN が主力

尺を持たせつつ費用を抑える主力が、**止め絵にカメラの動きだけ付ける**カット。

- **縦の PAN**（上から下、下から上）は縦画面でしか成立しない見せ方で、
  背景美術 1 枚を長く見せられる。
- **T.U（寄り）** は感情を上げる。表情に寄る。
- **止めて、決める。** 動かないカットを混ぜないと、全部が同じテンポになる。

止め絵 + カメラのカットは、動画生成せず静止画を描いて動かす作り方も選べる
（[motion-stills.md](motion-stills.md)。モーションコミックもここ）。

## 5. 音を切って見られる前提

`vertical-shortform` §6 のとおり、**台詞は原則すべて字幕にする**。
アニメは台詞で状況を語る比率が高いので、字幕が無いと成立しない。

**だから台詞を減らさない。** 止め絵が主力な形式ほど、**画から取れる情報が少ない** ——
動きで語れないぶんを言葉が背負う。**150 字/分 が下限**、標準 200〜280 字/分
（`screenwriter` の references/dialogue-and-exposition.md §1）。
**無言カットを 3 秒より長く続けない。** 止め絵 + 無言は、ミュート視聴では静止画と同じになる。

- 字幕は**下 400〜500 px を避ける**（UI に隠れる）。
- 文字は生成に任せず**タイムライン側で載せる**（`compositor`）。

## 6. 構成

- 1 話は **5 ブロック**（beat-sheets.md §5）。
- **冒頭 3 秒にフック**。日常の説明から始めない（`vertical-shortform` §3）。
- 末尾は**引き**。次の話が気になる状態で切る。
- 全体の設計は `arc.v1`（beat-sheets.md §6）。

## 7. 声

- キャラクターに**声の既定を持たせる**（`audio-engineer`）。
  話数ごとに選び直すと、同じキャラの声が変わる。
- **口を音に合わせる手はある**（`ai-video-craft` の references/lip-sync.md）。
  台詞をモデルに喋らせるならルート A、録音済みの声に合わせるならルート B。
  **アニメは音素に厳密でなくてよい**（2〜6 形の口形で足りる）ので、
  口が開閉しているカットを細かく割るだけでも成立する。
- 合わせないなら**口元のアップを避ける**。喋っているカットは寄りすぎず、
  聞き手の顔や背景を挟む。

## 8. 禁じ手

| 禁じ手 | なぜ |
|---|---|
| 横型で作って縦に切る | 構図が壊れ、下が UI に隠れる |
| 1 話に 3 人以上を並べる | 縦画面では読めない |
| 全カットを動かす | アニメに見えず、費用も跳ねる |
| 1 話を完結させて引きを作らない | 連作として続きが見られない |
| **状況を画と表情だけで立てる** | 止め絵主体ほど画の情報量が少ない。誰・どこ・望み・障害は言葉で立てる |
| **台詞が 150 字/分 を割る** | 「静かな演出」ではなく情報不足。何の場面か分からなくなる |
| 冒頭にタイトルやロゴを置く | 3 秒で離脱される |
