# キネティックタイポグラフィ（動く文字）の作法 — 2D も 3D も

文字そのものを主役に動かす表現。MV の歌詞・タイトル・説明ものの要点・CM のコピーで使う。
**何を・どれだけ・どの技で出すか**を決めるときに読む。出し方の実装は末尾の道具表。

根拠は `docs/_research/2026-11-16-kinetic-typography-2d.md` と `…-3d.md`。
**[出典値]** は公式資料・規格の数字、**[設計値]** は一次の数字が無く、ここで置いた出発点
（書き出して見て直す前提。確定値として人に言わない）。

## 1. 先に決めること（技より前）

1. **読ませるか、見せるか**。読ませる = 欠けると困る（説明・セリフ・サビの核）。
   見せる = 音で既に知っている（歌詞の多く）。**読ませる文字は動いている間は読めない**
   ので、着地して止まる時間を別に作る。
2. **主役は 1 画面に 1 つ**。大きさ・太さ・色・位置・動きのどれか 1 つで決める。全部使わない。
3. **動かす単位**: ブロック・行・語・字。**意味の単位で動かす**。字単位は短い語（〜10 字）か
   子音ハメ・日本語 1 字ずつの演出だけ。長文の字単位は読めない。
4. **2D か 3D か**: 3D は奥行き・カメラの通過・立体の物としての存在感を足す。
   足さないなら 2D が安く安全（読める・速い・崩れない）。**迷ったら 2D**。
   3D は「サビのビルド」「曲名の登場」「場面転換」の山にだけ置く（§5）。

## 2. 読める時間の下限

| 指標 | 値 | 根拠 |
|---|---|---|
| 日本語の読み速度 | **4 字/秒以下** | [出典値] Netflix 日本語字幕 |
| 最短表示 | **0.5 秒**（24fps で 12 コマ） | [出典値] 同 |
| 1 行の長さ | 横 13 字・縦 11 字・2 行まで | [出典値] 同（字幕の基準を借用） |
| 動きの出入り（0.3〜0.5 秒）は読み時間に**含めない** | 静止した状態を別に取る | [設計値] |
| 核の語 1〜2 個 | 着地して最低 0.5 秒静止 | [設計値] |
| 3D の判読窓 | 語 ≥ 0.4〜0.5 秒、フレーズ ≥ 1.0〜1.5 秒を**正面・焦点内・ほぼ静止**で | [設計値] |
| 3D の傾き | 読ませる瞬間は文字面とカメラ視線のなす角 ≤ 30°（理想 ≤ 15°） | [設計値] |

速い曲は全文を出さず**語を間引く**（見せる歌詞）。語ごとに全部ハメると 1 語 0.2〜0.3 秒で 4 字/秒を超える。

## 3. 意図 → 技 の早見（2D）

数値は 30fps。時間の長さは [出典値]（pixel-point/animate-text・HyperFrames・GSAP）か [設計値]。

| 意図 | 技 | 値 |
|---|---|---|
| 平常の歌詞・説明（読ませる） | 行か語の rise / マスクリビール | 行 0.6〜0.76s・stagger 0.09〜0.12s・`power3.out`・移動は字高の 0.3〜0.5 倍 |
| サビ頭・決意・怒り | スラム | scale 1.5→1 + blur 16→0・0.45〜0.5s・`power4.out`/`expo.out`。**着地を拍に**。1 曲 5〜10 回まで |
| 軽い・かわいい | 語単位のポップ | 0.36s・stagger 0.095s・scale 0.7→1。**字単位は跳ねすぎる** |
| 静か・余韻 | ブラーイン / 焦点合わせ | 大きい見出しだけ。blur 中は読めない |
| 短いタイトル | 字の rise / 中心から外 | 0.7s/stagger 0.024s、総 stagger ≤ 0.8s |
| 機械的・字幕風 | タイプライター | 0.24s/0.046s・`steps(1,end)` |
| 言葉を積み上げる | 押し出し / word stack | 1 行ずつ 0.3〜0.5s、最終形を ≥ 0.5s ロック |
| デジタル・不安 | グリッチ（色ずれ） | ベースの字は常に最前面。決定論ハッシュ。0.2〜0.4s |
| 解読・暗号 | スクランブル | **素のライブラリ版は seed 不可で再現しない**。時刻を量子化→ハッシュで字を選び、語単位で確定 |
| 1 語を強調 | scale 1→1.15 + 太さ/色 | 周囲は止める。0.2〜0.3s |
| 日本語の意味の核（漢字 1〜2 字） | 巨大化 + 静止 | 4〜10 倍が定番（**目測・一次なし**）。かな・助詞は小さく添える |
| 呼吸・息づかい | 可変フォントの太さ | 全軸を from/to に書く。リフローに注意 |

**stagger の総時間** = (n−1)×間隔 を **0.6〜0.8 秒以内**に（長文を 24ms × 40 字 = 0.94 秒で出すと読み始めが遅い）。
**イージング**は `power3.out` を既定、スラムは `expo.out`。**オーバーシュートは遊びの語り口だけ**
（行き過ぎ 5〜10%）。1 曲で「静 / 普通 / 叩く」の 3 性格程度に絞る。
**縦組み**は読みの進行が上→下なので、入りも上から降りる／下から立ち上がる。横スライドは読みと直交して散漫。

## 4. 3D の技（レシピ 14 種）

実装（どのノードをどう置くか・スクリプト）は previz スキルの
previz の `references/kinetic-typography-3d.md`。ここは**いつ使うか**。

| 意図 | レシピ | 要点（[設計値]） |
|---|---|---|
| サビのビルド・語数が多い | **R1 ワードトンネル** | 語を奥行きに並べ、カメラが抜ける。各語の手前で減速・0.3 拍止める（判読窓）。FOV 55〜65° |
| 叩きつけ | **R2 スラム＆シェイク** | 来る 0.12〜0.2s・着地で 1.0→1.15→1.0。シェイクは字高の 3〜6%・0.3s で減衰。**ロールはしない** |
| 曲名・タイトル登場 | **R3 オービットリビール** | −120°→0° を 1.2〜2.0s。終端で 0.5s 静止 |
| 焦点が語から語へ | **R4 深度スタック** | 3〜5 層。**うちは被写界深度が無い** → 奥の層を不透明度・小ささで退かせる |
| ビルドアップ | **R5 散らし→集め** | 字ごと 0.04s ずらし・0.8s で集合。seed 固定で再現 |
| 落下・衝突 | **R6 グラウンドドロップ** | 解析式のバウンス 3 回。接触影は偽物で十分 |
| 空間に語を巻く | **R7 円筒ラップ** | 一方向に 1 周 6s 以上。正面 ±35° が読み帯 |
| ネオン看板 | **R8 点滅** | 1 秒に 3 回まで。点滅はコマごとのハッシュ |
| 字ごとの波 | **R9 フリップ** | 0.05s ずらし・0.5s で 360°。最後は正面 |
| 爆発 → 再構築 | **R10** | 物理は走らせず**事前に焼く** |
| 3D → 2D の継ぎ目 | **R11 マッチカット** | 語が画面幅の 80〜90% になる距離で止め、正面・ロール 0 で 2D の板へ |
| 絵・人物と合成 | **R12 2.5D カードスタック** | 背景/中景/文字/前景の 4 層 |
| 曲線に沿わせる | **R13 経路追従** | 曲率半径 > 字高の 3 倍 |
| 圧縮ズーム | **R14 ドリーズーム** | 1 カットに 1 回まで |

**CJK**: 厚みのある文字（`depth`、字高 ×0.12）は 1〜2 語の主役だけ。
それ以外は**平らな板**（SDF / 画像）。**その曲の全文字だけを 1 回サブセット**して同梱し、
実行時に CDN から取らない。縦組みは字ごとに自前で置く。

## 5. 曲全体の配分

- A メロ = 控えめ（行の rise、動き小）→ B メロ = 徐々に（語単位・stagger を縮める）→ サビ = 最大
  （スラム・ジャンプ率最大・画面いっぱい・差し色 1 色）→ ブリッジ/落ち = ほぼ静止。
- **サビ直前に 1 拍の静止**を作る。次の叩きが効く。
- 叩く 5〜10 回、字ごとのハメ 2〜3 か所、**3D は曲に 1〜3 か所**。全行を同じ出方にしない。
- 拍への当て方: 視覚の「当たり」と音の onset を同じコマに。入りは**拍の 1〜3 コマ前から動き始め、
  拍で着地**（予備動作）。着地後に 0.2〜0.4s の減衰（ばね ζ 0.5〜0.7）。強拍で 1.0→1.15〜1.25→1.0。
  すべての出が**1 本の拍格子**から引かれていること（手で振ったずれはドリフトする）。

## 6. 守ること（映像として壊さない）

| 守ること | 理由 |
|---|---|
| **フラッシュは 1 秒に 3 回まで**。赤の全面フラッシュを避ける | WCAG 2.3.1 [出典値] |
| **大面積のスケール脈動・パンの連発を避ける**。ロール 0（使っても ±5° まで 1 秒以内） | 前庭への負荷 |
| カメラ回転は一方向・1 周 6 秒以上。FOV を急に変えない | 酔い [設計値] |
| **乱数は seed 付き・時刻の関数**。`Math.random` / `Date.now` / 無限リピートは使わない | 書き出しが再現しない（HyperFrames の契約） |
| フォントは同梱（woff2）。読み込み後に分割 | マシン差・ずれ |
| 影・縁・グロー・色収差を既定値のままにしない | 安っぽい。差し色は絵の中の色から 1 色 |
| 目と口の上に文字を重ねない。人物の前後は意図して決める | 重ねるのは 1 曲で要所 1〜2 回 |
| 背景に**実際に載せて**確かめる（細い字は絵に溶ける） | コントラスト目標は大きい字で 3:1、通常 4.5:1 |

## 7. 禁じ手（多い順）

1. 全行・全語に別々の派手な動き（階層が消える）
2. 読ませる文をぼかし・グリッチ・高速 stagger で出す
3. 長文を字単位で動かす
4. オーバーシュート / バウンスを既定にする
5. 3D を全編に使う・押し出し文字を大量に使う・CJK 全字をメッシュ化する
6. 判読窓（正面・静止・焦点内）を作らずに通過させる
7. letter-spacing / 太さを無造作に動かして周りをリフローさせる
8. 歌詞の区切りに編集点を律儀に揃える・歌詞を全部出す
