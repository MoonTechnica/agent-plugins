# 実写ドラマ・映画

**生成では最も難易度が高い形式。** 絵柄が様式になるアニメと違い、
実写は**現実と比べられる**ので、破綻がそのまま嘘として見える。

## 1. 規模の目安

| | 尺 | 構成 |
|---|---|---|
| 連続ドラマ 1 話 | 45〜60 分 | 三幕構成 + 幕間で引き |
| 30 分ドラマ | 22〜25 分 | ストーリーサークル 8 段 |
| 短編映画 | 5〜30 分 | 三幕構成 |
| 長編映画 | 90〜120 分 | **15 ビート**（beat-sheets.md §1） |

**1 カットの平均尺は 3〜5 秒**（現代の主流映画の実測。アクションは約 2 秒）。字コンテの段で
`screenwriter` の `scripts/cut_pacing.py --format drama_film` で測る（帯と出典は同 references/cut-timing.md §4）。

**生成でこの尺を通すのは費用が重い。** 長編を作るなら、まず
1 シーンだけ通して品質と費用を確かめてから全体に広げる（`director` §5）。

## 2. カバレッジは「撮る」のではなく「マスターを先に 1 枚」

実写の現場は 1 シーンを**複数のアングルで撮り切る**（マスター → 寄り →
切り返し → インサート）。編集で最適な組み合わせを選ぶのが前提の作り方。

生成では**マスターの役割だけが残り、選ぶ側は無い**。シーンの空間・立ち位置・光を
決める引きの静止画を 1 枚描いて `set_scene_master` にすると、絵コンテの全コマが
その中で描かれ、**空間・光・人物の位置**が揃う（`storyboard` §1.5）。動画は
その絵コンテから撮る（マスターを動画に渡しはしない）。
一方で寄り・切り返しは**頼んだ 1 通りしか出てこない**ので、
**編集で選ぶのではなく、設計で決める**必要は変わらない。

| 実写のカバレッジ | 生成での置き換え |
|---|---|
| マスターショット（全体を通しで） | **マスターを 1 枚描く**（引きの静止画。`set_scene_master`）。絵コンテの空間と光の正本になる |
| 寄り（各人物） | 本番の多カット生成に含める。シートのコマで**構図を設計**する |
| 切り返し | **イマジナリーラインを決めてから**両側を設計（`film-grammar` §2.1）。マスターは線を守ってくれない |
| インサート（小物・手元） | **手元は避ける**（`ai-video-craft` §5）。物単体で撮る |

**つまり絵コンテの精度が実写より要る。** 迷ったまま撮って編集で決める、
ができない。掛け合いの無い短いシーンは、マスターを省いてよい（`board_sheet.use_master=false`）。

## 3. シーンの切り方

**1 シーン = 1 つの場所 + 1 つの時間帯。** これは実写の慣習であると同時に、
生成では**背景と光が変わるため 1 パスで通せない**という物理的な理由がある
（`screenwriter` §2）。

- 場所が変わったら**必ず確立ショット**を入れる（`film-grammar` §5）。
- **時間帯をまたぐシーンを 1 つにしない。** 光が飛んで別の場所に見える。

## 4. 会話の撮り方

実写ドラマの本体は会話。ここで繋がりが壊れると全部壊れる。

1. **2 ショット**で位置関係を見せる（誰がどちら側か）
2. **イマジナリーラインを決める**（`film-grammar` §2.1）
3. 以降は**肩なめ / 寄り**を、線の同じ側から交互に
4. 感情が動く所で**さらに寄る**

- **切り返しの両者は同じ焦点距離・同じ距離・同じ頭のサイズで撮る**（ずらすと意図しない力関係が出る）。
  寄りは望遠ではなくカメラを近づけて作る。ジャンル別の定石は [camera-by-genre.md](camera-by-genre.md) §1。

- **全部の台詞で切り返さない。** 聞いている側に留まる時間が芝居になる。
- 音と画をずらす（J カット / L カット）と会話が自然になる（`audio-engineer`）。

## 5. 生成で特に苦しい所

| 苦しい所 | 対処 |
|---|---|
| **同じ役者が同じ顔で出続ける** | 確定素材を毎回参照に渡す（`ai-video-craft` §6） |
| **手元の芝居**（物を渡す、書く、料理） | 受け渡しの前後でカットを割る。手を大きく映さない |
| **群衆のいる場所**（街・オフィス・学校） | 引きでボケさせる。時間帯を夜にして人を減らす |
| **長回し** | 割る。ネイティブ尺を超えない（`ai-video-craft` §1） |
| **看板・書類・画面の文字** | タイムライン側で載せる（`compositor`） |
| **アクション・激しい動き** | 引きで撮る。動きの一部だけを見せる |

**実写らしさを狙うほど破綻が目立つ。** 様式を寄せられる余地があるなら
（フィルム調・モノクロ・夜・雨）、そちらに寄せたほうが成立しやすい。

## 6. 構成の当て方

- 長編は **15 ビート**で点検する（beat-sheets.md §1）。
  とくに**中間点（50%）で反転しているか**を必ず見る。
- 連続ドラマは**幕の切れ目に引き**を置く（beat-sheets.md §6）。
- **10 のジャンル分類**（beat-sheets.md §1）を当てると、
  「この話に何が足りないか」が言語化できる。

## 7. 禁じ手

| 禁じ手 | なぜ |
|---|---|
| カバレッジを撮るつもりで多めに生成する | 費用が跳ねる。設計で決める |
| 1 シーンに複数の場所・時間帯を入れる | 1 パスで通らない |
| 手元・文字・群衆を正面から撮る | 破綻する |
| 長回しで見せようとする | ネイティブ尺を超えると品質が落ちる |
| 絵コンテを詰めずに生成へ進む | 編集で救えない |
