# MV の歌詞の見せ方（リリックモーション・作字・キネティックタイポ）

歌詞を**字幕ではなく構図の要素**として組む作法。出すかどうか・どこまで出すかは企画で決める
（mv.md §2「歌詞を画面に出すか」）。出すと決めたら、ここに沿って**しっかり演出する**。
組み方の HTML / CSS / three.js は `compositor` の references/lyric-motion.md、文字の置き場を
絵に空ける描かせ方は `art-director` の references/motion-stills.md §7。
調査の根拠は `docs/_research/2026-11-11-mv-lyric-typography.md`。

## 1. 「見せる」行と「読ませる」行を分ける

| | 見せる行（要所） | 読ませる行（残り） |
|---|---|---|
| 役割 | 図として画面を割る。意味の核を叩きつける | 歌を追わせる |
| 組み | ジャンプ率を極端に（§2）、縦横・散らし・3D | 1〜2 行、控えめな出方（フェード・マスクの上がり） |
| 画面全体の処理（色収差・フィルム・黒帯） | **内側に入れる**（文字だけ処理の外にあると後から乗せた字幕に見える） | 外側でもよい（読みやすさ優先） |

字コンテの段で、**見せる行と、その行の核の語（1〜2 字）に印を付ける**。

## 2. 大きさと組み

| 決まり | 中身 |
|---|---|
| **ジャンプ率を極端に取る** | 見せる行は意味の核の漢字 1〜2 字を画面の高さの 1/2〜ほぼ全高、かな・助詞は 1/8〜1/10（倍率は見本からの目安）。表意文字であることが日本語のリリックの面白さ（G子: 「孤独」「葬」を 1 コマだけ大きく出すと「ピリッとする」） |
| **書体 1 つ・色 1 つ** | 差は大きさと置き場だけで作る。1 曲でも書体は 2 つまで |
| 差し色は絵の中の色から | 瞳・小物・光の色（アートディレクションのパレットの「強調」色）。モノクロの絵に赤だけ、のように 1 色 |
| 縦と横 | 縦組みは和・静・余白、横組みは速さ・現代に寄る（推測）。混ぜるなら区間で切り替える |
| 散らし組み | 縦の列を複数、列ごとに天地と大きさをずらす。静かな区間（A メロ・落ちサビ）に向く |
| 1 語だけ出す | 1 行を全部出さず核の語だけ、も選べる |
| 書体の選び方 | 細〜中の明朝（静か・透明感）/ 極太の明朝・筆（情念・毒）/ 極太の角ゴシック（叩きつけ・速さ）/ 手書き（可愛さ）/ 装飾書体は 1 曲 1 回まで。**商用の映像に使えるもの（OFL）だけ**から選ぶ（候補の一覧は compositor） |

## 3. 人物との前後関係（カットごとに 3 択）

| 型 | 重ね順（下 → 上） | 向くところ |
|---|---|---|
| **後ろに回す** | 背景 → 文字 → 人物 | 文字と人物が同じ空間にいる一体感。巨大な字を人物の背後に |
| **避ける** | 背景 → 人物 → 文字（人物の輪郭の外に置く） | 散らし組み・縦の列で余白を埋める |
| **重ねる** | 背景 → 人物 → 文字（小さな字を頬・肩・手に） | 感情の転換点。**1 曲 1〜2 回、目と口は潰さない** |

後ろに回す・3D に置くには**人物が別の層に分かれた絵**が要る（描くときに注文する）。

## 4. 出方と動き

| 型 | 中身 |
|---|---|
| 叩きつけ | 巨大な 1〜2 字が拍で着地して止まる |
| 1 文字ずつ | 拍頭・語頭・子音の立ち上がりで 1 字ずつ |
| 1 コマの閃き | 核の字を 1〜2 コマだけ全画面に（読ませない演出として意図したときだけ） |
| 書き順で描く | 字が筆の運びで現れる。トメ・ハネ・ハライのタメツメで手が書いているように |
| 変形・作字 | 字が次の字へ変わる、字の一部が図形になる。手作業の見せ場 |
| 意味で動かす | 「膨らむ」なら膨らむ、「散る」なら散る |
| 崩す | 色ずれ・スライス・明滅で崩して戻す。**ごく控えめに**（既定値の色ずれは安っぽい） |
| 止めて読ませる | 動かないタイポも強い |

**奥行き（3D）**: 層の間に文字を挟んでカメラが寄る / 床や壁に寝かせる / 被写界深度で読む列だけピントを
合わせる / 奥から飛んでくる / 文字のトンネルをカメラが進む / 押し出した立体文字。どれを使うかは
「層が 10 枚程度までで交差も光も要らないか」で作り方が分かれる（compositor）。区間の入り・サビの
引きに 1〜3 カット。続けて使わない。

## 5. 配分（3〜4 分の MV。数値は目安）

打点の配分（motion-stills.md §5）に文字の型を割り当てる。

| 型 | 1 曲あたり | どこに |
|---|---|---|
| 巨大な 1〜2 字の叩きつけ | 5〜10 回（= ピークハメ） | サビ頭・キメ・曲名の語 |
| 1 文字ずつ子音で | 2〜3 か所（= 子音ハメ） | 破裂音・摩擦音の強い語 |
| 1 コマの閃き | 1〜3 回 | ブリッジ・不穏な語 |
| 書き順・作字・変形 | 1〜2 回 | 曲の主題の語 |
| 3D | 1〜3 カット | 区間の入り・サビの引き |
| 顔に重ねる | 1〜2 回 | 感情の転換点 |
| 散らし組み | 区間ごとに 1 回程度 | 静かな区間 |
| 控えめな出方 | 残りの行 | 歌われている間だけ。間奏に残さない |

## 6. 避けること

| 避けること | なぜ |
|---|---|
| 全行を同じ出方 | 字幕に戻る |
| 歌詞の区切りに編集点を律儀に揃える | 「記号」として消費されて古く見える（大橋史） |
| 効果を既定値のまま使う（縁取り・影・グロー・色ずれ・斜体・揺れ） | どの効果も既定値のままが安っぽさの原因 |
| 書体・色を増やす | 1 本に見えなくなる |
| 目と口を潰す | 歌唱と感情が消える |
| 読めない時間 | 3 秒出すなら 2 秒で読める量。閃きは意図したときだけ |
| 小さすぎる字 | 1920×1080 で 40px 未満にしない。小さい側のかなも 48px 以上を目安 |
| 生成 AI に文字を描かせる | 読めない字が出る。文字は必ずタイムラインで載せる |
