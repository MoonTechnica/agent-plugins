# MV（ミュージックビデオ）

## 0. MV は「曲に映像を付ける仕事」ではない

**曲を説明する宣伝映像ではなく、記憶に残る短い映画をつくる**のが MV。
歌詞を絵にしただけのものは、曲を聴けば分かることを繰り返しているにすぎない。

設計するのは**「見る人がどの瞬間に心を動かされるか」**であって、歌詞の内容ではない。

**歌唱シーンと演奏シーンは、MV を構成する要素の 1 つでしかない。**
実際には、歌っていない映像だけで 1 本成立している MV のほうが多い。

## 1. 順序が逆になる

```
通常:  映像の尺が確定 → 音を作る
MV:    音が確定       → その尺に映像を合わせる
```

**この順序を先に宣言してから作業に入る**（`audio-engineer` §1）。
途中で入れ替えると、作り直しが両方向に発生する。

### 最初の作業は「曲の地図」を作ること

**楽曲の構成を秒数で書き出す。** これが設計図になり、以降のすべてがここに乗る。
あなたは曲を聴けないので、**地図は機械に測らせ Gemini に名付けさせ、分割はあなたが決めて `write_music_map` で書く**（`audio-engineer` §7）。
機械が拍・小節頭・小節ごとの音量と**鳴っている楽器**を測り、Gemini がそれに名前を付ける。
返る `audio_map.v2` には下の表に加えて、**編成の帯**（`arrangement`。いつ誰が鳴っているか）、
**出来事**（`events`。楽器が入る / 抜ける / 全員が入る / 引き算 / ソロ / キメ。大きさ 1〜3）、
`scene_plan`（どこで替え、拍で切るか流すか、画の狙い）が入る。

```
0:00-0:12  イントロ    （歌なし）
0:12-0:38  A メロ 1    （歌あり）
0:38-0:52  B メロ 1    （歌あり）
0:52-1:20  サビ 1      （歌あり・最重要）
1:20-1:32  間奏        （歌なし）
...
```

- カットの尺は**小節と拍**に合わせる。尺の指定は整数秒なので
  （`screenwriter` §3.1）、**合わない所はタイムライン側で詰める**（`compositor`）。
- **BPM が分かるなら 1 拍の秒数を出しておく**（60 ÷ BPM）。
- **「動きの点」は地図の `events` にある。** 楽器が増える・全員が入る・声が入る・落ちる・
  キメ。ここが画を変える場所になる。**編成の変化は区間名より強い** —— 「イントロ」の中でも、
  ギターだけ → 全員 に変わる瞬間が画を変える場所。

## 1.5 展開を決めるのは曲（物語ものとの違い）

**MV では、曲の構造がそのまま作品の構造になる。**
物語ものの手順（シーンの転換を決めて、ビートへ割って、カットにする）を
そのまま持ち込むと噛み合わない。

| | 物語もの | **MV** |
|---|---|---|
| 展開を決めるもの | 物語のビート（行動と反応） | **曲の構造**（区間・拍） |
| 起点 | 「このシーンで何が転じるか」 | **曲の地図**（§1） |
| カットを割る基準 | ビートが変わるとき | **拍の頭・区間の切り替わり・編成の変化** |
| 物語 | 骨格そのもの | **区間に配る**（無くてもよい） |
| 完結性 | 各シーンが転じる必要がある | **断片でよい**。曖昧なまま終わってよい |

**物語をやる場合も、物語が音楽に従属する。**
「物語のビートで曲を切る」のではなく、**「区間に物語を配る」**。
逆にすると、曲を無視した映像になる。

**シーンの境目は「変化の大きさ」で決まる。長さの下限は無い。**

- 大きな変化（`events` の magnitude 2 以上。全員が入る・引き算・ソロの始まり・ドロップ）は
  **必ずシーンの境目**。7 秒のギターリフの導入でも、全員が入る瞬間までが 1 シーン
  （束ねると「全員が入った」瞬間が画に出ない。2026-10-09 の本番はこれで平板になった）
- キメと止めはシーンを割らず、**そのシーンのカットの打点**（`scene_plan[].hits_sec`）
- 小さな変化（magnitude 1）はシーンの中でカットを変える
- **生成の都合（1 回の生成のカット数・尺の上限）は境目の理由にしない。** 入りきらないときは
  シーンの中をフレーズの頭で割る（`screenwriter` の references/other-formats.md §2）

### 作る順序

```
① 曲の地図を作る              区間と秒数、拍、編成の帯、出来事（§1）
② 企画を決める                コンセプト / 視覚言語 / 見せ場 1 つ（§2）
③ 区間ごとの役割を割り当てる    イントロ=世界、サビ=見せ場、大サビ=着地（§4）
④ 見せ場を先に置く             サビ・大サビの画から決める。前から順に埋めない
⑤ 区間の中でカットを割る        小節の表の上で、拍・フレーズ・歌詞の行で切る。密度は区間で変える（§5）
⑥ 各カットに情景を足す          誰が / どこで / 何を / 何が見えている / 光
```

**④が物語ものと最も違う。** 物語は頭から順に積むが、**MV はサビから決める**。
サビの画が決まらないうちに A メロのカットを作っても、後で作り直しになる。

**⑥の書き方は物語ものと同じ**（`screenwriter` の references/scene-writing.md
第 2 部）。内面を外面化する、具体名詞と動作動詞、情景は選んだ数点、
生成で変わるもの（時間帯・光・天気）を決める —— ここは形式を問わず効く。

## 2. 企画（トリートメント）— ここで作品の質が決まる

**絵コンテより前に、1 枚の企画を書く。** 撮り方を考える前に「何をやるのか」を
言語化する。これが最初の演出行為になる。

### 書くこと

| 項目 | 中身 |
|---|---|
| **コンセプト（2 段落）** | ① どんなアイデアで、なぜ心が動くのか ② その見せ方が**曲の構造をどう反映するか** |
| **視覚言語（4 つ）** | **色 / 光 / カメラの振る舞い / 質感** |
| **見せ場（1 つ）** | この MV を一言で説明できる「これ」。**1 つでいい** |

### 差し替えテスト（必ずやる）

**その企画を別の曲に差し替えても 1 語も変えずに成立するなら、企画になっていない。**

「都会の夜を歩く」「雨に打たれる」「白い部屋で歌う」——どれも**どの曲にも当てはまる**。
当てはまってしまう時点で、その曲のための企画ではない。

**曲の固有名詞を掴む。** 歌詞・メロディ・声質・テンポのどこが特別なのかを 1 つ挙げ、
それに衣装・色・動きを直接結び付ける。

### 歌詞をどう扱うか

**強い歌詞ほど、そのまま映像にすると余白が無くなる。**
歌詞が既に言っていることを画でも言うと、見る側のする事がなくなる。

| やり方 | 例 |
|---|---|
| **比喩に置き換える** | 「終わり」→ 片付けられていく部屋 |
| **反対を見せる** | 悲しい歌詞に、明るい情景 |
| **関係ない筋を並走させる** | 歌詞と別の物語が同時に進む |
| そのまま見せる | **決め所だけ**。ここぞで効く |

### 歌詞を画面に出すか（企画で決めて書く）

**歌詞の表示は演出の選択であって、既定で出すものでも、既定で出さないものでもない。**
企画（トリートメント）に**どれにするかを 1 行で書く**。ユーザーの指定があればそれが最優先。

| 出し方 | 中身 | 向いている MV |
|---|---|---|
| **出さない** | 画だけで見せる | 実写調・コンセプト型・歌詞より音と画で押す曲 |
| **要所の演出** | サビ頭・キーワード・決めの一節だけを**画の一部として**組む（タイポグラフィ・手書き・画面に溶け込む文字） | **アニメ調の MV**（下記） |
| **全編** | 歌われている行を順に出す（リリックビデオ・字幕的な出し方） | リリックビデオ（§9）・歌詞を読ませたい曲・縦型の短尺 |

**アニメ調の MV は「要所の演出」を既定の候補にする。** 日本のアニメ MV では、歌詞を
文字として画面に組み、映像と一緒に動かす演出がよく使われる。歌詞の一節を背景や
小物に置く、カットの切り替わりに文字を叩きつける、サビ頭でタイトル的に大きく出す、など。
ただし**全行を出すと画が文字に負ける**ので、出すのは要所に絞る（全編にするのは
リリックビデオとして企画したときだけ）。

どの出し方でも、**歌詞の時刻は取っておく**（`audio-engineer` の歌詞の時刻合わせ）。
出さない MV でも、歌詞で切るカット・どのカットで何を歌うかの割り当てに使う。
組み方は `compositor` の「MV の歌詞」。**文字は生成させない**（読めない字が出る）。

## 3. 型（6 つ）— 歌唱・演奏はそのうち 1 つ

| 型 | 中身 | 生成での作りやすさ |
|---|---|---|
| **パフォーマンス** | 歌唱・演奏 | **難しい**（口の同期・手指・楽器が破綻する） |
| **ダンス** | 振付を見せる | **難しい**（全身と連続した動きが要る。§6） |
| **ナラティブ** | 物語を演じる | **作りやすい**。ドラマとして設計できる |
| **コンセプト** | 物語を持たず、イメージで見せる | **最も作りやすい**。破綻を避けやすい |
| **リリック** | 歌詞を画面に出す | **作りやすい**（§9） |
| **アニメーション** | 絵で作る | 作りやすい。様式が生成の癖を吸収する |

**生成で作るならナラティブ / コンセプト / リリック / アニメーションが有利。**
パフォーマンスとダンスを主にする場合は、条件を満たす設計が要る（§6・§7）。

**実作の多くは混合。** サビだけパフォーマンス、A メロはナラティブ、が定型。
**混ぜる場合は、切り替わる場所を曲の構造に合わせる**（区間の頭で切り替える）。

## 4. 区間ごとに何をするか

**曲全体を 1 つのやり方で通さない。** 区間ごとに役割を変える。

| 区間 | 既定の方針 |
|---|---|
| イントロ | 世界を見せる。**まだ人物を出し切らない** |
| A メロ | 物語・情景を進める。カットは長め |
| B メロ | 溜める。寄っていく |
| **サビ** | **見せ場**。カットを短く、画を変える。曲の顔 |
| 間奏 | 画で遊ぶ。ダンス・抽象・風景 |
| 大サビ | **最も強い画**。ここが着地点 |
| アウトロ | 引く。余韻を残す |

**区間名より編成が強い。** 同じ「イントロ」でも、ギターだけの 4 小節と全員が入ってからの
16 小節は別の画にする。地図の出来事（`events`）ごとの画の決まりは
**[mv-dynamics.md](mv-dynamics.md) §7「編成を画に写す」**が正本（単独楽器 → その奏者だけ、
全員が入る → 初めて全体・サイズ跳躍・光を開く、引き算 → 画も引き算、1 パートのキメ → その奏者に光）。

**歌なしの区間に歌唱カットを置かない。** 当たり前に見えて、通しで作ると起きる。

## 5. カット数とテンポ

**費用の上限と、音楽的な密度は別の話。** 混ぜると「等間隔の長いカット」になる。

| | 目安 |
|---|---|
| 音楽的な密度（実測の平均ショット長は MV で約 2 秒） | **サビ 1〜2 小節、A メロ 2〜4 小節、間奏 4〜8 小節**（120 BPM なら 2〜4 / 4〜8 / 8〜16 秒） |
| **生成で作るカット（15 秒シーンあたり）** | **サビ・ドロップ・大サビ 5〜6（2〜3 秒）**、B メロ 3〜4（詰めていく）、A メロ 3、イントロ 2〜3、ブリッジ 1〜2。3 分の曲で 50〜70 カット前後になる。区間ごとの表と理由は **[mv-dynamics.md](mv-dynamics.md) §1** |
| 生成費で削るとき | **サビのカット数から削らない。** 削るのはイントロ・A メロ・アウトロの長さと、2 番の A メロ（1 番の画を回す）。1 秒のキメは生成せず既存クリップから切る（mv-dynamics.md §1） |
| サビ | **カットを増やし、頭で画を変える**（既定。長回しで通すなら意図を書く） |
| A メロ・静かな箇所 | カットを減らし、**歌詞と芝居で切る**（拍は節目だけ） |
| ブリッジ | **拍から浮かせる**（遅く、詩的に）。次のサビ頭で拍へ戻る |
| パフォーマンス区間 | 同期は口と手の継続性で取る。カットは楽器の入り・語頭で切り、ダウンビート一致を要求しない |

**最大の失敗は「等間隔で切ること」。** 全カットが同じ長さで並ぶと、
編集していないように見える。これが生成で作った MV が安く見える最大の原因。
**拍で切ると等間隔が構造上の既定になる**ので、1 / 2 / 4 小節を混ぜて崩す。

**次に多い失敗が「切りすぎ」。** 速く切れば格好よくなるわけではない。
**切る回数ではなく、切る場所**で決まる。ただし生成した MV で実際に起きているのは逆で、
**サビまで A メロの密度とカメラの抑制で通してしまう「のっぺり」**のほうが多い。
サビ・ドロップ・ダンス・大サビの既定（密度・カメラ・サイズの跳躍・二次運動）とテンプレート、
書き終えたときのチェックは **[mv-dynamics.md](mv-dynamics.md)** が正本。

### ビートへの合わせ方（正本は `film-grammar` の `references/beat-sync.md`）

- **シーンとカットの切り替わりは必ず拍の上に置く**（この製品の MV の既定。外れた切り替わりは違和感に
  なる）。機械的にしないのは、**どの拍で切るかを散らす**ことで行う（下記）。置くのは
  `apply_scene_proposal(boundaries_sec)` と `align_scene_cuts`（`compositor`）
- **カットごとに切る根拠を 1 つ決める**（拍・歌詞・旋律 / 和声・芝居・物語）。根拠は**どの拍を選ぶか**に
  効く（歌詞なら語頭に最も近い拍）。**「機械的」の正体は全部が同じ拍（毎回ダウンビート・等間隔）で
  切れること**で、拍に乗っていること自体ではない。ジャンルで選ぶ拍は変わる（ヒップホップ / R&B は
  毎拍寄り、ポップは区間の頭、ロック / エレクトロは小節の中の拍も使う）。
- **拍で切るカットの場所は拍の階層で決める。** 区間の頭（サビ・ドロップ）＞ フレーズ頭（4 / 8 小節）＞
  小節頭 ＞ 2・4 拍目。**既定は 1〜2 小節。すべての拍で切らない**（決め所だけ）。
  **ずっと 1 拍目で切らない** —— 担当楽器（キック / スネア / ハイハット）を 1 フレーズに 1 回は乗り換える。
- **拍から外すのはユーザーが求めたときだけ**（区間先行・ブリッジを浮かせる等の技法は beat-sync.md §4）。
  歌唱カットの入りは語頭の前後の拍から選ぶ（サビ頭は語頭に最も近い拍）。
- **キメ（揃って打つアクセント。1 パートだけのこともある）では 1 ヒット = 1 カット**で切り替えてよい。
  時刻は地図の `scene_plan[].hits_sec`（`events` の `kime` / `stop`。計測の打点で、拍の格子ではない）。
  1 パートのキメは**その奏者だけに光を当てる**。直前に長いカットか静止を置く。
- **カットは拍の 1〜2 コマ前に置く**（約 40〜80 ms）。拍ぴったりは遅れて見える。
- **小さな動きを拍に乗せる**（拍で振り返る、拍で目を開く、拍で光る）。
  **拍で着地させる動きは拍より前に始める。** カットを切らなくてもリズムは出る。
- **カメラの動きは 1 カットに 1 つ、尺は小節で決める**（1 小節で寄って小節頭で止める）。A メロ・ブリッジは
  1 フレーズに 1 回が目安。**サビはカットごとに別の動きを並べる**（mv-dynamics.md §2）。1 カットの中で
  拍ごとに揺らさない
- **サビ頭の直前で 1 拍止める**（静止か無音）。落差でサビが立つ。
- **速度の変化を繋ぎ目に使う**（ゆっくり → 急に速く）。
  速度が変わる瞬間に切り替えを隠すと、切れ目が見えなくなる。
- **必ず合わせる点（アンカー）を先に決めて逆算する**。サビ頭・ドロップ・歌詞のキーワード。
- **拍を正確に置けるのはタイムラインだけ。** 字コンテは整数秒、生成も整数秒なので、
  上流は「小節数で尺を決め、ピークを拍の近くに置く」まで（吸着は `compositor` §10）。

**編集は 2 回目の演出。** どこで切るかで曲の体感速度が変わる。

## 6. ダンスの撮り方

**歌唱カットとは要求が正反対**なので、混同しない。

| | 歌唱カット | ダンスカット |
|---|---|---|
| 画角 | **顔が画面の 20〜40%** | **全身が入る。足まで入れる** |
| 寄り | ミディアム中心 | **引き中心** |
| カメラ | 固定寄り（**口を見せるカットは遅い動きだけ**） | **振りに従う**: 周回か固定、決めのカウントだけ bump。踊りと逆向きに動かさない（mv-dynamics.md §2.2） |
| 切る場所 | フレーズの切れ目 | **拍と、振りの決めの瞬間** |

- **足を切らない。** 振付は足まで含めて設計されている。切ると何をしているか分からない。
- **同じ振りを別角度で持つ。** 角度を変えて繋ぐと密度が出る。
- **振付は歌詞に沿って作られていることが多い。** フレーズの切れ目で切ると噛み合う。
- **ズレが一瞬で分かる。** ダンスは同期の精度が最も厳しい。
- 生成では**連続した複雑な動きが破綻しやすい**ので、**引きで撮り、1 カットを短く**する
  （`ai-video-craft` §5）。全身の激しい動きを長く映さない。

## 7. 歌唱カットとリップシンク

**MV の既定は「音を渡して生成する」ルート B**（`ai-video-craft` の references/lip-sync.md §3）。
曲は先に確定しているので、`reference_to_video` の `reference_audio` にその区間の音を渡す
（Seedance 2.5 / MiniMax H3）。

**音を渡しただけでは歌わない。** 参照音声はリズムと声色の参照で、口を動かすのは
プロンプト本文の指示。歌唱カットのト書きには次を書く（`（台詞なし）` は書かない）:

```
レン sings the lead vocal of @Audio1. レン's mouth follows the vocal: opens on each
phrase onset, holds one shape on sustained vowels, closes when the vocal stops.
```

| 決まり | 理由 |
|---|---|
| **歌い手を名指しし、どの参照音声かを本文で言う** | 素材の `note` はモデルに送られない |
| **歌い手は 1 カットに 1 人** | 帰属が決まらないと誰の口も動かない |
| **口を見せたいカットでは口を隠し続けない**（マイク・手・髪） | 合っているかどうかが分からない |
| 画角・カメラワークは演出で選ぶ | 決め打ちしない |
| 合わせないカットは**逆光・横顔・後ろ姿**でもよい | 口が見えなければズレも無い |

**ボーカルのみのステムがあるか、着手時にユーザーへ確認する**（あると精度が上がる）。
**無くても歌唱カットは作る**。完成ミックスのまま渡し、合わなかったカットだけ組み替える。

## 8. 繰り返しをどう変えるか

**同じサビが 2 回来ても、同じ画を出さない。** 曲は繰り返すが、映像は進む。

| 2 回目のサビでの変え方 |
|---|
| 場所を変える（同じ振り・別の場所） |
| 人数を増やす |
| 時間帯・季節・色を変える |
| 寄る（1 回目は引き、2 回目はアップ） |
| 状況が変わっている（服が汚れている、髪が濡れている） |

**繰り返しは「変化を見せる枠」。** 同じ画を出すと、映像だけ止まって見える。

## 9. リリックビデオ・ビジュアライザー

**歌詞を出す企画では、出し方を必ず演出する**（見せる行と読ませる行・ジャンプ率・人物との前後関係・
3D・配分・避けること）。正本は [mv-lyrics.md](mv-lyrics.md)。

**歌詞を出す形式は生成と相性が良い**（人物の破綻を避けられる）。

- **文字はタイムライン側で載せる**（`compositor`）。生成に頼むと読めない字が出る。
- 時刻は曲の地図の `lyric_lines[]`（行ごとの開始・終了）。行が歌われている間だけ出す。
- 文字も**拍に乗せる**（拍で出す、拍で消す、拍で動かす）。
- 背景はループする抽象映像でよい。**全編に物語を要求されない形式**。
- 縦型に落としやすい（`vertical-shortform`）。

**1 枚絵 MV・複数枚の静止画の MV**（絵を描いて動かす。ボカロで主流）の作り方の選び方・
関門・打点の配分・動きの語彙・規模の目安は [motion-stills.md](motion-stills.md)。

## 10. 画作り

**美術・衣装・色は飾りではなく、人物の心理そのものを語る。**

- **1 本を通した様式**を決める（色・光・画風）。MV は物語の連続性より
  **見た目の統一**で 1 本に見せる形式（`art-director` の色と光の設計）。
- **サビで画が変わる**設計にする（色が変わる・場所が変わる・光が入る）。
  同じ画のまま盛り上げようとしても上がらない。
- **色は感情の照明。** 温度（暖色 / 寒色）を区間ごとに設計すると、
  聴いている感情と画が揃う。
- **照明プラン（L1 / L2 / L3 …）は字コンテの言葉で持つ。見本の画像を作らない。**
  時間帯・光の色（カラーコード可）・向き・フィルの有無を、そのプランを使うシーンの
  字コンテに書く。動画は言葉で光を決め、シーンごとに切り替えられる。光の見本が
  欲しければ**シーンのマスター（静止画。`storyboard` §1.5）**として作り、絵コンテに
  だけ効かせる。**`style.*` にも動画の参照にも入れない** —— 2026-10-24、L1 の見本として
  作った 4 人の引きの 1 枚絵が `style.main` に入り、全シーンの動画に添わって
  アップのカットが引きに引っ張られ、L2 / L3 のシーンにも L1 の光が入った。
- **繰り返し出る物（モチーフ）を 1 つ決める。** 花・鏡・水・赤い糸など。
  同じ物が形を変えて出てくると、**断片的なカットが 1 本に繋がって見える**。

## 11. 避けるクリシェ

**既に何度も見た画は、それだけで飛ばされる。**

| よくあるもの |
|---|
| 都会の夜をなんとなく歩く |
| 雨に打たれて感情を表す |
| 白い / 黒い空間で歌うだけ |
| 荒れるパーティー、割れる物 |
| 空っぽの部屋で寂しげに座る |
| 意味のないスローモーションの連発 |

**やるなら、ひねりを 1 つ足す。** そのままやると「見たことがある」で終わる。
アーティスト側から出た案が既出のものなら、**別の方向を提案する**のが仕事。

## 12. 禁じ手

| 禁じ手 | なぜ |
|---|---|
| 企画を書かずに絵コンテへ進む | 「何をやるのか」が無いまま画だけ作ることになる |
| **別の曲でも成立する企画** | その曲のための映像になっていない（§2） |
| 曲の構造を書き出さずに作り始める | 尺が合わず、後から全部ずれる |
| 等間隔で切る | 編集していないように見える |
| 切りすぎる | 速さと格好よさは別 |
| 歌詞を直訳して絵にする | 余白が無くなる |
| 歌なしの区間に歌唱カットを置く | 合うわけがない |
| ダンスで足を切る | 何をしているか分からない |
| 口を合わせたいカットに伴奏込みのミックスを渡す | 精度が落ちる（lip-sync.md §6）。ステムがあれば渡す |
| 歌唱カットに `（台詞なし）` を書く／本文に歌う指示を書かない | 曲が BGM 扱いになり口が動かない（lip-sync.md §3） |
| 2 回目のサビで同じ画を出す | 映像が進んでいないと見える |
| サビで画が変わらない | 盛り上がらない |
| 映像を先に作る | 音に合わず、作り直しになる |
| **物語のビートで曲を切る** | 順序が逆。**区間に物語を配る**（§1.5） |
| A メロから順に埋めていく | **サビの画を先に決める**（§1.5 の④） |
| サビに A メロと同じ密度・抑制したカメラを当てる | のっぺりする。サビは 5〜6 カット / 15 秒・カットごとに別の動き（mv-dynamics.md） |
| 状態だけの `note`（`stands` / `looks sad`） | キャラが動かない。始点と終点のある動作 + 二次運動（mv-dynamics.md §3） |
