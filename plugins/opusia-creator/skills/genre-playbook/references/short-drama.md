# 縦型ショートドラマ

スマートフォンで縦に見る前提の、1 話 1〜3 分の連続ドラマ。
国内市場は 2026 年に**約 1,530 億円**規模と予測されるまで伸びており、
**独立した形式として設計する**必要がある。

画面の設計（セーフゾーン・フック・ループ）は `vertical-shortform` が正本。
ここには**ドラマとしての作法**だけを置く。

## 1. 規模の目安

| | 目安 |
|---|---|
| 1 話の尺 | **1〜3 分** |
| 1 話のカット数 | 20〜50 |
| 1 カットの尺 | 2〜4 秒 |
| **登場人物** | **1 話に最大 3 人** |
| 話数 | 数十話〜100 話規模の連作もある |

## 2. 登場人物は 3 人まで

**4 人以上になると離脱率が跳ね上がる。** 縦画面・短尺では、視聴者が
関係性を把握しきれない。

- **1 シーンに映るのは 2 人まで**が基本（縦画面に 3 人は並ばない）。
- 人物は**見た目で役割が分かる**ようにする（服装・髪型で対比）。
  短尺では名前を覚えてもらう時間が無い。
- **関係は呼び方で示す**（「兄さん」「部長」）。**ただし示すには呼ばせなければならない** ——
  人物は**初登場から 2 発話以内**に、呼ぶ／名乗る／肩書きで呼ばれること。
  一度も呼ばないのは「示した」ことにならない。

## 3. 構成

**5 ブロック**（beat-sheets.md §5）で、**末尾はオチではなく引き**。

| ブロック | 中身 |
|---|---|
| フック（0〜3 秒） | **一番おいしい場面から始める**。時系列を無視してよい |
| 設定 | 誰が・どこで・何に困っているか |
| 展開 | 対立が動く |
| 山 | 反転（勝ったと思ったら / 隠していたことが出る） |
| **引き** | **答えを出さずに切る** |

**冒頭に日常や説明を置かない。** 離脱の大半は冒頭 3 秒で起きるので、
「今日はいい天気だ」から始めた時点で終わる。

## 4. 引きの作り方

日本の連続ドラマで「引き」と呼ばれてきた手法。
**中途半端な所で切って、続きを気にさせる。**

| 型 | 例 |
|---|---|
| **正体が出る直前** | 振り向いた相手の顔を見せずに切る |
| **決断の直前** | 「実は私……」で切る |
| **最悪の事態が始まった瞬間** | 扉が開く音だけ聞かせて切る |
| **前提が覆った直後** | 味方だと思っていた人物の裏が見えた所で切る |

**引きを毎話やる。** 1 話でも「きれいに終わった」話があると、そこで視聴が止まる。

**引きは「謎を増やす」ことではない。** 回収されない謎を積むと、
見ている側は「どうせ答えが出ない」と判断して離れる。**1 つ引いたら 1 つ返す。**

## 5. 感情の振れ幅で見せる

短尺ドラマは**心情の落差**で持たせる形式。理屈より感情が優先される。

| 効くもの | 中身 |
|---|---|
| **立場の逆転** | 見下されていた側が覆す |
| **隠していたことの露見** | 正体・秘密・過去 |
| **すれ違い** | 片方だけが真相を知っている状態 |
| **報い** | 悪意を持った側に結果が返る |

**カタルシスを先送りしすぎない。** 短尺は「溜めて溜めて最後に解放」が効かない。
**各話に小さな解放**を置き、大きな解放を連作の節目に置く（beat-sheets.md §6）。

## 6. 芝居の見せ方

- **表情のアップが主力。** 縦画面は顔が大きく映る。**ただし表情に情報を預けない** ——
  音を切って見られるうえ、生成映像は微細な表情差が出にくい。
  **感情は表情で、事実は言葉で**（`screenwriter` の references/dialogue-and-exposition.md §0）。
- **手元・小物のアップ**は感情の代弁に使えるが、**手指は破綻しやすい**
  （`ai-video-craft` §5）。物を持つ手のアップは避け、机上の物などに置き換える。
- 台詞は**1 発話 30 字以内**（字幕が 2 行 x 13〜16 字までしか出せない）。
  **1 発話を短くすることと、台詞の総量を減らすことは別**。縦型は**長尺より密度が高く**、
  **150 字/分 が下限**（同 §1）。割ったら「静かな演出」ではなく情報不足。
- **台詞は字幕に出す**（音を切って見られる）。

## 7. 禁じ手

| 禁じ手 | なぜ |
|---|---|
| 冒頭に説明・タイトル・ロゴ | 3 秒で離脱される |
| 1 話に 4 人以上 | 関係を把握できず離脱する |
| きれいに終わる | 次の話が見られない |
| 回収しない謎を積む | 見切られる |
| 横型で撮って縦に切る | 構図が壊れる（`vertical-shortform` §0） |
| 台詞で関係を説明する（互いに既知のことを喋らせる） | 呼び方と見た目で示す。**観客がまだ知らないことを言わせるのは禁じ手ではない** |
| **状況を画だけで立てる** | ながら見・ミュートで落ちる。縦型の現場は「ト書きで説明せず、セリフで説明しろ」（同 §0） |
| **無言カットを続ける** | 3 秒を超えて画も音も台詞も変わらない区間を作らない |
