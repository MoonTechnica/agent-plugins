# アニメ（横型・TV / 配信）

## 1. 規模の目安

| | 目安 |
|---|---|
| 1 話の尺 | 約 22〜24 分（30 分枠から OP / ED / 予告を引いた本編） |
| **1 話のカット数** | **約 300 カット** |
| 1 カットの平均尺 | 約 4〜5 秒（300 カット ÷ 22〜24 分。字コンテで `screenwriter` の `scripts/cut_pacing.py` が測る） |
| パート構成 | A パート / B パート（中央に区切り） |

**300 カットは生成では現実的でない。** 費用がそのままカット数に比例するので、
生成で作るなら**カットを減らす設計**にする（`director` §5 で見積もる）。
減らし方は §3。

## 2. アニメらしさは「動き」ではなく「止めと間」から出る

実写と最も違うのがここ。**アニメは常に動いているわけではない。**
止まっている画をカメラで見せる時間が長く、**動くのは決めの瞬間だけ**。

ただし止めは尺を稼ぐ道具ではなく、**人物の中で時間が止まる瞬間（主観的な時間）を作る装置**
（出崎統「瞬間の美を残したい」）。**出来事を伝える所で止めると「何が起きたか」が飛ぶ**ので、
止めるのは 1 シーンに 1 回が目安。使い所の判断は `film-grammar` の references/direction-design.md §9。

| 見せ方 | 中身 | 使い所 / 外す条件 |
|---|---|---|
| **止め絵 + カメラ** | 絵は動かず、寄る（T.U）・振る（PAN）だけ | 感情が留まる瞬間。3 秒を超えるなら画の中で 1 つ変える（光が差す・音が入る） |
| **タメ** | 動く前に一瞬止める。溜めるほど次の動きが速く見える | 全カットでやると「全部が決め」になる |
| **ツメ** | 動きの前後を詰め、中間を速く抜く。速度に緩急が出る | — |
| **決めの静止** | 動いた直後に完全に止める。印象が焼き付く | 1 シーンに 1 回 |
| **三回パン** | 同じ動きを 3 サイズで 3 カット | 作品に 1〜2 回。生成では 3 倍の費用 |
| **心象風景・無人の繋ぎ** | 空・光・窓・無人の部屋で人物を映さず感情を語る（新海 / 庵野） | **生成で最も安定する演出**。状況が立っていない所に置くと「置いていかれた」 |

**生成モデルは常に何かを動かそうとする**ので、放っておくと
「ずっとゆらゆらしている」アニメらしくない映像になる。
**止めたいカットには止めたいと書く**（`static shot` / `subtle motion only`）。

**止め絵 + カメラで作るカット**（OP / ED・アイキャッチ・回想・モーションコミック）は
動画生成ではなく静止画を描いて動かしてよい。作法は [motion-stills.md](motion-stills.md)
（漫画の 1 コマ = 字コンテの 1 行、吹き出しと擬音は絵に焼かない）。

## 2.5 カメラは「安い / 高い」で配分する

アニメのカメラは作り方で 2 系統に分かれる（出典: `docs/_research/2026-10-03-camera-work-techniques.md` Part 4）。

| 系統 | 中身 | 生成での作り方 |
|---|---|---|
| **安いカメラ** | 平面の素材をスライド・拡縮する（PAN / T.U / T.B / 密着 / 画面動）。視差が出ない | **生成しない。** 静止画（立ち絵・背景・止め絵）を作り、タイムラインで動かす（`compositor`） |
| **高いカメラ** | パースごと描き変える（回り込み・背動・作画による追従） | 生成。**見せ場にだけ**使う |

**持続・提示は安いカメラ、変化・見せ場は高いカメラ。** 生成モデルは既定で高いカメラ（3D 的な動き）を出すので、
何も考えないと全カットが見せ場の手触りになり、アニメらしい緩急が消える。用語は会社で定義が揺れるので、
`shot` には**見え方**を書く（`film-grammar` の references/shot-vocabulary.md §3.1）。

| 手 | 中身 | 使い所 |
|---|---|---|
| **レイアウト = カメラ位置 + レンズ** | 押井守の転機は「レンズという意識」。構図は焦点距離と被写体との距離で決める | 望遠 = 圧縮・観察、広角 = 誇張・参加。プリビズの焦点距離にそのまま対応 |
| **時代・場所を跨ぐ match cut**（今敏） | 前のカットの終わりと共通の動作・形で次の場面へ入る | 回想・夢・場面転換。次のカットの頭を前のカットの尻の構図に合わせて**画像で作り**、ハードカットで繋ぐ（`ai-video-craft` の references/seams.md §2） |
| **同ポジの反復**（細田守） | 同じ構図・固定のカメラで、中身だけを変えて 2〜3 回見せる | 時間の経過・関係の変化。構図が同じなので生成でも揃えやすい |
| **顔を映さない**（山田尚子） | 足元・手元・後ろ姿で感情を見せる | 感情の強い台詞。顔の崩れも避けられる |
| **バンク**（幾原邦彦） | 儀式的な反復は同じ素材を再利用し、1 か所だけずらす | 変身・決めの反復。素材の再利用で費用ゼロ |
| **過程を省いて結果へ飛ぶ** | 移動の途中のカットを作らない | カット数を減らす（§3） |
| **アクションは中に入るカメラ** | 群れの中を抜ける・レンズの直前を物が横切る | 生成で回り込むなら**速く短く、または引き**で（遅い回り込みは作画でも生成でも崩れやすい。要実測） |
| **寄りの細かい芝居と 3D 的な大移動を同じカットに入れない** | 3DCG のアニメ制作でも、寄りの表情と指先は作画に残している（MAPPA） | 大きく回すカットは引き、表情を見せるカットは固定か遅い寄り |

**転換（O.L / F.O / W.O / C.I）は生成に書かず、タイムラインで付ける。** 絵コンテには始点と終点の 2 枠で書く。

## 3. カットを減らす

生成ではカット数が費用そのもの。**アニメの文法を保ったまま減らせる所**がある。

| 減らし方 | 中身 |
|---|---|
| **止め絵 + カメラで長く持たせる** | 4 秒のカットを 2 つ割るより、1 つを寄りで持たせる |
| **会話を切り返しで割りすぎない** | 2 ショットで受ける。全台詞で切り返さない |
| **説明カットを削る** | 場所・時計・掲示板は、台詞か字幕で置き換えられる |
| **モブを描かない** | 群衆は破綻もするので（`ai-video-craft` §5）引きかボケで処理 |

**逆に削ってはいけないのが確立ショット**（`film-grammar` §5）。
場所が変わったのに引きが無いと、生成では背景が毎回変わるので一気に迷子になる。

## 4. アニメ特有の記号

実写に無い記号が意味を担う。**生成で出しにくいものは、後段で載せる**。

| 記号 | 生成での扱い |
|---|---|
| 集中線・効果線 | 生成では安定しない。**タイムライン側で載せる**（`compositor`） |
| 汗・青ざめ・怒りマーク | 同上。プロンプトでは出たり出なかったり |
| 目のハイライト | プロンプトで指定できる（感情に応じて消す / 増やす） |
| 光の玉・レンズフレア | 生成でも出る。`lens flare` / `bloom` |

## 5. 画作りの前提

| 決めること | 例 |
|---|---|
| **画風** | セル調 / 水彩調 / 劇場版寄り。**シリーズで固定**する |
| **線** | 太さ・色トレスの有無 |
| **色** | 昼 / 夕 / 夜 / 室内のパレットを先に決める（`art-director`） |
| **画角** | 16:9。縦にするなら vertical-anime.md へ |

**画風はスロットに確定した設定資料で担保する**（`art-director`）。
プロンプトに画風の言葉を書くだけでは、話数をまたいで必ずずれる。

## 6. 構成

- 1 話は**三幕構成**（beat-sheets.md §2）か**起承転結**（§4）。日常系は起承転結が収まりやすい。
- **A / B パート**の切れ目は、引きになる所に置く。
- OP / ED も**それぞれ 1 本のタイムライン**として作る（`start_timeline(role='op')`）。
  並びは `sort_order` が持つので、あとから間に挟むのも自由。
- シリーズ全体のうねりは `arc.v1` に持つ（beat-sheets.md §6）。

## 7. このジャンルの禁じ手

| 禁じ手 | なぜ |
|---|---|
| 全カットを動かす | アニメに見えない。費用も跳ねる |
| 話数ごとに画風の言葉を書き直す | 必ずずれる。設定資料を参照する |
| 群衆・手元・文字を正面から描く | 破綻する（`ai-video-craft` §5） |
| 300 カットをそのまま生成しようとする | 見積もりの段で止まる。先に減らす |
