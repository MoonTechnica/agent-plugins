# 静止画とモーショングラフィックで作るシーン（形式を問わない）

ボカロ MV のような「絵を描いて、それを動かす」映像の作法。**MV に限らない** ——
説明ものの図解、アニメのモーションコミック・OP / ED・回想、ドラマのインサート、
撮影素材への挿入カットも同じ作法で作る。形式に固有のこと（MV の 1 枚絵・リリックの
打点、モーションコミックのコマ割り）は各篇が持ち、ここを指す。

段取り（誰が・どの tool を・どの順で）は `director` の references/other-formats.md §2、
描かせ方は `art-director` の references/motion-stills.md、組み立てと書き出しは
`compositor` の references/motion-scene.md。
**`motion` のシーンはモーション（`previz`）の 1 シーンに組んで、本編には 1 本の層で置く**（絵はカード / 画像の板、歌詞は `text` レイヤー、光・粒は 2D レイヤー）。別の composition に HTML を組んで書き出すのは、試作でもしない。

## 1. シーンの作り方は 3 通り

**どの形式でも、シーンごとに作り方を 1 つ選ぶ。** 完成品はどれも動画 1 本で、
タイムライン・書き出し・検品の扱いは変わらない。

| 作り方 | 中身 | 向くカット |
|---|---|---|
| **`motion`**（静止画 + 動き） | 静止画を層に分け、カメラ・揺れ・差分の切り替え・粒子・光・文字で動かす | 感情が留まる所、歌詞・見出し・図解が主役の所、1 枚絵を長く持たせる区間、モーションコミック、回想・タイトル・インサート |
| **`previz3d`**（3D） | プリビズの文書に見た目を足して書き出す | 3D の背景を飛ぶ、3D の文字・ロゴ、製品の回り込み、層の間をカメラがくぐる |
| **`generate`**（動画生成） | 動画生成 | 人物が振り向く・歩く・表情が連続して変わる芝居。物語ものの本編 |

**選び方の軸は「人物が連続して動く必要があるか」だけ。** 必要なら `generate`、
止め絵とカメラと差分で足りるなら `motion`。`motion` は絵が崩れず、何度書き出しても
同じ絵になり、費用は動画生成の 1 割に満たない。

### 1.1 形式ごとの既定

| 形式 | 時刻の基準 | 既定の作り方 | `motion` の典型 |
|---|---|---|---|
| MV（イラストが主役。ボカロ・イラスト MV・リリック MV） | 曲の地図（拍・歌詞の行） | `motion` | 1 枚絵 MV・リリック MV・複数枚の静止画の MV |
| MV（実写調・アニメ調。芝居や映像そのものが主役） | 曲の地図（拍・歌詞の行） | `generate` | 歌詞の要所の演出（mv.md §2）・タイトル・転換。図形や光で画を埋めない |
| 説明もの | ナレーションの語の時刻 | `motion` | 図解・データ・製品紹介・会社 / サービス紹介・広告 |
| アニメ / 縦アニメ | 台詞の語の時刻 | `generate` | モーションコミック、OP / ED、アイキャッチ、回想 |
| ショートドラマ / 実写 | 台詞の語の時刻 | `generate` | 回想・手紙・写真のインサート、タイトル |
| 撮影済み素材の編集 | 撮影した素材 | 素材のまま | 図解・地図・年表の挿入カットだけ |

既定は出発点で、シーンごとに変えてよい。**既定と違う作り方を選ぶときは理由を字コンテに書く**
（既定が `motion` の形式で `generate` を選ぶなら「静止画では表せない理由」、既定が
`generate` の形式で `motion` を選ぶなら「止め絵で見せる理由」—— 回想・漫画の文法・費用）。

**MV はどちらの型かを企画で 1 行決める**（ユーザーの指定・曲の性格・素材がイラストか芝居か）。
モーショングラフィックス（文字・帯や図形・光と粒・2.5D のカメラ）を画の主役にするのはイラストが主役の MV と
説明もの・広告・短尺。実写調・アニメ調の MV、ドラマ・アニメの本編では OP / ED・タイトル・歌詞の要所・転換に留める。

既存の形式に無い用途は近い形式で受ける: 広告・会社紹介 → 説明もの、漫画・絵本の映像化 →
アニメ / 縦アニメ、ゲームの PV → 曲が先なら MV・語りが先なら説明もの。

### 1.2 混ぜる

| 段 | 例 |
|---|---|
| **シーンの間** | サビは `generate`、A メロは `motion`、間奏は `previz3d` |
| **シーンの中で重ねる** | 3D の背景に 2D の立ち絵 / 生成した芝居の上に歌詞・粒子・光 / 撮影素材に図解 |
| **シーンの中でつなぐ** | プリビズの書き出しを下敷きに生成する / 静止画を最初のコマにして生成する |

シーンの中で混ぜたときの作り方は**最後に確定動画を作ったもの**で呼ぶ（重ねたなら `motion`、
つないだなら最後の工程）。重ね方の難しさ:

| 重ね方 | 判断 |
|---|---|
| 生成・撮影の映像を一番下に敷き、上に文字・粒子・光・図解 | すぐできる（透過が要らない）。**ただし生成の前に層の持ち分を決める**（`ai-video-craft` の references/layer-ownership.md）。決めないと生成の光・粒子・文字と上の層が二重になり、絵コンテに効果を描くと動画へ焼き込まれる |
| 3D と 2D を同じ画面の中で描く | 3D の背景 × 2D のキャラの本命（透過が要らない） |
| 生成した動画を中ほどの層にする（イラストの背景の上に生成したキャラ） | **一番難しい**。背景を抜く必要があり、縁が崩れやすい。見せ場だけにし、まず層の順を入れ替えて避けられないか考える |

## 2. 関門は「絵」と「動き」の 2 系統

実務では絵を作る工程（ラフ → 完成）と動かす工程（V コン → 最初の山場 → 全編）が分かれ、
人の確認もそれに沿う。**費用の大半は「何枚描くか」で決まる**ので、それが決まる V コンより
前に本番の絵を描かない。

| 確認 | 何を見るか | なぜここで |
|---|---|---|
| **方向性** | スタイルフレーム 2〜3 枚（完成の質の止め画。色・質感・書体・配置） | 全カットの見た目の物差しになる |
| **キャラ・製品・キービジュアル** | 設定表・メインの 1 枚 | 依頼主が口を出すのはここ |
| **字コンテと V コン** | ラフと文字を音に乗せて流したもの。尺・カット順・文字の出 | 「何枚描くか」「どのカットが 3D / 生成か」が決まる |
| **最初の山場** | 一部を完成の質で（MV は 1 コーラス、説明ものは冒頭約 30 秒、アニメは最初の引きまで） | **大きな変更はここで締め切る** |
| **全編** | 通し | — |

V コンは**完成度ではなくタイミングと流れの確認**。絵は粗くてよい。

## 3. 絵コンテの役割は作り方で変わる

動画生成では絵コンテが**生成の入力**（絵柄・光・人物の同一性・構図）になる。
`motion` では最終の絵を自分で描くので、絵コンテは誰の入力にもならず、
**人が承認する設計図**になる。

| 作り方 | 絵コンテ | 要るか |
|---|---|---|
| `generate` | 生成の入力。1 シーン 1 枚のグリッド絵コンテ | 必須 |
| `motion` | 設計図。**1 カット 1 枚のラフ**（そのカットの構図）。V コンで流す | 絵のあるカットだけ。文字・図解だけのカットは絵を描かず、組み立てたもの自体が V コン。図形・光・文字が主役のカットは**組んで撮ったコマ**（スタイルフレーム。compositor の references/style-frames.md）を絵コンテにする |
| `previz3d` | プリビズ自体が動く絵コンテ | 不要 |
| 混ぜる | 生成する層だけの入力 | 生成の層があるときだけ |

- **動きは絵コンテに描かない。** 寄り・パン・揺れ・打点は字コンテの「動き」の列に言葉で書き、
  V コンで確かめる。
- **最終の絵はラフから仕上げない。** ラフは構図の参照で、粗さを本番に移さない。
- 層に分けず解像度も上げない安いカットは、ラフを飛ばして本番を直接描いてよい。

## 4. 字コンテ（1 行 1 区切りの表）

| 列 | 中身 |
|---|---|
| 時刻 | 時刻の基準から取る（手で書かない） |
| 区間 | MV: イントロ / A メロ / サビ … / 説明もの: つかみ / 課題 / 解決 … / 物語: 幕・シーン |
| 語り | 歌詞 / ナレーション / 台詞（話者つき） |
| 画 | 何が見えているか（どの静止画・どの差分・どの層・どのコマ） |
| 動き | カメラ・揺れ・打点（拍頭 / ピーク / 子音 / 語の頭のどれに合わせるか） |
| 文字 | 出し方（出さない / 字幕的 / 演出として動かす）と中身 |
| 作り方 | `motion` / `previz3d` / `generate` |
| 上の層 | `generate` のカットに重ねる文字・粒子・光・揺れ（生成に渡さない。`ai-video-craft` の references/layer-ownership.md §2） |

1 行が何に当たるか: MV は歌詞の 1 フレーズ、説明ものはナレーションの 1 文、
アニメは台詞 1 つ（モーションコミックは漫画の 1 コマ）。

## 5. 動きで持たせる

**カットの境目より、カットの中の変化で拍を取る。** 1 枚絵を長く持たせる区間でも、
拍（語りの形式では文）ごとに何か —— 揺れ・差分・文字・光 —— が変わる。
等間隔に同じ動きを貼らない。

| 決まり | 中身 |
|---|---|
| 打点の配分（音が背骨の形式） | 一番強い音に合わせる**ピークハメは 1 曲 5〜10 回**、子音の立ち上がりに合わせる**子音ハメは 2〜3 か所まで**、残りは拍頭 |
| 打点（語りが背骨の形式） | 文字は語の頭に合わせ、**強調する語（数字・固有名・結論）だけを動かす**。全部動かすと読めない |
| 全部を歌詞・語りの切れ目に揃えない | 区切りに編集点が律儀に揃う型は古く見える。サビ頭・キメは合わせ、その間は散らす |
| 間奏・無言の区間 | 動きを落とすか、遊ぶか**決める**。何もしない区間を残さない |
| 止めて、決める | 動き続けると全部が同じテンポになる。動いた直後に止める所を作る（アニメの「決めの静止」と同じ。anime.md §2） |
| カメラは描いた範囲の中だけ | 寄り・パン・視差で絵の外が見える事故を作らない（描き足す範囲は `art-director` の references/motion-stills.md） |
| MV の歌詞 | 見せる行は図として組む。正本は [mv-lyrics.md](mv-lyrics.md) |
| 縦 9:16 は組み直す | 中央の人物と文字の配置を縦で組み直す。切り抜くだけにしない（`vertical-shortform`） |

### 5.1 動きの語彙

| 動き | 中身 | 使い所 |
|---|---|---|
| 寄り・引き・パン | 1 枚の絵の中でカメラを動かす | 1 枚絵で画角を変えてカットを作る（1 枚絵 MV の「カット」はたいてい同じ絵の別の画角） |
| 視差（2.5D） | 前景 / 人物 / 背景の層を奥行きに並べてカメラを動かす | 奥行きを出したい引き・場面の入り |
| カメラの揺れ・ピント送り | 画面全体の小さな揺れ・拍で減衰する衝撃、層ごとのぼけを送る | 手持ち感・不安・衝撃、歌詞の行の頭で視線を送る |
| 斜めの帯・図形 | 帯のスイープと束、流れる縞、図形のワイプ、枠、集中線、リング、拍で弾ける小図形、図形の窓 | 区切り・勢い・転換・サビの山。イラスト MV・広告・短尺・YouTube の部品 |
| 髪・服・リボン・旗の揺れ | 根元を固定して先へ行くほど大きく遅れて揺らす | 立ち絵を生きて見せる。突風を打点に置く |
| まばたき・口パク・表情の切り替え | 差分の絵を時刻で切り替える。口パクは歌詞・台詞の時刻から | 歌唱感・生きている感・感情の転換点（表情の切り替えは歌詞・台詞の転換に置く） |
| 粒子・光・色ずれ・グリッチ・フィルム | 花びら・雪・塵・火の粉、グロー・逆光の縁・光漏れ・フレア・光芒・キラキラ、色収差、ノイズ、ふわっと明るい空気 | 区間の色を変える・サビで画を変える |
| 文字の演出 | 歌詞の分解・書き順・変形（字が次の字へ変わる）・パース、見出し・数字のカウント、吹き出し・擬音 | リリック MV・説明ものの主張・モーションコミック |
| 図・グラフ・地図・UI | 絵にせず、図として組む | 説明もの・挿入カット |

**文字の演出・図・帯・光と粒の 1 まとまりはモーション（`previz`）で 1 シーンに作り、タイムラインには 1 本の層で置く**
（タイムラインは Premiere、モーションは After Effects。`docs/designs/2026-11-13-timeline-premiere-motion-ae.md`）。
動きの語彙の作り方は `compositor` の references（字コンテの「動き」の列にここの語で書けば引ける）:
文字 → text-motion.md、帯・図形 → shape-motion.md、光・粒 → light-particles.md、視差・カメラ → parallax-camera.md。
**1 カットに主役の動きは 1 つ**（文字・図形・光・カメラを全部同時に強くしない。強さは text-motion.md の段階で揃える）。

**できないもの**: 顔の向きが変わる・歩く・連続した芝居（`generate` へ）、Live2D 級の連動変形、
物理で揺れる髪（揺れは式で書く。物理は書き出しのたびに絵が変わる）。

## 6. 規模の目安（3〜4 分の MV）

一次情報で「標準」は見つからなかった。近い数字からの目安:

| 型 | 絵の枚数 | カット数 |
|---|---|---|
| 1 枚絵 MV | イラスト 1〜3 枚 + 差分 3〜10 | 20〜40（同じ絵の別の画角） |
| 複数枚の静止画の MV | イラスト 5〜20 枚 | 40〜70 |

カットの長さの例: 風景 7 秒、表情 4 秒、サビ 2〜3 秒、間奏の長回し 10 秒近く。
**絵の枚数とカット数は一致しない。** 費用は絵の枚数（と層・差分の数）で決まる。

## 7. 形式ごとの使いどころ

| 形式 | 作法 |
|---|---|
| MV の 1 枚絵 | 単色の鮮やかな背景・中央に大きな人物（バストアップ以上）・歌詞を周囲に散らす・表情差分で持たせる。塗りは重ねの少ないもの（真似しやすいことが拡散力になる）。**弱い MV ではなく主流の 1 形式**（mv.md §9） |
| 説明もの | 図・数字・UI は絵にせず組む。実物の画面を近似で描かない（explainer.md）。人物や製品の絵は「実物が無く、画で見せるしかない」ビートだけ |
| モーションコミック | **漫画の 1 コマ = 字コンテの 1 行**。吹き出しは字幕として出し入れし、擬音は打点で動かす（どちらも絵に焼かない）。コマの中をカメラで見せる |
| アニメの OP / ED・回想 | 止め絵 + カメラが主力（anime.md §2 / vertical-anime.md §4） |
| ドラマのインサート | 回想・手紙・写真。本編の生成と画風を揃える |

## 8. 禁じ手

| 禁じ手 | なぜ |
|---|---|
| V コンより前に本番の絵を全部描く | 差し替えで描き直しになり、費用の大半が無駄になる |
| 文字・ロゴ・UI を絵に焼き込む | 読めない字が出る・直せない・翻訳と縦横の作り直しができない |
| 人物が振り向く・歩くカットを静止画で無理に作る | 止め絵では表せない。そこだけ `generate` にする |
| 全カットを歌詞・語りの切れ目だけで切る | 単調になる（§5） |
| 長く止める静止画で何も変えない | 拍ごとに何かを変える（§5） |
| 動きを乱数や物理で付ける | 書き出すたびに絵が変わる。揺れは時刻の式で書く |
