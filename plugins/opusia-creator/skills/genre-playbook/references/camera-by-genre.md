# ジャンル・用途ごとのカメラの定石

**何を撮るかでカメラの責任が変わる。** アクションとダンスは全身と空間、会話は目線と対称、
ホラーは空いている所、CM は質感と形、ドキュメンタリーは編集できる素材の組み合わせを見せる責任を持つ。
字コンテを書く前に、作るものに当たる節を開く。MV は [mv-dynamics.md](mv-dynamics.md)、縦型は
`vertical-shortform`、アニメ固有のカメラは [anime.md](anime.md) §2.5 が正本。

出典: `docs/_research/2026-10-03-camera-work-techniques.md` Part 5（American Cinematographer 誌・
DGA Quarterly・Bordwell・撮影監督の発言ほか）。

## 0. ジャンルを横断して言えること

1. **ワイドでカットを減らすのは「演者を信じる」選択。** アクション（ジャッキー・チェン / John Wick）・
   身体コメディ・ダンス（Astaire）で共通。速いカットは技量と空間を隠す。生成では**1 カットの中で
   完結する動作を書けるか**に直結する。
2. **固定と手持ちは客観と主観の切り替えに使う**（It Follows・Pixar の Inside Out・観察型ドキュメンタリー）。
   全編どちらかに寄せると、切り替えで語る手段を失う。
3. **対称と実在が既定、崩すと意味が出る。** 会話の切り返しを同じ条件で撮ること、Pixar の
   「本物のカメラが物理的にできないことはしない」。
4. **繋ぎで避けることはどのジャンルでも 3 つ**: 似た構図同士を繋ぐ / 動きの途中から別の動きへ切る /
   ラインを越える（`film-grammar` の references/cut-to-cut.md）。

## 1. 会話（ドラマ）

| 定石 | 中身 |
|---|---|
| 段階的に寄る | 2 ショット → 肩なめ → 単独の寄り → アップ。最大の寄りは取っておく |
| **切り返しは同じ条件で撮る**（matching singles） | 両者を**同じ焦点距離・同じ距離・同じ頭のサイズ**で。結果として「対等」と読まれる。力関係を見せたいときだけ**意図して**ずらす |
| 寄りはカメラを近づけて作る | Deakins: 肩なめ 32〜35mm、寄り 40〜50mm。「何も考えずに長いレンズを付けるのは怠慢」 |
| 高さは目の高さ | 変えるのは意味があるときだけ |
| walk-and-talk | 起源は Schlamme（The West Wing）。ステディカムが正面から後退し、1 本の軌跡で複数人の会話を繋ぐ。**重要な情報の所では立ち止まらせる** |

**失敗**: 片方 35mm・片方 85mm の切り返し（顔の歪み・ボケ量・頭のサイズが揃わず、意図しない力関係が出る）/
全台詞で切り返す / 寄りを望遠だけで作る（背景が潰れ、カット間で背景が飛ぶ）。

**生成で**: 1 パスの multi-shot で切り返すとき、**両者のショットに同じサイズ語・同じレンズ語**を書く
（`50mm, medium close-up` を左右で揃える）。左右と視線の向きは毎ショット書く（`ai-video-craft` の references/seams.md §3）。

## 2. アクション・格闘

| 流派 | カメラ | 繋ぎ |
|---|---|---|
| **香港型**（ジャッキー・チェン） | ワイド寄りで全身と動作を同じ画に。**打つ側と打たれる側を同じフレームに** | 「良い 2 発 = 素晴らしい 1 発」= 同じ打撃を別角度で 2 回見せて強調。打撃の間を刻まない |
| **John Wick 型** | 「ハリウッドのアクションより広く撮る」。手持ちを避け、構図を美術の直線と平行に | ワイドからワイドへ。継ぎ目の少ないアクション |
| **Bourne 型** | 手持ち・ズーム。主観的な混乱 | 平均ショット長 約 2 秒。Bordwell の分析:「速さではなく、**動きが止まる前に切れる**ことが問題」 |

空間を保つ定石: **戦う前に位置関係（誰がどこ・出口・障害物）をワイドで見せる** / 攻める側の向きをカットが
変わっても保つ / **動きの頂点・着地まで見せてから切る** / カメラは振付の一部（並走・逆行・周回）。

**失敗**: 1 動作を多数のカットに割る（『96時間/レクイエム』のフェンス越えは 6 秒に 15 カットとされる）/
寄りの手持ちで殴り合い（誰が誰を殴ったか分からない）/ 打たれる側を別カットで後付け（因果が切れる）。

**生成で**: 速い動きは崩れやすいので、**引きで 1 動作を完結させ、打撃の強調は同じ打撃の別角度を 1 カット足す**
（香港型）。手持ちで混乱を作るのは生成の破綻と見分けが付かないので既定にしない。

## 3. ホラー・サスペンス

| 定石 | 中身 |
|---|---|
| サスペンスは先に情報を渡す | テーブルの下の爆弾を見せれば、何気ない会話が 15 分のサスペンスになる（Hitchcock） |
| 広角・深いピント・小さく映す | It Follows は遠くの人物を望遠で寄せず、広角で小さく映して現実の距離感で怖がらせる |
| 空いている所（ネガティブスペース） | 何も無い領域を残し、そこに何か現れうると思わせる |
| 無機的なカメラ | 脅威の場面は固定 + パン / ズーム。**手持ちは主人公の主観の瞬間にだけ取っておく** |
| 空間を先に覚えさせる | 長いトラッキングで家の中を探索させてから異物を置く（The Conjuring）。背景に隠す（Hill House は毎話 8〜10 体の幽霊を背景に置いた） |
| 長く持つ | 自然より少し長く持たせて圧を作る |

驚かせる瞬間は**音とカットを同時**に、その直前は静けさとゆっくりの寄りで溜める。偽の驚き → 本物の順で緩急を作る。

**失敗**: 怖いものを望遠で大写し（「いつ来るか」の時間が消える）/ 全編手持ち / 浅いピントで背景をぼかしすぎる
（背景に何か居る可能性そのものを消す）/ 空間の地図を作らない。

## 4. コメディ

| 定石 | 中身 |
|---|---|
| 身体のギャグはワイドの固定で | 全身が入る固定の引き。カメラの揺れはタイミングを壊す |
| 決めのギャグは 1 画で | 割ると「本当に起きた」感が消える |
| 笑いの決めは受け手の顔 | リアクションへ切り替えるタイミングで笑わせる。使いすぎると「ここで笑え」に見える |
| フレームで笑わせる（Edgar Wright） | 変な入り方・変な出方・行って戻る・場面転換を合わせる・効果音と音楽に動作を同期 |

**失敗**: 身体のギャグを寄りで撮る / 台詞を 2 カメで拾って編集で笑いを作る（視覚のギャグが消える）。

## 5. CM・商品映像

| 区間（30 秒の目安・通説） | カメラ |
|---|---|
| フック（0〜3 秒） | 最も強い動き・意外な画（容器の中へ入る、飛沫） |
| 使用場面（〜22 秒） | 人物 + 商品。手元・表情の寄りと、どこで使うかの引きを交互に |
| ヒーロー（〜26 秒） | **ゆっくり滑らかに**回す・横へ動かす（モーションコントロール・スライダー・ターンテーブル）。視差で立体感 |
| パックショット（最後 2〜5 秒） | **ほぼ静止**。商品名とロゴが読める時間を取る |

1991 年時点で TV CM の平均ショット長は 2 秒未満（MacLachlan & Logan）。透明な容器の液体は背後を写すレンズとして
働くので、**背景と光の設計が絵を決める**。

**失敗**: 商品を手持ちで揺らす（精度感が消える）/ ロゴが動き続けて読めない / 速いカットで商品の形が残らない /
ピントが浅すぎてラベルが読めない。

**生成で**: 商品の文字・ロゴは生成で崩れるので、**パックショットとロゴはタイムラインで載せる**（`compositor`）。

## 6. ドキュメンタリー・インタビュー

| 定石 | 中身 |
|---|---|
| A/B の 2 カメ | A は被写体に約 30° 以内、聞き手は A のレンズ脇・目の高さ。B は**30° 以上角度を変え、焦点距離も変える**（同じ角度だと切り替えがジャンプカットになる） |
| 目線 | 既定はレンズ脇（聞き手を見る）。カメラ目線にするなら一人称の語りになる（Errol Morris の Interrotron） |
| 説明映像の 5 ショット | ①手元の寄り（何を）②顔の寄り（誰が）③引き（どこで）④肩なめ（3 つを繋ぐ）⑤変わった角度。編集で繋げない素材を無くすための型 |
| 観察型 | 出来事を追う手持ち。インタビューは固定。長く持つ（Wiseman は撮った素材の約 3% しか使わない） |

**生成で**: インタビュー風の構成では、話の上に**5 ショットの型で説明カットを敷く**と、手元 → 顔 → 引きの順で
「何を → 誰が → どこで」が開く。

## 7. ライブ・スポーツ・マルチカメラ

| 定石 | 中身 |
|---|---|
| 似た構図を続けない | 同じ被写体なら角度差 35〜45° 以上、サイズ差ははっきり。主体を**画面の逆側**に置いた構図へ切る |
| 動くカメラ同士 | 動きの途中から入るのは可、**動きの途中で別の動きへ切るのは避ける** |
| 軸 | 中継カメラは片側のスタンドに置き続ける。逆側（リバース）はリプレイと選手の表情にだけ |
| 先読み | 常に 2 ショット先を用意する |

## 8. ダンス（MV 以外: 舞台・ミュージカル・ダンスフィルム）

| 流派 | カメラ | 繋ぎ |
|---|---|---|
| **Astaire 型** | 頭から爪先まで。寄りなし。動きは最小 | テイクを少なく通しで。リアクションを挟まない |
| **Gene Kelly 型** | カメラの動きを振付に仕えさせる | カメラの移動と踊りの方向を合わせる |
| **Maya Deren 型** | 跳躍の途中で森 → 室内 → 美術館へ場所が変わる | **動きの途中で切り、次の場所で動きが続く** |

**どちらを取るか先に決める**: 振りの頂点の途中で切らない（Astaire 型）か、頂点で切って別空間に繋ぐ（Deren 型）か。
足・手先を画面で切らない。寄りは振付が顔や手にあるときだけ。群舞を寄りだけで撮らない（フォーメーションが見えない）。

## 9. 3DCG・ゲームの仮想カメラ（プリビズにも効く）

| 定石 | 中身 |
|---|---|
| 仮想カメラを本物のカメラとして扱う | Pixar: 「本物のカメラが物理的にできないことはしない」。物体をすり抜けない・不可能な速度で飛ばない |
| 実在のレンズを使う | Toy Story 4 は実在のレンズをモデル化し、人物ごとに球面 / アナモルフィックを描き分けた |
| 意図した不完全さ | 加減速の無い動きは機械的に見える。手持ちの揺れや三脚のパンの癖を入れる |
| 文法の切り替えで心理を語る | Inside Out: 外の世界は手持ち・歪み・ピンぼけを許し、頭の中は機械的な動き・歪みなし・常に合焦。後半で入れ替わる |

**失敗**: 焦点距離をショットごとに無秩序に変える（空間が把握できない）/ 何でもできるので全カットを動かす。

## 10. 比較表

| ジャンル | 動きの量 | 平均カット長 | レンズ | 繋ぎ |
|---|---|---|---|---|
| 会話ドラマ | 少〜中 | 中（傾向） | 標準〜やや長め。切り返しは同じ焦点距離 | 段階的に寄る。ラインを守る |
| アクション（香港 / Wick 型） | 中（振付と一緒に） | 長め（John Wick 4 で約 4.5 秒） | 広め | 動きを完了させてから切る |
| アクション（Bourne 型） | 多（手持ち・ズーム） | 約 2 秒 | 望遠・ズーム | 動きの途中で切る |
| ホラー | 少（ゆっくり・定点） | 長め（傾向。集計値は未検証） | 広角・深いピント | 長く持って溜め → 音と同時に驚かす |
| コメディ（身体） | 少（固定） | — | ワイド | ギャグは 1 画で |
| CM | 中（精密にゆっくり） | 2 秒未満（1991 年の TV CM） | マクロ・プローブ | フック → 使用 → ヒーロー → パックショット |
| ドキュメンタリー | 固定（インタビュー）/ 手持ち（観察） | 長い（傾向） | A/B で焦点距離を変える | A/B 切替 + 説明カット |
| ダンス | 型による | 型による | 全身が入る画角 | 型による（上の 2 択） |
| 3DCG | 実写と同じ語彙に制限 | 作品次第 | 実在レンズ | 文法の切り替えで語る |
