# レンズ・ショットサイズ・カメラ距離

`previz_scene.v1` の `camera.fov` は **縦画角（度）** で、three.js の `PerspectiveCamera` と
同じ定義。撮影の言葉は焦点距離（mm）とショットサイズ（バスト / ウエスト / フル / ロング）なので、
ここで換算する。

> **アプリと同じ数値**を使うこと。GUI 側の正本は
> `frontend/packages/studio/src/entities/previz/lib/lens.ts`（`SHOT_SIZES` / `distanceForShot` /
> `aimHeightForShot`）。ここが**エージェント側の正本**で、両方が同じ表を指している。
> 片方だけ直すと、人が GUI で置いたカメラとエージェントが置いたカメラで画が食い違う。

## 1. 換算式（この 3 つで足りる）

**手で解かない**: `python3 <SKILL_DIR>/scripts/camera_math.py lens --mm 85` / `place --size bust --height 1.6`
（距離・カメラの高さ・縦画角が出る）/ `capsule --height-cm 160`（カプセルの寸法と原点の高さ）。

35mm フルサイズ（センサー 36 × 24mm）基準。センサー高の半分が 12mm なので:

```
fov(度)      = 2 * atan(12 / f) * 180 / π
f(mm)        = 12 / tan(fov / 2 * π / 180)

距離(m)      = 見せたい高さ(m) * f(mm) / 24        ← ★ カメラをどこに置くか
画面の縦(m)  = 24 * 距離(m) / f(mm)                 ← ★ そこに何が収まるか
```

**`距離 = 高さ × f / 24` を覚えておけば、ショットサイズは暗算で置ける。**
（例: 胸から上 0.7m を 85mm で → 0.7 × 85 / 24 = **2.5m**）

**横画角は使わない。** 同じレンズでも 16:9 と 9:16 で横画角が変わるため（縦画角は
フレームの向きに依らない）。横方向の判断は `references/framing.md` の `aspect` 込みの式で。

## 3. ショットサイズ → 見せたい高さ → 距離

**「見せたい高さ」は画面の縦にちょうど収まる実寸**（m）。身長 1.7m を基準にした値で、
実際の距離は**その人物の身長に比例**させる（背の低い人物でも同じ画になる）。

```
見せたい高さ = 基準値 × (その人物の身長 / 1.7)
距離         = 見せたい高さ × f / 24
```

| 絵コンテ表記 | 英 | 基準値 (m) | 既定レンズ | `SHOT_SIZES` | 1.7m を既定レンズで撮る距離 |
|---|---|---|---|---|---|
| 大アップ | ECU | 0.2 | 100mm | —（式で出す） | 0.8m |
| アップ / 顔 | CU | **0.4** | 85mm | `closeUp` | 1.4m |
| バスト（胸から上） | MCU | **0.7** | 85mm | `bust` | 2.5m |
| ウエスト（腰から上） | MS | **1.1** | 50mm | `waist` | 2.3m |
| ニー（膝から上） | MLS | 1.4 | 50mm | —（式で出す） | 2.9m |
| 全身 | FS | **1.9** | 35mm | `full` | 2.8m |
| ロング / 引き | LS | **4.0** | 28mm | `long` | 4.7m |
| 大ロング | ELS | 8.0 以上 | 24mm | —（式で出す） | 8.0m |

**全身が 1.9m なのは、身長 1.7m に頭と足の余白を足しているから。** 見せたい高さを
身長ちょうどにすると頭頂と足先が枠に接する（`references/framing.md` §3）。

**2 人を 1 枠に入れる（2 ショット）ときは、横に必要な幅から決める。**
2 人の間隔を W（肩幅込みで概ね 1.2〜2.0m）とすると

```
必要な画面の横(m) ≈ W * 1.4              # 両端に余白
距離              ≈ 必要な画面の横 * f / (24 * aspect)
```

（16:9 なら `aspect` = 1.778。縦持ちの 9:16 では 0.5625 なので**同じレンズでは倍以上
離れないと 2 人入らない** —— 縦の作品では 2 ショットを諦めて切り返しで割るのが普通）

## 4. カメラの高さ（`transform.t[1]` と `aim.offset[1]`）

**寄るほど顔へ、引くほど足元まで入るように下げる。**`aimHeightForShot` と同じ比率:

| サイズ | 身長に対する比 | 1.7m のとき |
|---|---|---|
| `closeUp` | 0.92 | 1.56m |
| `bust` | 0.85 | 1.45m |
| `waist` | 0.70 | 1.19m |
| `full` | 0.55 | 0.94m |
| `long` | 0.45 | 0.77m |

`aim` を使うなら **`aim.offset[1]` にも同じ高さ**を入れる（カメラの高さと狙う高さが
食い違うと、意図しないアオリ / フカンになる）。

### 意味を持たせる高さ

| 高さ | 見え方 | 絵コンテ表記 |
|---|---|---|
| 対象の目の高さ（身長 × 0.93） | 中立。既定 | 目線 / アイレベル |
| それより **低い** | 大きい・強い・威圧 | アオリ |
| それより **高い** | 小さい・弱い・客観 | フカン（俯瞰） |
| 座っている人の目線（1.1〜1.3m） | 食卓・車内 | — |
| 2.5m 以上 | 状況が読める | 俯瞰 |

**「目線」は絶対値ではなく相手の身長で決まる。** 身長 1.5m の人物を 1.7m の高さで撮ると
常に見下ろす画になり、意図しない力関係が付く。**`身長 × 0.93` を基準に置く**こと。

## 5. 「寄る」は 2 通りある（どちらかを決めてから触る）

| やり方 | 効果 | 触るもの |
|---|---|---|
| **カメラを近づける**（T.U / dolly in） | 遠近が強くなる。顔が歪む。背景が離れる | `transform.t` |
| **レンズを長くする**（zoom in） | 背景が近づく（圧縮）。歪まない | `fov` |

**両方いっぺんに動かさない** —— どちらの効果で寄ったのか後から分からなくなる。
`probe_previz_scene` の `distance` を見れば、どちらをしたのか判別できる。

用語の対応（絵コンテ表記 ↔ 生成プロンプトの英語）は
`film-grammar` の `references/shot-vocabulary.md` が正本。**ここで作り直さない。**
