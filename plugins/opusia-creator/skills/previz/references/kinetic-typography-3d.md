# 3D のキネティックタイポグラフィをプリビズで組む

**いつ使うか・どの技を選ぶか・読める時間・拍への当て方は
genre-playbook の `references/kinetic-typography.md`**（先に読む）。
ここは**そのレシピを、このプリビズの道具で作る手順**と、**作れないもの**。
根拠は `docs/_research/2026-11-16-kinetic-typography-3d.md`。数値の多くは [設計値]（書き出して見て直す）。

## 1. 道具の割り当て

| 作りたいもの | 道具 |
|---|---|
| 空間に浮かぶ語・字 | **文字の板**（`kind: text`）。`font_size`（字高 m）・`weight` 400/700/900・`color`。**語 1 つ = 1 ノード**、散らす・波にするなら**字 1 つ = 1 ノード** |
| 語の動き（位置・回り・大きさ・出入り） | ノードの `keys.translation` / `rotation` / `scale` / `opacity`。キー列は**時刻の関数**なので seek しても同じ |
| 横組みの歌詞・縦組み・字ごとの 2D の動きを 3D に置く | **カード**（2D の組版を 3D に貼る。compositor の lyric-motion.md） |
| カメラの通過・回り込み | カットの camera。`keys.path: "smooth"` + `follow_path: true`、注視は `aim`（camera-moves.md §8.9） |
| 色・グロー・周辺減光 | `render.look`（`flat` / `toon`）と `render.post`（`bloom` / `vignette` / `color`。**書き出しだけ**） |
| 絵・人物との前後 | `front: true`、2D の層（look.md §2、compositor の illustration-mv.md §3） |

**厚みは `depth`（m）と `side_color`**。同じ字を奥へ重ねた板で出す（表は動かない）。日本語でも書体を選ばない。
ただし**面取り・側面に当たる光は無い**（奥ほど暗くする陰影だけ）。1〜2 語の主役に使い、全語には付けない
（板が最大 32 枚増える）。本物の面取りと金属の光沢が要るなら Blender（§5）。

## 2. 計算はスクリプトに任せる（手で数値を作らない）

`python3 <SKILL_DIR>/scripts/kinetic_3d.py <cmd> …`。標準ライブラリだけ。出力は JSON。
**同じ引数なら同じ出力**（乱数は `--seed` の固定 seed）。`--ops` を付けると
`patch_previz_scene` の `{"op":"add","path":"/nodes/-","value":…}` の列で出る。
**ノードのキーの時刻はシーン時刻（秒）**。歌詞に合わせるなら `--t0` にシーン内の秒を渡す
（曲の時刻から、シーンの開始とメディアの開始を引く。motion-graphics.md §2.9）。
**キーがシーンの尺を越えると検証が落ちる**ので、`--duration` / `--per-word` を尺に収める。

| cmd | 作るもの | 主な引数 | 出力 |
|---|---|---|---|
| `tunnel` | **R1** 語を奥行きに並べ、カメラが抜ける | `--words 語…` `--per-word 秒` `--hold 秒` `--size` `--camera-distance` | `nodes` + `camera_translation` |
| `scatter` | **R5** 字を散らして組み上げる | `--text` `--t0` `--assemble` `--stagger` `--radius` `--center x,y,z` | `nodes`（最終キーが厳密に本来の位置） |
| `bounce` | **R6** 落下して減衰バウンス + 着地で潰れる | `--words 語…` `--interval` `--drop` `--bounces` `--shadow` | `nodes`（`--shadow` で偽の接触影の板つき） |
| `flip` | **R9** 字ごとに時間差で回る | `--text` `--stagger` `--duration` `--axis x\|y` | `nodes` |
| `ring` | **R7** 円筒に並べて一方向に自転 | `--text` `--radius` `--spin 度/秒` `--duration` | `nodes`（裏は不透明度で消す） |
| `shake` | **R2** カメラの減衰シェイク（ロールしない） | `--base x,y,z` `--t0` `--duration 0.3` `--amp` `--freq` | `camera_translation` |
| `fill` | **R11** 語が画面を満たすカメラ距離 | `--width` `--fov` `--fraction 0.85` | `distance` |
| `width` | 文字列の板の幅の見積り | `--text` `--size` | `width` `height` |

流れ: `width` で語の幅を見積り → `tunnel` 等で `nodes` を出す → `patch_previz_scene` で入れる →
`camera_translation` を**そのカットの `camera.keys.translation`** へ（`keys.path: "smooth"`、`follow_path: true`）→
判読窓のコマを描画して確かめる。**キーを手で打ち直さない**（直すなら引数を変えて出し直す）。

## 3. レシピごとの組み方（スクリプトに無いもの）

| レシピ | 組み方 |
|---|---|
| **R2 スラム** | 語のノードに `scale` キー 1.0 → 1.15 → 1.0（着地で 0.2s、`ease-out`）+ 着地の瞬間に `shake`。ブルームは `render.post` の強さを**カット単位**でしか変えられない → 強調は色（`color`）と scale で |
| **R3 オービット** | カメラの translation を `camera_math.py arc`（`--from-deg -120 --to-deg 0`、1.2〜2.0s、`ease-in-out`）。`aim` で語を見続ける。終端のキーを 0.5s 保つ |
| **R4 深度スタック** | 3〜5 層を z で並べ、**焦点の層だけ `opacity` 1・scale 1、奥は 0.35〜0.5 に落とす**。焦点移動は 0.4〜0.6s の `opacity` キー。**被写界深度は無い**ので「ボケ」ではなく「退く」で代える |
| **R8 ネオン点滅** | 点灯を 1、点滅区間だけ 0.2〜0.4 の `opacity` キーを**コマ（1/30s）刻みで手書きせず**、`--seed` 付きで数か所だけ。**1 秒に 3 回まで** |
| **R10 爆発** | **物理は走らせない**。字ごとの散らし（`scatter` を逆向きに使う = 集合の逆再生）で代える。本物の剛体は Blender で焼く |
| **R11 マッチカット** | `fill` で出した距離にカメラを止め、**終端で正面・ロール 0・ブルーム 0**。次のカットを 2D の板（カード）にして同じ位置・大きさで受ける |
| **R12 2.5D** | 背景・中景・文字・前景の板を z で重ね、カメラを横へ ±0.3 × 字高/秒。前景は 0.5s だけ文字の一部を隠す。切り抜きの裏が見える角度まで回さない |
| **R13 経路追従** | 字を曲線上に弧長等分で置く（`ring` の `--radius` を大きく / 手で通過点を置く）。曲率半径 > 字高 × 3 |
| **R14 ドリーズーム** | `camera_math.py dolly-zoom`（距離と fov を逆に）。1 カットに 1 回 |

## 4. 数値の出発点（[設計値]・見て直す）

| 項目 | 値 |
|---|---|
| 字高（1080p・fov 40°・距離 4〜5 m） | 0.5〜0.7 m（板の x 高さが画面で 40px 以上） |
| 語の z 間隔 | 字高 × 3 |
| 語の x/y のずれ・ロール | ± 字高 × 0.3・±8° まで |
| カメラの fov | 通常 30〜40°、トンネル 55〜65° |
| 判読窓 | 各語の手前で減速（`ease-in-out`）→ 0.3 拍静止。正面から ≤ 30° |
| シェイク | 振幅 字高 × 0.03〜0.06・0.3s・18〜28 Hz。**ロールなし** |
| 回り続けるもの | 一方向・1 周 6s 以上 |
| 面の色 | 地と輝度差を確保。`flat` で色が出る、`toon` は陰影が付く |

## 5. 作れないもの（言い切る。無理に近似しない）

| 無いもの | 代え方 |
|---|---|
| **被写界深度・ボケ** | 奥を `opacity` と小ささで退かせる。本物のボケは Blender |
| **フォグ（距離で霞む）** | 奥の語の `opacity` を下げる（`tunnel` の `--fade-in`） |
| **影・接触影** | 黒い円の板を床に置き `opacity` を高さに応じて動かす（`bounce --shadow`）。本物の影は Blender |
| **面取り・金属の光沢** | 厚みは `depth` で出る。面取りと反射が要るなら Blender |
| **剛体の物理（爆発・崩れ）** | 解析式（`bounce`）か集合の逆再生。本物は Blender で焼く |
| **時刻で変わるノイズ・モーションブラー** | 書き出しの設定にない。必要なら three.js 直書き（compositor の three-by-hand.md）か Blender |
| **字ごとのシェーダ（ネオンの発光ムラ等）** | `bloom` の全体強度だけ。細かい発光は Blender |

どれも「それが要るカットだけ Blender（`previz_sample.mjs` → compositor の blender-by-hand.md §7）」。
**3D のキネティックは曲に 1〜3 か所**に絞れば、残りの大半は 2D（text-motion.md）で成立する。

## 6. 日本語（CJK）

- 字は**その曲の歌詞の全文字だけ**で足りる。文字の板の書体は `sans` / `serif`（Noto JP）で、**字形は書き出しの環境に依存しない**
  （プレイヤーが持つ）。**縦組みは 2D のカード側で組む**（縦書きの約物は回転した字形が要る。スクリプトは横並びだけ作る）。
- 画数が多い字は小さいと潰れる。**板の x 高さ 40px 以上**（字高 0.5 m 以上が目安）。
- 太さは 700 を既定に。明朝（`serif`）の細い字は背景に溶ける。

## 7. 守ること

- **乱数は `--seed` で固定**。書き出しを 2 回して同じ絵になること
- カメラの**ロールは使わない**。シェイクは位置だけ
- キーはシーンの尺に収める（超えると検証が落ちる）
- 判読窓のコマ（語が正面・静止・手前）を**描画して見る**。通過中の語は読めない前提
- 3D を全行に使わない。山の 1〜3 か所
