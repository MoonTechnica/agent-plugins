# モーショングラフィックをプリビズ（モーション）で作る

**画面の名前は「モーション」**（ヘッダーのタブ。中身はこのスキルのプリビズ）。ここで組むのは
**レイアウトではなく、そのまま映像になる動きの絵**: 図形・文字・画像の層が出て、動いて、消える。
作ったものは**エディタ（タイムライン）が取り込む**。エディタ側に残るのは、クリップ 1 本ごとの
基本のモーション（位置・スケール・回転・不透明度。`compositor` の `references/clip-motion.md`）だけ。

| 作るもの | どこで作る |
|---|---|
| 図形・帯・文字・画像・3D が動く 1 まとまりの絵（タイトル、ローワーサード、MV の演出、サビ頭） | **ここ**（`previz_scene.v1`） |
| 動画 1 本・テロップ 1 つの拡大・フェード・位置ずらし | エディタのクリップのモーション（`compositor`） |
| HTML で組む文字の分解・粒・光・図形ワイプ | `compositor` の `references/shape-motion.md` / `text-motion.md` / `light-particles.md` |

## 0. タイムラインとの分担（Premiere と After Effects）

**モーションは After Effects、タイムラインは Premiere。** 複数の要素が連動して動く 1 まとまりの絵
（タイトル・ロワーサード・図形・帯・演出の文字や歌詞・3D）は**ここで 1 シーンに作り、タイムラインには 1 本の層で置く**。
部品をタイムラインのクリップとして並べない。字幕・キャプション・読ませるだけの歌詞の行・クリップ 1 本の
フェードや寄りはタイムライン（`compositor`）。直すときは層をダブルクリックしてここへ戻る。
線引きは `docs/designs/2026-11-13-timeline-premiere-motion-ae.md` §1。

**取り込み方は 2 通り。** 層として差し込む（**既定**。人があとから直せる）か、`render_previz_scene` で
mp4 にして置く（軽い。直すにはここへ戻る）。層は `place_previz_clip` で置く
（§9.3）。層のクリップは元のシーンの id（`data-previz-scene`）を持つので、人はタイムラインで
ダブルクリックしてこのシーンへ戻れる。

## 0.5 完了条件: 本編のタイムラインに置くまで（作って終わりにしない）

**モーションのシーンは、手元（モーションの画面）にあるだけでは未完成。** 本編に 1 本の層として置いて初めて
人のタイムラインに載る。**シーンを作ったら同じターンで必ず次を通す**:

```
1. place_previz_clip(composition_id=<本編>, previz_scene_id=<このシーン>)   # 読む・足す・書き戻すまで 1 回
2. get_composition_bundle(<本編>)                 # 置いたあとの本文と head_seq
3. hyperframes check → 置いた層の中間点を hyperframes snapshot --at <秒> → record_check
4. timeline_report.py の motion_layers に、そのシーンが載っているのを確かめる
```

- **字コンテのシーンに結んだモーション**（`create_previz_scene` の `scene_id`）なら、本編にそのシーンの
  **下書きのクリップ（絵コンテが流れている枠）があれば、`place_previz_clip` がそれを消して同じ位置・
  レーンに層を置く**（置き換え。下書きの変数は宣言と束ねからも外れる）。`start` は要らない
- 枠が無い・結んでいないときは `start`（本編の秒。字コンテのシーンの頭）を渡す。レーンは省けば空いている
  映像レーンへ入る。**同じレーンの別のクリップと重なるなら tool が断る**（別の `start` / `track_index` を選ぶ）
- 手で `get_previz_clip` → `put_composition_bundle` と組まない（置き忘れ・`base_seq` の取り違えの元）

**置いていないのに「できました」と報告しない**（報告には置いたタイムライン名と秒を書く）。置けない事情
（承認待ち・衝突）は `report_work` で伝える。直したあとは置き直さない（参照なので最新に変わる。§5）。

## 1. 不透明度（フェード）

どのノードも `opacity`（0〜1、既定 1）と、そのキー `keys.opacity` を持てる。

```json
{
  "id": "title", "kind": "text", "text": "SNAP", "font_size": 2.4,
  "font": "sans", "weight": 900, "align": "center", "color": "#ffffff",
  "transform": {"t": [0, 0.5, 1], "r": [0, 0, 0, 1], "s": [1, 1, 1]},
  "opacity": 0,
  "keys": {
    "scale":   [{"t": 0.8, "v": [0.6, 0.6, 0.6]}, {"t": 1.3, "v": [1.12, 1.12, 1.12], "ease": "ease-out"},
                {"t": 1.6, "v": [1, 1, 1], "ease": "ease-in-out"}],
    "opacity": [{"t": 0.8, "v": 0}, {"t": 1.2, "v": 1}, {"t": 3.2, "v": 1}, {"t": 3.9, "v": 0}]
  }
}
```

- **親から継承しない**（After Effects と同じ）。親を消えさせても子は残る。まとめて消したいなら
  **子それぞれに同じキー**を打つ
- 範囲は 0〜1（補間で外へ出ても 0〜1 に収まる）。キーの時刻は昇順・尺の内側（保存で弾かれる）
- 効くのは図形・板（文字・画像）・モデル。**2D のカード（`kind: card`）の枠と `group` には効かない**
  （カードの中身の 2D は `place: "card"` の 2D レイヤーの中で動かす。§2.7）
- 同じモデルを複数置くと材質を共有して一緒に変わることがある（未検証。フェードを使うなら先に 1 枚で確かめる）
- **`ease` は「到着するキー」に付く**（`camera-moves.md` と同じ規約）。上の例の `1.3 秒` の `ease-out` は
  0.8 → 1.3 秒の動き方。エディタのクリップのモーション（出発するキーに付く）とは逆なので取り違えない

## 1.5 出入り（`start` / `end`。AE のイン点 / アウト点）

ノードを**ある時刻から出して、ある時刻で消す**ときは `start` / `end`（シーン内の秒）を書く。
省略は頭から終わりまで。範囲の外では描かず、**親の出入りは子にも効く**（`group` に書けばまとめて出入りする）。
`scale` を 0.001 にする・`opacity` を 0 にするキーで代用しない（人がモーションの画面で帯を動かせなくなる）。
フェードで出すなら、`start` で出してから `keys.opacity` で 0 → 1。

## 2. 平らな 2D の組み方（実測で決めた値）

プリビズは 3D の空間なので、**平らな絵にするには決まりがある**:

| 決めること | 値 |
|---|---|
| 見た目 | `render: {"look": "flat"}`（陰影なし。色が見たまま出る）。ライトは `hemisphere` を 1 つ、強さ 1 |
| 板の向き | **`plane` は水平に作られる**。正面（+Z）を向けるには回転 `r = [0.7071068, 0, 0, 0.7071068]` |
| 画面の中で回す | 板を θ 度（反時計回りが正）回すなら `r = [c·0.7071068, s·0.7071068, s·0.7071068, c·0.7071068]`（`c = cos(θ/2)`, `s = sin(θ/2)`）。斜めの帯 -18° は `s = sin(-9°)` |
| カメラ | **正投影にする**: `camera.ortho_height`（画面に映す縦の長さ m。例 9）を書く。正面から `[0, 0, d]` に置いて原点を見る。奥行きで大きさが変わらず、背景は映したい大きさのままでよい。寄りは `keys.ortho_height` を小さくする（カメラを近づけても大きくならない） |
| 背景 | 正投影なら映したい幅・高さそのままでよい（遠近法のカメラで組むときだけ、奥ぶん大きく作る） |
| 重なり | **z で決める**（大きいほど手前）。帯 -0.5、文字 +1、背景 -2 のように 0.5〜1 刻み |
| 文字 | `kind: text`。`font` `weight` `align` も書く。`font_size` は 1 文字の高さ m（H=9 の画面で 2.4 なら画面高の約 1/4） |

組んだら `probe_previz_scene` で入っているかを見る（`framing.md`）。

## 2.5 円・角丸・楕円

`plane` に `shape` を付ける: `"circle"`（size に内接する楕円。幅と奥行きを同じにすれば真円）、
`"rounded"`（角丸の矩形。`corner` は角の半径 m で、短い辺の半分までに丸まる）。
ピル型は `size: [3.4, 1.6]` に `corner: 0.8`。寸法は `size` のまま変わらない。
向き・フェード・キーは普通の板と同じ。

## 2.6 グラデーション

`plane` に `gradient: {"from": "#1a1040", "to": "#ff2e88", "angle": 90}`。`angle` は度で、0 = 左 → 右、
90 = 下 → 上（板を正面に向けたとき。省略は 0）。円・角丸にも掛かる。`color` は使われない。
背景・帯・カードの 2 色の塗りに使う。2 色まで（3 色以上は板を重ねる）。

## 2.7 2D レイヤー（HTML。AE の平面・テキスト・シェイプレイヤー）

3D の板では書けないもの —— **1 字ずつの文字・粒・光・グロー・図形ワイプ・線を描く・枠・集中線・縞** —— は、
シーンの **`layers`**（2D レイヤー）に HTML で書く。タイムラインのクリップにはしない（§0）。
層を置くと、2D も 3D も**1 本のクリップの中**に入る。

```json
"layers": [
  {"id": "title", "name": "タイトル", "start": 1, "duration": 3, "place": "front",
   "html": "<div class=\"band\"></div><div class=\"t\">SNAP!</div><style>…</style><script>tl.fromTo(root.querySelector('.band'),{scaleX:0},{scaleX:1,duration:0.6},t0)</script>"},
  {"id": "bg", "place": "back", "html": "<div style=\"position:absolute;inset:0;background:linear-gradient(90deg,#1a1040,#0b6e99)\"></div>"}
]
```

**シーンの骨組み（`schema` / `frame` / `cuts` とカメラ）は書かない** —— `create_previz_scene` が作る。2D だけの
シーン（テロップ・ローワーサード）でもカット 1 本とカメラはそのまま残す（3D が無ければ何も映らないだけ）。
足すときは `patch_previz_scene` の `{"op": "add", "path": "/layers", "value": [...]}`（あれば `/layers/-` に 1 枚ずつ）。
**実写や別の映像の上に重ねるなら `{"op": "add", "path": "/world/transparent", "value": true}`**（AE の透明グリッド。
無いと 3D の背景色が全面に塗られる）。2D だけなら床（`floor`）も 3D の物なので消す（`{"op": "remove", "path": "/nodes/0"}`）。
テロップ・ローワーサードは画面の下端 5〜8% を空け、左右も 5% 内側に置く（字幕・縦型のセーフゾーンは `vertical-shortform`）。

| 項目 | 決まり |
|---|---|
| `id` | ノード・カットと**同じ名前空間**（重なると保存で弾く。`duplicate_layer_id`） |
| `start` / `duration` | シーン内の秒。省略は 0 から終わりまで。尺の外は弾く（`layer_after_duration`） |
| `place` | `front`（3D とカードの手前。既定）/ `back`（3D の奥。**back があると 3D は背景色を描かず透過**になる） |
| 重なり | **上の行ほど手前**（AE と同じ） |
| 器 | 画面いっぱいの `position:absolute; inset:0` の箱に入る。中は絶対配置で組む（シーンの `frame` の px） |
| script | `tl`（シーンの paused timeline）・`t0`（このレイヤーの出の秒）・`root`（器）と、`gsap`・`document` が使える。**時刻は `t0 +` で書く**。timeline の登録は層がやる（`window.__timelines` を書かない） |
| 決定論 | `Math.random` / `Date.now` / `performance.now` / `repeat: -1` は保存で弾く（`layer_not_deterministic`）。乱数は種付きの自前の関数で |
| `visible: false` | 書き出さない（AE の目のアイコン） |
| `text` | **文字の型**（`html` の代わり。どちらか 1 つ）: `{content, preset: fade/rise/pop/type/blur/slam, unit: char/word/line, stagger（秒）, each（秒）, size（px）, color, weight（400 / 700 / 900 だけ）, font（sans / serif / **mincho**（Zen Old Mincho）/ **brush**（Yuji Syuku の毛筆）/ **heavy**（Dela Gothic One の極太）/ **hand**（Klee One）。brush・heavy・hand は太さが 1 つなので `weight` は無視される。書き出しが Google Fonts から取得して埋め込む。**初出の書体は 1 コマ書き出して確かめる**）, align（left / center / right）, vertical, x, y, order（出る順: start / end / center / edges）, preset に `custom`（出る前の値 `from{x,y,rotate,scale,blur,opacity}` と `ease`: linear / out / in-out / back / expo / step）, karaoke{color, each, start, stagger, at[]（単位ごとの時刻。歌詞の時刻に合わせるならこれ）}, tracking（字間 em）, stroke{width px, color, hollow（中抜き）}, shadow{x, y, blur, color}, glow{blur, color}}`。**縁取り・中抜き・影・グロー・字間は人が画面で直せる**（縁は字の後ろに描くので、見える太さは `width` の外側の半分）。**`x` / `y` は画面の左上からの px（AE の位置）**で、`align` の側（左端 / 中央 / 右端）と縦の中央をそこへ合わせる。省略は画面の中央。`content` 以外は省略でき、既定は `preset: rise` / `unit: char` / `stagger: 0.05` / `each: 0.4` / `size: 96` / 白 / 900。型に無い入り方（左から滑り込む等）はレイヤーの `motion` で足す。1 字・1 語・1 行ずつ出る HTML と動きはサーバが組む。**人がモーションの画面で型を選び直せる**ので、出方が既定の型で足りる見出し・歌詞の行・テロップ風の文字はこちらで書く。型に無い動き（文字の分解・変形・作字）だけ `html` |
| `shape` | **平面・長方形・楕円・角丸の塗りつぶし**（`html` の代わり。どれか 1 つ）: `{shape: rect / ellipse / rounded, width, height（px）, fill, stroke?, stroke_width, corner（rounded の半径 px）, x?, y?（中心。省略は画面の中央）}`。**単純な図形（背景の地・帯・円・枠）は `html` ではなくこちらで書く**（人が画面で色・大きさ・形を直せる）。**平面（Solid）= 画面いっぱいの長方形**（`width` / `height` をシーンの `frame` に合わせる）。複雑な形・グラデーション・動く図形・線を描くものだけ `html`。位置・拡大・回転・不透明度のキーは下の `motion` |
| `motion` | レイヤー全体の位置・拡大・回転・不透明度・アンカーのキー（AE のトランスフォーム）。形は `{"position": [{"t": 0, "v": [-120, 0], "ease": "ease-out"}, {"t": 0.45, "v": [0, 0]}], "opacity": [{"t": 0, "v": 0}, ...]}`（`position` / `anchor` は px の `[x, y]`、`scale` は倍率、`rotation` は度、`opacity` は 0〜1）。時刻は**レイヤーの出から**。`position` は**元の位置からのずれ**（文字なら `text.x` / `y` からのずれ）。**`ease` は「そのキーから次のキーまで」の動き方**（クリップのモーションと同じ。§1 のノードのキー＝到着側とは逆）。人がモーションの画面のストップウォッチで付け直すので、レイヤー全体の出入り（フェード・スライド）は script ではなくここに書く |

**レイヤーの出入り（入場・退場）は `motion` のキーで書く。** 画面には**入場 / 退場のプリセット**
（フェード・スライド（左右上下）・ズーム・ポップ・スピン）があり、選ぶと同じ `motion` にキーを書く。**同じ形で書く**と、
人が画面のストップウォッチ・ドープシートでそのまま詰められる（別の「入場」という欄は無い）:
窓は 0.5 秒（短い層は長さの半分）。**入り**は層の頭から窓の終わりで休止値へ着地（`ease-out`）、**出**は
尻の窓の頭で休止値から始まり尻で消える（`ease-in`）。フェード = 不透明度 0 ↔ 1 / スライド = `position` を
120px ずらして不透明度も / ズーム = `scale` 80% から / ポップ = `scale` 60% → 110% → 100% / スピン = `rotation` −90° から。
スライドの向きは入りも出も**同じ語**（「左」は左から入り、左へ出る）。窓の中の既存キーは置き換わる。

**動きの作り方（語彙・強さ・レシピ）は `compositor` の references をそのまま使う**: 文字は `text-motion.md`・`lyric-motion.md`、
帯・図形は `shape-motion.md`、光・粒は `light-particles.md`。違うのは**置き場所だけ**（本編のトラックではなくここ）と、
script の `window.__timelines` の代わりに `tl` / `t0` / `root` を使うこと。
**2D のカード（`kind: card`）の中身**（rig・歌詞の組版・映像）は `place: "card"` のレイヤーに書く。中に
`data-previz-card="<カードの名前>"` の要素を置けば、プレイヤーがカードの位置に遠近で貼り、奥の 3D と手前の 3D の間に積む。
このレイヤーは時間で畳まず（出入りはカードのノードの `start` / `end`）、`motion` を持てない（`card_layer_motion`。
カードを動かすのはノードのキー）。中身の要素の大きさ（`width` / `height` px）は書き、位置・変形・z-index は書かない。

## 2.8 音声レイヤー（AE の音声レイヤーとガイドレイヤー）

モーションの画面は**再生ヘッドに合わせて音声レイヤーを鳴らす**。レイヤーに音を持たせると、画で
タイミングを合わせ見られる（人もあなたも、音なしで拍や歌詞が合っているかを推測しなくてよい）。

```json
{"op": "add", "path": "/layers/-", "value": {
  "id": "song", "start": 0, "duration": 7.5,
  "audio": {"asset_id": "<曲の素材 id>", "media_start": 42.0, "guide": true}}}
```

| 欄 | 意味 |
|---|---|
| `audio.asset_id`（+ `version_id`） | プロジェクトの音声素材（`list_*` で引いた id。当てずっぽうを書かない） |
| `start` / `duration` | シーン内の出入り（秒）。`duration` の省略はシーンの終わりまで |
| `audio.media_start` | **素材の中の開始位置（秒）**。レイヤーの出の瞬間に素材のこの位置が鳴る |
| `audio.volume` | 0〜2（1 = 素材のまま。編集画面は最大 1 で鳴らし、1 を超えた分は書き出しにだけ効く） |
| `audio.guide` | **true = 編集画面でだけ鳴らし、書き出しにも本編に置いたクリップにも入れない**（AE のガイドレイヤー） |

**使い分け（取り違えると二重に鳴る）**

| 音 | 置き方 |
|---|---|
| **MV の曲・ナレーション**（本編のタイムラインが持つ） | `guide: true`。`media_start` = **そのシーンが曲の何秒目から始まるか**（曲の地図の区間の頭）。`start` / `duration` はシーンの全体 |
| 動きと一体の音（タイトルの効果音・決めの 1 音） | `guide: false`（既定）。書き出しと、本編に置いたクリップに入る。曲やナレーションは入れない |

- **MV のシーンを作ったら、曲の該当区間をガイドで必ず入れる。** 入れないと、人は歌詞・カット・光の
  タイミングが曲に合っているかを画面で確かめられない（手で直すのが難しくなる）
- 音声レイヤーは**見えない**ので、`place` / `motion` は持てない（`audio_layer_motion`）。1 レイヤーは
  `html` / `text` / `audio` / `shape` のどれか 1 つ（`layer_content`）
- 隠す（`visible: false`）と鳴らさず、書き出さない。曲のずれを人が直すときは `media_start` と
  レイヤーの出入りを動かす（モーションの画面のインスペクタとドープシート）

## 2.9 MV のシーンで迷いやすい 3 点

**① 試作も本編に置く（置いた印は名前と報告に書く）。** 本編に置かずに見せる道は無く、§0.5 は試作にも
効く。取り違えないよう、**シーンの名前を「S6 試作」のように書き**、`report_work` にも「試作」と書く。
本番にするときは**同じシーンを直す**（置き直さない。参照なので置いた層がそのまま変わる。§5）。

**② 歌詞の時刻はシーンの中の相対秒。** シーンの `layers` の `start` / `duration` は**シーンの頭が 0**。
曲の地図（`lyric_lines[]`）の時刻は曲の秒なので、`曲の秒 − そのシーンが曲の何秒目から始まるか`
（= ガイド音声の `media_start`）に直して書く:

```
start    = 行の start_sec − media_start − 1〜2 コマ     # 歌の 1〜2 コマ前に出す
duration = (行の end_sec + 0.2〜0.5) − (行の start_sec − 1〜2 コマ)   # 消えは歌い終わりの少し後
```

`lyric_check.py` は**本編の HTML の `data-start`**（曲の時刻）を地図と突き合わせる道具で、シーンの文書の
相対秒は読まない。シーンの歌詞は上の式で書き、**`hyperframes snapshot --at` で行の頭と終わりの
コマを見て**確かめる（§0.5 の手順 4）。

**③ 絵の置き方の既定は「画像の板」。** 背景・小物・止めのキャラは**画像の板**（`kind: image`）。
**カード**（`kind: card`、中身は `place: "card"` のレイヤー）は、髪・服を揺らす rig、まばたき・口パク、
歌詞の組版を絵に貼るときだけ。**試作は rig・まばたきを省いて、止め絵（画像の板）で出してよい**
（動きの質は本番で足す。省いたことは `report_work` に書く）。

## 3. 動きの型（そのまま使える形）

- **スライドイン**: `translation` の 2 つ目のキーに `ease-out`、同じ時刻の手前に `opacity` 0 → 1（0.4〜0.5 秒）
- **ポップ**: `scale` を 0.6 → 1.12（`ease-out`）→ 1（`ease-in-out`）。`opacity` は 0.4 秒で 0 → 1
- **フェードアウト**: 最後の 0.7〜0.8 秒で `opacity` を 1 → 0
- 帯を 2 本以上重ねるときは**入りの時刻を 0.2 秒ずらす**（同時に動くと 1 枚に見える）

## 4. できないこと（先に言う）

- **線**の専用の層は無い。細い角丸の板（`size: [長さ, 0.06]`、`shape: rounded`、`corner: 0.03`）で描く
- 正投影では `fov` と `p3d_orbit`（回る）は意味が薄い。**寄る・引く（`p3d_move`）と距離（`p3d_dolly`）は映す縦の長さ（`ortho_height`）に掛かる**
  （カメラの位置は動かさない）。`pan` は映す幅の 30% だけ横へ振る
- **Blender への橋**（`previz_sample.mjs` → `previz_to_blender.py`）: 位置・見え隠れ・カメラ・正投影の高さ・つまみ
  （`--tuning '{"move":"pushIn","light":0.8}'`。値は `p3d_*` から `p3d_` を外した名前）・ライトの倍率は渡る。
  **不透明度は 0 のとき描かないだけ**（途中の半透明は渡らない）。投影の型はキーにできないので、
  正投影か遠近法かは最初のコマで決まる（カットで混ぜない）。円・角丸・グラデーションの形は Blender 側で未対応。
  **この橋の Blender 側は実機（bpy）で未検証**。書き出して見て直す

## 5. 人が詰めた値を戻さない（層として取り込まれたあと）

モーションの層には、人が**つまみ**で詰められるカメラの値が付く（エディタの「つまみ」タブ）。
値は層のクリップの `data-variable-values` に入る。

| id | 意味 | 範囲 |
|---|---|---|
| `p3d_move` | 動きの型 | `none` / `orbit`（回る）/ `pushIn`（寄る）/ `pullOut`（引く）/ `pan` |
| `p3d_moveAmount` | 動きの量（カットの頭から尻まで） | 0〜1（orbit は 1 で 90°、寄るは距離 60%、引くは 160%、pan は画面幅の 30%） |
| `p3d_moveEase` | 緩急 | `linear` / `ease-in-out` / `ease-in` / `ease-out` |
| `p3d_orbit` | 見る位置の角度のずれ | -180〜180° |
| `p3d_dolly` | 距離の倍率 | 0.5〜1.8 |
| `p3d_height` | カメラの高さのずれ | -3〜3 m |
| `p3d_light` | ライトの強さの倍率（文書の `lights[].intensity` に掛ける） | 0〜2 |

- **クリップを置き直すとき（`place_previz_clip` をもう一度呼んで置き直すとき）は、既存のクリップの
  `data-variable-values` を消さない。** クリップの HTML を置き直すなら、既存の値を写す
- カメラの**基本の動き**（経路・向き・画角のキー）は**シーンの `cuts[].camera`** を直す。つまみは
  その上に重なる微調整（人が詰める値）で、AI が「直して」と頼まれていないのに書き換えない
- **層はシーンへの参照**。`patch_previz_scene` で直せば、タイムラインの層は**そのまま変わる**
  （置き直さない）。同じシーンを置いた全タイムラインが変わるので、**ほかのタイムラインに影響させたくない
  直しは、シーンを複製して別のシーンで直す**

### 5.1 直す前に使用箇所を見る・複製して独立させる

1. **直す前に `list_previz_scene_uses`**（`previz_scene_id`）。シーンを置いたタイムラインと、
   そのクリップ id が返る。**自分が今開いているタイムライン 1 本だけの話でなければ、
   ほかのタイムラインも変わる**ことを人へ伝えてから直す。空なら、どこにも置かれていない
2. **1 本だけ変えたい / この姿で止めたいとき**は `detach_previz_clip`（`composition_id` と `clip_id`）。
   シーンを複製し、**そのクリップだけ**の `data-previz-scene` を複製先へ付け替えて 1 回で保存する
   （`data-variable-values` ・開始・尺・トラックは触らない。読んだ後に人が書いていれば断るので読み直す）。
   返りの `previz_scene_id` が複製先で、以降の直しはそこへ `patch_previz_scene` する。
   複製だけが欲しい（まだ置かない）ときは `duplicate_previz_scene`（名前は「元の名前 (copy)」）
3. 複製しても、元のシーンを置いたほかのタイムラインは**そのまま**。元を直す必要はない

### 5.2 置いたあとの見た目の確認（公式の手順）

HyperFrames 公式の手順どおり、`get_composition_bundle` で本文を手元に写し、`npx hyperframes check --json` を
通してから `npx hyperframes snapshot --at <t,…>` の PNG を読む。**本文のモーション層は展開済み**で返るので、
そのまま check も snapshot も通る（実測: 参照のままだと `missing_or_empty_sub_composition`）。
層の**始まりより前の秒**を撮ると背景しか写らない。層の開始秒と終了秒（`timeline_report.py` の
`motion_layers`）の内側を撮る。展開した `compositions/previz-*.html` は確認用で、`put_composition_bundle`
には渡さない。
