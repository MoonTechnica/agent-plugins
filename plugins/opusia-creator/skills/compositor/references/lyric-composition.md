# リリックモーションの面付け（語の大小・四隅・縦組み・キャラの前後）

MV の歌詞を**絵として組む**ときの手順。1 行の歌詞を語に割り、語ごとに大きさ・位置・出方を決め、
キャラの前後に差し込む。**使いどころと強度は genre-playbook の kinetic-typography.md**、技法の語彙は
[text-motion.md](text-motion.md)、歌詞の時刻の基準は [lyric-motion.md](lyric-motion.md)。
根拠と数値の出どころは `docs/_research/2026-11-17-lyric-motion-technique-catalog.md` §7
（**2 枚の静止画の目視計測 + 設計値**。動く映像は見ておらず、動きの値は [提案]）。

## 1. 2 つの型（まずどちらかを選ぶ）

| 型 | 見た目 | 向く曲 | 道具 |
|---|---|---|---|
| **四隅の大小（tone-on-tone）** | 薄い地に同系の濃い明朝。語を画面の四隅へ、主役を特大・助詞を小さく。中央の縦帯（顔）を空ける | 静か・内省・Aメロ | `--pattern surround --style tone` |
| **縦組みの見切れ + 中抜き（high-contrast）** | 赤地に白の極太縦組みが下端で見切れ、反対側に中抜きの縦列。キャラの後ろに入る | 攻撃的・サビ | `--pattern column --style pair --bleed 0.12` |

そのほか `stack`（中央の縦積み。語のブロック）。**散らし・放射・格子・形の配置は `glyph_layout.py`**（[glyph-layout.md](glyph-layout.md)）。
**セクションで型を切り替える**（A メロ = 四隅、サビ = 縦組み）と曲に起伏が出る。

## 2. 手順

1. **歌詞を語に割り、格を付ける**（あなたの仕事。機械で決めない）。行の `text` に書く:
   `|` が語の区切り、語頭の `!` が**主役（S）**、`,` が**助詞（P）**、無印が普通（M）。
   - 主役は**名詞・代名詞・感情語・フレーズの意味の核**（歌で長く伸ばす語）。1 フレームに **1〜2 語**。対になる語（俺 / 私）は S 同士で左右に置く
   - 助詞は**前の語の直下に寄せる**。文節の切れ目で区切る（「の」だけ離さない）
   - 大きさの比は主役 : 助詞 ≒ 2.2〜4 : 1。**3 段（S / M / P）まで**。同時表示は **5〜7 語**まで
2. **避ける箱を決める**: キャラの**顔の外接矩形を各辺 +8〜12%** 広げた箱を px で。目 > 手 > 口の順に守る
   （`probe_previz_scene` の ndc か、絵を見て決める）。迷ったら文字をキャラの**後ろ**へ
3. **面付けする**:
   ```
   python3 <SKILL_DIR>/scripts/lyric_layers.py --lines lines.json --pattern surround --style tone \
     --avoid 560,160,1360,1080 --scene-start <シーンが曲のこの秒から始まる> --ops
   ```
   出力の `layers`（`--ops` で操作列）を `patch_previz_scene` で入れる。`boxes` は各語が占める矩形、
   `warnings` は避ける箱に収まらなかった語（位置を手で直す）。語は行の中で**文字数に比例して時刻を配る推定**
   なので、語ごとの時刻（ASR 等）があれば行の `words` に `start_sec` を書く
4. **キャラの前後を決める**（`--place back` が既定 = 3D の絵・立ち絵の**後ろ**）。顔の前に出したい語だけ
   `--place front` で別に出す。**読ませない副の層（中抜き）は奥、読ませる主は手前**
5. **カラオケ**（`--karaoke <色>`）: 歌に合わせて字が色を変える。語ごとの時刻を使う
6. **描いて確かめる**: 各フレーズの**頭・最後の語が出た直後**の 1 コマ。顔・目・手が隠れていないか、見切れの量が
   字高の 5〜35%（縦組みは**最後の 1 字だけ**切る）か

## 3. 動かし方（フレーズ単位）

| 型 | 内容 | 向く場面 |
|---|---|---|
| **累積** | 歌う順に 1 語ずつ足し、フレーズ末まで残す。次のフレーズで**全部まとめて消す** | 四隅の型（`lyric_layers.py` の既定。各語は行の end + 0.3 秒まで残る） |
| **フレーズ置換** | フレーズごとに別の構図へカット。**同じ構図を使い回さない** | 縦組みの型・サビ |
| **差分更新** | 構図は固定で語だけ置換 | 静かな節 |

- **入り**（`lyric_layers.py` の既定）: 主役 = `slam`（0.22 秒、着地を歌の onset に）、普通 = `pop`、助詞 = `fade`
  （目立たせない）。見切れ文字は切れる端からスライドイン（字高の 100〜150%）
- **同時に動かす語は 3 つまで**。主役の着地では他を止める（動きの引き算）
- **退出に凝らない**: 既定は**カット**（拍頭で全消し + 次の構図）。フェードは余韻・静かな節だけ
- キャラが動いている間は文字を静止、文字が動くときはキャラを静止（**両方動くと読めない**）

## 4. 見た目の決まり

- **tone-on-tone**: 地と同系の濃い色（黒を避け、地の色相を引いた暗色。例: 地 `#F7E3A0` に文字 `#585858`）。
  **high-contrast**: 赤地に白。塗りと中抜きが**同じ色**で、太さだけで主従をつける
- 書体は**1 フレームに 1 か所だけ別書体**（筆文字など）。今のエディタは明朝 / ゴシックの 2 種（Noto）。
  筆書体（Yuji Syuku 等）はローカル書き出しでは `font-family` の名前だけで出ると実測済み。Cloud とプレビューは未確認なので、確実にしたいときは `html` の層で `@font-face` を同梱する（lyric-motion.md §1 書体）
- **質感は背景とキャラに、文字には載せない**（判読を守る）。ハーフトーン・紙のむら・淡い放射線は
  `html` の層（`place: back`）で、シード付きの値から 1 回だけ作る（研究 §7.5）
- 画面の端の余白は通常の語で 4〜6%。**見切れは意図して**字高の 5〜35%

## 5. 使えないもの・手で書くもの

- 筆の書き込み（書き順）、手書きの揺らぎ（ボイル）、液状・粉砕、ハーフトーン: 専用の道具は無い。
  `html` の層で書く（kinetic-2d-recipes.md / 研究カタログの B11・B13・B16・B17・T 系）
- 顔の位置の自動検出は無い。`--avoid` は人かエージェントが決める
