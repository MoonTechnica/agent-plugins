# 持ち込みの 1 枚で、文字を被写体の後ろへ回す

PV・説明・MV の 1 カットで、**既にある 1 枚の絵**（人・動物・製品・建物）の背景に巨大な文字や図形を
入れ、被写体を手前に残す（文字の一部が被写体に隠れる）ときの組み方。**層に分かれていない絵**でもできる。

**文字の質感は決めない。** 掠れ・RGB ずれ・走査線・箔・手書き・ネオン・グラデ・影…は
**企画・曲・絵のトーンから、プロジェクトごとに選ぶ**（`genre-playbook` / `art-director` の
スタイル）。下の骨組みは**重なり順と手順だけ**で、色・書体・動きは例にすぎない。
ホラー調の PV に合わせて作ったときの組み合わせ（赤橙の太字 + RGB ずれ + 走査線）を
既定にしない。

## 1 重なり順（これだけが型）

```
最背面  plate        背景の絵（被写体を含んだ元の 1 枚、文字・ロゴが焼き込まれていないもの）
        文字・図形    ← ここに挟む。被写体の縁をまたぐ位置に置くと「後ろに回っている」と読める
        cutout       被写体の切り抜き（透過 PNG）。plate と同じ寸法・同じ位置・同じ object-fit
最前面  暗部・光・走査線・粒など「全体に掛かる」もの
```

- plate と cutout は**同じ親（world）に入れて一緒に動かす**。別々に動かすなら視差
  （[parallax-camera.md](parallax-camera.md)）。同じ倍率・同じ基準点でないと縁がずれて切り抜きが浮く
- 文字が**被写体の外側だけ**にあると、後ろに回っているのではなく横に並んでいるだけに見える。
  文字の一部が被写体に隠れる位置と大きさにする（文字の置き場は構図で決める。
  [lyric-motion.md](lyric-motion.md) §4）
- 文字より前に置く層は cutout だけにする。暗い縁取りや光を cutout より下に置くと、被写体の縁だけ
  明るくなって切り抜きに見える

## 2 手順

```
1. get_asset_preview(元の 1 枚)
     文字・ロゴが焼き込まれている? → ある: §3 の plate を作る / 無い: 元の 1 枚がそのまま plate
2. 切り抜く（§4）                       → cutout（透過 PNG）
3. 縁を確かめる（§4）                    → 足りなければ設定を変えて切り直す
4. モーションのシーンに組む（motion-scene.md §1〜§2。create_previz_scene → patch_previz_scene。別の composition を作らない）
     plate / cutout は画像変数（data-var-src）→ list_composition_variables → bind_composition_variable
5. 検査（SKILL.md §2。§5 の許可属性を忘れない）→ 打点の前後と静止後のコマを見る → 書き出し
```

文字は読ませる行ならトラック、演出ならモーションのシーンの 2D レイヤー（motion-scene.md §0）。**被写体の後ろに回す文字は
モーションのシーンの中**（層の間にしか置けない）。

## 3 焼き込みの文字・ロゴを消して plate にする

`generate_asset`（task `image_edit`、画像編集のモデル）で「文字とロゴだけを消し、背景を自然に
補完し、被写体・光・色調・質感は変えない」と頼む。参照の渡し方・fields は `get_model_capabilities`
で確かめてから埋める。

- **編集は描き直し**。実測では被写体と構図は保たれたが、背景の細部（木・地面）は元と少し違った。
  元の画素をそのまま使いたい（商品写真など）なら、**文字の無い元の絵を人にもらう**
- 切り抜きは**編集した後の plate**から作る（plate と cutout の絵を揃える）

## 4 切り抜く（`seedream-5-layerize` ではなく背景除去）

| | 向く | 理由 |
|---|---|---|
| **`image_background_removal`（BiRefNet v2）** | **持ち込みの 1 枚**・写真・完成した絵 | **元の画素を保つ**。毛並み・輪郭の質感がそのまま残る |
| `seedream-5-layerize` | これから作る絵（パーツに分けて揺らす） | 描き直すので、持ち込みの 1 枚に使うと**形が変わる**（art-director の references/motion-stills.md §4） |

- `generate_asset` の task `image_background_removal`。**素材から作るタスクなので `canvas_node_id`
  が要る**（空ノードを先に置く。tool の説明のとおり）。設定（プリセット・出力の解像度・出力形式）は
  `get_model_capabilities` で確かめる。毛・羽・半透明は **Matting 系 / Heavy**、解像度は被写体が
  小さいほど上げる、出力は **png / webp**（透過を保てる形式）
- **縁は見る**: `get_asset_preview` で、**暗い色と明るい色の両方の上**に置いて、毛先のハロ・
  欠け・背景の切れ残りがないか確かめる。暗い絵に白いフチが出るなら出力を変えるか切り直す
- 被写体を**動かす**（前へ出す・回り込む）カットは、動かして**背後に欠けが出る**ので plate の
  補完が要る。固定カメラで文字だけを叩きつけるなら要らない

## 5 検査で止められる所（意図した重なりは明示する）

`hyperframes check` の layout は、文字が上の層に隠れることを**既定ではエラー**にする
（`text_occluded` / `content_overlap`）。後ろに回す設計では必ず当たるので、**意図的な重なりと
明示する**:

| 属性 | 付ける所 |
|---|---|
| `data-layout-allow-occlusion` | 被写体に隠れる文字・図形、全体に掛かる暗部や走査線の層 |
| `data-layout-allow-overlap` | RGB ずれのゴーストなど、同じ文字を重ねたもの |
| `data-layout-allow-overflow` | 画面の外へはみ出す巨大な文字 |

明示は**意図した層だけ**に付ける（全部に付けて検査を黙らせない）。

## 6 動き・質感（プロジェクトごとに決める）

- 打点で叩きつけ、**出し終えたら止める**（`genre-playbook` の「わざと止めるビート」）。止めたあとの
  カメラは動機のある寄りだけ
- 質感・書体はそのプロジェクトの絵と企画から決める。書体は同梱の Noto Sans JP 以外は
  `@font-face` で `assets/fonts/` のファイルを指す（`hyperframes-core`）。**文字の色は絵の差し色から取る**（art-director の
  motion-stills.md §7）
- 動きの作り方は [text-motion.md](text-motion.md) / [effects.md](effects.md)（`rgbShift` など）/
  [light-particles.md](light-particles.md) / [shape-motion.md](shape-motion.md)

## 7 実測（2026-11-15）

横長 1 枚（熊・暗い森）に対し、画像編集 1 回（文字とロゴを消す）+ BiRefNet v2（Heavy・2048）1 回で
plate と cutout を作り、4 秒のカット（叩きつけ → 止め → ゆっくり寄る）を HyperFrames 0.9.52 で
組んで `check` を通し、書き出して確かめた。毛並みと光る目の縁まで切り抜けた。これは **手元で部品を
つないだ検証**で、エージェントが自力で通した記録ではない（Cloud の書き出しでも未確認）。
