# イラスト MV・2D と 3D の融合（AE の 3D レイヤーとカメラで組む画）

歌い手のカバー曲・ボカロ曲に多い **イラスト MV（リリックモーション）** の組み方。After Effects で作り手が
1 人でやっていること —— 絵をパーツに分けて揺らす、3D の空間に絵と歌詞の板を並べる、カメラで抜ける、
歌詞を組む、写真やフレームで密度を上げる、光を足す —— を、うちの道具に割り当てる。
絵は 1 枚とは限らない（キャラが何人も・背景の絵・小物の切り抜き）。

## 1. 道具の割り当て

| AE でやること | ここで使うもの | 参照 |
|---|---|---|

| まばたき・口パク | face cues | SKILL.md §9 |
| 2D のレイヤーを 3D 空間に置く（3D レイヤー） | プリビズの文書の **2D のカード**（`kind: card`）。中身は composition の 2D のまま動く | previz の references/look.md §2.1 |
| 切り抜きの絵・写真・看板を奥行きに並べる | **画像の板**（`kind: image`。透過 PNG 可） | 同 §2 |
| 空間に浮かぶ語（横組み・語の単位） | **文字の板**（`kind: text`） | 同 §2 |
| 縦組み・1 字ずつ動く歌詞を 3D に置く | 歌詞の組版を 2D で作り、**カード**に貼る | [lyric-motion.md](lyric-motion.md) |

## 2. 段取り

1. **曲と絵を分ける**: 歌詞の時刻（lyric-motion）、カットとカメラの区切り（音楽の山）。キャラ・背景・小物の絵を
   1 枚ずつ揃える（足りなければ生成。キャラは立ち絵、背景は奥行きのある絵か分けた板）
2. **キャラを rig にする**: 1 人ずつ layerize → `rig_parts.py` → `frames/rig-<名前>.html`（layer-rig.md §7）
3. **空間を組む**（previz スキル）: 床・背景の板・小物・カードの位置、カメラの経路。エディタではカードが
   半透明の枠で見えるので、構図はそこで決める
4. **モーションのシーンに 2D を持たせる**（previz の `references/motion-graphics.md` §2.7）: rig の器・歌詞の 2D
   （`data-previz-card`）は `place: "card"` のレイヤー、フレーム・光の 2D は `front` / `back` のレイヤー。
   タイムラインには `place_previz_clip` で層（シーンへの参照）を 1 本置くだけ。重なり順は §3
5. **書き出して見る**: 頭・カットの境目・サビの頭の 1 コマ。カードの中身（揺れ・字）は書き出しでしか見えない

## 3. 重なり順と、カードの器

プレイヤーが 3D の層の中を 3 枚に積む（基準は器の `data-previz-z`、既定 10）:

```
z 110〜   手前の 2D（字幕・フレーム・光）           ← 書き手
          手前の 3D（front: true の物）              ← プレイヤー
z 11〜    2D のカード（奥から順に。手前のカードが上）  ← プレイヤー
z 10      奥の 3D（床・背景・front でない物）          ← プレイヤー
z 0〜9    3D の奥の 2D（背景の絵・人物の奥に回す歌詞）  ← 書き手（層は transparent: true）
```

- カードの中身は**シーンの `place: "card"` の 2D レイヤー**に置き、`data-previz-card="<名前>"` と、中身の大きさの
  `width` / `height`（px）を書く。位置・変形・z-index はプレイヤーが毎コマ書くので書かない
  （以前は層を置いた先の composition の root 直下に書いていた。新しく作るときはレイヤーへ）
- 映像をカードにするときは `<video>` を `<div data-previz-card>` で包む（`<video>` 自身に付けない）。
  包む `div` に `data-start` を書かない（`<video data-start>` の親に `data-start` を付けると lint の error）
- カードどうし・カードと 3D の前後は「奥の 3D → カード → 手前の 3D」の 3 段だけ。カードを 3D の物の
  **隙間に挟む**（モニターが前後の鉄骨の間にある）なら、前の物に `front: true` を付ける（`group` に付ければ子も手前）
- 器の `data-previz-z` を変えると、3 段がまとめて動く（他の 2D との順を変えるとき）

## 4. 密度を上げる（「何も起きていないコマ」を作らない）

| 手 | 書き方 |
|---|---|
| フレーム | 画面の縁に細い線・角のマーク・番号・タイムコード風の数字。手前の 2D。カメラが動いても動かさない（画面の座標） |
| ダミーテキスト | 小さな英字の段落・ラベル・座標・曲名とクレジット。歌詞より 1 段小さく・薄く。意味の無い文字列でよいが、**歌詞と同じ書体系**に揃える |
| スクロール型 | 写真・文字の帯を縦か横に流し続ける（時刻で位置を決める `translate`）。カードに貼れば 3D の壁になる |
| 写真のオブジェクト | 切り抜いた写真・ポラロイド風の枠を画像の板やカードにして奥行きに散らす |
| インサート | サビ前・間奏に 0.5〜1 秒の寄り（手元・目・小物）。プリビズのカットを 1 つ足すか、2D の別カット |
| カメラ割り | 同じ空間でも、カットごとに経路と画角を変える（引きの通過 → 寄りの回り込み → 正面の止め） |

詰めすぎない。主役（キャラの顔・その瞬間の歌詞）の周りは空ける。

## 5. 光と仕上げ（逆光・にじみ・粒子）

- **逆光**: キャラのカードの**後ろ**に、放射グラデーションの 2D を置く（`mix-blend-mode: screen` か `plus-lighter`）。
  カードの中身の縁に `filter: drop-shadow(0 0 12px <光の色>)` を掛けると縁が光る（器ではなく中身に掛ける）
- **差し込む光・フレア**: 手前の 2D に、斜めの光の帯（線形グラデーション + `screen`）。時刻で位置と強さを決める
- **3D のグロー**: 文書の `render.post.bloom`（奥の 3D にだけ効く。手前の 3D とカードには掛からない）
- **粒子・雨・粒状感**: effects.md の `rain` / `snow` / `filmGrain` を手前に
- 入れすぎない。光は 1 シーン 1〜2 種類

## 6. 守ること

- CSS アニメーションを使うなら `animation-iteration-count: infinite` にしない（effects.md「守ること」）。揺れ続ける
  物は回数を尺から決めるか、GSAP / 時刻の式で書く
- カード・rig・プレイヤーは**全体の時刻から自分の開始を引いて**動く。器の `data-start` は数値で書く
- カードの縦横比と文書の `size` を揃える。カメラがカードの near より手前に入るとそのコマだけ消える
- 画面に張り付く歌詞（字幕）はカードにしない（カメラで歪む）
