# 文字をバラバラに散らす・幾何学的に並べる（センスのよい面付け）

「ランダムに撒いた」ではなく「デザインされた散らし」にするための手順と道具。
規則の根拠・数値の出どころは `docs/_research/2026-11-17-lyric-motion-technique-catalog.md` §9
（**設計値が中心で、描いて確かめた範囲は下の「確かめたこと」**）。歌詞を語に割る面付けは
[lyric-composition.md](lyric-composition.md)、曲線に沿わせるのは `scripts/text_path.py`
（[kinetic-2d-recipes.md](kinetic-2d-recipes.md) §0）。

## 1. 道具: `scripts/glyph_layout.py <配置>`

標準ライブラリだけ・乱数は seed 付き（同じ引数なら同じ出力）。語ごとに 1 つの文字レイヤーを作り、
**回転・移動はレイヤーのモーションのキー**（人がドープシートで直せる）。`--ops` で `patch_previz_scene` の操作列。

| 配置 | 見た目 | 向く場面 | 要点 |
|---|---|---|---|
| `scatter` | ジッタ付き格子。整って見える散らし | **既定の散らし** | 空きマス 3 割・語の 4 割は縦の軸へ寄せる・主役は三分割の点 |
| `noise` | ブルーノイズ。有機的 | 記憶の断片・粒のような歌詞 | 固まりも穴も出ない |
| `pack` | ぎっしり詰める（螺旋サーチ） | サビの畳みかけ | 大きい語から置く |
| `grid` | モジュラーグリッド。整然 | 対句・列挙 | 主役は大きい枠。左上基準で揃う |
| `burst` | 中心の主役から外へ放射 | サビ頭・叫び | 字は外向き（逆さにしない） |
| `rings` | 同心リング。内ほど小さく、輪ごとに向きが交互 | 回る・時計 | 内の輪は小さい語 |
| `cascade` | 1 つの傾き（−10°）で段ごとに小さく薄く | 余韻・残り香 | 控えめな見た目 |
| `silhouette` | 形に沿って並べる（`--shape heart\|circle\|star`） | 愛・光・タイトル | **字を 1 つずつ（`--text … --unit char`）で使う** |

入力は `--words "!主役|普通|,助詞"`（語単位）か、`--text "…" --unit char --size 80`（字単位）。

```
python3 <SKILL_DIR>/scripts/glyph_layout.py scatter --words "!夜空|を|駆ける|流れ星|,の|ように" \
  --seed 3 --assemble outward --at 12.4 --ops
python3 <SKILL_DIR>/scripts/glyph_layout.py silhouette --shape heart --unit char \
  --text "君を思う気持ちが溢れて止まらない夜空の下で" --size 78 --font serif --ops
```

## 2. センスの規則（道具が守る。変えるときも守る）

- **大きさは 3 段まで・主役は 1 つ**（段ごとに同じ字高）。調子は `--tone calm`（1 : 0.67 : 0.44）か `bold`（1 : 0.38 : 0.15）
- **回転は集合から**（0° 6 割・±90° 2 割・±8° 2 割）。**主役と小さい語（60px 未満）は回さない**。斜めは 1 つの角度に統一（`--rot dominant:-12`）
- **すき間は 16px 以上**（接するか、十分離すか。0 < すき間 < 12px の近接は作らない）。外周に 6〜8% の余白
- **置けない語は黙って捨てない**: 収まらなければ字を 0.92 倍にして再試行し、それでも置けなければ `failed` と `check.issues` に出る。
  **`check.pass` が false のまま使わない**（字を減らすか `--hero-size` を下げる）
- 3×3 に分けて空きマスを 2〜4 個残す（`check.info.empty_cells`）

## 3. 動かす: 散 → 集（`--assemble`）

**最終位置を正本にして、開始位置をそこから逆算する**（seek しても同じ座標）。

| `--assemble` | 見た目 | 使いどころ |
|---|---|---|
| `outward` | 中心から外へ飛んだ語が戻る | サビ頭 |
| `inplace` | その場で回って縮んで現れる（**読みやすさ最優先**） | 迷ったらこれ |
| `flow` | 左から全員が流れ込む | カスケード・列挙 |
| `random` | seed の位置から | 背景の語だけ |

- 主役は**動く前に 0.3 秒止まる**。語の出は読み順で、**全体 0.9 秒以内**（`--step` で上書き）
- 動いている間は不透明度を落とし、着地で戻す。**回転は最後の 30% で 0° へ収束**
- 開始のサイズは 1.3 倍から（引き寄せる）か 0.6 倍から（湧く）。**混ぜない**

## 4. 使い分けの目安

- 静かな節: `scatter` か `cascade`、`--tone calm`、`inplace`
- サビ: `pack` か `burst`、`--tone bold`、`outward`
- 形で意味を伝える（愛・光）: `silhouette` + 字単位。**語単位だと形が崩れる**

## 5. 確かめたこと・限界

- **確かめた**: 8 配置 × 8 seed の 64 通りで重なり・近接・余白・主役 1 つ・決定論が通ること、描画して見た目を確認
  （散らし・ブルーノイズ・詰め・放射・リング・ハート・円は期待どおり）
- **限界**:
  - **星は字が少ないと星に見えない**（21 字では五角形に近い）。30 字以上か、ハート・円を使う
  - `cascade` は全体に控えめ（段ごとに縮むため）。目立たせたいときは `scatter` か `pack`
  - `grid` は左上に寄りやすい（行は上から下へ散らしてあるが、語が少ないと偏る）
  - 動く映像で見たわけではない。`--assemble` の値は設計値で、**書き出して着地の 1 コマ**を見て直す
  - 箱は全角 = 正方形で近似する（実際の字面より少し余白が広く見える）
