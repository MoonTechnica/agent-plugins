# 文字のモーション（歌詞・字幕・タイトル・キネティックタイポ）

**文字は上に置く飾りではなく、演技である。** 何が書いてあるか・どんな気持ちか・音のどこで鳴るかを読んで、
その意味と拍に合った動きを選ぶ。効果の数ではなく、選び方で質が決まる。

| 知りたいこと | 正本 |
|---|---|
| MV の歌詞で**何をどれだけ**やるか（見せる行 / 読ませる行・ジャンプ率・前後関係・配分・避けること） | `genre-playbook` の references/mv-lyrics.md |
| MV の歌詞を **HTML / CSS / GSAP でどう書くか**（書体・縦組み・叩きつけ・人物との前後・CSS 3D） | [lyric-motion.md](lyric-motion.md) |
| 出入りの秒・1 枚の量・`lyric_check.py`・拍（`beat_grid.py`） | SKILL.md §10 |
| **動きの選び方と、動きの語彙をここで何で作るか**（このファイル） | ここ |

歌詞だけでなく、字幕・テロップ・タイトル・説明動画の文字にも使う。

## 1. 動かす前に読む

文字の塊（歌詞の行・字幕の 1 枚・タイトル）ごとに、次を決めてから動きを選ぶ。

| 読むこと | どこから |
|---|---|
| 何を言っているか・**曲や話の中でどれだけ大事か**（ふつうの行 / キメの語 / サビ / 山場） | 脚本・歌詞・曲の地図 |
| 気持ち（明るい・切ない・怒り・不穏・静か・高揚） | 同上 |
| 音（拍・小節頭・歌い出し・フレーズの切れ目・区間・強い打点・無音） | 曲の地図（`write_music_map`）、`beat_grid.py` |
| 絵（人物の位置と顔・色・構図・動き） | `get_asset_frames` / 層の配置 |
| 読む時間（何秒で読めるか） | SKILL.md §10 の量の目安 |
| 既にある見た目（このシーン・前後のシーンの書体と動き） | `get_composition_bundle` |

### 1.1 動きの強さ（0〜5）

| 段 | 中身 | 使いどころ |
|---|---|---|
| 0 | 止まっている | 情報・注記 |
| 1 | ほとんど動かない（静かなフェード） | ドキュメンタリーの字幕 |
| 2 | ほどほど（スライド・ポップ） | YouTube のテロップ・説明動画 |
| 3 | 表情がある（1 字ずつ・揺れ・意味の動き） | MV の歌詞 |
| 4 | 劇的（叩きつけ・ズーム・崩し） | サビ・山場 |
| 5 | 実験的（グリッチ・文字の壁・変形の連続） | ボカロ MV の見せ場 |

**4〜5 を続けない。** 静かな区間と強い区間の差が効く。いちばん大事な語にいちばん強い動きを当て、
脇の文字（補足・背景の文字・飾り）は一段ずつ弱くする。同じ歌詞が繰り返されたら、同じ効果を繰り返さず
**少しずつ変える**（大きさ・向き・崩し方を 1 つだけ変える）。

## 2. 時刻は音から取る

- 拍・小節頭・区間は**計測をそのまま使う**（`beat_grid.py grid / fit / nearest`）。一定のテンポを仮定しない
  （1 拍 = `60 / BPM` 秒、8 分は半分、16 分は 4 分の 1 は目安の計算だけに使う）
- 歌詞の出入りは**歌われている時刻**（曲の地図の行の時刻、`lyric_align.py` の対応付け）。`lyric_check.py` で確かめる
- **語やモーラ単位の時刻が測れていないときは、作らない。** 行（フレーズ）単位で動かし、「行単位で合わせた」と報告する。
  推定した時刻を「歌に合わせた」と言わない
- 強い動き（着地・ズーム・崩し）は強い打点か、狙った裏拍に置く。**着地は打点の 1〜2 コマ前**（lyric-motion.md §3）
- 打点の前に溜め（予備動作）、後に余韻（止まる・少し流れる）。全部を拍の格子に揃えない（歌い回しが優先）
- ゆっくりした区間は行単位、リズムの立つ区間・言葉の立つ区間は 1 字単位

## 3. 動きの語彙と、ここでの作り方

名前は動きの型。**作り方は上から順に試す**: CSS / GSAP（`hyperframes-animation` の rules）→ 効果の棚（[effects.md](effects.md)）→
SVG → 3D（プリビズの文字の板・カード → three.js の直書き → Blender）。いちばん簡単に狙いの質が出るものを選ぶ。

| 型 | 中身 | ここでの作り方 |
|---|---|---|
| **出入り** フェード / スライド / ポップ / ズーム / バウンス / 弾む戻り / 落ちる / 飛び込む / ブラー / 回転 | 不透明度・位置・大きさ・ぼけ・回転の出入り | GSAP の `from` / `to`。ポップは rules/spring-pop-entrance.md、続けて差し込むのは rules/waterfall-entry.md、速い入りのぶれは rules/motion-blur-streak.md |
| ワイプ / マスクで現れる | 線や形で隠しながら出す | `clip-path` の tween（`inset()` / `polygon()`）。斜めのワイプは effects.md の `wipe` |
| **1 字・1 語ずつ** タイプライター / 1 字ずつフェード・ポップ / 散って集まる / ランダムな字から解ける / 字間が開く・詰まる / 1 字ずつ回る | 単位ごとに時間差 | **1 字ずつ `<span>` を HTML に直書き**（lyric-motion.md §2）して stagger。打ち間違い・消して打つは rules/discrete-text-sequence.md、ランダムな字から解けるのは rules/hacker-flip-3d.md、散って集まるのは rules/depth-scatter-assemble.md。字間は `letter-spacing` を動かさず各字の `x` で |
| **強調** 叩きつけ / パンチズーム / 揺れ / 閃き / 脈打つ / 拍で弾む / 潰れて伸びる / 一瞬で差し替え | 打点で強く当てる | rules/kinetic-beat-slam.md（叩きつけ・拍の連打）。揺れは数コマだけ（時刻の式で）。閃きは §6 の光の点滅の決まりの内側で。差し替えは `autoAlpha` を同じ時刻で入れ替え |
| **空間・3D** 回る・めくれる / 奥へ飛ぶ / 回り込む / 文字のトンネル / 渦 / 曲線に沿う / 厚みのある文字 | 奥行きの中で動く | 層が少なく光が要らない → CSS 3D（lyric-motion.md §5.1、rules/3d-camera-flight.md、rules/3d-text-depth-layers.md）。人物やカメラワークと一緒 → プリビズの**文字の板 / 2D のカード**（previz の references/look.md §2）と曲線の経路（camera-moves.md §8.9）。厚み・面取り・光 → Blender（[blender-by-hand.md](blender-by-hand.md) §7 の `--text-depth`）。字が奥行きへ散る・トンネル → [three-by-hand.md](three-by-hand.md) |
| **変形** 波打つ / 波紋 / 溶ける / 変身 / 伸び縮み / ねじれ / 曲がる / 砕ける / 粒になって消える / ゴムのように | 字の形が変わる | 波・ねじれは 1 字ずつの `y` / `rotation` を時刻の式で（rules/sine-wave-loop.md の決定論の書き方）。字から字へは SVG のパスで（lyric-motion.md §6）。砕ける・粒になる・溶ける → Blender の物理と粒子（blender-by-hand.md）か three.js。CSS の `filter` で溶けたふりをしない |
| **グリッチ・デジタル** 色ずれ / スライス / ちらつき / 走査線 / ランダムな字から解ける | デジタルの崩れ | rules/chromatic-glitch.md（時刻を量子化したハッシュで決定論）、effects.md の `rgbShift` / `vhs`。**ごく控えめに・数コマで戻す** |
| **歌詞・MV** 歌に同期 / カラオケの塗り / 拍で組み替え / モーラ単位 / 一気に広がる / 文字の壁 / 重ねて貼る / 縦組みで動く / 手書きで描く / 速い差し替え / 人物に付いて動く / 文字で場面転換 | 歌と一緒に演じる | 縦組み・前後関係・叩きつけは lyric-motion.md。塗りは rules/gradient-text-sweep.md（`background-clip: text`）。書き順は rules/svg-path-draw.md。語に合わせて光らせるのは rules/asr-keyword-glow.md（時刻は測った語の時刻だけ）。文字で場面転換は文字の形の `clip-path` / マスクで次の絵を見せる |
| **カメラと構図** 文字の上をパン / 文字から文字へ寄る / 広い画面を旅する / 奥行きの層 / 組み替え / 分割画面 / 文字の形で絵を見せる | 文字の配置そのものをカメラで見せる | 仮想カメラは rules/viewport-change.md・rules/multi-phase-camera.md・rules/coordinate-target-zoom.md。奥行きの層は CSS 3D か 2D のカード（プリビズのカメラ）。文字の中に絵は `background-clip: text`（lyric-motion.md §4） |
| **線・質感・光** 輪郭を描く / 塗りが満ちる / ネオンのちらつき / 光が脈打つ / インクがにじむ / 筆で現れる / 粒が集まって字に | 字の描かれ方と光 | 輪郭は rules/svg-path-draw.md、背後の光は rules/ambient-glow-bloom.md、粒が集まるのは rules/particle-burst.md の逆再生か Blender。画面全体のにじみは Blender の仕上げ（グロー） |
| **物理** 重力で落ちる / ぶつかる / 弾む / 振り子 / ばね / 布のように / 爆発 / 引き寄せられて組み上がる | それらしい物理 | 弾む・ばねは GSAP の ease（`back` / `elastic`）か rules/press-release-spring.md の式。**本物の衝突・落下・布・爆発は Blender の剛体・布・粒子**（blender-by-hand.md。焼いてから書き出す） |
| **字幕・テロップ** 話している語を光らせる / 語を大きく / 下から送る / 帯と一緒に出す / 名前の帯 / マーカー / 下線を引く / 吹き出し | 読ませるための動き | rules/asr-keyword-glow.md、rules/css-marker-patterns.md（マーカー・下線）、rules/vertical-spring-ticker.md（送り）。強さは 1〜2 に抑える |
| **実験的** 可変フォントの軸を動かす / 語から語へ変身 / 文字の中に文字 / 自己相似 / 文字が物になる / 錯視 / 生成的な配置 | 見せ場の作字 | 可変フォントは `font-variation-settings` を動かすと描き直しで重いので、数段の静的な太さを差し替える。語の変身・文字が物になるは SVG のパスか Blender。生成的な配置は種を決めた式で。1 曲に 1〜2 回 |

**作れないものは似た動きで代え、何を代えたかを報告する**（例: 布のような字 → 波打つ 1 字ずつの動き）。

## 4. 選び方

### 4.1 気持ち → 動き（出発点。決まりではない）

| 気持ち | 合う動き |
|---|---|
| 明るい | 弾む・ポップ・1 字ずつのポップ |
| 高揚 | パンチズーム・一気に広がる・拍で弾む |
| 怒り | 叩きつけ・短い揺れ・スライス |
| 悲しい | ゆっくりのフェード・落ちる・ぼけ・溶ける |
| 恐れ・不穏 | ちらつき・歪み・コマの飛び |
| 混乱 | ランダムな字から解ける・変身・ねじれ |
| 懐かしさ | 柔らかいフェード・字間が開く・ぼけ |
| 謎 | マスクで現れる・ランダムな字から解ける |
| 恋 | 静かなフェード・波・ゆっくりの拡大 |
| 混沌 | 散る・グリッチ・砕ける・文字の壁 |
| 勝利 | 大きくなる・奥から飛んでくる・一気に広がる |
| 孤独 | 文字を少なく・ゆっくり・余白 |

### 4.2 意味で動かす

語の意味を動きにする（「落ちる」→ 重力で落ちる、「壊れる」→ 砕ける、「消える」→ 粒になって消える、
「震える」→ 小さく揺れる、「溶ける」→ 溶ける、「走る」→ 横へ飛ぶ、「爆発」→ 一気に広がる、「回る」→ 渦、
「歪む」→ 歪み、「繰り返す」→ 文字の中に文字、「叫ぶ」→ 叩きつけ + 拡大 + 揺れ、「静寂」→ 止めて余白）。
**全部の行を直訳しない。** 比喩・逆（「笑う」を止めて見せる）・前の行との対比で選ぶ。

### 4.3 曲の流れで変える（既定の型。決まりではない）

| 区間 | 文字 |
|---|---|
| イントロ | 控えめ（0〜1） |
| A メロ | 読めて、拍に乗る（2〜3） |
| B メロ | 緊張を上げる（3。字が大きく・密に） |
| サビ | 表情のある組み（4。カメラ・重ね・大きな字） |
| 落ちサビ・ブリッジ | 違う見た目に切り替える（静か・別の書体の役） |
| ラストサビ | 1 回目のサビの動機を育てた形（同じ型の発展） |
| アウトロ | 静かに収める |

## 5. 組み立て

- **動きは部品の組み合わせ**: 変形（位置 X/Y/Z・大きさ・回転・傾き・原点・透視）、見え方（不透明度・色・線・ぼけ・光・影・
  質感・マスク）、変形（波・歪み・曲げ・変身・砕け）を、単位（塊・行・語・字・**モーラ / 歌の時刻の単位**・字の欠片）と
  時間（遅れ・長さ・ease・stagger・ばね・行き過ぎ・拍・歌）で組む。新しい効果を作る前に、部品の組み合わせで出せないか考える
- **日本語は空白で語が分かれない。** 語の単位は歌詞の文節・曲の地図の語で切る。1 字ずつは書記素（合字・濁点の付いた
  かな・絵文字を割らない）で切り、拗音（「きゃ」）は 1 モーラとしてまとめる
- 1 つの要素に変形を重ねるときは**順番が結果を変える**（回してから動かす ≠ 動かしてから回す）。
  役割ごとに入れ子の要素に分ける（外側 = 位置、内側 = 回転と大きさ、さらに内側 = 色と光）
- 例: サビ頭の強い組み = 1 字ずつの stagger → 大きさの行き過ぎ → 色ずれ（2 コマ）→ 短い揺れ → 砕けて消える（Blender / three.js）

## 6. 読みやすさと光の点滅

- 背景との差（明るさの差・縁取り・下に敷く帯）を保つ。読ませる行は動かしすぎない。読ませる時間を取る（SKILL.md §10）
- 日本語の字形は、狙った崩しでない限り読める形に保つ。字の欠け・はみ出し・枠の外を書き出した 1 コマで見る
- 目と口・大事な被写体に重ねない。セーフゾーン（`hyperframes-studio`）を守る。字形の揃った日本語の書体を使う（lyric-motion.md §1）
- **光の点滅**: 画面の広い範囲の明るさが **1 秒に 3 回を超えて**明滅しない（WCAG 2.3.1）。赤い閃きは特に避ける。
  強い打点は、明滅ではなく**位置の短い衝撃・色の小さなずれ・歪み**で出す。閃き（白飛び）は 1 回で、続けない
- 揺れ続けるカメラ・続くバウンス・効果の重ねすぎ・理由の無い転換・強すぎるぶれは避ける

## 7. 決定性と重さ

- 状態は**時刻（またはコマ番号）だけ**から決める。`Math.random()` / `Date.now()` / `requestAnimationFrame` を使わない。
  ランダムに見せる動き（散る位置・ちらつき・グリッチ）は**種を決めた式か、時刻を量子化したハッシュ**（rules/chromatic-glitch.md）
- 1 コマだけを単独で描いても、頭から順に描いても同じ絵になること（書き出しは並列のワーカーが飛び飛びの時刻を描く）
- 文字の分割・寸法の計測は組むときに 1 回だけ（`document.fonts.ready` の後）。毎コマ測り直さない。`font-size` /
  `letter-spacing` を動かさず `scale` / `x` で動かす（描き直しが重い）
- 粒は少なく（数百まで）。重い粒・物理は Blender で焼いて透過の動画にする

## 8. 計画を書いてから作る

新しく文字の連なりを作るときは、作る前に**計画の表**を書く（会話の報告にもそのまま出す）。

| 時刻 | 文字 | 動き | 単位 | 気持ち・役 | 強さ | 時刻の根拠 | 置き場所 | 作り方 |
|---|---|---|---|---|---|---|---|---|
| 00:12.00 | 壊れて | 1 字ずつ + グリッチ | 字 | 緊張 | 3 | 曲の地図の行 | 右上・縦 | GSAP stagger + chromatic-glitch |
| 00:12.80 | しまえ | パンチズーム + 叩きつけ | 塊 | 衝撃 | 4 | 小節頭の打点 | 中央・巨大 | kinetic-beat-slam |
| 00:13.40 | — | 砕けて消える | 欠片 | 解放 | 4 | 次の拍 | 同上 | Blender の剛体 → 透過の WebM |

- **時刻の根拠**を必ず書く（曲の地図の行 / 拍の格子 / 測った語の時刻 / 目分量）。目分量は目分量と書く
- 同じ型を何度も使うなら、名前と値を決めて使い回す（例: `chorus_glitch_impact` = 1 字の遅れ 0.035 秒・大きさ 1.8 → 1・
  行き過ぎ 0.15・色ずれ 2 コマ・`back.out`）。値の単位（秒・px・画面幅に対する比）を書く
- 計画は計画。実際の時刻は音と曲の地図に合わせて書く。**計画で止まらず、作って確かめる**

## 9. 手順

1. **読む**（§1）: 目的・縦横比・文字・音・既にある見た目・誰が見るか
2. **分ける**: 歌は行と歌の時刻、字幕は話した単位、タイトルは強調する語で
3. **決める**（§1.1・§4）: 気持ち・大事さ・強さ・構図の役・時刻の制約。隣り合う塊で見た目に差を付ける
4. **計画を書く**（§8）
5. **作る**（§3）: 書体・置き場所・動き・出入り・同期・効果・カメラ。既にある部品と型を使う
6. **確かめる**: `lyric_check.py`・`npx hyperframes check --at-transitions`（SKILL.md §1 の 6）。書き出したら
   `get_asset_frames` で代表のコマ（打点の直前と直後・サビ頭・文字が最も多いコマ）を見る。見るのは時刻・読めるか・
   動きの滑らかさ・強弱の順・文字同士や人物との衝突・拍との合い・描画の欠け
7. **直す**: 長さ・ease・stagger・大きさ・効果の強さ・構図・同期

## 10. 決まり

1. 効果があるから使う、をしない
2. 強さは気持ちと話の大事さに合わせる
3. 狙いが出るいちばん簡単な動きを使う
4. ボカロ MV では文字が主役の絵。字幕扱いしない
5. 拍と歌に合わせる（でたらめな時刻にしない）
6. 型は変えていく。ただし 1 本の見た目の筋は保つ
7. 効果だけでなく、構図・組み・余白・コントラストで見せる
8. **歌詞・句読点・意味を変えない**（許されたときだけ）
9. 推定の時刻を、測った同期と言わない
10. 書き出して見る（見られる道具があるなら必ず）
11. 作れない動きは似た動きで代え、何を代えたかを言う
12. テンプレートの既定値の動きで終わらせない

意図 → 技 → 値の早見・読める時間・曲全体の配分・3D の文字は
`genre-playbook` の references/kinetic-typography.md（3D の実装は previz の references/kinetic-typography-3d.md）。
円周を回る文字・輪郭だけの巨大な字・輪と目盛りは [kinetic-2d-recipes.md](kinetic-2d-recipes.md)。
歌詞を語に割って四隅・縦組みに面付けする手順は [lyric-composition.md](lyric-composition.md)。
文字を散らす・幾何学的に並べる（散らし・放射・格子・形・散→集の動き）は [glyph-layout.md](glyph-layout.md)。
