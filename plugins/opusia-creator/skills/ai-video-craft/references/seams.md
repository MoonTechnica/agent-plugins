## 1. 継ぎ目を 3 つにラベルする

| ラベル | 何か | 作り方 |
|---|---|---|
| **カット**（既定） | 見ている側が切り替わりを期待している所 | 別々に生成してよい（1 パス multi-shot の中のカット点も含む）。match cut もここ（§2） |
| **チェーン** | カメラが途切れずに続いて見えてほしい所 | 前のカットの最終フレームを次の先頭フレームにする（§4） |
| **トランジション** | ホイップ・ディゾルブ・ワイプ・ズーム・光の転換 | **編集（タイムライン）で作る**（§5）。生成は端のブレまで |

## 2. match cut —— 生成で繋がず、先頭フレームを画像で作る

**first/last frame は「1 本の連続した動き」を作る機能で、カットを作る機能ではない。** 別の空間の 2 枚を
先頭と末尾に入れると、モデルは間を補間して**モーフ**（溶けて変形する）を作る。

match cut（形・動き・色の一致で別の場所・時間へ切る）の作り方:

1. **A（前のカット）の尻の構図を決める**: 揃える要素を 1〜2 個（形の画面上の位置と大きさ、または動きの向き）。
   形は画面中央に置くと一致が読まれやすい（`film-grammar` の cut-to-cut.md §5）。
2. **B（次のカット）の先頭フレームを、B の場所・光で画像生成する**。A の尻のフレームを**構図の参照**として渡し、
   本文に「同じ位置・同じ大きさに〇〇がある」と書く。**A のフレームをそのまま B の先頭に使わない**
   （A の空間と光が B に持ち込まれる）。
3. B をその先頭フレームから i2v で生成する。
4. **編集でハードカット**する。一致が弱ければ短いディゾルブ（6〜12 コマ）で補う。

今敏型の「時代・場所を跨ぐ match cut」も同じ手順。A の尻の動作（振り向く・手を伸ばす）を B の頭で
同じ向きから始めさせると、動きの match cut になる。

**意図したモーフ**（変身・場面転換の見せ場）だけは first/last に別の内容を入れてよい。そのときは
**構図（角度・被写体の大きさ・位置）と光を揃え**、何が変わり何が固定かを本文に書く。

## 3. 1 パス multi-shot で繋ぎを守る

1 回の生成で複数カットを作ると、カット点では空間をかなり守るが完璧ではない。PersonaShot ベンチマーク
（arXiv 2608.16717）では、最良の Seedance でも **180 度の遵守 0.818・視線の一致 0.813**、ショットをまたぐと
**人物の同一性がショット単体より 25.6% 落ちる**。**書かなかった軸と方向はモデルの任意になる。**

| 規則 | 書き方の例 |
|---|---|
| **全ショットの先頭に「サイズ + 角度 + 左右」** | `Shot 1: wide two-shot, MAYA on the left of frame facing right, KEN on the right facing left.` |
| **移動方向を毎ショット同じ語で** | `runs left to right` を全ショットで繰り返す。`toward camera` を混ぜない |
| **視線の向き** | `looking off-screen right` と書き、次のショットの対象を `seen from the left side` で受ける |
| **光の向きを毎ショット言い直す** | `key light from frame left`。「前と同じ光」は通じない（SKILL.md §6 と同じ理屈） |
| **カメラの質感を 1 語に揃える** | `cinematic handheld` を全ショットに（Kling 公式例の書き方） |
| **カット点を明示する** | `Shot N` / `cut to` を書く。書かないとモデルが任意に切るか、1 テイクに潰す |
| **隣のショットはサイズ 1 段以上か角度 30 度以上変える** | 変えられないならカットせず 1 テイクにする |
| **切り返しの両者は同じサイズ語・同じレンズ語** | `50mm, medium close-up` を左右で揃える（`genre-playbook` の camera-by-genre.md §1） |

人物は毎ショット**同じラベル**で呼ぶ（途中で呼び方を変えると、モデルの推測が揺れる）。

## 4. チェーン —— 動きを途切れさせずに続ける

前のカットの**最終フレームを抜き出し**（`get_asset_frames(times_s=[-0.05], as_asset=true, canvas_id)`。手元に落として ffmpeg で抜かない）、
次のカットの `first_frame` に渡す。

| 守ること | 理由 |
|---|---|
| **最終フレーム 1 枚では動きの方向と速度は運べない** | 構図・見た目・光は運べるが勢いは運べない。継ぎ目の直後に一瞬の減速や逆走が出る。本文に**前のカットと同じ動きの方向と速さ**を書く。継ぎ目直後の数コマを編集で捨てる前提で尺に余裕を持たせる |
| **抜き出すフレームは崩れていないか目で見る** | 生成の末尾は減速・歪みが出やすい（SKILL.md §8 の 6）。崩れていれば数コマ前を使う |
| **チェーンは 2 段まで** | 継ぎ足すほどズレが累積する（SKILL.md §1）。3 段目からはシーンの絵コンテ（板・コマ）から撮り直す |
| **継ぎ目の色ずれは編集の色補正で吸収する** | 生成をやり直さない |

同じ空間の 2 つの構図を**カメラが移動して繋ぐ**（reveal・回り込み・寄り切り）なら、先頭と末尾の両方を渡す
（`last_frame` スロット。受けるかは `get_model_capabilities` で確かめる。**FLUX 3（無印）・Vidu Q4・Grok Imagine lite の i2v は末尾を取らない**）。
2 枚は同じ人物・同じ光で作り、間の動きはカメラ語 1 つで書く。

前のクリップの続きを動画ごと継ぎ足す `video_extend`（LTX 2.3 Extend）もあるが、**別のモデルが続きを描く**ので
絵柄が揃うかは確かめてから使う。

## 5. トランジションは編集で作る

| 転換 | 既定 | 生成に頼むこと |
|---|---|---|
| ホイップパン | **編集**（ブレの中で切る） | A の尻 `camera whips right into motion blur`、B の頭 `camera settles from a whip, entering from the left`（**同じ向き**）。**顔の無いカット**の端にだけ |
| クラッシュズーム / ズームで抜ける | 編集（同じ軸の寄りを別カットで用意し、拡大で繋ぐ） | 同じ軸の寄りのカット |
| ディゾルブ / フェード | 編集 | — |
| ワイプ・プッシュ・スライド | 編集 | — |
| ライトリーク・フラッシュ | 編集 | **生成しない**（画面内の光源として描かれ、次のカットと光の向きが食い違う） |
| match cut | 編集（ハードカット） | 両端の構図を画像で揃える（§2） |
| 動作の繋ぎ（cut on action） | 編集で動作の途中で切る | 動作の途中で終わる A と、続きから始まる B |

- **強いカメラの動きは顔の崩れの主因**。ホイップやクラッシュズームを人物の顔のカットで生成させない。
- **汎用の短いフェードを既定にしない**（スライドショーに見える）。ディゾルブは時間の経過・心象の意味があるときだけ。
- 個別に生成したカットの不一致（動き・光・角度）は、**後から付けたディゾルブでは隠せない**。繋ぎは生成の前に設計する。
- 使える転換は `compositor` §9（`dissolve` / `wipe` / `mix` / `whiteFlash` / `zoomIn` / `motion` / `rgbShift`）。
  ホイップの方向ブラーやライトリークは在庫に無いので、ホイップは生成した端のブレの中で切るか、`motion`（ブラーしながら画面が左へ流れる。**向きは固定**なので、
  生成した端のブレも同じ向き = カメラが右へ振れる向きに揃える）で代用し、
  在庫に無い効果を前提に設計しない。

## 6. 軸・方向・カメラの動きを確実に揃えるならプリビズ

3D のプリビズで仮想カメラを動かしたドラフトを参照動画に渡すと、複数カットのカメラの動き・立ち位置・
軸が揃う。Google の ANCESTRA は同じ方式（3D の仮想カメラで撮ったドラフトの動きを Veo に追わせた）で、
本リポジトリの `previz_asset_id` はこの形そのもの（`cinematographer` §3.2）。**切り返し・画面方向・
軸の越え方を外せないシーンは、プロンプトで頑張るよりプリビズを撮る。**

## 7. 繋ぎが破綻する典型と回避

| 破綻 | 回避 |
|---|---|
| カットの後で動きの向きが逆になる | 方向語を全ショットで揃える（§3）。チェーンなら本文に同じ方向を書く（§4） |
| 動きの速さが合わない | 編集で速度を変えて合わせる。寄り側は遅く（`film-grammar` の cut-to-cut.md §2） |
| 光の向き・時間帯が変わる | 光の句を毎ショット言い直す。**光は言葉で持つ** —— 光の見本の画像を参照に足すと構図ごと引っ張られる（`cinematographer` §0） |
| 切り返しで 2 人が同じ側を向く | 左右と視線を書く。外せないならプリビズ |
| ジャンプカットに見える | サイズ 1 段以上か角度 30 度以上変える。無理ならカットしない |
| 同一シードで繋がると期待する | **シードは継続性の手段ではない**（同じ入力の再現用。公式に根拠が無い） |

**繋ぎの成否は静止画では分からない。** 継ぎ目を挟んで前後 1 秒ずつ動画で見る（方向・速度・光・人物の 4 点）。
