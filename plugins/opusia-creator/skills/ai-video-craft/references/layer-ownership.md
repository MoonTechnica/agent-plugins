# 生成動画の上に重ねるとき：層ごとの持ち分（見た目も音も）を先に決める

生成した動画を一番下に敷き、上にモーショングラフィック（文字・粒子・光・図形・色ずれ）を重ねる
カットで起きる事故の型と、その防ぎ方。**字コンテの時点で決める**。生成のあとに足し算で直すと、
必ず「同じものが二重に見える」。

## 1 何が起きているか

| 症状 | 原因 |
|---|---|
| 光・粒子・グローが二重で濁る | 生成動画の中にモデルが描いた光・粒子と、上の層の光・粒子が**同じ役割**を持っている |
| 文字が読めない・字が二重 | 生成の絵や絵コンテに**文字が焼き込まれている**ところへ、文字の層を重ねた。生成の文字は読めない形になる |
| 文字が被写体の顔・手に被る | 動画の**どこが空いているか**を知らずに文字の置き場を決めた |
| 動きが喧嘩する | 生成のカメラ移動・揺れと、上の層の寄り・揺れ・色ずれが**同じ打点で別々に動く** |
| 上の層が絵に馴染まず浮く | 色・光の向きが生成の画と揃っていない |

どれも**生成と上の層が同じ仕事を取り合っている**のが根。分け合えば起きない。

## 2 責務は字コンテで割る（絵コンテより前）

**カットごと・要素ごとに、持ち主をちょうど 1 つ決める**（字コンテを書く時点。`screenwriter`）。
同じ要素を 2 つの層で作らない。持ち主は 4 つ: **生成 / モーション / タイムライン / 音声トラック**
（モーションとタイムラインの線引きは `compositor` §0）。絵コンテ（`storyboard`）と生成
（`cinematographer`）は、決まった持ち分を**受け取って従う側**で、途中で足し引きしない。

下の表は**既定**。カットごとに理由があれば別の持ち主にしてよい（例: 看板の文字をそのカットの
絵として生成に持たせる）。**禁止ではなく、決めたら 1 か所だけ**。

| 要素 | 既定の持ち主 | 生成に持たせるとき |
|---|---|---|
| 人物・芝居・背景・自然な環境光・（生成が動かすなら）カメラ | 生成 | — |
| 文字（字幕・歌詞・タイトル・数字・ロゴ） | 上の層（読ませる字幕はタイムライン、動く文字はモーション） | 読めない字が出やすい。持たせるなら上の層は**同じ文字を重ねない** |
| 粒子・火花・光の筋・グロー・レンズフレア | モーション | 持たせるなら上の層は同じ光を足さない |
| 色ずれ・グリッチ・走査線・フィルム粒子・図形・帯・集中線・枠 | モーション | 同上 |
| 画面の揺れ（打点の衝撃） | モーション | — |
| カメラの寄り・引き・パン | **どちらか 1 つ** | 生成が動かすなら上は動かさない |
| 声（台詞・ナレーション） | 音声トラック | 口が動く台詞のカットだけ生成。持たせるなら音声トラックに同じ台詞を置かない |
| BGM | 音声トラック | 持たせない |
| 効果音 | 音声トラック | 生成の音を使うなら音声トラックに同じ音を置かない |
| 環境音 | 生成が出すなら生成 | 音声トラックで足すなら生成の音は使わない |

**音の取り合い**も見た目と同じ。生成映像に音が付いて返ってきても、持ち主が音声トラックなら
その映像は**ミュート**で本編に置く。持ち主が生成なら、音声トラックに同種の音を足さない。

迷ったら上の層（モーション / 音声トラック）に寄せる（上の層は作り直せるが、生成は一度作ったら固定する）。

**書き場所（重要）:** 生成に渡るのは `plan_scenes` の `note` / `shot` だけ。**そこには生成の持ち分
しか書かない**。上の層の持ち分は、字コンテの文書（人が読む本文）のカットごとに
`上の層:`・`音:` の行で書き、`note` / `shot` には入れない（入れると動画モデルに届いて描かれる）。

```
C09  4s  [medium shot, handheld follow]
     ユキが人混みを縫って走る。屋台の湯気が横切る。
     上の層: 歌詞「待って」を右下に（拍頭で出す）／火花の粒子／打点で画面を揺らす
     音: 声は音声トラック／環境音は生成（屋台のざわめき）／BGM は音声トラック
```

文字の置き場がある行は、**被写体の反対側を空けた構図**で `shot` / `note` に書く
（例: 「ユキは画面左寄り」）。空きは生成の構図で作る。

## 3 生成用の絵コンテは「生成の持ち分」だけで描く

**動画生成に渡す絵コンテ（グリッド・人物シート・マスター）に、上の層の要素を入れない。**

1. 描くのは、字コンテの `note` / `shot` に書いてある**人物・背景・光・構図**だけ。文字・ロゴ・
   光線・粒子・枠・効果を描かない（動画に焼き込まれて戻り、上の層と二重になる）
2. 文字の置き場は**空きの構図**として描く。文字そのものは描かない
3. 生成のプロンプトも同じ。見えるもの・動き・光だけ書く。文字や効果を書かない
   （否定形「文字を出さない」は効きにくく、逆に呼び込む。書かないのが正しい）。
   画面に文字が出やすい題材（看板・画面・本）は構図から外す（SKILL.md §5）
4. 上の層の粒子・グローの色は、絵の光の色に合わせる（色は絵から取る）
5. 重要な被写体は 90% のアクション安全枠、文字は 80% のタイトル安全枠に入れる

上の層の見た目を人が確認したいときは、**生成用とは別に**、スタイルフレーム（組んで撮ったコマ。
`compositor` の references/style-frames.md）で見せる。生成の入力と同じ絵に混ぜない。

## 4 重ねたあとの確認（必須）

重ねた動画は、**上の層を載せた状態で**次の 3 つのコマを見る（`get_asset_preview` / `snapshot`）:

| コマ | 見ること |
|---|---|
| 打点の直前・直後 | 文字・光が被写体の顔・手を隠していないか。意図して後ろへ回すなら `data-layout-allow-occlusion`（`subject-text-layering.md` §5） |
| 静止後 | 光・粒子が二重になっていないか（生成の光 + 上の光） |
| 動いている途中 | カメラの動きが二重になっていないか |

二重なら、**上の層を削る**（生成は作り直さない）。上の層で解決できないなら、持ち分表に戻って
生成を撮り直す。

## 5 既に生成した動画に効果が焼き込まれているとき

| 状況 | 対処 |
|---|---|
| 焼き込みの光・粒子が出来のよい範囲 | **上の層の同じ効果を外す**。生成のほうを活かす |
| 焼き込みの文字（読めない・誤字） | 生成を撮り直す（文字は直せない）。`video_edit` で消せるかは `get_model_capabilities` で確かめてから |
| 上の層をどうしても残したい | 生成を、効果の無い版で撮り直す。持ち分表を先に直す |

## 6 チェックリスト（字コンテを確定する前・生成の依頼を出す前）

- [ ] 字コンテのカットごとに `上の層:` と `音:` の行がある（文字・光・粒子・揺れ・カメラ・声・BGM・効果音・環境音。各要素の持ち主が 1 つ）
- [ ] `note` / `shot` に上の層の持ち分が入っていない
- [ ] 生成用の絵コンテのコマに文字・効果・枠が入っていない
- [ ] 文字の置き場が生成の構図で空いている
- [ ] 重ねたあと、打点前後・静止後・動く途中の 3 コマを見る段取りがある
