# 文字コンテのカメラを絵コンテに引き継ぐ

対象は主観の揺れ・空撮・FPV・円周移動など、動きのあるカット。
技法の定義は `film-grammar` の references/shot-vocabulary.md §3、選択と設計は同
references/camera-design.md。ここは**静止画シートへの引き継ぎ方**だけを持つ。

## 描く前

1. 最新のカットの `shot` と `note` をセットで読む。サイズだけを抜き出さない。
2. 開始構図・経路・終了構図、注視点、水平保持かバンクか、揺れの原因を確認する。
   不明なら文字コンテ側を補い、画像生成の本文だけに秘密の指示を残さない。
3. 各コマがどの瞬間かを決める。通常は開始、音楽のピークなど既存の例外はその瞬間。
   終了の見せ場を描く場合も、その時点を文字コンテに明記する。

## コマへ反映するもの

| カットの指示 | 絵コンテで反映すること | 間違い |
|---|---|---|
| 一人称の歩行・呼吸 | 人の目の高さ・視線先・自然な姿勢。手が映るならその指定 | Handheld と読んで、外から人物を撮る画へ変える |
| Orbit / Arc | 指定時点の人物の見える面と背景、回り込みで効く前景 | Pan のように同じ位置からの見回しへ変える |
| 向き固定の円周移動 | 位置は円周上、その時点でも指定された世界方向を見る | 自動的に円の中心へ向ける |
| Pan / Tilt | 同じ位置から向きが変わる構図。開始なら開始の向き | 横移動や上昇に読み替え、背景の位置関係を変える |
| Roll / Bank | 指定された瞬間の水平線・垂直線の傾き | 傾きの指定を消す、または全コマをダッチにする |
| Dronie / Rocket / Helix | 指定時点の高度・距離・見下ろし角・被写体の大きさ | 空撮という理由だけで全コマを真俯瞰にする |
| Reveal / 稜線越え | 手前の遮蔽物と、まだ隠れている情報。終了なら開けた全景 | 開始から終了で初めて見える景色を全部出す |
| 低空飛行 / FPV / Dive | 地表・壁との距離、進行方向、速度感が出る前景、視線角 | 遠い上空の風景写真へ置き換える |

**揺れはブレた静止画に変換しない。** 呼吸や歩調を線・残像・分身で描くと、
それが人物や背景の形として動画へ混入する。細かな揺れはカットの文字指示とプリビズが持つ。

## 開始・途中・終了を扱うとき

現在のシートはカット順と構図を動画へ渡すもの。**1カット1コマ、上限6コマを維持**する。
同じカットの始点・終点を、勝手に別の本編カットとして並べない。矢印・軌跡線・番号・
説明文を本編参照の画像に焼き込まない（そのまま映像に出るため）。

経路の確認が必要なら、開始・途中・終了の構図を文字のレビューに併記し、プリビズで
連続した動きを確かめる。人が別途「始点と終点の画像も」と求めた場合はレビュー用素材として
区別し、本編用のシートに無断で混ぜない。

## 描いた後

- コマ数・順序を最新の文字コンテと照合し、代表時点・画角・位置・被写体の見える面を確認。
- 空撮の高度・水平線、POV の視線、reveal の遮蔽が指示と一致するか見る。
- 隣接カットの画面方向・視線・サイズ差も確認。空撮の後だからといって左右を反転しない。
- 画像で分かる不一致は絵コンテで直す。経路・揺れ・回転の時間変化はプリビズ／動画で検証する。
- 文字コンテが修正されたら最新の記述を使い、古いカメラ指示を手書きの生成プロンプトに残さない。
