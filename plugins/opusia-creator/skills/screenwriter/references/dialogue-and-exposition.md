# 台詞の量と、説明の渡し方

「カットが何を持つか」は SKILL.md 本体（§3）、「何秒にするか」は
[cut-timing.md](cut-timing.md)。ここは **何を、どれだけ喋らせるか**。

**この reference は、実際に作った 63 秒のアニメが「セリフが少なすぎて、
どういう場面なのか分からない」と言われたことから起こした。** 原因は書き手の
怠慢ではなく、**このスキル自身が「削れ」としか言っていなかった**ことにある
（[scene-writing.md](scene-writing.md) §11「間を置く」／§17「状況は画でやる」／
§18「本音をそのまま言わせない」）。どれも長尺では正しいが、**3 つ同時に守ると無言劇になる**。

---

## 0. 短い作品ほど、言葉が要る（現場は「逆」を言っている）

**「尺が短いのだから台詞も減らす」は、業界の実務と正反対である。**

| 形式 | 脚本 1 ページが映像になる長さ | 1 分あたりの本文量 |
|---|---|---|
| 劇映画（脚本 2,520 本の実測） | **約 55 秒** | 約 1.09 ページ |
| 会話中心の劇映画（コメディ） | 55 秒より**さらに短い** | 約 1.15 ページ |
| **縦型ショートドラマ** | **30〜40 秒** | **1.5〜2.0 ページ** |

縦型ショートの脚本は、**劇映画の 1.4〜1.8 倍の密度で本文が詰まっている**。
短いのは**尺**であって、**観客が理解に要する情報量ではない**。むしろ短いぶん、
状況を飲み込ませる「間」も引きのショットも無いので、**言葉で立てるしかない**。

プロの脚本家集団（シナリオ作家集団トキワ）が、こう明記している:

> 我々、脚本家がシナリオ学校やシナリオ本などで基礎を学んだ際に口酸っぱくいわれてきたことが
> 『セリフで説明しない。ト書きで説明しろ』ということでした。**しかし、驚くことに縦型ショートの
> 制作現場では『ト書きで説明せず、セリフで説明してください』といわれます。**
> …縦型ショートドラマの視聴者は、おりる駅を確認したりメニュー表からランチを選んだりと
> 『ながら見』しているのですから、**画面から目を離してもストーリーを追える『説明セリフ』が
> 親切でしょう。**

**この判断は生成で作るときさらに強く効く。** 生成映像は微細な表情差が出にくいので、
「表情で察してもらう」経路が実写より細い。**表情に預けた情報は、高い確率で届かない。**

> ⚠️ **これは「ト書きを薄くしろ」ではない。** ここで言っているのは**観客に届く情報**の
> 分担（画に預けるな、言葉で言え）であって、**ト書き（`cuts.note`）はモデルしか読まない**。
> ト書きはむしろ**普通のコンテなら書かないところまで厚く書く**のが正しく、
> 薄いと「箸を使わず手で食べる」映像が返る → **[acting-and-gestures.md](acting-and-gestures.md)**。
> **台詞は下限、ト書きは上限なし** —— 向きが逆なので取り違えない。

### 実際に外した例（このスキルで作った 63 秒の本編）

| 指標 | その作品 | 下限 | 標準 |
|---|---|---|---|
| セリフ量 | **41 字/分** | 150 字/分 | 200〜280 字/分 |
| 総セリフ | 43 字 / 63 秒 | 158 字 | 210〜294 字 |
| 台詞のあるカット | 19 中 **5**（26%） | — | — |
| 無言カットの最長連続 | **5 カット・18 秒** | — | 3 秒まで |

台詞は 6 つしかなく（「……あ。」「あの……いいんですか。」「余ってる。」
「……多く作りすぎて。」「どうぞ。」「……いただきます。」）、**二人の名前も関係も
職業も、作品中で一度も言われていない**。画は丁寧に作られていたが、
**観客が新しく知るべきことが、どこにも言葉で置かれていなかった。**

## 1. 量の下限（勘で決めない）

```
総セリフ文字数の下限 = 尺（秒） × 2.5 字      ← これを割ったら「情報不足」
総セリフ文字数の標準 = 尺（秒） × 3.3〜4.7 字
```

| 尺 | 下限 | 標準 |
|---|---|---|
| 30 秒 | 75 字 | 100〜140 字 |
| 60 秒 | 150 字 | 200〜280 字 |
| 2 分 | 300 字 | 400〜560 字 |
| 3 分 | 450 字 | 600〜840 字 |

| 項目 | 規律 |
|---|---|
| **下限 150 字/分** | 割った稿は「静かな演出」ではなく**情報不足**。書き足す |
| **標準 200〜280 字/分** | ここを狙う |
| **上限 300 字/分** | 発話速度の限界（[cut-timing.md](cut-timing.md) の 1 秒 ≒ 5 字は**上限であって目標ではない**） |
| **1 発話 30 字以内** | 字幕は 2 行 × 13〜16 全角字が上限（Netflix の日本語字幕規程は **7 字/秒**）。超えるなら発話を割る |
| **発話回数 1 分あたり 20〜24 回**（下限 12 回） | 30 秒のシーンなら 10〜12 往復。大きく割るなら**理由を書く** |

**「台詞を減らして尺を持たせる」をやらない。** 尺は**カットの数と画**で持たせる。

## 2. 「謎」と「混乱」は別物（今回落ちたのはこちら）

| | **謎**（設計されている） | **混乱**（ただの事故） |
|---|---|---|
| 作り手 | 何が起きているか分かっていて、手がかりを 1 つずつ渡している | 渡し忘れている（または決めていない） |
| 観客 | 「まだ知らされていない」と自覚し、**知りたくなる** | 「置いていかれた」と感じ、**怒って離れる** |

ロバート・マッキーが withhold してよいと言っているのは
**"except that which is absolutely necessary for comprehension"** ——
**理解に絶対必要な情報は、最初から伏せてよいものの外にある。**

| 観客が理解に必要とするもの | 伏せてよいか |
|---|---|
| **誰か**（名前・関係・立場） | ❌ 早く渡す |
| **どこか**（場所） | ❌ 早く渡す |
| **いつか**（時間・時系列） | ❌ 早く渡す |
| **何を望んでいるか / 何が邪魔か** | ❌ 早く渡す |
| なぜそう望むのか（動機の深い理由） | ✅ 伏せてよい |
| この先どうなるか | ✅ 伏せる（それが引き） |
| 隠している秘密・正体 | ✅ 伏せる（それが山） |

**上 4 つを伏せたまま進むのは演出ではなく、事故である。**

## 3. 冒頭で 4 点を立て終える

**冒頭 20 秒以内**（30 秒尺なら **10 秒以内**）に、
**誰が・どこで・何を望み・何が邪魔しているか**を全部立て終える。

- **0〜3 秒は画で立てる**（まだ音が出ていない視聴環境がある）
- **3 秒以降はセリフ ＋ 字幕が主経路**

### 1 行目の型（関係と状況を同時に立てる）

**1 行に「関係・場所・時間・対立」のうち 2 つ以上**を載せる。

| 型 | 例 | 渡しているもの |
|---|---|---|
| **呼称 ＋ 要求** | 「**兄さん**、その金、どこで拾ったの」 | 関係／対象／疑い |
| **呼称 ＋ 時制** | 「**課長**、例の件、**もう 3 回目**ですよ」 | 上下関係／反復／不満 |
| **場所の名指し ＋ 禁止** | 「**この教室**に、あんたが入っていい理由は無い」 | 場所／部外者／排除 |
| **固有名詞 ＋ 過去** | 「**ユキ**が死んだの、**去年の今日**だよ」 | 人物／出来事／時間 |

これは説明台詞にならない。**言う理由と感情があるから**である（§5 の技法 1）。

## 4. 呼称で人物を特定する（いちばん効く即効性のある規律）

**人物が初登場してから 2 発話以内に、呼ぶ・名乗る・肩書きで呼ばれるのいずれかを入れる。**

- 「お兄ちゃん」「社長」「先生」「〇〇くん」—— **関係は呼称で立つ**（説明台詞は要らない）
- **縦型・短尺は、長編より名前を多く呼ばせてよい領域である**
- 場所と時刻は**テロップで出してもよい**。ミュートでも読める唯一の経路

> ⚠️ `genre-playbook` の references/short-drama.md §2 は「関係を台詞で説明しない。
> **呼び方で示す**」と言っている。**呼び方で示すには、呼ばせなければならない。**
> 一度も呼ばないのは「示した」ことにならない。

---

## 5. 説明の渡し方（技法を名前で呼ぶ）

**マッキーの 2 原則**:

1. **説明は第一に対立を前へ進めること、第二に情報を伝えること**（順序を逆にしない）
2. **withhold してよいのは「理解に絶対必要なもの」以外**（§2）

| # | 技法 | やり方 |
|---|---|---|
| 1 | **対立の中に置く**（ammunition） | 情報を「相手を打ち負かす材料」として言わせる。「あんた、3 年前に同じこと言って店を潰したよね」 |
| 2 | **登場人物に訊かせる** | その場にいる人物が**自然に訊くはずの質問**を訊かせる |
| 3 | **無知な人物を置く** | 新入り・部外者・子どもに説明する |
| 4 | **説明が職務の人物** | 教師・医者・刑事・受付。説明が職業的に自然な役 |
| 5 | **呼称・固有名詞** | §4 |
| 6 | **態度を乗せる** | 同じ情報を「呆れながら」「誇らしげに」言わせる。情報 ＋ 人物造形が同時に出る |
| 7 | **語順で感情にする** | 「うまいんだな、これが」（感情）／「これが、うまいんだな」（理屈）。**1 行の台詞にも構成がある** |
| 8 | **受け手の顔を撮る** | 説明する人ではなく**聞いている人**を映す。情報が「人物についての証拠」に変わる |
| 9 | **知識の差を作る** | 観客が知っていて人物が知らない状態にすると、同じ情報が緊張になる |
| 10 | **小道具・美術・衣装** | 言葉と同じ強さで伝わる。**ただし単独で使わない**（§0） |
| 11 | **劇中メディア** | 手紙・LINE・ニュース・館内放送 |
| 12 | **テロップ・タイトルカード** | 場所・時刻・肩書き。**縦型では最も確実に届く** |
| 13 | **ナレーション** | 隠さず堂々とやるなら成立する（§6） |
| 14 | **モンタージュ・回想** | 経緯を短く畳む |

**どれを使ったかをカットの `note` に書く。** 書くと、同じ技法の連投に気づける。

### 禁止すべき「説明台詞」の定義（狭くする）

**禁止なのは「登場人物同士が、互いに既に知っていることを、観客のためだけに喋る」こと。**
**観客がまだ知らない情報を言わせること自体は、禁止ではない。**

```
❌ 「私たちは 5 年前に結婚した夫婦だけど、去年から別居しているよね」   ← 互いに既知
✅ 「……判子、まだ押してないから。」                                  ← 同じ情報／言う理由がある
```

## 6. モノローグ・ナレーション

| 規律 | 中身 |
|---|---|
| **置くのは 2 ヶ所まで** | **冒頭（問題提起）と結び（余韻）**。中盤の心情説明には使わない（そこは会話にする） |
| 冒頭のあらすじには**使ってよい** | 短尺では推奨されてさえいる |
| 内面の描写に頼らない | 内面は会話と行動で出す |
| 表記 | `人物名（N）` = ナレーション、`人物名（M）` = モノローグ |

## 7. 無言が成立する条件

[scene-writing.md](scene-writing.md) §11 は「1 シーンに台詞の無いカットを**最低 1 つ**」と
言っている。**「最低 1 つ」であって「多いほど良い」ではない。**

| 成立する | 成立しない |
|---|---|
| **既に立った状況**の結果を見せる（リアクション・余韻） | **まだ立っていない状況**を無言で立てようとする |
| 画の情報量が高い（動き・表情の変化が大きい） | 止め画に近い／表情差が微細（**生成映像はここが弱い**） |
| 音（SE・劇伴）が状況を語っている | 音も無い（＝ミュート視聴と同じ情報量） |
| 1〜2 秒の「間」として置く | **3 秒以上**続く |
| 前後のカットが言葉で挟んでいる | 無言カットが**連続する** |

**無音は 1〜2 秒、最長 3 秒。** 60 秒に意図的な「間」は 3〜5 回。

## 8. 提出前に測る（数えない）

```bash
python3 <SKILL_DIR>/scripts/dialogue_report.py cuts.json      # list_cuts の戻り値を保存したもの
python3 <SKILL_DIR>/scripts/dialogue_report.py -              # 標準入力から
python3 <SKILL_DIR>/scripts/dialogue_report.py cuts.json --json
```

`<SKILL_DIR>` はこの reference を含むスキルのディレクトリ。**`python3` で呼ぶ**
（実行ビットは付かない）。終了コード: 0 = 所見なし / 1 = 所見あり / 2 = 読めなかった。

見るのは次の 7 つで、**全部このスクリプトが数える**:

| # | 検査 | 落ちたときに防いでいる事故 |
|---|---|---|
| 1 | セリフ総字数 ÷ 尺（分）が **150 字/分**以上 | 「場面が読めない」 |
| 2 | 同上が **300 字/分**以下 | 早口で潰れる |
| 3 | **1 発話 30 字以内** | 字幕で読み切れない |
| 4 | **冒頭 20 秒**（30 秒尺なら 10 秒）に発話がある | 冒頭離脱 |
| 5 | **無言カットが 3 秒を超えて連続していない** | 間延び・離脱 |
| 6 | 1 分あたりの発話数が **12 回**以上 | 会話が成立していない |
| 7 | 話者が `character_id` か `speaker_label` を持っている | 誰の台詞か伝わらない |

**機械が測れないので、自分で確かめること**（§2〜§4）:

- 誰・どこ・いつ・望み・障害の 5 つが、**画だけでなく言葉にも**載っているか
- 各人物が**初登場から 2 発話以内に呼称で特定**されているか
- モノローグが**冒頭と結びの 2 ヶ所以内**か
- 台詞が**全部字幕に出る**か（`compositor`）

## 9. 形式ごとの当て方

| 形式 | 当て方 |
|---|---|
| **縦型ショート（`vertical_anime` / `short_drama`）** | §0〜§8 をそのまま。**ここが最も強く効く** |
| 横型アニメ・ドラマ（20 分以上） | 下限（§1）は効く。§0 の「ト書きより台詞」は**弱める**（間と画で持たせる尺がある） |
| **`mv`** | **当てない。** 言葉は歌詞が持つ（`genre-playbook` の references/mv.md） |
| `footage_edit` | **当てない**（台詞は撮影済み素材が持つ） |
