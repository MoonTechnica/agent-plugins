# カットの尺と音

「カットが何を持つか」は SKILL.md 本体（§3）。ここは**何秒にするか**と
**何を鳴らすか**の決め方。**字コンテの 4 列のうち「尺」と「音」の 2 列**にあたる。

## 1. 尺は台詞の文字数から決める（**1 秒 ≒ 5 文字**）

**カットの尺を勘で置かない。** 字コンテの段で原稿を音読して測るのが実務で、
日本語の話速はほぼ確立している。

| 話し方 | 1 分あたり | 1 秒あたり |
|---|---|---|
| ゆっくり・情感を持たせる | 250〜300 字 | 約 4〜5 字 |
| **標準（既定にする）** | **約 300 字** | **約 5 字** |
| 詰め込む（解説・情報もの） | 350〜400 字 | 約 6〜7 字 |

早見: **15 秒 ≒ 75 字 / 30 秒 ≒ 150 字 / 1 分 ≒ 300 字**。

```
台詞のあるカット = ceil( そのカットの台詞の総文字数 ÷ 5 + 0.5〜1 ) 秒
                                                      ↑ 言い終わりの間（必須）
台詞の無いカット = 画の情報量で決める（film-grammar §4 の表）
```

⚠️ **この 5 字/秒は「話せる速さの上限」であって、書く量の目標ではない。**
ここは**カット 1 つの尺**を決める式で、**作品全体にどれだけ台詞を置くか**とは別の話。
全体の量には下限があり、`150 字/分` を割ったら情報不足として書き足す
（[dialogue-and-exposition.md](dialogue-and-exposition.md) §1）。
式だけを守って台詞を減らすと、**尺は埋まっているのに何の場面か分からない**作品になる。

**外すとどうなるか**は 2 方向ある。どちらも生成してから直すと課金し直しになる。

| 症状 | 原因 |
|---|---|
| **早口で潰れる / 台詞が切れる** | 文字数に対して尺が足りない（32 字を 3 秒に置いた） |
| **間延びする** | 尺に対して台詞が短い（7 字に 6 秒）。生成モデルは尺を守るので、余った時間ぶん何かを動かす |

**言い終わりの間を必ず足す。** 台詞の秒数ぴったりで切ると詰まって聞こえる
（撮影済み素材の [other-formats.md](other-formats.md) §1 で
「カット尻に 0.3〜0.5 秒」と言っているのと同じこと）。
間の設計そのものは references/scene-writing.md §11。

## 2. 音は `note` に書く（字コンテの 4 列目）

**BGM の出入りと効果音は、字コンテの段で決める。** ⑦ の音の段まで持ち越すと、
「どこで何が鳴るか」の設計がどこにも残らない。列は無いので `note` の中に書く。

| 書式 | 意味 |
|---|---|
| **`♪M3 in` / `♪M3 out`** | 劇伴の出入り。`M3` は `music_menu.v1` の cue コード（§1） |
| **`SE:<音>`** | 効果音 |

```
note: "ユキ、財布を追って走り出す。 ♪M3 in / SE:下駄が石畳を蹴る"
```

**何を書き、何を書かないか:**

- **書く** … 後から載せるもの（劇伴・強調する効果音）、**画に映っていない音**
  （画面外の声・遠くの太鼓・隣室の物音）
- **書かない** … 画に映っているものが出す音（足音・環境音・台詞）。
  これらは**動画生成の出力として出る**ので、指示すると二重になる（`director` §1.1 ⑦）

作品全体の音の基調（環境音のパレット）は `style_guide.v1` の `sound`（§1）に置き、
カットごとに書き直さない。

## 3. 全体の尺を積算する（**生成予算とは別物**）

**④ の終わりに、カット尺の合計を目標尺と突き合わせる。**
`get_scene_budget` が返すのは**1 シーンの生成予算**であって、作品の上映尺ではない。

```
list_cuts で duration_seconds を合計 → 形式ごとの目標尺と比べる
```

| 形式 | 目標尺 |
|---|---|
| `anime` | **本編 22〜24 分**（30 分枠から OP / ED / 予告を引いたぶん） |
| `vertical_anime` / `short_drama` | 1 話 1〜3 分 |
| 縦型ショート（1 本もの） | 60 秒以下 |
| `mv` | **曲の長さそのもの**（`audio_map.v2` の `duration_sec`） |

超えていたらカットを削る。**削るほど生成費も下がる**ので、迷ったら減らす
（`genre-playbook` §5）。**ただし削る先は前置きで、山ではない**
（references/scene-writing.md §10・§15）。


## 4. 平均カット長を形式の実測と突き合わせる（**生成尺のまま置かない**）

**1 カットずつ「台詞が入る長さ」で置くと、平均が実測の倍に伸びる。** 動画生成モデルの
ネイティブ尺（8〜10 秒）は 1 カットの長さではなく、**1 回の生成で撮れる上限**である
（`ai-video-craft` §1）。そのまま字コンテの尺にすると、どのカットももっともらしいのに
作品全体は現代映画の倍以上遅い。**④ の終わりに、合計尺（§3）と一緒に平均も測る。**

| 形式 | 平均カット長の帯 | 実測の根拠 |
|---|---|---|
| `drama_film` | **2.5〜6 秒** | 1930〜60 年のハリウッドは 8〜11 秒、現代の主流映画は **3〜5 秒**、アクションは約 2 秒（Bordwell）。1935〜2005 年の 150 本の計測で、トーキー初期の最大 10 秒から**現代は平均約 4 秒**（Cutting et al. 2010）。下限はアクションの速さを許すぶん |
| `anime` | **3〜6 秒** | TV アニメ 1 話（本編 22〜24 分）は**約 300 カット**が標準、多い回で 400（→ 平均 3.3〜4.8 秒） |
| `short_drama` | **2〜4.5 秒** | 1 話 1〜3 分で 20〜50 カット（`genre-playbook` の short-drama.md） |
| `vertical_anime` | **2〜3.5 秒** | 1 話 30 秒〜2 分で 15〜40 カット（`genre-playbook` の vertical-anime.md） |
| `mv` | 帯で測らない | 曲の区間が密度を決める（実測は約 2 秒・寄りが最多。`genre-playbook` の mv-dynamics.md §1） |

帯の下限は**生成するカットの最短 2 秒**でも縛られる（それより短い刻みはタイムラインで
既存クリップから切る）。帯は「平均」の話で、**1 本ずつを帯に揃えるのではない** ——
確立ショットは長く、反応は短く、長短を混ぜる（`film-grammar` §4）。

```
python3 <SKILL_DIR>/scripts/cut_pacing.py cuts.json --format anime     # list_cuts の戻り値
python3 <SKILL_DIR>/scripts/cut_pacing.py - --format short_drama --json
```

所見は 4 種類で、どれも**生成する前に**直す（生成後に割ると課金し直し）。

| 所見 | 直し方 |
|---|---|
| 平均が帯より長い | 会話は聞き手の顔へ切り返す / 情報の少ない画を縮める / 1 カットに 2 つの出来事を入れていたら割る |
| 平均が帯より短い・2 秒未満のカット | 隣と束ねる。1 秒のキメは生成せずタイムラインで切る |
| 台詞が尺に入らない（§1 の式） | 尺を足すか、台詞を 2 カットに割る |
| 同じ長さが 4 カット以上続く | 長短を混ぜる（等間隔は「編集していない」に見える） |

**生成費で削るときも帯は守る。** 削るのはカットの数ではなく**シーンの数**（前置き・説明
カット。§3）で、残したシーンを長回しで間延びさせない。アニメの「止め絵 + カメラで長く
持たせる」（`genre-playbook` の anime.md §3）は帯の上限の中で使う。
