# 登場人物（口調と身長）

`create_character` / `list_characters` の手順は SKILL.md 本体（§3.5）。
ここは **`note` に何を書くか**と、**なぜ `height_cm` を最初に入れるか**。

## 1. 口調を `note` に持たせる（**空だと全員が同じ喋り方になる**）

`characters.note` は**話し方・一人称・禁則の置き場**で、
**台詞を書くときと読み上げるときの両方が読む**。ここが空のまま台詞を書くと、
書き手が同じである以上、**全員が同じ言い回しになる**。

**登場人物を作る時点で、この 5 つを `note` に書く。**

| 項目 | 例 |
|---|---|
| **一人称 / 二人称** | 僕・俺・わたし・うち / 君・お前・あんた・名前呼び |
| **語尾・文末** | 「〜だよ」「〜だぜ」「〜っす」。**主要人物どうしで必ず違えておく** |
| **敬語の距離** | 誰に敬語で、誰にタメか。**`relationships.v1` の `address`（呼称）と揃える**（SKILL.md §1） |
| **口癖・言い回し** | 1 つで足りる。多いとうるさい |
| **禁句** | **このキャラが絶対に言わない言い方**。「〜しなきゃ」と言わない / 弱音を吐かない |

**禁句がいちばん効く。** 書き手が便利に使う一般的な言い回しを、名指しで弾けるため。

⚠️ **役割語に逃げない。** 「〜じゃ（老人）」「〜ですわ（お嬢様）」「〜アルヨ」は
**属性の記号であって、その人ではない**。これは
[scene-writing.md](scene-writing.md) §15「『型』ではなく『その人』を書く」と同じ検査で、
**話し方にも当てる**。台詞だけ読んで誰か分かるのが目的であって、
記号を貼ることが目的ではない。

**内面（欲しいもの / 本当に必要なもの / 欠落 / 恐れ）は `character_sheet.v1` に書く**
（`art-director` §3）。`note` は「どう喋るか」、設定文書は「なぜそう振る舞うか」。

**呼称は必ず台詞の中で使わせる** —— 人物は初登場から 2 発話以内に、呼ぶ／名乗る／
肩書きで呼ばれること（[dialogue-and-exposition.md](dialogue-and-exposition.md) §4）。

**書けたかの確認**: `python3 <SKILL_DIR>/scripts/character_lint.py --characters <list_characters> --cuts <list_cuts>
[--relationships <relationships.v1>]`（`height_cm`・口調の 5 項目・初登場からの呼称・短尺の話者数）。

## 2. `height_cm` を入れておく

**書いた時点では使わないが、後で全員分が要る。** 身長比較表（`lineup` シート）は
**全員分が揃っていないとサーバが断る**ので作れず、複数人が並ぶカットでは
**身長が入れ替わる**（生成でいちばん起きる破綻）。**登場人物を作るときに一緒に入れる。**
