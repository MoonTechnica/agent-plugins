# シーンとカットの解像度 — ビートが本体

> **適用範囲: 物語もの**（アニメ / ドラマ / 映画 / 縦型ショートドラマ）。
> **MV は対象外** —— MV は曲の構造が展開を決めるので、手順が根本的に違う（§21）。

**いちばん多い失敗は「あらすじの要約をカットに書いてしまうこと」。**

```
❌ 1: A と B が言い争う
❌ 2: A は自分の過ちに気づく
❌ 3: 二人は和解する
```

**「言い争う」「気づく」「和解する」は出来事ではなく、出来事の要約。**
実際にはその内側に**行動と反応の往復が何回もあり、それがビート**である。
ビートを飛ばすと、見ている側には**なぜそうなったのかが伝わらない。**

**ビートが物語の中身、速度がその効き方、情景はそれを載せる器。** 順番を間違えない ——
まずビートを割り（第 1 部）、速さを整え（第 2 部）、あとから情景を足す（第 3 部）。

---

# 第 1 部 ビート（最重要）

## 1. ビートとは何か

**ビート = 「行動 → 反応」の交換 1 回。** シーンの最小単位。

```
A が湯呑みを机に置く（行動）→ B の手が止まる（反応）     ← ビート 1
B が背を向ける（行動）→ A は動けない（反応）              ← ビート 2
```

**シーンは、ビートが積み重なった結果として転じる。**
ビートが 1 つも無いシーンは、何も起きていないシーン。

## 2. 圧縮語を検出する（最重要の検査）

**次の語がカットやシーンの記述に出てきたら、そこはビートが潰れている。**

| 圧縮語 | 中に隠れているもの |
|---|---|
| **和解する / 打ち解ける / 心を開く** | 拒む → 差し出す → 迷う → 受け取る、の往復 |
| **気づく / 理解する / 悟る** | 見る → 違和感 → 確かめる → 分かる |
| **決意する / 覚悟を決める** | 揺れる → 何かを見る → 手が止まる → 動く |
| **対立する / 言い争う** | 誰が何を要求し、相手が何を返したか |
| **距離が縮まる / 絆が深まる** | 具体的に何を分け合ったか |
| **惹かれ合う** | どちらが先に見たか。目が合ったか、逸らしたか |
| **成長する / 変わる** | 前はできなかった何が、今できたか |
| **葛藤する** | 二つのどちらを取るか、行動で示す |
| **受け入れる / 諦める** | 何を手放したか。物として見せられるか |

**これらは「結果」であって「過程」ではない。** 過程を書くのが仕事。

**検査のしかた**: 書いたカット列を読み返し、上の語（およびその類語）に印を付ける。
**印が付いたカットは、必ず 2 つ以上のビートに割り直す。**

## 3. ビートを飛ばすとどうなるか（実例）

```
❌ 3 カットで済ませる
   1: 言い争う
   2: A が気づく
   3: 二人は和解する
```

これを映像にすると、視聴者には「**急に仲直りした**」としか見えない。
A が何をして B が態度を変えたのかが、画のどこにも無いため。

```
✅ ビートに割る
   1: B「もう来ないで」。A は動かない                    ← 拒絶（行動→無反応）
   2: B が背を向け、食器を洗い始める。水音だけが続く      ← 遮断
   3: A が割れた湯呑みの片割れを棚から出し、机に置く      ← 差し出し
   4: 水音が止まる。B は振り返らない                     ← 届いた（が、まだ）
   5: B の手が蛇口を締める。肩が下がる                   ← 折れる
   6: B が振り返る。目は合わせない。「……座れば」          ← 受け入れ
```

**2〜5 が「和解」の中身。** ここが無いと、6 は成立しない。
**心理は、飛ばしたぶんだけ伝わらなくなる。**

**4 がとくに効いている。** 届いたのに、まだ変わらない —— この 1 ビートを抜くと、
3 の直後に 6 が来て「差し出したら許された」になる（§9）。

## 4. シーンは「変わる」ために存在する

**始まりと終わりで何も変わらないシーンは、無くても成立する。**

シーンとは、ある人物の**大事なものが + から − へ、あるいは − から + へ転じる**
出来事。転じないなら、削るか書き直す。

### 型

```
① 誰かが何かを求めて動く（目的）
② 邪魔が入る（障害）
③ 予想と違う結果になる（← 転換点。ここがシーンの山）
④ 状況が変わる（価値の反転）
```

**③ が「予想と結果のズレ」であることが肝。** 思ったとおりに進むシーンは、
書く必要が無い。

### 検査

**「このシーンの前後で、誰の何がどう変わったか」を 1 行で言えるか。**

```
✅ 「A は B を信じていた → B が嘘をついていたと知る」（信頼 + → −）
❌ 「A と B が話した」（何も変わっていない）
```

言えないなら、そのシーンはまだ書けていない。あと 2 つ、**「なぜ今このシーンか」**（言えないなら
どこに置いても同じ = 構成上の位置に意味が無い）と、人物側の転換とは別の**「観客の感情を
どこからどこへ動かすか」**（不安 → 安堵、など）を 1 行ずつ。カメラ・色・音・尺はこの移動の
道具として選ぶ（`film-grammar` の references/direction-design.md §1）。

## 5. ビートの数と重さ

**全部のビートを描かない。** 描くのは**変化が起きる瞬間**だけ。
移動・準備・挨拶は捨てる（第 3 部 §16）。

| | 目安 |
|---|---|
| 1 シーンのビート数 | **3〜7**。1〜2 なら転換が足りない。10 を超えるならシーンを割る |
| **1 カット** | **1 ビート**が基本 |
| 転換点のビート | **前後を長めに**取る。ここが山（尺の規則は §10） |
| つなぎのビート | 短くてよい |

**すべてのビートを同じ重さで並べない。** 均等に並ぶと、どれが山か分からなくなる
（`film-grammar` §4 の「同じ長さのカットを並べない」と同じこと）。

⚠️ **数を満たしても速さは直らない。** ビートが 7 つあっても 1 つ 2 秒なら早い。
**数は第 1 部、時間は第 2 部（§10）が縛る。** 両方を通すこと。

## 6. シーンを書く手順（この順で書く）

**この順を守るだけで、雑なカットはほぼ出なくなる。**

```
① このシーンで何が転じるかを 1 行で書く      （§4 の検査）
      例: 「B は A を拒んでいた → 受け入れる」

② ビートを箇条書きで列挙する                （行動 → 反応 の往復）
      まだカットにしない。文章にもしない

③ 圧縮語が残っていないか検査する             （§2）
      残っていたら、そのビートを割る

④ 速度を整える                              （第 2 部）
      一度で成功していないか（§8）／変化の直前に揺り戻しがあるか（§9）／
      間を置いたか（§11）

⑤ 各ビートを 1 カットに割り当て、尺を配る    （§5 / §10）
      転換点はつなぎの 2 倍以上

⑥ 各カットに情景を足す                      （第 3 部）
      誰が / どこで / 何をしている / 何が見えている / 光と時間帯 / 寄りとカメラ
```

**②を飛ばして⑤へ行かない。** ビートを列挙せずにカットを書き始めると、
必ず要約になる。**④を飛ばすと、ビートは足りているのに速い**という形で残る。

# 第 2 部 速度（「展開が早すぎる」を直す）

**ビートが足りていても、速いものは速い。** 数を満たしたうえで、
ここの 5 つ（§8〜§12）を通し、**尺に合わせて当て方を変える（§13）**。

## 7. なぜ速くなるのか（機序を知らないと直せない）

**世の中のテキストでは、物語は圧倒的に「あらすじ」の形で存在している** ——
作品紹介、レビュー、宣伝文、感想。実際の脚本本文はごく少ない。だから
「物語を書け」と言われたときの既定の出力形式があらすじになる。
あらすじは定義上、出来事の**間**を飛ばしたもので、それが §2 の圧縮語として表に出る。

そこから先に、**症状の違う 4 つ**が派生する。**それぞれ効く薬が違う。**

| # | 機序 | 症状 | 効く節 |
|---|---|---|---|
| 1 | **納得の所要時間を勘定に入れない**。因果は繋がっているが、観客が受け入れるのに要る出来事の量を数えていない | 「筋は通っているのに納得できない」 | §8 |
| 2 | **感情を状態遷移として書く**。拒絶 → 受容。「まだ変わっていないが変わり始めている」中間が消える | 「急に態度が変わった」 | §9 |
| 3 | **情報量に比例して尺を割る**。説明は情報量が多く、山場は少ない（結果は 1 行） | **説明が長く、見せ場が一瞬**。とくに終盤が速い | §10 |
| 4 | **「何も起きていない行」を冗長と判断して削る** | 息継ぎが無い。詰まって聞こえる | §11 |

さらに、**情報を隠して最後に明かす**書き方（あらすじの発想）をするので、
同じ出来事で場面が保たない（§12）。

> **生成の段でもう一度速くなる。** 動画生成モデルは指定尺の中で何かを起こそうとするので、
> 止めたいカットも動く（`genre-playbook` の references/anime.md §2）。
> **字コンテが正しくても加速する**ので、止めたいカットには止めたいと書く。

## 8. 一度で成功させない（試みと失敗）

**求めたものが 1 回目の試みで手に入ると、話はそこで終わる。**
これが「早すぎる」のいちばん太い原因で、しかもビートを数えても検出できない
（1 回の試みでもビートは 5 個書ける）。

### 回数

**基本は 3 回。** 3 回未満だと「簡単だった」に見え、4 回以上は「くどい」。
**難しく見せたいほど増やし、軽く見せたいほど減らす。**

| 尺 | 試みの回数 |
|---|---|
| 60 秒 | **2**（1 回は「簡単すぎ」に見える） |
| 1〜3 分 | 2〜3 |
| 5〜15 分 | **3** |
| 20 分以上 | 3。幕ごとに別の 3 を持ってよい |

### 結果は「はい、しかし」か「いいえ、そのうえ」

**各回の結末を、この 2 つのどちらかにする。**

| 結末 | 意味 | 例 |
|---|---|---|
| **はい、しかし**（Yes, but） | 手には入った。**しかし代償が出た / 別の問題が開いた** | 財布は返せた。しかし相手は名前を覚えていた |
| **いいえ、そのうえ**（No, and） | 手に入らない。**そのうえ状況が悪くなった** | 追いつけない。そのうえ屋台を倒して騒ぎになる |

**「はい」で終わらせない。** 単なる「はい」は話を終わらせ、単なる「いいえ」は
話を止める（同じ所に戻るだけ）。**先へ進めるのは「しかし」と「そのうえ」の側**。

### 失敗のたびに前提が変わっていること

**同じ壁に 3 回ぶつかるのは繰り返しであって、高まりではない。**
「やり方を変えた。それでも別の理由で駄目だった」が高まり。

```
❌ 繰り返し: 頼む → 断られる / また頼む → 断られる / また頼む → 断られる
✅ 高まり  : 頼む → 断られる（いいえ、そのうえ噂が広まる）
            → 金を出す → 受け取られる（はい、しかし足元を見られる）
            → 盗む → 手に入る（はい、しかし戻れなくなる）
```

**検査**: 各回のあとで「登場人物の置かれた条件が変わったか」を言えるか。
言えないなら、その回は削ってよい（尺の無駄でもある）。

### 終盤で向きが変える

山を越えたら **「はい、そして」「いいえ、しかし」**へ切り替える。
好転し始めた合図になり、観客は決着が近いと分かる。

## 9. 変わる前に、揺り戻す

**気づいただけでは変わらない。** 「真実を告げられて泣いて、その人は変わった」は
変化ではない。**気づきは必要だが、足りない。**

人は必要だと分かっていても変化に抵抗する。**試して、戻って、また試す。**
だからこう書く:

```
拒む → 揺れる → **やはり拒む（揺り戻し）** → 綻び → 受け入れる
```

### 規則

**変化するビートの直前に、「まだ変わっていない」ことを見せるビートを 1 つ置く。**

§3 の実例の 4 —— 「水音が止まる。B は振り返らない」がそれ。
**届いてはいる。でも、まだ動かない。** これを抜くと 3 の直後に 6 が来て、
「差し出したら許された」になる。

### 揺り戻しには代償を伴わせる

戻ったことで**何かを失う**（時間・信用・機会・物）。失うものが無い揺り戻しは
足踏みに見え、今度は「話が進まない」と言われる。

| 揺り戻し | 代償 |
|---|---|
| 差し出された手を取らなかった | 相手が帰ってしまう。次に会うまでが遠くなる |
| 言いかけてやめた | 別の誰かが先に言ってしまう |
| 一度は逃げた | 逃げた場所に、置いてきたものが残る |

**検査**: 変化の直前 1 ビートが「まだ変わっていない」か。
いきなり受け入れていないか。**揺り戻しに代償があるか。**

## 10. 尺は山へ寄せる

**情報量ではなく、体験の長さで尺を割る。** 説明は情報量が多く、山場は少ない
（結果は 1 行）。情報量に比例させると**説明が長く、見せ場が一瞬**になる。

### 規則

**転換点のビートは、つなぎのビートの 2 倍以上の尺を取る。**

| ビートの役割 | 尺の配り方 |
|---|---|
| つなぎ（状況を運ぶ） | 短い。切り詰めてよい |
| **転換点（シーンの山）** | **つなぎの 2 倍以上。** 前にタメ、後にリアクションを足して厚くする |
| 決着のあと | **1 カット残す**（余韻。§11） |

**ビートの数（§5）を満たしても、配分が均等なら速い。**
「全カットが 3〜4 秒」は編集していないのと同じ
（`film-grammar` §4「同じ長さのカットを並べない」）。

**尺の実務**（秒への換算・台詞の文字数・全体尺の積算）は
`screenwriter` §3.1 と [cut-timing.md](cut-timing.md) が正本。

### 短尺ほど、山に寄せる

60 秒で 5 ブロック（`genre-playbook` の beat-sheets.md §5）を等分すると、
山が 12 秒しか無い。**前置きを削って山に回す**（§15）。

## 11. 間（ま）を置く

宮崎駿がロジャー・イーバートに説明した概念（[2002 年のインタビュー](https://www.rogerebert.com/interviews/hayao-miyazaki-interview)）。
手を 3〜4 回叩いて、**「叩いている間の時間が ma だ」**と言った。

> If you just have non-stop action with no breathing space at all, it's just busyness.
> But if you take a moment, then the tension building in the film can grow into
> a wider dimension.
> —— 動きっぱなしで息継ぎが無ければ、それはただの忙しさ。
> でも一拍置けば、映画の中で高まっていく緊張がもっと広がりを持てる。

**間は「何もしていない時間」ではなく、緊張を広げる装置。**
イーバートが「物語を進めない動き（gratuitous motion）が好きだ」と言ったのに対して
返された言葉で、**ため息をつく・流れる水を見る・ただ座っている**といった、
筋に要らない一拍のことを指している。

### なぜ明示的に書かせるか

**台詞の無いカットは、テキストにすると「何も起きていない行」に見える。**
書き手はそれを冗長だと判断して削る。しかし映像では、そこが感情の置き場になる。
**だから規則として置く。**

### 規則

**1 シーンに、台詞の無いカットを最低 1 つ入れる。**

置く場所は 3 つ。

| 場所 | 何を置くか |
|---|---|
| **山の直前（タメ）** | 手が止まる / 息を吸う / 視線が落ちる。次が速く見える |
| **山の直後（余韻）** | **リアクション**。喋った側ではなく**受けている側**の顔 |
| **シーンの出際** | 残された物・去った方向・鳴り続ける音 |

- **台詞の後に 0.5〜1 秒残す。** 言い終わりで切ると詰まって聞こえる
- **リアクションが間の中身になる。** 「間を取る」を「引き伸ばす」と取り違えない ——
  受けている人の顔を見せている時間であって、空白の時間ではない
- 音を先に出す / 後ろに伸ばす（J カット / L カット）と間が生きる（`audio-engineer`）。
  重要な台詞を次のカットの表情の上まで響かせるのは定石

**検査**: そのシーンに、台詞の無いカットが 1 つでもあるか。
無いなら、山の直後にリアクションを 1 つ足す。

### ⚠️ 「最低 1 つ」であって「多いほど良い」ではない

**この節を「無言カットを増やす指示」と読むと、作品ごと無言劇になる**（実際になった。
63 秒で台詞 43 字・19 カット中 14 カットが無言。[dialogue-and-exposition.md](dialogue-and-exposition.md) §0）。

| 上限 | 中身 |
|---|---|
| **無音は 1〜2 秒、最長 3 秒** | 画も音も台詞も変わらない区間を 3 秒より長くしない |
| **無言カットを連続させない** | 前後を言葉で挟む |
| 60 秒に**意図的な間は 3〜5 回** | それ以上は「間」ではなく空白 |

**間が成立するのは、状況が既に言葉で立っているときだけ。**
まだ立っていない状況を無言で立てようとすると、観客は「余韻」ではなく
「置いていかれた」と受け取る（同 §7）。

## 12. 先に教えて、待たせる

ヒッチコックがトリュフォーに説明した、**サプライズとサスペンスの違い**
（『映画術 ヒッチコック / トリュフォー』の「テーブルの下の爆弾」）。

| | 観客が知らない | 観客が先に知っている |
|---|---|---|
| 場面 | 何気ない会話 → 突然の爆発 | テーブルの下に爆弾があると**先に見せる** → 同じ何気ない会話 |
| 得られるもの | **15 秒の驚き** | **15 分の緊張** |

**同じ出来事、同じ長さの会話で、持ち時間が桁で違う。**
結論は「**可能なかぎり観客には知らせる**」—— ただしヒッチコック自身が**例外**を認めている:
**どんでん返しそのものが見せ場のとき**はサプライズを選ぶ（作品に 1 回。連発すると観客が構えて
サスペンスが作れなくなる）。観客も人物も知らず**問いだけ明示する**ミステリーが 3 つ目の選択肢で、
謎解きとホラーの既定。この 3 択はシーンごとに**選ぶ**もので、サスペンスが唯一の正解ではない
（`film-grammar` の references/direction-design.md §4）。

**あらすじの発想は逆を向く** —— 情報を伏せて最後に明かすほうが要約としては面白いので、
放っておくとそう書く。結果、**場面が保たず、次々に出来事を足すしかなくなる**（＝速い）。

### 規則

**観客に先に教えられるものは、教える。**

- 登場人物は知らないが観客は知っている、という状態を作る
- 「これから起きること」を冒頭で見せる（縦型・短尺のフックはこれそのもの）
- 期限・約束・待ち合わせ・持っている物を先に出す

**これは引き伸ばしではない。** 尺を足すのではなく、**同じ長さの場面が保つようになる**。
だから「速い」を直しながら、カット数を増やさずに済む（＝生成費が増えない）。


## 13. 尺で当て方が変わる（**短尺と長尺で逆を向く規律がある**）

**§8〜§12 はどの尺でも効くが、当て方が変わる。**
短尺に長尺の作法を当てると間延びし、長尺に短尺の作法を当てると疲れて見られない。

| 規律 | **60 秒以下** | 1〜3 分 | 5〜15 分 | **20 分以上** |
|---|---|---|---|---|
| §8 試みの回数 | **2**（3 回目が結末） | 2〜3 | 3 | 3。**幕ごとに別の 3** |
| §9 揺り戻し | **1 カット**（表情だけ） | 1〜2 カット | 1 ビート | 1 シーン使ってよい |
| §10 山への寄せ | 倍率は同じ。**絶対値が小さい**（つなぎ 1.5 秒 → 山 3〜4 秒） | 同左 | ビート単位 | **シーン単位**。山の前後にシーンを足す |
| §11 間 | **1 か所だけ**。山の直後 | 1〜2 か所 | 各シーンに 1 つ | 各シーンに 1 つ ＋ **幕の切れ目に長い間** |
| §12 先に教える | **冒頭で見せる。待たせない**（下記） | 10〜15 秒で回収 | シーン内で回収 | **幕をまたいで引っ張れる** |

### 短尺（60 秒〜3 分）で変わること

**作品全体が「1 つの転換」になる。** 長尺は転換の連なりだが、短尺は
§4 の型（目的 → 障害 → 予想と違う結果 → 反転）を**作品全体で 1 回**やる。
だから **1 シーン 1 目的**で、シーンごとに別の目的を持たせない。

| 規律 | 短尺での形 |
|---|---|
| **§12 は「待たせる」を捨てる** | **フックで先に見せ、約束したものはすぐ出す。** 引っ張ると引っ張ったぶんだけ落ちる。教える → 待たせるの「待つ」が 3 秒しかない |
| **§11 の間はカットを伸ばして作らない** | 縦型は**画が 1.5〜2 秒に 1 回変わる**必要があり、3 秒止めると落ちる。短尺の間は**音を止める / 動きを止める**で作る（1 カット・1 秒未満・無音）。カットを長く持つのは長尺のやり方 |
| **§9 は表情 1 カット** | 「迷いは表情 1 カットで済ませる」（`genre-playbook` の beat-sheets.md §5）。悩みの時間は入らない |
| **末尾** | ループ（末尾が冒頭に繋がる）か引き（クリフハンガー）。**余韻で終わらない** |

**冒頭 3 秒の設計・離脱曲線・ループ・セーフゾーンは `vertical-shortform` が正本。**
ここと矛盾する所は**あちらを優先する**（尺が短いほど、視聴維持の制約が物語の作法より強い）。

### 長尺（20 分以上）で変わること

**速度を落として持たせるのではない。落とすと中だるみになる。**
長尺が持つのは、**別の筋を編み込むから**。

| やること | 中身 |
|---|---|
| **副筋（B ストーリー）を通す** | 主筋と対照的な筋（相棒・恋愛・内心）を 1 本。**息継ぎと変化の両方**を担う。§9 の揺り戻しを副筋の側で見せられる |
| **副筋を消さない** | 40 分消えて突然戻る、をしない。**主筋の間に編み込む** |
| **幕をシークエンスに割る** | 第二幕を 10〜15 分の塊に割り、**それぞれに小さな目的と高まり**を持たせる。§8 の試みと失敗が入れ子になる |
| **間を長く持てる** | アニメなら止め絵 + カメラ（`genre-playbook` の anime.md §2）。短尺と違い、**カットを伸ばして**間を作れる |
| **悩みの時間が入る** | 15 ビートの 5。短尺では入らないが、長尺で飛ばすと「軽い」と言われる |

**「第二幕が一瞬で終わる」ときは §8**（試みが 1 回しかない）、
**「第二幕が保たない」ときは副筋**（`genre-playbook` の beat-sheets.md §2）。
症状は逆だが、どちらも第二幕に出る。

### 中尺（5〜15 分）

**短尺の規律を基本にして、間と揺り戻しだけ長尺寄りにする。**
副筋は 1 本まで（2 本入れると 15 分では回収できない）。

### 尺を間違えたときの症状

| 症状 | 何を当て間違えたか |
|---|---|
| 短尺が**間延びする / 冒頭で切られる** | 長尺の §12（引っ張る）と §11（カットを伸ばす）を当てた |
| 短尺が**何も起きないまま終わる** | 全体で 1 つの転換を作っていない（シーンごとに別の目的を置いた） |
| 長尺が**疲れる / 平坦** | 短尺の刻みを通しで当てた。間と余韻が無い |
| 長尺の**中盤が保たない** | 副筋が無い。速度ではなく筋の問題 |

# 第 3 部 情景と描写（ビートを載せる器）

## 14. カメラに撮れることだけ書く

**内面は撮影できない。** 「A は不安だ」と書いても、モデルには何も渡らない。
**不安な人が何をするか**に翻訳する。

| 内面（撮れない） | 外面（撮れる） |
|---|---|
| 不安だ | 爪を噛む / 袖口を引っ張る / 何度も時計を見る |
| 動揺している | 手が震えて湯呑みを取り落とす / 同じ行を読み返す |
| 怒っている | 静かに箸を置く / ドアを閉める音だけ強い |
| 拒んでいる | 鳴っている電話の画面を見て、伏せる |
| 決心した | 脱いだ上着を椅子に掛けず、着たまま出ていく |
| 気まずい | 目を合わせないまま、同じ方向を見ている |

**「〜と思う」「〜と感じる」「〜のようだ」「〜な雰囲気」が出たら書き直しの合図。**
その語は映像に変換できない。

**外面化は、そのままビートになる**（行動として書けているから）。

## 15. 具体名詞と動作動詞を使う

**「型」ではなく「その人」を書く。**

```
❌ 男が店に入る
✅ 前掛けをしたままの魚屋が、暖簾を肩で押して入る
```

**動詞を強くする。** 「調べる」より「引き出しを片端から開ける」。
抽象的な動詞は、モデルにとって「何をすればいいか分からない」と同じ。

**情報を持たない語を書かない** ——「美しい」「悲しい」「雰囲気のある」「印象的な」。

## 16. 遅く入って、早く出る（**削った尺は山へ回す**）

**シーンは「必要な瞬間の直前」から始め、決着した瞬間に切る。**

- 挨拶・入室・座る・お茶を出す —— 捨てる
- 結論が出たあとの雑談 —— 捨てる
- 移動そのもの —— 捨てる（着いた所から始める）

⚠️ **これは「短くする」規則ではなく、「配分を変える」規則である。**
削ったぶんは必ず**転換点（§10）と間（§11）へ回し、シーンの総尺は減らさない**。

この節だけを単体で読むと、**既に飛ばしすぎているものをさらに削る方向に働く**。
前置きが厚いのは人が書いたときの症状で、このスキルを読む書き手の症状は逆（§7）。
**「捨てる」を実行したら、同じ数のカットを山へ足したかを必ず確かめる。**

決着したあとに 1 カット残すのは「雑談」ではなく**余韻**（§11）。これは捨てない。

## 17. 情景は「全部」ではなく「選んだ数点」

**部屋にある物を全部書かない。** 効く数点だけを選ぶ。

| 基準 | 例 |
|---|---|
| **感情を語るもの** | 割れたままの湯呑み / 片方だけの靴 |
| **あとで効くもの** | 冒頭で映した傘が、終盤で置き去りにされる |
| **その場所を特定するもの** | 黒板の日直の名前 / 壁の非常口の緑 |

### 生成では毎回変わるものを必ず決める

| 決めること | 決めないと |
|---|---|
| **時間帯** | カットごとに昼と夜が飛ぶ |
| **光の向き** | 隣のカットと繋がらない（`film-grammar` §7） |
| **天気** | 雨が降ったり止んだりする |
| **場所のどこか**（入口 / 窓際 / 奥） | 同じ部屋に見えない |
| **音**（何が聞こえているか） | 音を作る段で手掛かりが無い |

### 繰り返す物を 1 つ決める

**作品を通して出てくる物を 1 つ置くと、断片的なカットが 1 本に繋がる。**
最後に**それがどうなったか**を見せると、説明せずに話が終わったと分かる。
出すのは初出・中間・終盤の 3 回が目安で、**終盤は意味が変わっていること**（割れた湯呑み → 継いだ
湯呑み。同じ意味のまま戻すのは水増し）。映すのは**人物の動作のついでに**、寄るのは回収の 1 回だけ。
「これは象徴だ」と見えた瞬間に効果が消える（`film-grammar` の references/direction-design.md §3・§7）。

「あとで効くもの」を先に見せておくのは §12（先に教えて、待たせる）と同じ働きをする。

## 18. 台詞は思っていることをそのまま言わない

**本音をそのまま喋る台詞は、聞いた瞬間に終わる。**
**言えないことがある**ほど、その場面は持つ。

```
❌ 「私はあなたに捨てられて傷ついた。だから許せない」
✅ 「……傘、まだ返してもらってない」
```

**説明台詞の検出**: 登場人物同士が**既に知っていること**を喋っていたら、
それは視聴者向けの説明であって台詞ではない。

### ⚠️ 禁じているのは「互いに既知のことを喋る」ことだけ

**観客がまだ知らない情報を言わせること自体は、禁止ではない。**
ここを広く取ると、**誰が・どこで・何を争っているかまで伏せてしまう**
（実際に起きた。[dialogue-and-exposition.md](dialogue-and-exposition.md) §2）。

```
❌ 「私たちは 5 年前に結婚した夫婦だけど、去年から別居しているよね」  ← 互いに既知
✅ 「……判子、まだ押してないから。」                                ← 同じ情報／言う理由がある
```

**短尺・縦型では「状況は画でやる」を当てにしない。** ながら見・ミュート視聴では
画にしか無い情報は届かず、生成映像は微細な表情差も出にくい。
**場所・関係・時間・目的の 4 つは、画に加えて必ず言葉にも載せる**
（同 §0 / §4。渡し方の技法は同 §5）。

**言えないことを持たせるのは、速度にも効く。** 本音を言った瞬間に場面は決着するので、
言わせないぶんだけシーンが保つ（§12 と同じ理屈）。

## 19. カットに何を書くか（実務）

カットの記述が**そのまま絵コンテと動画生成の材料**になる
（`storyboard` / `cinematographer`）ので、**各カットが自足していること**が要る
（前のカットを読まないと分からない書き方をしない）。

**1 カットに必ず入れる 6 つ:**

| # | 何 | 受け皿 | 例 |
|---|---|---|---|
| 1 | **誰が** | `note` | 「A（三つ編み・紺のセーラー服）」 |
| 2 | **どこで** | **`location`** | 「放課後の教室、窓際の最後列」 |
| 3 | **何をしている**（動作 1 つ＝ビート） | `note` | 「机の上の手紙を裏返す」 |
| 4 | **何が見えている**（選んだ数点） | `note` | 「開いた窓、揺れるカーテン、伏せられた花瓶」 |
| 5 | **光と時間帯** | **`time_of_day`** + `note` | 「夕方、光は窓（画面左）から」 |
| 6 | **寄りとカメラ** | **`shot`** | `medium close-up, slow push in` |

**6 を空にしない。** `shot` は**そのまま動画生成の本文に載る**ので、空だと
モデルが毎カット勝手に画角を決める（＝全カットが似た寄りになる / 構図が繋がらない）。
語彙と英語表記は `film-grammar` の references/shot-vocabulary.md、
何を選ぶかは `film-grammar` §1。

### 7 つ目: **芝居**（3 の「動作 1 つ」を、要約で終わらせない）

**「A が食べる」は出来事の要約であって、芝居ではない。** 動詞 1 個で止めたト書きは
未完成で、**箸を使わず手で食べる映像**が返ってくる（実際に起きた）。最低でも
**小道具（何を、どちらの手で、どう持つか）／予備動作／主動作**の 3 つを書く。

**日本的な所作は書かなければ西洋の既定値が出る**（「食べる」→ フォーク、
「家に入る」→ 土足、「挨拶」→ 握手）。**予備動作と余韻がとくに落ちる** ——
手を合わせずに食べ始め、立ったまま襖を開け、言いながら頭を下げる。

6 分割の型・7 つのルール・速度と力みの語彙・**日本の所作チートシート 54 行**・
negative 語彙は **[acting-and-gestures.md](acting-and-gestures.md)**。

> **ト書きを厚く書くことは §18 と矛盾しない。** 台詞は観客が聞くもの、
> **ト書きはモデルしか読まない**。厚く書いても生成費用は変わらず、
> 所作が違う映像を撮り直すとカット 1 本ぶんかかる。

**動きの指示（`gen_prompt`）／画への指示（ト書き = `note`）／
声への指示（`delivery`）／カメラ（`shot`）は別のもの。** 混ぜない。

## 20. 書き直しの検査（提出前に必ず）

**上から順に通す。** 1〜4 はビート、5〜11 は速度、12〜19 は情景。

| # | 症状 | 直し方 |
|---|---|---|
| 1 | **圧縮語がある**（和解する・気づく・決意する…） | **ビートに割る**（§2・§3） |
| 2 | **シーンの前後で何も変わっていない** | 転換を作るか削る（§4） |
| 3 | **ビートが 1〜2 個しかない** | 往復を足す（§5） |
| 4 | ビートを列挙せずにカットを書いた | §6 の手順でやり直す |
| 5 | **求めたものが 1 回目の試みで手に入っている** | 試みを 3 回にし、各回を「はい、しかし」「いいえ、そのうえ」で閉じる（§8） |
| 6 | **失敗のたびに条件が変わっていない**（同じ壁の繰り返し） | やり方を変えさせる（§8） |
| 7 | **変化の直前に「まだ変わっていない」ビートが無い** | 揺り戻しを 1 つ置き、代償を伴わせる（§9） |
| 8 | **転換点が、つなぎと同じかそれより短い** | 山へ寄せる（§10）。前にタメ、後にリアクション |
| 9 | **台詞の無いカットが 1 つも無い** | 山の直後にリアクションを足す（§11） |
| 10 | **観客が知らないまま何気ない会話をしている** | 先に教える（§12） |
| 11 | **尺に合わない当て方をしている**（短尺で引っ張る / 長尺で刻み続ける） | §13 の早見表で当て直す |
| 12 | 「〜と思う」「〜な雰囲気」がある | 外面化する（§14） |
| 13 | 「男」「女」「人物」で書いている | その人にする（§15） |
| 14 | 挨拶や移動から始まっている | 遅く入る（§16）。**削ったぶんを山へ回したか** |
| 15 | 場所が「教室」だけ | 選んだ数点を足す（§17） |
| 16 | 時間帯・光が書いていない | 決める（§17） |
| 17 | 台詞が本音をそのまま言っている | サブテキストにする（§18） |
| 18 | 前のカットを読まないと分からない | 自足させる（§19） |
| 18b | **ト書きが動詞 1 個で止まっている**（「食べる」「話す」「怒る」） | 小道具・予備動作・主動作に割る（[acting-and-gestures.md](acting-and-gestures.md) §1） |
| 18c | **日本的な所作が書かれていない**（箸・靴・襖・お辞儀） | 明示する。書かないと西洋の既定値が出る（同 §6） |
| 19 | **`shot` が空のカットがある** | 寄りとカメラを入れる（§19 / `film-grammar` §1） |
| 20 | 全カットが同じ長さ・同じ寄り | 緩急を付ける（§10 / `film-grammar` §4） |
| 21 | **台詞の文字数が尺に入らない** | 尺を直すか台詞を削る（[cut-timing.md](cut-timing.md) の 1 秒 ≒ 5 字） |
| 22 | **台詞が 150 字/分 に満たない** | 書き足す。「静かな演出」ではなく情報不足（[dialogue-and-exposition.md](dialogue-and-exposition.md) §1） |
| 23 | **無言カットが 3 秒を超えて続く** | 前後を言葉で挟む（§11 / 同 §7） |
| 24 | **冒頭 20 秒で誰・どこ・望み・障害が立っていない** | 呼称と状況を言わせる（同 §3・§4） |
| 25 | **人物が一度も名前・呼称で呼ばれない** | 初登場から 2 発話以内に呼ばせる（同 §4） |

22〜25 は `python3 <SKILL_DIR>/scripts/dialogue_report.py` が数える（25 は `scripts/character_lint.py` が
名前と `relationships.v1` の呼称で見る）。9・19・20 は `scripts/shot_lint.py` / `scripts/cut_pacing.py`、
18b・18c は `scripts/gesture_lint.py`（食べるのに道具が無い・本文の negative 語・セル撮影の手段名）。

## 21. MV には、この手順を当てない

**MV は曲が展開を決める形式**なので、第 1 部の手順（シーンの転換を決めて
ビートへ割る）を持ち込むと噛み合わない。

| | 物語もの | MV |
|---|---|---|
| **展開を決めるもの** | 物語のビート（行動と反応） | **曲の構造**（区間・拍） |
| 起点 | 「このシーンで何が転じるか」 | **「曲の地図」**（区間と秒数） |
| カットを割る基準 | ビートが変わるとき | **拍の頭・区間の切り替わり** |
| 物語の扱い | 骨格そのもの | **区間に配る**（無くてもよい） |
| 完結性 | 各シーンが転じる必要がある | **断片でよい**。曖昧なまま終わってよい |

**MV で物語をやる場合も、物語が音楽に従属する。**
「物語のビートで曲を切る」のではなく、**「区間に物語を配る」**。
逆にすると、曲の構造を無視した映像になる。

**MV の手順は `genre-playbook` の references/mv.md が正本。**

ただし**第 2 部の一部と第 3 部は MV でも効く**:

| 節 | MV での効き方 |
|---|---|
| §11 間 | **効く。** 音が詰まっている区間ほど、画の側に一拍が要る |
| §14 外面化 / §15 具体名詞 / §17 選んだ数点 / §19 カットの 6 項目 | **効く**（形式を問わない） |
| §8 試みと失敗 / §9 揺り戻し / §10 尺を山へ | **当てない**（曲の区間が決める） |
| §13 尺で変わること | **縦型 MV でだけ効く**（冒頭 3 秒と画の切り替わりの制約は形式を問わない） |
| §12 先に教えて待たせる | 物語を入れる MV でだけ効く |

**撮影済み素材（`footage_edit`）と説明もの（`explainer`）にも第 1 部・第 2 部を当てない**
（`screenwriter` §2.5）。
区間の選び方は [other-formats.md](other-formats.md) が正本で、
**カット尻の余白 0.3〜0.5 秒は §11 と同じ考え方**。
