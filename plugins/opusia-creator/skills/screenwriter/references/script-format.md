# 脚本の書き方（ハコ書きと書式）

「どこに置くか」は SKILL.md 本体（§1）。ここは**本文をどう書くか** ——
**先に箱を並べ（§1）、それから柱・ト書き・セリフで書く（§2 以降）**。

## 1. ハコ書き

**脚本を一発書きしない。** シナリオの工程は **企画 → プロット → ハコ書き → 初稿 → 決定稿**で、
**箱書きが構成の土台**（全工程の 2/3 を箱書きに使う脚本家もいる）。ここを飛ばすと、
書いたあとに型（`genre-playbook` §1）を当てて「中間点が無い」と分かり、**全文の書き直し**になる。

### 箱は 3 段

| 段 | 単位 | 中身 |
|---|---|---|
| **大バコ** | 幕・章 | 全体の起承転結（または三幕） |
| **中バコ** | シークエンス | 大バコの各段をさらに割る。長尺は 10〜15 分の塊 |
| **小バコ** | **シーン** | ここが `plan_scenes` のシーンになる |

**短尺は小バコだけでよい**（60 秒に幕は要らない）。**20 分以上は 3 段とも作る。**

### 1 つの箱に書くもの

```
S3 夜市・路地（夜） / ユキ・屋台の主人 / 約 25 秒
    ユキは財布を返せない → 主人に押し返される（拒絶 −）
```

**場所 / 時間帯 / 出る人 / 何が転じるか（1 行）/ 概算尺**の 5 つ。
**転じることを書けない箱は、まだシーンになっていない**（[scene-writing.md](scene-writing.md) §4）。
本文はまだ書かない —— 箱を並べ終えてから ③ の本文に入る。

### 箱書きが効く理由

- **箱＝シーンの切れ目**（1.場所 2.時間帯）なので、**④ の字コンテがほぼ機械的に起こせる**
- **尺の見積もりが本文の前に出る**（概算尺の合計 → SKILL.md §3.1 の目標尺と突き合わせ。
  **短尺ほど効く** —— 60 秒に箱を 8 つ置いた時点で入らないと分かる）
- **直すのが安い。** 全文ではなく箱を入れ替える
- **構成の型を、本文を書く前に当てられる**（`genre-playbook` §1。書いたあとに
  「中間点が無い」と分かるより桁違いに安い）

置き場所は `series_bible.v1`（`name`「箱書き」）に **`composition_id` を渡して**
そのタイムライン専用にする（SKILL.md §1.1）。

## 2. 書式

アニメのシナリオは **柱（場所・時間）/ ト書き（動き・状況）/ セリフ（誰が何を）**
の 3 要素でできている。**この 3 つは、字コンテの受け皿とそのまま 1 対 1 で対応する**:

| シナリオ | `plan_scenes` の受け皿 |
|---|---|
| 柱 | `location` / `time_of_day` |
| ト書き | `note` |
| セリフ | `lines[{text, speaker_label, delivery}]` |

だから**この書式で書く**。散文で書くと、字コンテを書くたびに自分で抽出し直す
ことになり、**抽出のたびに話者名や場所の呼び名が揺れる**。

```
.夜市・屋台前（夜）

ネオンの下、ユキが立ち止まる。足元に財布。

@ユキ
（小さく）……これ、僕のじゃない。

.同・路地（夜）

ユキ、財布を追って走り出す。
```

| 書き方 | 意味 |
|---|---|
| **`.場所（時間）`** | 柱。先頭のドットで強制する（[Fountain](https://fountain.io/syntax/) の記法）。時間帯は任意 |
| **`@名前`** の次の行 | セリフ。`@` は**非ローマ字言語のために仕様にある**ので日本語名をそのまま書く |
| **`（小さく）`** で始まる台詞 | 括弧の中は**言い方**。台詞本文には混ぜない —— 混ぜると声優にそのまま渡る |
| それ以外の行 | ト書き |

`○ 場所（時間）` と `名前「台詞」` の伝統的な書き方でも読める。

**そのまま書く。コードブロックで囲まない。** 画面は本文を Markdown として描くが、
**改行はそのまま改行として出る**ので、柱・ト書き・セリフの行はこの形で保たれる。
囲むと等幅の枠に入って脚本に見えなくなるうえ、`read_script` の読み取りにも
余計な行が混じる。

**この書式は推奨であって必須ではない。** 構想段階でラフに書くのは構わない ——
`read_script` の `counts` が 0 なら書式に乗っていないと分かるだけで、
本文は落ちない。**清書するときに整える**。

## 3. `read_script` で読み直す

字コンテを書く前に **`read_script(composition_id)`** を呼ぶ。タイムラインが名指しした
脚本（`compositions.script_asset_id`）を柱・ト書き・セリフに分けて返し、**話者は登録済みの
登場人物へサーバが解決する**（`character_id`）。自分で id を書かない —— 間違えると
黙って別人の台詞になる。

## 4. 脚本は尺を決めない

秒数・カット割りは書かない。**どこで切るか・何秒にするかは字コンテの判断**で、
脚本に書くと二重管理になる（そして必ず片方が古くなる）。
