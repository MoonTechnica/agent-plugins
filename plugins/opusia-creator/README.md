# Opusia

Make short films, animation and music videos with the coding agent you already use (Claude Code, Codex): script,
design sheets, storyboards, video, audio and the final render, through your Opusia account.

> This plugin directory is generated by CI from the main repository. **Do not edit it directly** — your changes
> will be overwritten by the next generation.

## Claude Code

```text
/plugin marketplace add MoonTechnica/agent-plugins
/plugin install opusia-creator@moon-technica
```

Then run `/mcp`, select `plugin:opusia-creator:opusia`, and approve the login in your browser. You only need
to do this once. Turn on auto-update for the marketplace under `/plugin` → Marketplaces to receive new versions.

## Codex

```sh
codex plugin marketplace add MoonTechnica/agent-plugins
codex plugin add opusia-creator@moon-technica
codex mcp login opusia
```

Then start a new Codex session. (You can also install from `/plugins` inside Codex.)

## Use it

Ask for what you want ("make a 30-second teaser from this script"). The agent starts an Opusia conversation, follows
the instructions you gave the project, and the work appears in Opusia. You can see and remove what you allowed under
**Account settings → Connected apps** at https://opusia.app.

## Credits and your own machine

Server-side generation spends your Opusia credits. In Codex the agent draws images with Codex's own image generation
instead. If you want images drawn in your local ComfyUI, tell the agent once ("draw images in my local ComfyUI, never
with credits"); Opusia remembers it for the project and every agent follows it. ComfyUI is not bundled: register the
`comfy-mcp` server in your CLI yourself (Claude Code: `claude mcp add`; Codex: `[mcp_servers]` in `config.toml`).

## 日本語

Claude Code / Codex から Opusia を使って、短編・アニメ・MV を作れます。上の手順でインストールし、
`/mcp`（Claude Code）または `codex mcp login opusia`（Codex）でログインしてください。
画像を手元の ComfyUI で作りたいときは、エージェントに一度そう伝えるだけで、プロジェクトに記録されます。
接続したアプリは、アカウント設定の「接続済みのアプリ」から取り消せます。
